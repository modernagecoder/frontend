Spot it in your own code

A loop inside
a loop. That is it.

for a in students:
  for b in students:  # the expensive line
    if a.name == b.name:
      print("duplicate")
This looks harmless. With 100 students it runs 10,000 times. With 10,000 students it runs 100 million times.
whenever you indent a loop inside a loop, pause and ask how big the list gets.
