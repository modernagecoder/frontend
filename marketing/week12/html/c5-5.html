The catch nobody mentions

The key has to
hold still.

If a key could change after you filed it, the calculated address would point at the wrong shelf. So a key must be something unchangeable.
BREAKSd[[1, 2]] = "x"  # a list can change. not allowed
WORKSd["Meera"] = "x"  d[(1, 2)] = "x"  d[7] = "x"
"unhashable type: list" now makes complete sense. it changes, so it cannot be an address.
