# AI Without the Hype Carousel

## Concept

**AI SAID IT. WOULD YOU TRUST IT?**

A five-slide Modern Age Coders carousel that teaches learners to question, verify, test, and improve AI output before using it in a real build.

The carousel applies the content strategy in `marketing/INSTAGRAM-CONTENT-STRATEGY-AND-CREATIVE-SYSTEM.md`:

- A provocative cover for discovery.
- A simple visual model for understanding.
- A memorable misconception correction.
- An interactive learner framework.
- A human, project-focused conversion slide.

## Slide order

1. `01-ai-said-it.png`
   - Hook: AI said it. Would you trust it?
   - Visual: A teen builder inspects a polished answer with an unknown source.

2. `02-what-ai-is-doing.png`
   - Lesson: Data to patterns to prediction.
   - Takeaway: AI predicts. It does not verify.

3. `03-confident-not-correct.png`
   - Lesson: Confident language is not proof.
   - Action: Check the source.

4. `04-builders-three-check.png`
   - Framework: Source, test, compare.
   - Interaction: Which check would you run first?

5. `05-test-then-build.png`
   - Brand takeaway: Do not just use AI. Test it. Then build.
   - CTA: Book a free demo.

## Final prompt direction

The carousel was produced with the built-in image-generation workflow using the existing Modern Age Coders logo, teen-girl character, and AI/ML campaign artwork as references.

Shared prompt direction:

> Create an exact 4:5 Modern Age Coders Instagram carousel in a warm engineering-notebook world. Use cream grid paper, an ink frame, deep pine torn-paper inspection lab, coral editorial headlines, amber details, dimensional paper cards, hard shadows, and the recurring teen girl as an active builder. Explain responsible AI use through clear visual cause and effect. Preserve the real logo. Avoid generic neon AI imagery, glassmorphism, glowing brains, stock photography, clutter, and tiny text.
