Ans. The short version

The class 10 AI practical exam is worth 15 of the 50 Part C marks in CBSE 417 and is conducted by the school before the theory paper. Tasks come from four practical units: Statistical Data, Computer Vision, Natural Language Processing and Advance Python. Expect an unseen task close to your file programs: NumPy statistics, a Pandas CSV task, a labelled chart, an image or a text task, in Python or Orange. Examiners check that it runs, gives the right output and that you can explain it. Modern Age Coders practises these tasks live in a Monday and Wednesday 9:00 PM IST batch, or one to one.

How long is the AI practical exam?

The 417 curriculum does not print a duration for the task, so your school sets the slot, often alongside the file check and the viva. We train for a one-hour task window, which leaves room if the school is stricter.

Our time plan for a one-hour task

  1. 5 minutes: read the task twice and underline every output it asks for.
  2. 5 minutes: write the steps as comments in the first cell.
  3. 30 minutes: code one step per cell, running each as you go.
  4. 10 minutes: run again with a second input and check by hand.
  5. 10 minutes: add labels and comments, save, and prepare to explain.

Q2. Advance Python and Statistical Data

417 practical questions with Python, NumPy, Pandas and Matplotlib, solved

Four exam-style tasks, each written for this page and run in Python with the output pasted exactly. Read the task, try it, then compare.

Task 1 (Unit 7). Store seven marks in a NumPy array. Print the mean, median and mode, then the marks above the mean and how many there are.

Task 2 (Unit 7). Read the names and scores out of 50 of three students. Print each percentage with a grade, then the class average.

Task 3 (Unit 4). rainfall.csv has the columns month, rain_mm and rainy_days for June to November. Show its size and first three rows, the average rainfall, and the months above 100 mm.

Task 4 (Unit 4). Draw a bar chart of the same rainfall with a title, axis labels and a dashed line at the average. Save it as an image.

The Orange version of Tasks 3 and 4: File, then Data Table to view rows, Feature Statistics for the mean, Select Rows for the filter, and Bar Plot or Distributions for the chart. CBSE's eight suggested programs, and the twists they come back with, are on Python for CBSE Class 10 AI.

Q4. What does the examiner check?

What examiners check in the class 10 AI practical exam

CBSE does not publish a mark-by-mark rubric for the 417 practical task. From what examiners look for when they watch, this is the checklist our mock tasks are marked against; treat it as ours, not CBSE's.

The examiner checksHow it shows on screenHow marks slip
It runsEvery cell executes top to bottom without an errorA cell that only works because an older cell was run first
The output is rightNumbers that can be checked by hand, every requested item printedPrinting the mean but forgetting the count the task also asked for
The output is readableLabels in print statements, chart title and axis namesA bare list of numbers nobody can match to the question
It is your ownVariable names you can explain, comments in your wordsFreezing when asked to change one value
It handles a changeThe examiner swaps an input and it still worksValues typed into the output instead of computed
You can explain itA clear sentence for what each block does"I saw it in a video"

Restart and run all

Before you call the examiner, restart the kernel and run every cell. It catches the hidden dependence on a deleted cell.

Keep error messages calm

Read the last line of the error first: it names the problem, often a misspelt column name or a missing import.

Say what you would add

If time runs out, explain the missing step aloud. A clear plan for the last line is worth more than silence.

The oral that follows the task is a separate 5 marks; its questions are on class 10 AI viva questions.

Questions about the Class 10 AI practical exam

What students and parents ask about the class 10 AI practical exam

What questions come in the class 10 AI practical exam?

An unseen task from the four practical units of CBSE 417: a Python program with input and conditions, NumPy statistics such as mean and median, a Pandas task on a CSV file, a labelled Matplotlib chart, an image shape or grayscale task, or a text task such as tokenising and counting words. Some schools set the task in Orange instead of Python.

How many marks is the class 10 AI practical exam?

The practical examination is 15 marks. It sits inside Part C, which carries 50 marks: practical file 15, practical exam 15, viva 5, project 10 and project viva 5. The theory paper carries the other 50 marks of the subject.

Which units come in the AI practical exam 2027?

Four units: Unit 4 Statistical Data, Unit 5 Computer Vision, Unit 6 Natural Language Processing and Unit 7 Advance Python, as in the 2026-27 curriculum. Units 4 and 7 are examined only in the practical, never in the theory paper, so they deserve real practice.

Is numpy and matplotlib asked in the class 10 AI practical?

Yes, they are the core of the Python tasks. Expect NumPy for arrays and statistics, Pandas to read and filter a CSV file and Matplotlib for line, bar or scatter charts with a title and axis labels. NumPy has no mode function, so use the statistics module for the mode.

Is the practical exam the same as the practical file programs?

Not exactly. The task is usually close to a file program but changed: a different dataset, an extra condition, a second chart or a new sentence. A student who understands each line adapts in minutes, while one who memorised the file often gets stuck.

Can I use Orange in the class 10 AI practical exam?

Many schools allow it, because Orange is part of the 417 curriculum for data, image and text tasks. Whether your task is in Python or Orange depends on the school and the examiner, so ask your teacher and practise both, especially the image and text workflows.

How long is the class 10 AI practical exam?

The 417 curriculum does not fix a duration for the practical task, so each school sets its own slot, usually with the file check and the viva on the same day. We train students to finish a task in about an hour, with time left to test and explain it.

When is the CBSE class 10 AI practical exam held?

It is conducted by the school before the theory board paper, on dates the school announces. Ask your school for the exact date, and aim to finish the practical file early so the last weeks go into timed practice rather than writing.

What if my code shows an error in the practical exam?

Read the last line of the error first, because it names the problem, then fix that one line. Common causes are a misspelt column name, a missing import or a bracket left open. If you cannot fix it in time, explain the step you intended: examiners credit a clear plan.
