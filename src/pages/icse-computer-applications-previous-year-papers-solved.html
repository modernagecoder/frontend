Ans. The short version

An ICSE Computer Applications previous year question paper is most useful when it is solved by pattern. In the 2023, 2024, 2025 and 2026 board papers, Section B (any four of six programs, 15 marks each) always had a class with a calculation, a method overloading question with a nested-loop pattern and a String program; a digit-based number check, a 2D array task and a sorting or searching task came in most years. Section A is 40 compulsory marks. Q2. Which kinds of program keep coming back?

Which program families repeat in ICSE computer board papers?

Three families were in all four papers: a class with a calculation, method overloading and a String program. Three more appeared in three of the four. Because a candidate picks four of six, a student strong in the steady families always has four questions to choose from.

What the count tells a 2027 candidate

  • Question 3 is a gift. A class with three or four methods and a calculation came first every year. Practise it until it takes fifteen minutes.
  • Overloading carries a pattern. Every overloading question hid a nested-loop pattern inside it, so pattern practice pays twice.
  • 2D arrays have arrived. They were absent in 2023 and present in each of the next three papers, always as a short scan of rows and columns.
  • Sorting and searching rotate. One of them came every year, so learn bubble sort, selection sort, linear search and binary search, not just one.

Section A changed shape too

Question 1 is still twenty one-mark MCQs and Question 2 ten two-mark parts. What changed from 2024 is the style. Solved copies of the papers show one assertion and reason item in 2024 and two each in 2025 and 2026, and every one of those three papers had at least one item built on a real-life picture or scenario, such as an everyday repeat that stands for a nested loop.

Those newer items are worked on ICSE Computer Applications competency based questions, and an original bank of twenty-mark Question 1 practice is on ICSE Computer Applications MCQ questions.

A count of four papers shows habits, not a promise; any family in the 2027 syllabus can be set. That is why the hub of every program family, ICSE Class 10 Java programs practice, covers the families that did not appear as well.

Q3. Where are the solutions in the same shapes?

ICSE computer applications question paper with answers: three original programs for the steady families

These are new questions written in the same shapes as the board's, not copies. Try each one in BlueJ before reading the answer.

Practice 1: class and object with a slab calculation (the Question 3 shape)

Define a class CabRide with members name, km, ac (Y or N) and fare. The fare is 18 per km for the first 4 km, 15 per km for the next 6 km and 12 per km beyond 10 km; an AC ride adds 10 percent. Write accept(), calculate(), display() and a main that uses an object.

Practice 2: method overloading with a pattern inside

Overload compute: void compute(int n) prints n rows, row i counting down from n to i; double compute(double r, double h) returns the volume of a cylinder; boolean compute(String s, char ch) returns true when ch occurs more than once in s.

Practice 3: a digit-based number check

A Twin-end number (our own definition) has the same first and last digit, and a digit sum divisible by 3. 2742 qualifies: it starts and ends with 2 and its digits add to 15. Accept a number and say whether it is one.

Dozens more digit checks, each with its loop rule, are on special number programs in Java.

ICSE computer board paper solutions in the same shapes: String, 2D array and binary search

One original question for each family that came in three of the last four papers.

Practice 4: a String program that rebuilds words

Accept a sentence. Print it with the first and last letters of every word swapped, and count the words that begin with a vowel.

Practice 5: a double dimensional array check

Accept a 3 by 3 integer matrix. Say whether it is symmetric (each a[i][j] equals a[j][i]) and print the sum of its boundary elements.

Store six city names, arrange them alphabetically by bubble sort, print them, then search for a city typed by the user with binary search, ignoring case.

Q5. How should past papers be used?

How to solve ICSE Computer Applications previous year papers so they raise your marks

Solve each past paper twice: once by family, early, to learn the shapes, and once whole, timed, near the exam. Reading a solution is not solving a paper.

  1. Group the questions by family first

    Take all four Question 3s together, then all four overloading questions, and so on. Seeing the same shape four times in a row shows what is fixed and what changes from year to year.

  2. Write, then run, every Section B answer

    Write the program on paper as the exam demands, then type it into BlueJ exactly as written. The compiler finds the missing semicolon and the wrong method name that your eye skipped.

  3. Test with more than the example

    The example in a question is the easy case. Try a one-digit number, an empty space, the first and last elements of an array, and a value that is not there. The 2025 binary search only proves itself when a missing character is searched.

  4. Mark against points, not a feeling

    For each program, check the parts an examiner looks for: the class and method headers asked for, input taken the way the question says, correct logic, the output in the format shown, and the meaningful variable names or short variable description the Section B instructions ask for so the logic is clear. Flowcharts and algorithms are not required.

  5. Then sit whole papers, timed

    From January, sit one complete past paper at a time in two hours, choosing your four Section B questions in the first minutes and sticking to the choice.

Questions about previous year papers

What students ask about ICSE Computer Applications previous year papers

Where can I find ICSE Computer Applications previous year question papers with solutions?

Past board papers are printed in the solved-paper books most ICSE schools recommend, and CISCE publishes specimen papers on cisce.org. This page does not reprint any paper. It describes what Section B asked in 2023, 2024, 2025 and 2026, tags each question by program family and gives original practice programs in the same shapes, with full solutions that were compiled and run.

What was asked in the ICSE Computer Applications 2025 paper Section B?

In our own words: a cloud storage class billed in three slabs, the square root of the sum of squares of a 4 by 4 matrix, a String with equal capital and small letters, a binary search of a sorted character array, an overloaded method with a symbol pattern, a half-step series and a character comparison, and the parity of the sum of a number's largest and smallest digits.

How many questions are there in Section B of ICSE Computer Applications?

Six, numbered Questions 3 to 8. A candidate answers any four, each worth 15 marks, for 60 marks. Section A, Questions 1 and 2, is 40 compulsory marks: twenty one-mark MCQs and ten two-mark parts. The whole paper is 100 marks in two hours, with reading time before writing starts.

Which programs come every year in the ICSE Computer Applications board exam?

In the 2023 to 2026 papers, three families came every year: a class with a calculation as Question 3, a method overloading question containing a nested-loop pattern, and a String program. A digit-based number check, a 2D array task and a searching task each came in three of the four years. Sorting came twice.

Are 2D array questions asked in ICSE Computer Applications?

Yes. Double dimensional arrays are in the 2027 syllabus and a 2D array program appeared in Section B in 2024, 2025 and 2026: comparing diagonal sums, finding the square root of the sum of squares, and counting zeros to test a sparse matrix. Each was a short scan of rows and columns with nested loops.

How many previous year papers should I solve for ICSE Computer Applications?

At least the last four board papers and the current specimen paper, each solved twice: first question by question grouped by family, then as a whole timed paper. Older papers are useful for extra Section B practice, but their Section A layout differs, so use them for programs rather than for timing.

Do ICSE Computer Applications questions repeat from previous years?

The exact questions rarely repeat, but the shapes do. Every recent paper opened Section B with a class that calculates a bill or a result, and every one had an overloading question with a pattern. Practising new questions in each repeating shape prepares you better than memorising old answers.

Are assertion and reason questions in the ICSE Computer Applications paper?

Yes, inside Question 1. Solved copies of the papers show one assertion and reason MCQ in 2024 and two in each of 2025 and 2026. They test the same Java facts as the other MCQs, so the key is to judge the assertion and the reason separately before deciding whether one explains the other.
