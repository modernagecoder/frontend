## By Grade 3, Ontario expects a Mississauga child&rsquo;s code to repeat

Mississauga public schools teach the Ontario curriculum. The quoted wording below was pulled from the Ontario curriculum website&rsquo;s content service on 22 October 2026, and the second column is our plain-language reading of it.

**Ontario Elementary Mathematics (2020), Grade 3, coding. Quoted from the Ontario Ministry of Education curriculum; the notes are our reading**

| What the ministry writes | What it means at home |
|---|---|
| Expectation C3.1: code &ldquo;that involves sequential, concurrent, and repeating events&rdquo; | Steps in order, two things happening at once, and now a loop: the same instructions run again and again |
| Teacher note: &ldquo;Loops make code more readable and reduce the number of instructions that need to be written.&rdquo; | The ministry is teaching an eight-year-old why programmers prefer one loop to ten copied lines |
| Worked example: &ldquo;Set value to 0. Repeat 10 times: Add 2 to Value, Output value.&rdquo; | Counting by twos, written as code. The ministry gives the output as 2, 4, 6 and so on up to 20 |
| Grade summary: students &ldquo;will write code to perform a repeating operation, such as a repeating number pattern&rdquo; | Loops arrive through patterns the child already knows from math class, not as a separate computer subject |

Here is the ministry&rsquo;s example rewritten by us in Python, the language most children in our classes move to at about age nine. It prints exactly the ten numbers the ministry lists, from 2 to 20:

```
value = 0
for step in range(10):
    value = value + 2
    print(value)
```

### Why four lines matter

Without the loop the child would write ten print lines and ten additions. Change the rule to counting by threes and the loop needs one edit; the long version needs ten. That single edit is the Grade 3 idea, and a good class makes the child feel it.

### Blocks or typing?

Ontario lets classrooms use block or text code, so Mississauga children arrive with different habits. Under about eight we stay with blocks, where a repeat block is a shape the child can see; once typing stops being the hard part, the same loop moves to Python.

### The spring assessment

Grade 3 is also the first EQAO year. EQAO&rsquo;s window for the Grade 3 provincial assessment opens on 4 May 2027 and closes on 8 June 2027. Our lessons are not drills for it, though pattern spotting and patient step-by-step work travel well into any math task.

### The two that matter most

If you only have time for two questions, ask about grouping and about the struggle. A well-grouped class where the teacher waits through mistakes will usually get the rest right too.

### Watch one lesson

In any free trial, sit within earshot for the first ten minutes. Count how often your child talks. A class where only the teacher speaks is a lecture with a screen attached.

### Ask your child afterwards

Ask one thing at dinner: what did you make, and what went wrong on the way? A child who can tell you about a bug they fixed has had a real lesson.

## How many Mississauga playground rows are in the Region of Peel file?

For our older children, around ages 10 to 12, we use a real open file from the Region of Peel. It maps active recreation sites in Mississauga, Brampton and Caledon, so the first job is to keep only Mississauga. The counts are ours; the Region publishes the file, not these numbers.

**Our count of the Region of Peel Active Recreation file, downloaded 22 October 2026 (2,415 rows in all). A row is one mapped area, not one swing**

| What we counted | Rows |
|---|---|
| Rows with Mississauga in the MUN column | 1,179 |
| Rows with no town at all (and no type either) | 9 |
| Mississauga rows whose type starts with Playground | 325 |
| Playground - Playset/Swings | 252 |
| Playground - Playset | 32 |
| Playground - Splashpad | 17 |
| Playground - Swings | 11 |
| Playground - Climber, and Playground - Wading Pool | 4 each |
| Playground - Playset/Climber | 3 |
| Playground - Climber/Swings | 2 |
| Of the 325 playground rows, last updated in 2012 | 295 |

This is our script. It uses only Python&rsquo;s standard library and runs in the same folder as the downloaded CSV. The continue line is the whole filtering lesson: any row that is not Mississauga is skipped before it can be counted.

```
import csv

kinds = {}
years = {}
no_town = 0
with open("Active_Recreation.csv", encoding="utf-8-sig") as f:
    reader = csv.DictReader(f)
    for row in reader:
        town = row["MUN"].strip()
        if town == "":
            no_town += 1
        if town != "Mississauga":
            continue
        kind = row["LM_TYPE"]
        if kind.startswith("Playground"):
            kinds[kind] = kinds.get(kind, 0) + 1
            year = row["UPDATED"][:4]
            years[year] = years.get(year, 0) + 1

print("rows with no town:", no_town)
for kind in sorted(kinds, key=kinds.get, reverse=True):
    print(kind, kinds[kind])
print("playground rows:", sum(kinds.values()))
print(sorted(years.items()))
```

### 1. Keep one town

The Region&rsquo;s file has 971 Brampton rows and 256 Caledon rows beside the Mississauga ones. A child who forgets the filter reports a Peel number as a Mississauga number, which is the most common mistake in real data work.

### 2. Notice the blanks

Nine rows name no town and no type. Our script counts them instead of quietly dropping them, so the child can say exactly how much of the file was unusable.

### 3. Read the date column

Each row has an UPDATED value. For 295 of the 325 Mississauga playground rows it is a 2012 date, so the file is a picture of an older survey. A new splash pad may simply not be in it.

### What the counts cannot tell you

The Region says attempts were made &ldquo;to only include features that are on public lands&rdquo;, and warns that these sites are not necessarily open to the public. So 325 is not the number of playgrounds a child can visit today. It is the number of rows of one kind in one file, last touched mostly in 2012. Saying that clearly is the real skill.

## Does a Mississauga child still need to learn loops when AI can write them?

Yes, because the child has to know whether the loop is right.

An AI tool will write the counting-by-twos loop in a second. It will also write the playground script, and it may forget the Mississauga filter, which quietly turns a Mississauga answer into a Peel answer. A ten-year-old who has written the filter by hand spots that at once. One who has only ever asked for code does not.

So our younger classes are about thinking: predict, run, compare, fix. We teach what AI is and where it goes wrong in our AI literacy course, but we do not hand children a chatbot to do their thinking. Families who try ChatGPT at home should know that OpenAI asks for a parent&rsquo;s permission before users younger than 18 sign up.

Ontario wrote loops into Grade 3 math so that children learn to think about repetition, and an eight-year-old who can explain a loop owns something a chatbot cannot hand over. The longer argument is in [why coding is still worth learning in 2026](/blog/is-coding-worth-learning-2026).
