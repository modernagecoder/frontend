Q2. Can I see a real program from class?

A double dimensional array program, worked for the Pune group

Double dimensional arrays are part of the 2027 syllabus and suit Section B well: nested loops, indexes and a little arithmetic in one question. This original program reads a 4 by 4 grid, prints each row with its sum, adds both diagonals and finds the largest number with its position.

The question. Accept 16 integers into a 4 × 4 array. Print the array in matrix form with the sum of each row shown beside it. Print the sum of the left diagonal, the sum of the right diagonal, and the largest element together with its row and column, counting from 1.

Sum3325

Mistakes that cost marks on grid programs

  • Diagonals inside the inner loop. Adding m[r][r] inside the column loop counts each diagonal value four times. It belongs once per row, in the outer loop.
  • Right diagonal written as m[r][4 - r]. With indexes 0 to 3, the partner of row r is column 3 - r. Using 4 runs past the end and throws an exception.
  • Starting max at 0. If every number were negative, 0 would wrongly win. Starting from m[0][0] is always safe.
  • Printing positions from 0. The question asks for row and column counted from 1, so the answer adds 1 when printing, not when storing.
  • Reset in the wrong place. rowSum must go back to 0 at the start of every row, or each row's sum includes the rows above it.

Column sums, transposes and more grid programs are on ICSE Class 10 2D array programs.

Q4. How do we keep the lab file on track?

Pacing twenty lab assignments across the year, alongside your school

CISCE asks for at least twenty laboratory assignments for the internal assessment, worth 100 marks. Your school decides which ones and when. Our job is to stop them piling up in the winter, when board papers need the time.

The internal assessment is marked half by the subject teacher and half by an external examiner, 50 each. Each examiner gives up to 20 for a program that executes with correct output, and up to 10 apiece for the design of the class, the table describing its variables, and the quality of its code and comments. All four improve when assignments are written steadily rather than in a rush, because a rushed program is usually the one without a description table or comments.

Pune questions

What Pune parents ask about ICSE computer tuition

Do you have an ICSE computer class in Pune that we can attend in person?

No. Modern Age Coders has no centre in Pune and does not offer home tutoring there. All classes are live online, with a teacher and six students at most, each writing and running code in BlueJ. For face to face teaching, a local tutor is the right choice.

What are the online ICSE Java class timings for Pune?

The group meets every Tuesday at 5:30 PM and every Wednesday at 8:00 PM IST, which is Pune time. Tuesday is for theory, outputs and short answers; Wednesday is for one full 15-mark program. Private classes can be arranged at other times.

What equipment does my child need for online Java tuition?

A laptop or desktop with BlueJ installed, a stable internet connection and a notebook for planning and tracing. A phone or tablet is not enough, because the student must type, compile and run Java programs during every class. Headphones help in a busy home.

Are double dimensional arrays in the ICSE 2027 syllabus?

Yes. Double dimensional arrays are part of the ICSE Class 10 Computer Applications syllabus for 2027, alongside single dimensional arrays. Typical questions ask for row or column sums, diagonal sums, the largest element or a transposed matrix, so nested loops must be secure first.

Do you teach the Maharashtra SSC computer subject?

No. Our Pune students all sit the ICSE: the course follows the CISCE Computer Applications syllabus set for the 2027 Class 10 examination, taught in Java with BlueJ. Students on the Maharashtra state board or on CBSE follow different syllabi and would not be served by this class.

How many lab assignments are needed for ICSE Computer Applications?

CISCE requires at least twenty laboratory assignments across the year for the internal assessment, which is worth 100 marks. Your school decides the questions and deadlines. Spreading them out, rather than finishing most in the winter, protects both the file and board preparation.

Do you write the lab assignments for students?

No, never. The student writes every program they submit. We teach the concept behind a school question using a different example, help the student test their own program, and rehearse the explanations an examiner may ask for. That keeps the work honest and the marks safe.

How much is ICSE computer tuition for Pune students?

Look at the course card near the top: it lists what one month of the group costs and what one month of private classes costs, converted to your currency. There is nothing to pay on joining, billing is monthly, and you pay nothing until after a free trial class. Compare any quote on what each class includes.

Is self-study enough for ICSE Computer Applications?

For a disciplined student who already writes programs confidently and scores well, often yes, with past papers and timed practice. Tuition helps most when programs are copied rather than written, Section B marks lag theory marks, or the lab file is falling behind.

What happens in the free demo for Pune students?

Your child sits in on a genuine lesson, builds a small BlueJ program from a blank screen, then talks the teacher through how it works. You then hear plainly what is strong, what needs work, and whether the group or a private class fits better.
