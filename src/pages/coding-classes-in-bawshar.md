## Can one histogram show one peak and three?

Bawshar's mix of national, Indian and private schools makes school-size data locally meaningful. It also makes a histogram dangerously easy to tune until it tells the story the analyst expected.

Source: Oman Ministry of Education open dataLevel: Grade 8 and upConcept: Histogram bin width

The Ministry publishes 2024/2025 student counts by government school, grade and sex, with a matching school file by governorate. Students identify the Bawshar schools in the current data, document the match and calculate one total per school.

The ordinary question is whether Bawshar has one typical school size or several groups. A histogram with wide bins can show one broad mound. Narrow bins can split the same values into several apparent peaks. Both charts use the same schools.

The trap

Bin width is a modelling choice, not decoration. Too wide hides structure. Too narrow turns sampling noise into a pattern. A responsible analysis shows several defensible widths, states the rule used and checks whether any claimed cluster survives the choice.

The issue generalises to ages, travel times, exam marks, prices and sensor readings. A chart can change the reader's conclusion without changing a single observation.

| 2 | Builds one checked enrolment total per school. | The unit of analysis comes before the chart. |
| 3 | Plots equal-width histograms using several bin widths. | A visual default is an analytical decision. |
| 4 | Compares the histogram with a dot plot and summary table. | Another view can expose invented peaks. |
| 5 | Writes which conclusions survive every reasonable width. | Robust claims should not depend on one setting. |
