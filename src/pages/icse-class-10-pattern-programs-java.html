Ans. The short version

Pattern programs for ICSE Class 10 are Java programs that print a shape, such as a star triangle, a number pyramid or a letter triangle, using nested for loops. The outer loop runs once per row; the inner loop decides how many items that row holds; an optional first inner loop prints leading spaces; and the print statement decides which character appears. Answer three questions for any pattern: how many rows, how many items in row i, and what is printed at row i, column j. Modern Age Coders teaches pattern programs live in a Tuesday and Wednesday mini batch in India, or one to one at the family's time.

Q1. How do you write any pattern program in Java?

Nested loop patterns in Java for ICSE: the four loop rules

Every pattern is a grid printed one row at a time, so every pattern program is an outer loop for the rows with one or two inner loops inside. What changes from shape to shape is only the limit of the inner loop, whether spaces come first, and what gets printed.

RuleThe question it answersWhere it lives in the codeTypical form
RowsHow many lines does the shape have?The outer loop, ending with System.out.println()for (i = 1; i <= n; i++)
ColumnsHow many items does row i hold?The limit of the inner loop, written in terms of ij <= i, j <= n - i + 1, j <= 2 * i - 1
SpacesDoes row i start further to the right?A separate inner loop placed before the itemsfor (s = 1; s <= n - i; s++)
CharactersWhat is printed at row i, column j?The argument of System.out.print"*", j, i, (i + j) % 2, (char) ('A' + j - 1)

The three questions, in order

  1. Count the rows. That number is the outer loop's limit, usually n.
  2. Write down the item count for rows 1, 2 and 3. If it goes 1, 2, 3 the limit is i; if it goes 5, 4, 3 it is n - i + 1; if it goes 1, 3, 5 it is 2 * i - 1. If the left edge moves, count the spaces the same way.
  3. Look at one column. If the same column shows the same value on every row, print j. If a whole row repeats one value, print i. If nothing repeats, find the formula in i and j, or a test that picks the edge.

The full-mark answer is the same shape every time: Scanner input for n, the nested loops, a println() after each row and a variable description table. Here is the pyramid, written that way.

VariableTypePurpose
nintnumber of rows, read from the user
iintcurrent row, 1 to n
sintcounts the leading spaces in row i
jintcounts the stars in row i
scScannerreads input from the keyboard

Q2. How do you make a triangle grow or shrink?

Triangle pattern ICSE: changing only the inner loop limit

A left-aligned triangle needs no spaces at all. Rows and characters stay fixed while the inner loop's limit decides the shape: j <= i grows, j <= n - i + 1 shrinks.

PatternItems in rows 1, 2, 3Inner limitPrinted
Star triangle1, 2, 3j <= i"* "
Shrinking count5, 4, 3j <= n - i + 1j
Row repeat1, 2, 3j <= ii

The most common slips with these three

  • println inside the inner loop. Every item lands on its own line and the triangle becomes a column.
  • n - i instead of n - i + 1. The first row loses one item and the last row is empty. Test the limit with i = 1 and i = n.
  • Printing j where the row repeats. If each row shows one value repeated, the value comes from the outer counter, i.

Q3. How do you push a pattern to the right?

Star pattern program ICSE: right-aligned triangles, pyramids and the diamond

Add a spaces loop before the items. When row i has n - i spaces, row 1 starts furthest right and row n touches the margin, which turns a left triangle into a right-aligned one and, with 2i - 1 items, into the pyramid above.

Spaces are where most pattern answers go wrong under exam pressure, so in the class every student draws the grid on squared paper first and writes the space count beside each row. The same habit of counting each pass is drilled on loop programs in Java for ICSE Class 10.

Q4. How do number, letter and 0 1 patterns work?

Number pattern Java Class 10: letters, 0 and 1, palindromes and hollow shapes

Once the rows, limits and spaces are right, the remaining work is the value printed at position (i, j). It can be a formula, a char made from a number, two loops that climb and then fall, or an if-else that picks the border.

PatternWhat is printed at (i, j)Why it works
0 1 triangle(i + j) % 2i + j changes parity at each step along a row and each step down a column
Letter triangle(char) ('A' + j - 1)'A' is 65; adding j - 1 and casting back gives A, B, C
Palindrome pyramidj from 1 up to i, then j from i - 1 down to 1Two inner loops: one climbs, one falls, so each row reads the same both ways
Hollow square"* " when i or j is 1 or n, else two spacesOnly the border passes the test; the gap must be as wide as a star plus its space
Word trianglew.substring(0, i)Row i shows the first i letters, so one loop is enough

Turn one pattern into another: practice changes

Each change below touches one rule only. Make it in BlueJ, predict the output first, then run it.

  1. In binaryTriangle, print (i + j + 1) % 2. The triangle now starts with 1 instead of 0.
  2. In letterTriangle, print (char) ('A' + i - 1). Every row repeats one letter: A, B B, C C C.
  3. In palinPyramid, remove the spaces loop. The rows become a left-aligned stack of palindromes.
  4. In hollowSquare, add || i == j to the test. A diagonal now crosses the square.
  5. In wordTriangle, print w.substring(w.length() - i). The word now builds from its last letter: J, EJ, UEJ.

Single letters printed with charAt instead of substring belong to the string family on ICSE Class 10 string programs, and tracing what a pattern prints without running it is practised on ICSE Computer Applications output questions.

Q5. Where do patterns appear in the ICSE paper?

Pattern programs in the ICSE 2027 paper, and how they are marked

Patterns appear in two places: as a full Section B program, and very often as one part of a method overloading question, where one version of the method prints a pattern and the others do something else. They also turn up in Section A as short trace questions.

Inside an overloading question

A recent pattern in board papers has been one method name with two or three parameter lists, one of which prints a number or symbol pattern. The pattern part is often the quickest marks in the question if the loop rules are second nature.

As a menu choice

A switch menu may offer a pattern as option 1 and a series as option 2. The pattern code goes inside its case, followed by break, and the default case handles a wrong choice.

As a trace in Section A

A short nested loop is shown and the student writes what it prints. The same rules work backwards: read the limits to find the item count per row.

What earns the marks

Correct loops and limits, a println at the end of each row, sensible variable names, comments on what each loop does and the variable description table. A shape that is off by one row usually loses part of the logic marks.

Check two rows by hand

Before moving on, trace row 1 and row n on the margin. Most wrong patterns are wrong at one end, and two quick traces catch both kinds of off-by-one.

Keep it to for loops

A pattern can be printed with while loops, but for loops show the counter, the limit and the step on one line, which makes the logic easy for the examiner to follow.

Overloading answers with a pattern inside are worked on user-defined methods and overloading for ICSE Class 10, and how often the pattern-in-overloading question came up in recent years is mapped on ICSE Computer Applications previous year papers, solved.

Questions about pattern programs

What students ask about ICSE pattern programs

How do I solve any pattern program in Java?

Answer three questions before coding. How many rows are there? That is the outer loop. How many items are in row i? That is the inner loop limit, written using i. What is printed at row i, column j? That is the print statement. If the shape is pushed to the right, add a spaces loop before the items. Then trace row 1 and the last row by hand.

Are pattern programs important for ICSE Class 10?

Yes. They test nested loops, which are part of the 2027 Computer Applications syllabus, and they appear as Section B programs, as one part of method overloading questions and as Section A trace questions. A student who knows the loop rules can usually collect these marks quickly.

What is the difference between print and println in pattern programs?

print leaves the cursor on the same line, so the items of one row sit side by side. println moves to a new line. In a pattern, print goes inside the inner loop and a single println goes after the inner loop, once per row. Putting println inside the inner loop prints every item on its own line.

How do you print a star pyramid in Java?

Use an outer loop for i from 1 to n. Inside it, print n - i spaces, then 2 * i - 1 stars with no space between them, then call println. For n = 5 the first row has four spaces and one star, and the last row has nine stars and no spaces.

How do you print a letter pattern such as A, AB, ABC in Java?

Print (char) ('A' + j - 1) inside the inner loop, where j runs from 1 to i. Adding a number to a char gives an int, so the cast is needed to turn the code back into a letter. Without it the program prints 65, 66 and 67.

How do you print a 0 and 1 triangle pattern in Java?

Print (i + j) % 2 at row i, column j. The sum i + j changes between odd and even at every step, so the digits alternate along each row and each column. Use (i + j + 1) % 2 instead if the first row must start with 1.

How do you print a hollow square or hollow triangle?

Loop over every position in the grid and use an if-else. Print the symbol when the position is on the border (first row, last row, first column or last column) and print blanks otherwise. The blank must be as wide as the symbol plus any space printed after it.

Which loop is best for pattern programs?

The for loop, because the start, the limit and the step of each counter sit on one line, and a pattern is a fixed number of rows and items. While and do-while loops can print patterns too, but they make the limits harder to see and to mark.

Is recursion used for patterns in ICSE 2027?

No. Recursion is not part of the ICSE Computer Applications syllabus for 2027. Every pattern the paper can ask is printed with nested for loops, sometimes inside a method that takes n, a character or a word as a parameter.

Yes. In the ICSE mini batch a new pattern is planned on paper, written against the clock, then run and fixed in BlueJ on a shared screen. Students who need more time on nested loops can take personalised one to one classes at a time the family chooses.
