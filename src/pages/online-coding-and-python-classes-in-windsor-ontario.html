Does anyone teach coding and Python live online to Windsor students?

Modern Age Coders does. Windsor, Ontario students from age 6 to adult learn coding and Python in live online classes where the teacher reads their shared code and helps them find their own bugs, one to one or in a group of fifteen to twenty. Python and AI for Kids and Python for Teens are where most begin, after a free first class.

The clearest way to show what a live online coding class is, is to show one minute of it. So this page starts with a single debugging moment: a Windsor student's program crashes on a City of Windsor data file, and the teacher, reading the student's shared code, does not fix it. What happens instead is the actual teaching. After that comes our Python path, described not as a list of topics but as the kinds of error a student learns to handle, from a missing bracket to a file that is not as tidy as it looks. Then the full project on the playground file, and the contest and school facts a Windsor student should know for 2026 to 2027.

One live moment

A Windsor student's program crashes. Here is what the teacher does

This is a reconstruction, written by us, of a moment that happens in some form in most of our Python classes. The code and the error are real: we ran them on the City of Windsor playground file on 22 October 2026.

One debugging moment in a live online class, in order (our reconstruction; the error text is Python's own)
MomentOn the shared screenWhat the teacher says or does
1. The crashThe student's parse() function stops with ValueError: not enough values to unpack (expected 2, got 1)Nothing yet. The teacher waits for the student to read the message aloud
2. Reading itThe student reads the last line, then the line number it points to“Expected 2, got 1. Two of what?”
3. A guessThe student says key, value = part.split("=") wanted two pieces but got one“Good. Which row gave it one piece? How could you find out?”
4. LookingThe student prints each description before parsing it and sees a blank one on line 3 of the file“What does split give you for an empty string?”
5. The fixThe student adds if "=" in part: and runs the program again over all 131 rowsAsks how many rows had nothing to parse. The answer is 14
6. The habitThe student writes one comment explaining the guard“Next time a file crashes your program, what will you do first?”

Six short steps, and the teacher never typed. That is the difference between a live class and a recorded one: the recording would have shown a tidy program that never crashed, and the student would have copied it. In our classes the error is the lesson, and the student leaves knowing how to read the next one without help.

In a group class

With fifteen to twenty students at one stage, the teacher puts one student's crash on the shared screen and the whole group reasons through it. Often several of them have the same bug.

In a one to one class

The same six steps, at the student's own pace. One to one suits students working on an ICS4U project or preparing for the CCC.

The setup

A laptop or desktop, a microphone and Python installed with the teacher in the first lesson. The student shares their editor; the teacher never takes the keyboard.

Stage 3 is the turning point. Up to stage 2, Python tells the student something is wrong. From stage 3 on, the program runs and the answer is simply incorrect, and only a student who predicted the answer first will notice. That is why every class asks for a prediction before the run, from a child's first loop to a teen's data project.

Windsor data project

How many Windsor playgrounds does the city file mark as accessible, ward by ward?

The City of Windsor publishes a playground layer as open data, 131 rows on our download of 22 October 2026. Size and accessibility are not separate columns; they are packed into one text field such as SIZE=MEDIUM, ACCESSIBLE=YES, so a program has to parse them. All figures below are our own output.

This is the corrected program from the debugging moment above, with the guard in place. It reads the CSV with the standard csv module, turns each description into a small dictionary, and counts with Counter:import csv from collections import Counter def parse(description): info = {} for part in description.split(","): if "=" in part: key, value = part.split("=") info[key.strip()] = value.strip() return info sizes = Counter() accessible_by_ward = Counter() with open("playground.csv", encoding="utf-8-sig", newline="") as f: for row in csv.DictReader(f): info = parse(row["asset_description"]) sizes[(info.get("SIZE", "not given"), info.get("ACCESSIBLE", "not given"))] += 1 if info.get("ACCESSIBLE") == "YES": accessible_by_ward[row["political_ward"]] += 1 for (size, access), n in sorted(sizes.items()): print(size, access, n) print(accessible_by_ward.most_common())

Size against access

Parsed, the descriptions give LARGE with ACCESSIBLE=YES on 28 rows and LARGE with NO on 9; MEDIUM YES 13, MEDIUM NO 33; SMALL YES 10, SMALL NO 23. One row gives accessibility without a size, and 14 give neither.

Themes

Twenty-seven rows also carry a THEME, with 24 different values: Forest appears three times and Pirate Ship twice, and single rows include Automotive, Aviation, Dinosaur and Space Ship.

Ward 7

Ward 7 has the most playground rows, 19, and only 3 of them are marked ACCESSIBLE=YES. Ward 3 has 9 rows and 6 marked YES. The next question is why, and the file alone cannot answer it.

What ACCESSIBLE=YES does and does not tell you

It records a label in the City's asset description, not an inspection a student has made, and 14 rows have no description at all, so a missing YES is not a NO. Seven park_id values also end in a stray space, which would split one park into two if a student grouped by park. Reporting the counts with those caveats is the finished project.

Python and AI

Can a Windsor student let AI fix the bugs instead?

It can fix this bug. It cannot teach the student to find the next one.

Paste the ValueError into an AI assistant and it will suggest the same guard our student wrote. What it will not do is make the student look at line 3 of the file, count the 14 blank descriptions, or notice the stray spaces in park_id. The fix arrives; the understanding does not.

We teach the reasoning first: read the error, form a guess, test it, then fix. Older students use AI tools later within the age rules we follow, as a second opinion to check, never as the place answers come from.

A Windsor student who can explain why a missing ACCESSIBLE=YES is not the same as a NO has learned the part of coding that stays human. The longer argument is in what students still need to learn about code.

FAQ

Windsor coding and Python questions

What Windsor families ask before the first lesson.

What makes an online coding class live rather than recorded?

A teacher at a set time who can see the student's own code and responds to it. When the program crashes, the teacher asks questions until the student finds the cause.

Do you have a coding school in Windsor?

No. There is no Windsor classroom. All lessons are live online, so students in LaSalle, Tecumseh or South Walkerville join from home.

How many students are in each group?

Fifteen to twenty at the same stage. A one to one class is one student with one teacher, following the same course.

What is a good age to start Python?

About 9 for most children. From age 6 we use blocks, then move to typed Python when reading and typing are comfortable.

Will this help with ICD2O in Grade 10?

Yes. ICD2O asks students to apply coding concepts in hands-on projects and to look at AI and automation critically. Our Python stages give the coding a firmer base.

Can a Windsor student go from the CCC to the CCO in Python?

The CCC accepts Python, but CEMC says the CCO requires C++. Students who aim that high learn C++ as well. Entry is through a school.

Do you award Ontario credits for ICS3U or ICS4U?

No. We do not grant Ontario credits. The school awards ICS3U and ICS4U credits; our companion course adds practice beside them.

What time are classes for Windsor students?

Weekdays or weekends, flexible: choose your batch, or for a very personalised plan choose 1-on-1 at your convenience, weekend mornings or weekdays. We confirm every time in Eastern time.

Do adults in Windsor learn Python with you?

Yes. Adults start from zero if they need to and work towards automating tasks or handling data files, in a group or one to one.

Do 519 and 226 numbers work in the form?

Yes, and 382 and 548 as well. Enter the ten digits; the +1 is already shown.

How do I see the fees?

The fees section shows the free first lesson, the monthly group fee and the monthly one to one fee in your own currency. You pay nothing before the free lesson.
