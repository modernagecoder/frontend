> AI or computer applications in Class 10 comes down to what your child enjoys. Each CBSE option is marked out of 100, half written paper and half practical. Artificial Intelligence (417) teaches how AI is built and judged, with Python. Information Technology (402) teaches office software and databases in LibreOffice. Computer Applications (165) teaches networking, HTML and CSS web pages, and cyber ethics. Only one of 165 and 402 is allowed. Decide in Class 9, since the two years form one course. If you pick AI, Modern Age Coders runs a live 417 batch on Mondays and Wednesdays at 9:00 PM IST, or one to one.

## AI vs IT vs computer applications: what each CBSE subject is

They are three different subjects that fill the same place in the timetable, the optional sixth subject alongside the five compulsory ones. AI 417 and IT 402 come from CBSE's skill education stream; Computer Applications 165 is an academic elective. Each is marked out of 100, half of it practical.

- | Artificial Intelligence (417) | Information Technology (402) | Computer Applications (165)

- In one line | How AI systems are planned, trained, tested and used fairly | Advanced word processing, spreadsheets and databases for office work | How the internet works, building web pages, and behaving well online

- Type of subject | Skill subject | Skill subject (job role: Domestic Data Entry Operator) | Academic elective

- Main tools | Python in Jupyter, NumPy, Matplotlib, Orange Data Mining, Teachable Machine | LibreOffice Writer, Calc, Impress (Class 9) and Base (Class 10) | A text editor and a browser for HTML and CSS; office tools in Class 9

- Do they write code? | Yes, Python, in both years | Not a programming language; simple macros in Class 10 Calc | Yes, HTML markup with CSS styling, in Class 10

- Maths in the theory paper | Some: statistics in Class 9, model evaluation metrics in Class 10 | Spreadsheet formulas only | Almost none

- Theory and practical | 50 and 50 | 50 and 50 | 50 and 50

- Natural next step in Class 11 | Artificial Intelligence (843) | Information Technology (802) | Computer Science or Informatics Practices, by the school's own rules

### A common mix-up: CBSE 165 is not ICSE Computer Applications

Both boards use the name Computer Applications, but they are unrelated. CBSE subject 165 is web pages in HTML and CSS, networking and cyber ethics. The ICSE subject of the same name is Java programming in BlueJ, a far heavier coding course. If you have moved from an ICSE school, or read about Java on a forum, check which board is being discussed. The ICSE subject has its own series of pages, starting at [ICSE Class 10 Java classes](/icse-class-10-java-classes-online).

### What "skill subject" means for a parent

Skill subjects are written by CBSE's Department of Skill Education around practical competence, so both 417 and 402 begin with the same five employability units, worth 10 marks, on communication, self-management, ICT, entrepreneurship and green skills. Subject 165 has no such part; all of its theory is about computers and the web.

## Class 9 then Class 10: the two-year path of 417, 402 and 165

Each subject builds from a Class 9 foundation into a different Class 10 focus. The Class 9 year is assessed by the school; the Class 10 year ends in the board exam. These are the theory units and marks in the 2026-27 curricula.

- Subject | Class 9 theory units (marks) | Class 10 theory units (marks)

- AI 417plus Part A, 10 marks, both years | AI Reflection, Project Cycle and Ethics (10); Data Literacy (10); Math for AI, statistics and probability (7); Introduction to Generative AI (5); Introduction to Python (8) | Revisiting AI Project Cycle and Ethical Frameworks (7); Advanced Concepts of Modeling (11); Evaluating Models (10); Computer Vision (4); Natural Language Processing (8). Statistical Data and Advance Python: practical only

- IT 402plus Part A, 10 marks, both years | Introduction to the IT-ITeS industry (4); Data Entry and Keyboarding (6); Digital Documentation (10); Electronic Spreadsheet (10); Digital Presentation (10) | Digital Documentation, advanced (8); Electronic Spreadsheet, advanced (10); Database Management System (12); Maintain Healthy, Safe and Secure Working Environment (10)

- Computer Applications 165 | Basics of Information Technology (20); Cyber Safety (15); Office Tools (15) | Networking (15); HTML, including forms, tables and CSS (25); Cyber Ethics (10)

### AI: ideas, then models
Class 9 meets the project cycle, data and Python basics such as variables, conditions and lists. Class 10 moves to how models learn and how they are scored, then to images and language.

### IT: office, then data
Class 9 is typing accuracy, documents, spreadsheets and presentations. Class 10 goes deeper into each tool and adds a full database in Base, with queries, forms and reports.

### 165: computers, then the web
Class 9 covers hardware, memory, networks, safe browsing and office tools. Class 10 switches to the internet itself and to building multi-page websites by hand in HTML.

## 417 vs 165, and 402: how the Class 10 board marks are earned

Every option is 50 theory marks in a two-hour paper plus 50 internal practical marks. The papers differ in style: 417 and 402 offer a lot of choice, while 165 asks every question and offers choice only inside some of them.

- What is marked | AI 417 | IT 402 | Computer Applications 165

- Theory paper layout | Same for both (2025-26 sample papers): 46 questions printed, 34 answered; 24 marks of one-mark items | 26 questions, all compulsory, sections A to E; 12 marks of one-mark items; two 4-mark case-based questions (2026-27 sample paper)

- Hands-on test | Practical exam on statistical data, computer vision, NLP and Python, 15 | Writer 5, Calc 5, Base 10, so 20 in all | Lab test: design one web page from a given diagram, 20

- File or portfolio | At least 15 programs, 15 | Portfolio of Writer, Calc and Base tasks, five or more per tool, 10 | Report file of at least 10 HTML pages, 15

- Viva | 5 on the practical, 5 on the project | 10 | 5, on the report file

- Project | Project, field visit or portfolio, 10 | Real-world case study built in Base and written up in Writer, 10 | A project that uses most of what was learnt, 10

- Practical total | 50 | 50 | 50

## Can a student take AI and Computer Applications together, or switch later?

The 2026-27 CBSE scheme says only one of 165 and 402 can be offered, and in the 2026 board exams all three subjects sat in the same morning slot, so in practice a student takes one of the three. Switching between Class 9 and Class 10 is discouraged by the scheme itself.

-
**One of 165 and 402, never both** The footnote to the 2026-27 subject list says it directly: out of the subjects with codes 165 and 402, only one can be offered.

-
**One morning, one paper** In 2026, AI 417, IT 402 and Computer Applications 165 were all on Friday 27 February, 10:30 AM to 12:30 PM. A student cannot sit two papers at once, so plan on one of the three. The 2027 date sheet is not out yet.

-
**Classes 9 and 10 are one course** CBSE asks students to take in Class 9 only the subjects they mean to continue in Class 10. A switch at the start of Class 10 leaves a year of theory and a full practical to catch up, and the school has to agree.

-
**The school decides what is on offer** CBSE lists the subjects; each school chooses which to run, based on teachers and labs. The real choice is often between two, not three.

If your child is in Class 9 now (2026-27): their Class 10 board falls in 2028. Newspapers reported in October 2026 that this batch moves to a revised scheme with a fixed core of compulsory papers and a choice of skill papers that still lists AI and IT. CBSE has not notified how each subject fits, so we treat it as reported and promise nothing. Get the school's circular in writing before the Class 9 subject form is due. Checked 6 November 2026.

## Which skill subject to choose in Class 10: a checklist for parents

Match the subject to how your child likes to work, not to which name sounds most modern. Find the row that sounds most like your child, then confirm with the questions for the school.

- If your child | Look first at | Why

- Asks how apps and chatbots work, and likes puzzles | AI 417 | Concepts, small calculations and Python from Class 9

- Enjoys designing things on screen and wants to see results at once | 165 | Every HTML tag shows up in the browser straight away

- Is careful and organised, and likes tidy documents and tables | IT 402 | Rewards exact, repeatable steps in office software and databases

- Finds maths stressful this year | 402 or 165 | Neither puts metric calculations in the theory paper

- Is set on Computer Science in Class 11 | AI 417 or 165 | Early coding in Python or HTML; neither is a formal entry rule

- Has little computer access at home | Ask the school | All three need lab time; the practical is half the marks

- Is moving from an ICSE school with Java | Not 165 by name | CBSE 165 is HTML, not Java; AI 417 is closer to programming

### Questions to ask the school

- Which of 417, 402 and 165 will run for this batch, and who teaches it?

- How many lab periods a week, and is the software installed?

- Is a change allowed between Class 9 and 10, and until when?

- What does the school's circular say about the 2028 scheme?

### Questions to ask your child

- Would you rather work out why, build something you can see, or get a task exactly right?

- Are you willing to keep a practical file going all year?

- Which of these would you still enjoy in February of Class 10?

Then open one Class 10 unit of each subject together for a few minutes. The reaction tells you more than any ranking.

## Frequently asked questions

**Which is better, AI or computer applications, in Class 10?** Neither is better for every child. AI 417 suits a student who enjoys ideas, small calculations and Python. Computer Applications 165 suits one who likes building web pages and seeing results at once, with almost no maths. Both carry 100 marks, half practical. Choose by how your child likes to work and by what the school teaches well.

**What is the difference between 417 and 165?** Subject 417 is Artificial Intelligence, a CBSE skill subject covering the AI project cycle, ethics, modeling, model evaluation, computer vision and NLP, with Python in the practical. Subject 165 is Computer Applications, an academic elective covering networking, HTML and CSS web pages and cyber ethics in Class 10. Both have a 50-mark theory paper and a 50-mark practical.

**Which skill subject should I choose in Class 10?** Choose in Class 9, since CBSE treats Classes 9 and 10 as one course. Pick AI 417 for a child curious about how AI works and willing to code in Python, IT 402 for one who likes precise office and database work, or Computer Applications 165 for one who wants to build websites. Then confirm the school runs it with a teacher and lab time.

**Can I take AI and computer applications together in Class 10?** Not in any practical sense. The 2026 timetable put the 417, 402 and 165 papers at one and the same time, 10:30 AM on 27 February, so nobody could write two of them. On top of that, the 2026-27 subject list forbids pairing 165 with 402. Find out which of the three your school runs, then choose among those.

**Is CBSE Computer Applications 165 the same as ICSE Computer Applications?** No. They share a name but not a syllabus. CBSE 165 covers networking, HTML web pages with CSS and cyber ethics. ICSE Computer Applications is Java programming in BlueJ, with object-oriented programs, arrays and strings. A student moving from ICSE will find CBSE AI 417 closer to programming than CBSE 165.

**Is computer applications easier than AI in Class 10?** For many students 165 feels lighter because its theory has almost no calculation and HTML shows results instantly. AI 417 asks for model evaluation metrics and Python, which some students find harder and others enjoy more. CBSE does not publish subject averages, so judge by your child, and remember that half the marks in either subject are practical.

**Does Computer Applications 165 include coding?** Yes, but it is web markup rather than a programming language. In Class 10 students write HTML pages with headings, lists, images, tables, forms, links, audio and video, and style them with CSS. The practical includes designing one web page from a diagram in a lab test and a report file of at least 10 HTML pages.

**Which subject is better for computer science in Class 11?** AI 417 gives the most Python practice, and Python is the language of CBSE Class 11 Computer Science and Informatics Practices. Computer Applications 165 gives a good grounding in the web and networking. None of the three is a formal entry requirement; schools set their own criteria for Class 11 streams, often on overall and maths marks.

**Can my child change the subject in Class 10?** It is possible only if the school agrees, and it is hard work. The CBSE scheme describes Class 9 and Class 10 as a single composite course, so a late switch means learning the new subject's Class 9 base and its Class 10 content, plus building a fresh practical file, inside one year. If you are unsure, decide before the Class 9 form goes in.

**Will the 2028 board exam change these subjects?** Possibly. News coverage from October 2026 says today's Class 9 students, who reach the Class 10 board in 2028, will follow a revised scheme in which AI and IT still appear among the optional skill papers. CBSE has not yet notified the details for each subject, so treat it as reported only and rely on the written circular your school sends.
