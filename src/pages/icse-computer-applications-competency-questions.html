Q2. How do assertion and reason items work?

Assertion reason ICSE Computer Applications: the method and six worked items

Judge the assertion alone, judge the reason alone, and only if both are true ask whether the reason is why the assertion holds. The four options are: (a) both true and R explains A, (b) both true but R does not explain A, (c) A true and R false, (d) A false and R true.

  1. A: System.out.println('A' + 2); prints 67. R: a char used in arithmetic is promoted to int.
    Answer (a) 'A' is 65, promoted to int, plus 2 is 67, and the promotion is exactly why a number prints instead of C.
  2. A: System.out.println(Math.sqrt(25)); prints 5. R: Math.sqrt returns a double.
    Answer (d) It prints 5.0, so A is false. R is true, and it is the very reason A fails.
  3. A: after String s = "board"; s.toUpperCase(); s still holds "board". R: String objects in Java cannot be changed.
    Answer (a) toUpperCase builds a new String that was never stored; immutability is the cause.
  4. A: after int[] m = new int[5]; the element m[5] holds 0. R: elements of a new int array start at 0.
    Answer (d) Valid indices are 0 to 4, so m[5] throws ArrayIndexOutOfBoundsException when run. R is a true rule about indices 0 to 4.
  5. A: a class can have two constructors, Box() and Box(int s). R: a constructor has the same name as its class.
    Answer (b) Both are true, but constructors can coexist because their parameter lists differ, not because of their name.
  6. A: binary search for 9 in {9, 4, 7, 1} reports "not found". R: binary search assumes the array is sorted.
    Answer (a) The search checks 4, then 7, then 1, always moving right, and never looks at index 0. It fails because the data is not sorted.

The trap in (b)

Students pick (a) whenever both statements are true. Ask: if R were false, would A still be true? If yes, R does not explain A.

The trap in (d)

An assertion that is almost right, such as "prints 5" for 5.0, is false. Exact output is part of the fact.

Q3. What does a case study look like in Java?

Case study questions ICSE computer: two worked cases

A case study gives a short real situation and then several linked questions on it. The board has not set a separate case-study section in this paper, but its scenario MCQs and real-world Question 3 classes read the same way, so these two original cases train that reading.

Case 1: the school bus

A school bus makes five stops. The number of students boarding at each is stored as int[] board = {6, 11, 4, 13, 9};. (i) Which construct suits five values of one type? (ii) Find the total and the busiest stop. (iii) The bus is full at 30 or more students; which statement stops counting once it is full? (iv) After which stop is it full?

Case 2: the self-watering planter

A planter reads soil moisture as a percentage. Below 20 it gives 1.5 litres, from 20 to under 45 it gives 0.75 litres, otherwise none. (i) Which kind of constructor takes the reading? (ii) Why should moisture be private? (iii) What does a reading of 32 print? (iv) Write the rule as one statement.

Q4. What do HOTS and application items ask?

HOTS questions ICSE Java and application based questions, worked

Higher-order items ask you to evaluate or repair code rather than write it from scratch. Four shapes from recent Question 2 papers, each with an original item.

H2. Put the statements in order

To count the vowels in a word: (1) return c; (2) if ("AEIOU".indexOf(w.charAt(i)) >= 0) c++; (3) int c = 0; w = w.toUpperCase(); (4) for (int i = 0; i < w.length(); i++). Answer: 3, 4, 2, 1. For "Education" it returns 5.

H3. Turn a rule into one statement

A ride admits a rider at least 120 cm tall, or any rider with an adult. Answer: boolean canRide = height >= 120 || withAdult; With height 115 and withAdult true it is true; using && would wrongly refuse that child.

H4. Fill the blanks to reverse an array in place

int i = 0, j = r.length - 1; then while (i < j) { int t = r[i]; r[i] = r[j]; r[j] = t; ___; ___; }. Answer: i++ and j--. {2, 4, 6, 8, 10} becomes 10 8 6 4 2.

Questions about competency questions

What students ask about competency questions in ICSE Computer Applications

What are competency based questions in ICSE Computer Applications?

They are questions that ask a student to apply, analyse or evaluate Java knowledge in a new situation instead of recalling a definition. In recent papers they include assertion and reason MCQs, picture or real-life scenario MCQs, find-and-fix code parts, writing an everyday rule as a Java statement and completing code with blanks.

Are there case study questions in ICSE Computer Applications?

Not as a separate section so far. The 2024 to 2026 papers kept the usual Section A and Section B, with scenario-based MCQs and real-world class questions instead. No 2027 Computer Applications specimen has been reported. Practising short cases still helps, because the reading skill is the same.

Are assertion and reason questions asked in ICSE Computer Applications?

Yes. They sit among the twenty one-mark MCQs of Question 1. The 2024 paper carried one, and the 2025 and 2026 papers carried two apiece, judging by solved copies. Treat each as three small decisions: is A true, is R true, and does R cause A.

How many competency based questions will be in ICSE 2027 Computer Applications?

Nobody can say yet for this paper. News reports of an October 2026 CISCE release say the 2027 specimen papers give about half the weight to higher-order skills, but the reported Class 10 list did not include Computer Applications. Check cisce.org for any specimen before trusting a number.

What are HOTS questions in ICSE Java?

Higher order thinking skill questions ask you to judge, repair or design rather than repeat. In this paper they look like: name the type of error and correct the code, order jumbled statements, fill blanks so a fragment works, or explain why a search or loop gives a wrong result.

How do I answer an assertion and reason question?

Decide whether the assertion is true, then whether the reason is true, each on its own. If both are true, ask whether the reason causes the assertion; if the assertion would still hold without it, choose "both true but R does not explain A". An assertion with a slightly wrong value, such as 5 for 5.0, is false.

How do I prepare for application based questions in ICSE Computer?

Practise reading code you did not write. Take programs with planted errors and name each error type, rewrite everyday rules as single Java statements, and run every guess in BlueJ to check it. Past-paper Section B classes, each built around a real service, are good practice too.

Is the ICSE Computer Applications paper pattern changing for 2027?

Nothing confirmed. The 2027 syllabus keeps a 100-mark paper with Section A of 40 compulsory marks and Section B of any four from six programs. Reports about competency weighting refer to specimen papers in selected subjects; until CISCE publishes something for this paper, prepare for the pattern of recent years.

Each answer is explained aloud and checked in BlueJ. A private one to one slot, timed around the family, is the other route.
