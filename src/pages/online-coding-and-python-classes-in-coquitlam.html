Online coding and Python classes in Coquitlam

Where can a Coquitlam student learn Python live online?

Coquitlam students from age 6 to adult can learn coding and Python with Modern Age Coders in live online classes on BC time. Each class has a real teacher reading the student's code as it is typed, in a group of fifteen to twenty or a private lesson. Python and AI for Kids and Python for Teens are the usual first courses, and the first class is free.

British Columbia changed its clocks for the last time in March 2026. Since then Pacific time has stayed seven hours behind UTC, so a Coquitlam family no longer has to re-learn its class times every November. That makes this a good moment to explain plainly how a live online class is arranged from Coquitlam: what a group class and a private class each give you, when they can run, and how either fits beside what BC schools teach in Applied Design, Skills, and Technologies and in Computer Programming 11 and 12. The page ends with a small Python project on a City of Coquitlam file, chosen because its distances are written as text, which is exactly the kind of mess a beginner has to learn to clean.

Because BC now stays on UTC-7, those India times do not move on 1 November 2026 or on 14 March 2027. What does move is the gap to Ontario. Under IANA tzdb 2026e, Toronto goes to UTC-5 on 1 November 2026, so from then until 14 March 2027 Coquitlam is two hours behind Toronto, and from 14 March 2027 it is three hours behind again. A class shared by Coquitlam and Ontario students therefore shifts by an hour on one side or the other on those dates.

Which Coquitlam walks are under 2 km and have washrooms? Let Python choose

The City of Coquitlam publishes a layer called Walking Jogging and Hiking Routes. It holds 12 routes, and its distances are stored as text, so a program has to turn them into numbers first. The results below are our own run on the file downloaded 22 October 2026.

Look at the DISTANCE column: half the values are written like 0.6km and half like 1.15 km, with a space. Python cannot compare either with 2.0 until it is cleaned. Our program does that in a two-line function, then answers questions with a second function whose options have default values:import json def km(text): return float(text.lower().replace("km", "").strip()) def pick_walks(routes, max_km, need_washroom=False, flat_only=False): chosen = [] for r in routes: if km(r["DISTANCE"]) > max_km: continue if need_washroom and r["WASHROOMS"] != "Yes": continue if flat_only and r["GRADE"].strip() != "Flat": continue chosen.append(r["NAME"]) return chosen with open("walking-routes.json", encoding="utf-8") as f: routes = [item["attributes"] for item in json.load(f)["features"]] print(sorted(km(r["DISTANCE"]) for r in routes)) print(pick_walks(routes, 2.0, need_washroom=True)) print(pick_walks(routes, 5.0, flat_only=True))

Text to number

km() lowers the text, removes “km”, strips spaces and calls float(). Run on all 12 rows it prints 0.6, 1.0, 1.15, 1.2, 1.2, 2.1, 2.7, 2.8, 4.0, 4.1, 5.6 and 5.7.

Under 2 km with washrooms

pick_walks(routes, 2.0, need_washroom=True) returns Stadium Loop, Lakeside Loop, Como Lake Loop Trail, Complex Loop and Mundy Lake Loop Trail: five routes, in the order the file stores them.

Flat and up to 5 km

pick_walks(routes, 5.0, flat_only=True) returns five routes too, including the DeBoville Slough Dike Trail at 4.1 km. It leaves out every route marked Flat / Minor Grade Change, because the test asks for exactly Flat.

The trailing space

The Coquitlam Crunch Trail's GRADE is stored as Steep followed by a space. Without .strip(), a test for the word Steep would miss it. Students find that bug by printing repr() of the value, which shows hidden spaces, and it teaches them to distrust a match that silently fails.

The extension task is a judgment, not code: should flat_only accept Flat / Minor Grade Change, and who decides? Students write the rule in a comment before they change the test. Python and AI

Does a Coquitlam student still need to write Python by hand?

Yes, because the walking routes file shows what goes wrong when nobody reads the data.

Ask an AI tool for the Coquitlam walks under 2 km and it will write a filter in seconds. Whether that filter handles 0.6km and 1.15 km alike, notices the space after Steep, or treats Flat / Minor Grade Change as flat is a coin toss, and the tool will sound sure either way.

We teach students to do the thinking first: read the data, write the function, test it on a value they can check by eye. Older students then use AI assistants under the age rules we follow, as a second reader to question, never as a source of answers to hand in.

A student who can explain why pick_walks returned five routes, and not six, owns the reasoning that a code generator cannot supply. The longer argument is in why reading code still matters with AI around.

Should my Coquitlam child take a group class or a private class?

A group of fifteen to twenty suits steady progress and learning from classmates. A private class suits faster progress, school projects or contest work. The syllabus is the same.

Do your class times change when the clocks change in BC?

No. BC has stayed on UTC-7 since March 2026, so a Coquitlam class keeps its local time all year.

Are classes held in a Coquitlam centre?

No. There is no centre in Coquitlam. All lessons are live online, so families in Port Coquitlam and Port Moody join from home too.

When can a child begin typed Python?

Most children can at about 9. From age 6 we teach blocks first. The free class checks reading and typing readiness rather than age alone.

How does this fit Computer Programming 11 at school?

It runs beside it. BC Computer Programming 11 covers input and output, decisions and loops; we give extra practice and projects in Python. The course and credit stay with the school.

Can Coquitlam students enter Waterloo contests?

Yes, through a school. CEMC lists the CCC for Wednesday 17 February 2027 and the Beaver Computing Challenge for 9 to 20 November 2026.

What times are classes for Coquitlam?

Weekdays or weekends, flexible: choose your batch, or for a very personalised plan choose 1-on-1 at your convenience, weekend mornings or weekdays. Times are confirmed in Pacific time.

Is there a Python course for adults in Coquitlam?

Yes. Adults start from zero if needed, in a group or privately, and often aim at automation or data work.

Will a 604 or 778 number work in the form?
