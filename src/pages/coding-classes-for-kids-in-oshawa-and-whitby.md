## Efficient code: the Ontario Grade 6 coding a child in Oshawa or Whitby meets

Schools in Oshawa and Whitby teach the Ontario curriculum. The Grade 6 math and science wording below was downloaded from the ministry&rsquo;s curriculum service on 22 October 2026. The ministry&rsquo;s words are quoted on the left, and our classroom version sits on the right.

- **Grade 6, C3.1**: Children solve problems &ldquo;by writing and executing efficient code&rdquo;, with conditions and other control structures. Our answer: We ask two questions of every program: does it work, and could it do the same job with less? Children enjoy finding the line nobody needed.
- **Grade 6, C3.2**: Children &ldquo;describe how changes to the code affect the outcomes and the efficiency of the code&rdquo;. Our answer: We time programs. A version that reads a file once and a version that reads it eight times give the same answer, but one is clearly slower on a big file.
- **Grade 6, notes**: &ldquo;Efficient code may involve using the instructions to solve a problem, using the smallest amount of space to store program data, and/or executing as fast as possible.&rdquo; Our answer: Space and speed are both on the list. Our Whitby project uses a set to remember IDs it has seen, a classic speed trick children can explain in one sentence.
- **Grade 6, notes**: &ldquo;A flow chart can be used to plan and organize thinking.&rdquo; Our answer: Before typing, children draw boxes for steps and diamonds for decisions. A flow chart that fits on a page usually means a program that fits in their head.

The notes make a point we repeat often: &ldquo;Efficient code can be altered more easily than inefficient code to adapt to new mathematical situations.&rdquo; Their example is a probability simulation, where the number of trials goes up &ldquo;by changing the number of repeats rather than writing additional lines of code for each of the new trials&rdquo;. In our class that becomes a coin-flip program: one loop flips 10 coins, and changing one number makes it flip 10,000. Grade 6 science adds its own coding expectation, to write and run code &ldquo;with a focus on obtaining input in different ways for a variety of purposes&rdquo;, so our Grade 6 students also read input from the keyboard and from a file. More on the year is on [Ontario Grade 6 math and coding help](/ontario-grade-6-math-and-coding-help).

## How big is a typical Whitby park? An efficient program on the Town&rsquo;s parks file

The Town of Whitby publishes a points file of its parks, with a class for each (LOCAL, PARKETTE, DISTRICT and so on) and an area in hectares. Oshawa publishes open data too, but its licence document would not load when we tried on 22 October 2026, so this project uses Whitby data only. Every figure below is our own calculation from the Whitby download of that day.

**Whitby parks by CLASS, our calculation from the Town of Whitby Parks file (area column AREA1_HECT, which the metadata defines as area of park in hectares; one repeated ID counted once)**

| Class in the file | Parks | Mean area (ha) | Median area (ha) |
|---|---|---|---|
| LOCAL | 55 | 1.78 | 1.65 |
| PARKETTE | 33 | 0.39 | 0.39 |
| DISTRICT | 21 | 5.65 | 4.70 |
| WATERFRONT (TOWN) | 11 | 6.20 | 3.52 |
| TOWN PARK | 3 | 10.95 | 2.14 |
| OFFLEASH | 2 | 1.19 | 1.19 |
| FACILITY | 1 | 9.28 | 9.28 |
| LEASED TOWN LANDS | 1 | 14.39 | 14.39 |

The download has 128 rows but 127 parks: one ID appears twice with identical details, and another starts with a stray space, so the program strips spaces before comparing. 48 parks are under one hectare. The efficient part is the shape of the loop. A beginner might loop through the whole file once for each of the eight classes, eight passes. This program makes one pass, dropping each park into a list for its class as it goes, which is the Grade 6 idea of fewer wasted steps. A 12-year-old in our class writes:

```
import csv, statistics

sizes = {}
seen = set()
with open("whitby-parks.csv", encoding="utf-8-sig") as f:
    for park in csv.DictReader(f):
        pid = park["FACILITYID"].strip()
        if pid in seen:
            continue
        seen.add(pid)
        sizes.setdefault(park["CLASS"], []).append(float(park["AREA1_HECT"]))

for kind, ha in sizes.items():
    print(kind, len(ha), round(statistics.mean(ha), 2), round(statistics.median(ha), 2))
```

### A set for repeats

Checking whether an ID is in a set takes about the same time however many IDs it holds. Checking a long list means walking along it. For 128 rows either works; for a million, only one does.

### One mean that misleads

TOWN PARK has three parks: about 0.06, 2.14 and 30.66 hectares. Their mean is 10.95, larger than two of the three. The median, 2.14, describes the middle park far better.

### Typical is a choice

For PARKETTE the mean and median are both 0.39, because the sizes are even. Children learn to check both, and to say which one they used and why.

### The file and its description disagree

The Town&rsquo;s description lists five classes as included and says FACILITY is not included. The file holds a FACILITY row anyway, plus OFFLEASH and LEASED TOWN LANDS rows, and spells waterfront as WATERFRONT (TOWN). The dataset page says it was updated in December 2025, while the attached metadata says it was last updated in October 2024. Neither is wrong on purpose; they were written at different times. We teach children to report what the file actually contains and to note the mismatch.

There is a friendlier question in the AMENITIES column. Splitting it on commas, our count found Playspace listed at 90 of the 127 parks and Splashpad at 18, while 25 parks list no amenity at all. Park names are in the file, but several honour people, so in class we work with IDs and classes only. ### Younger writers allowed

### Why coders do well

Gauss questions reward careful counting, patterns and checking cases, the same habits efficient code needs. Neither requires memorised tricks.

### Practice without copying

CEMC keeps ten years of past contests free online. We send families there and teach with our own problems, labelled as ours, rather than reproducing CEMC papers.

One of our problems, for a Grade 6 child: a park is 1.65 hectares and a parkette is 0.39 hectares; how many parkettes, side by side, would cover about the same land as the park? Children estimate first, then check with a two-line program, then ask whether rounding up or down makes more sense. The [Gauss contest preparation page](/gauss-contest-preparation) goes further, and the [free CEMC resources guide](/cemc-free-resources-guide) lists the practice material. ## Durham evenings, Sunday mornings, and the clock in India

## If AI can code, why should an Oshawa or Whitby child learn?

Because efficient, correct code still needs someone who understands it.

An AI tool asked for the average size of a Whitby town park will happily report 10.95 hectares. A child who has seen the three numbers behind it knows that figure describes almost no real park, and knows to ask for the median. Spotting a misleading answer is a human job, and it starts with having done the work yourself.

Our students under 13 are not given adult chatbots. They learn how AI systems are trained and why they make mistakes through activities their teacher leads, and they spend most of each class reasoning: planning with a flow chart, writing a step, testing it, and fixing what breaks.

Ontario asks Grade 6 children to judge the efficiency of their own code, and judging work, not just producing it, is what keeps people useful next to AI. The longer argument is in [is learning to code still worth it](/blog/is-coding-worth-learning-2026).
