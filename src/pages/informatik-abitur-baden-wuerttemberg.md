# Informatik-Abitur Baden-Württemberg: Vorbereitung auf Englisch

In Baden-Württemberg schreibt nur ein Teil der Schulen überhaupt ein schriftliches Informatik-Abitur: Das Leistungsfach gibt es an Schulen im Schulversuch Informatik. Wer es belegt, bekommt einen Pflichtteil mit kurzen Basisaufgaben und wählt selbst drei von vier größeren Wahlaufgaben. ### Was sich geändert hat

Laut Aufgabenfundus galt von 2017 bis 2022 eine Bearbeitungszeit von 240 Minuten (in den Jahren 2021 und 2022 waren es 270), und die Lehrkraft wählte die Aufgaben aus. Seit 2023 wählen die Prüflinge selbst, seit 2024 werden 120 Bewertungseinheiten statt 60 Verrechnungspunkten vergeben.

Eine Programmierumgebung ist in der schriftlichen Prüfung als Hilfsmittel nicht erlaubt.

## Wie findet man das zweitgrößte Element eines Arrays?

Der Aufgabenfundus nennt "zweitgrößtes Element bestimmen" als Beispiel für eine Pflichtteilaufgabe. Die folgende Aufgabe dazu haben wir selbst geschrieben; sie ist keine echte Prüfungsaufgabe. Wir zeigen sie in Java und Python, weil der Erlass die im Kurs eingeführte Sprache zulässt.

**Aufgabe (unsere).** Gesucht ist der zweitgrößte verschiedene Wert eines Feldes ganzer Zahlen; das Feld enthält mindestens zwei verschiedene Werte. a) Implementieren Sie eine Methode. b) Eine Mitschülerin schlägt die Methode zweitgroessterFehler vor. Finden Sie zwei Eingaben, für die sie falsch rechnet, und erklären Sie die Ursachen.

**Zweitgroesster.java: richtige und fehlerhafte Variante** (Java)
```java
public class Zweitgroesster {
    // Liefert den zweitgroessten verschiedenen Wert; Voraussetzung: mindestens zwei verschiedene Werte.
    static int zweitgroesster(int[] a) {
        int erster = a[0];
        int zweiter = Integer.MIN_VALUE;
        for (int i = 1; i < a.length; i++) {
            if (a[i] > erster) {
                zweiter = erster;
                erster = a[i];
            } else if (a[i] < erster && a[i] > zweiter) {
                zweiter = a[i];
            }
        }
        return zweiter;
    }

    // Fehlerhafte Variante: Startwerte 0 statt Werte aus dem Feld, und gleich grosse Werte werden nicht abgefangen.
    static int zweitgroessterFehler(int[] a) {
        int erster = 0;
        int zweiter = 0;
        for (int x : a) {
            if (x >= erster) {
                zweiter = erster;
                erster = x;
            } else if (x > zweiter) {
                zweiter = x;
            }
        }
        return zweiter;
    }

    public static void main(String[] args) {
        int[][] tests = { {4, 9, 7, 9, 2}, {-5, -2, -8}, {3, 8} };
        for (int[] t : tests) {
            System.out.println(java.util.Arrays.toString(t) + " richtig: " + zweitgroesster(t)
                + ", fehlerhaft: " + zweitgroessterFehler(t));
        }
    }
}
```
Ausgabe mit OpenJDK 21, von uns ausgeführt: [4, 9, 7, 9, 2] richtig: 7, fehlerhaft: 9, [-5, -2, -8] richtig: -5, fehlerhaft: 0, [3, 8] richtig: 3, fehlerhaft: 3.

**Lösung zu b): zwei Fehler, zwei Testfälle (unsere Analyse)**

| Eingabe | Richtig | Fehlerhafte Variante | Ursache |
|---|---|---|---|
| {4, 9, 7, 9, 2} | 7 | 9 | die zweite 9 erfüllt x >= erster und schiebt die erste 9 auf Platz zwei |
| {-5, -2, -8} | -5 | 0 | Startwert 0 ist größer als jeder Wert im Feld und wird nie verdrängt |
| {3, 8} | 3 | 3 | unauffällig: dieser Test findet keinen der beiden Fehler |

Die dritte Zeile ist die wichtigste Beobachtung: Mit positiven, verschiedenen Zahlen sehen beide Methoden gleich gut aus. Fehler zeigen sich erst bei Duplikaten des Maximums und bei ausschließlich negativen Werten. Die richtige Variante vermeidet beides, indem sie mit dem ersten Feldelement startet und gleich große Werte ausdrücklich überspringt (a[i] < erster).

**zweitgroesster.py: dieselbe Idee in Python** (Python)
```python
def zweitgroesster(werte):
    erster = werte[0]
    zweiter = None
    for x in werte[1:]:
        if x > erster:
            zweiter = erster
            erster = x
        elif x < erster and (zweiter is None or x > zweiter):
            zweiter = x
    return zweiter

for t in [[4, 9, 7, 9, 2], [-5, -2, -8], [3, 8]]:
    print(t, zweitgroesster(t))
```
Ausgabe, von uns ausgeführt: [4, 9, 7, 9, 2] 7, [-5, -2, -8] -5, [3, 8] 3. Statt eines kleinsten int-Werts startet Python mit None für "noch kein zweiter Wert".

1. **Aus den Daten starten.** Ein Startwert wie 0 ist eine Vermutung über die Eingabe. Nehmen Sie das erste Element oder einen ausdrücklichen Platzhalter.
2. **Gleichheit mitdenken.** Die Aufgabenstellung sagt "verschiedener Wert". Prüfen Sie deshalb jedes > und >= darauf, was bei gleichen Werten passiert.
3. **Testfälle mit Absicht wählen.** Ein Test mit Duplikat, einer mit nur negativen Zahlen, einer mit genau zwei Elementen. Erst wenn alle drei stimmen, ist die Methode glaubwürdig.
