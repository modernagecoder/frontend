Ans. The short version

Wrapper classes in ICSE Class 10 are the library classes that wrap each primitive type in an object: Byte, Short, Integer, Long, Float, Double, Character and Boolean, all in java.lang. The 2027 syllabus lists twelve methods: parseInt, parseLong, parseFloat and parseDouble, which turn a String into a number, and the Character methods isDigit, isLetter, isLetterOrDigit, isLowerCase, isUpperCase, isWhitespace, toLowerCase and toUpperCase. Autoboxing converts a primitive to its wrapper automatically; unboxing does the reverse. Our live classes drill all of it in a small Tuesday and Wednesday evening group in India, with personalised one to one lessons for any family that needs another hour.

Q1. What are wrapper classes and library classes?

What are wrapper classes in Java? Library classes ICSE definitions

A wrapper class is a library class that stores one value of a primitive type inside an object and gives methods to work with it. A library class is a ready-made class that comes with Java, so a program can use it without writing it.

Primitive typeWrapper classSpelling trap

Four facts that answer most one-mark questions

  1. All eight wrapper classes are in the package java.lang, which every program imports automatically, so no import line is needed.
  2. Two names differ from their primitive: int becomes Integer and char becomes Character. The other six only gain a capital letter.
  3. Wrapper classes are needed because some parts of Java work only with objects, and because the conversion and testing methods live in these classes.
  4. String is a library class too, but it is not a wrapper class: there is no primitive type called string.

Primitive and composite types, which this chapter leans on, are defined on class as the basis of all computation, and the other big library class in the syllabus, Math, has its own page: Math library methods for ICSE Class 10.

Q2. What is autoboxing and unboxing?

Autoboxing and unboxing in Java, with output

Autoboxing is the automatic conversion of a primitive value into an object of its wrapper class; unboxing is the automatic conversion of a wrapper object back into its primitive value. Java does both by itself whenever one type is used where the other is expected.

PointAutoboxingUnboxing
DirectionPrimitive to wrapper objectWrapper object to primitive
ExampleInteger a = 25;int b = a;
Happens whenA primitive is stored where an object is expectedAn object is used in arithmetic or stored in a primitive
Who does itThe Java compiler, automaticallyThe Java compiler, automatically

Two methods outside the twelve on the syllabus list appear in some textbooks: Integer.valueOf("40") returns an Integer object (so Integer.valueOf("40") / 3 prints 13 after unboxing), and Integer.toString(70) returns the String "70". They are useful to recognise, but parseInt is the one to learn for the paper.

Q3. What does Integer.parseInt do, and what are the other parse methods?

Integer.parseInt ICSE: the four parse methods with exact outputs

Integer.parseInt(s) converts a String of digits into an int, so the value can be used in arithmetic. parseLong, parseFloat and parseDouble do the same for long, float and double. Every result below was printed by Java 21.

When a program needs parseInt

  1. A number arrives inside a String, for example a record such as Riya,78,91 read with nextLine().
  2. Digits are pulled out of a longer String with substring and must then be added or compared.
  3. A digit character has been collected into a String and needs its numeric value.

The return-type trap: char plus int

How to remember the eight

  1. Six start with is and answer a yes or no question, so they return boolean.
  2. Two start with to and hand back a changed character, so they return char.
  3. isWhitespace has a lower-case s in "space"; isLetterOrDigit has capital O and D.
  4. None of them changes the variable passed in; store the result if you need it.

These eight methods do most of the work in sentence programs, which are collected on ICSE Class 10 string programs, and longer fragments to trace, sorted by trap, sit on the output questions page.

Questions about wrapper classes

What students ask about wrapper classes in ICSE Class 10

What are wrapper classes in Java ICSE Class 10?

Wrapper classes are library classes that hold a primitive value inside an object and provide methods for it. There is one for each primitive type: Byte, Short, Integer, Long, Float, Double, Character and Boolean. They are in java.lang, so no import is needed.

What are library classes in ICSE?

Library classes are ready-made classes supplied with Java, grouped into packages, which a program can use without writing them. For ICSE Class 10 the ones that matter are the wrapper classes, Math, String and Scanner. The Library classes chapter itself covers the wrapper classes and autoboxing.

What is autoboxing and unboxing in Java?

Autoboxing is Java automatically converting a primitive value into an object of its wrapper class, as in Integer n = 45. Unboxing is the reverse, an Integer object automatically giving back its int, as in int k = n + 1. No method call is written for either.

What does Integer.parseInt do in ICSE?

Integer.parseInt(String s) converts a String containing a whole number into an int, so it can be used in arithmetic. Integer.parseInt("472") + 8 gives 480, while "472" + 8 gives 4728. If the String is not a valid whole number, such as "12.5", the program stops with a NumberFormatException.

Which Character class methods are in the ICSE syllabus?

Eight: isDigit, isLetter, isLetterOrDigit, isLowerCase, isUpperCase and isWhitespace, which return boolean, and toLowerCase and toUpperCase, which return char. Each takes one char and is called on the class, as in Character.isDigit(ch).

Which wrapper class methods must I learn for ICSE 2027?

The syllabus lists twelve: parseInt, parseLong, parseFloat and parseDouble, and the eight Character methods isDigit, isLetter, isLetterOrDigit, isLowerCase, isUpperCase, isWhitespace, toLowerCase and toUpperCase. Learn each one's return type as well as what it does.

Why does Character.toUpperCase('a') + 1 print 66?

toUpperCase returns the char A, whose code is 65. Adding the int 1 to a char gives an int, so 66 is printed. To print the letter B, cast the result back: (char) (Character.toUpperCase('a') + 1).

Is String a wrapper class?

No. String is a library class in java.lang, but it is not a wrapper class, because there is no primitive type called string for it to wrap. The eight wrapper classes match the eight primitive types exactly.

What is the difference between Integer and int?

int is a primitive type that stores a whole number directly. Integer is a wrapper class whose object holds an int and offers methods such as parseInt. Java converts between them automatically through autoboxing and unboxing.
