Ans. The short version

Class as the basis of all computation means that every Java program is written as one or more classes, and all data and work happen inside them. An object is an entity with state (its data members) and behaviour (its member methods). A class is the blueprint that describes such objects, so it works as an object factory. Because the programmer creates it, a class is a user defined, composite data type. Instance variables get a copy in each object; a static class variable is shared. Q1. Why is a class called the basis of all computation?

Why is class called the basis of all computation? Definitions in one sentence

A class is called the basis of all computation because in Java every program is written inside a class, and every piece of data the program works on belongs either to a primitive variable or to an object built from a class. These are the definitions the chapter asks for, one sentence each.

TermOne-sentence definition
ObjectAn entity that has a state, the values of its characteristics, and a behaviour, the actions it can perform.
StateThe data an object holds at a moment, stored in its data members (member variables).
BehaviourWhat an object can do, written as the member methods of its class.
ClassA blueprint or template that declares the data members and member methods shared by a set of similar objects.
Class as an object factoryA class can produce any number of objects of the same kind, each with its own state, using new.
InstanceAn object is called an instance of its class, because it is one concrete example of that blueprint.
Class as an abstractionA class keeps only the features of an object that matter to the program and leaves out the rest.
User defined data typeA class is a data type the programmer creates, so variables of that class type can be declared just like int variables.
new operatorAllocates memory for a new object and returns a reference to it, which is stored in a variable of the class type.

Q2. Why is a class a user defined data type?

Class as user defined data type: primitive against composite types

A class is a user defined data type because the programmer creates it, and once it exists, variables of that type can be declared and objects of it created. It is composite because one object bundles several values, possibly of different types, together with the methods that use them.

Why not every class is treated as a data type

A class written only to hold main and run a task is used as a program, not as a type. A class such as WaterTank, from which other code declares variables and creates objects, is the one that behaves as a user defined data type. Examiners accept either view if it is explained in a sentence.

Declaring variables of a class type

  1. WaterTank roof; declares a reference; no tank exists yet.
  2. roof = new WaterTank(1000); creates the object and stores its reference.
  3. WaterTank sump = new WaterTank(2000); does both in one line.

Q3. What is the difference between instance variables and class variables?

Instance variables vs class variables ICSE, with outputs

An instance variable is a data member declared without static, so every object gets its own copy; a class variable is declared static, so one copy is shared by all objects of the class. The syllabus lists these, together with argument and local variables, under the scope of variables in the Encapsulation chapter, and they are asked alongside this one.

Q4. How do you turn a Section B question into a class?

Design a class: from question text to finished program

Read the question twice and pull out its nouns and its verbs: the nouns that describe one thing become data members, the verbs become methods, and anything counted across all objects becomes a static member. Then write the parts in a fixed order.

  1. Name the class

    Use the name the question gives, with a capital first letter. If none is given, choose a singular noun: Batsman, not Batsmen.

  2. List the data members

    One line per member, with its type and a short comment. Mark shared totals or counters static.

  3. Write the constructor

    Set every member to a sensible start: 0, 0.0, an empty String, or the value passed in.

  4. Write one method per task

    Input, calculation and display are kept separate, with the method names and return types the question states.

  5. Write main last

    Create the object or objects with new and call the methods in the order the task needs.

  6. Add the variable description table

    Every variable, its type and its purpose. Section B asks for variable descriptions, and they carry marks in internal assessment too.

Questions about classes and objects

What students ask about class as the basis of all computation

Why is class called the basis of all computation in Java?

Because a Java program cannot exist outside a class. All code is written in classes, and all data either sits in a primitive variable inside a class or is stored in objects created from classes. So every computation a program performs happens within, or on, a class.

What is an object in ICSE Class 10?

An object is an entity with a state and a behaviour. Its state is the set of values in its data members, such as a fan's speed; its behaviour is what it can do, written as member methods, such as changing speed. In Java an object is created from a class with new.

What is a class in Java for ICSE?

A class is a blueprint or template that declares the data members and member methods common to a group of similar objects. It describes what every object of that kind will have and do, and objects are then created from it.

Why is a class called an object factory?

Because one class can produce as many objects as the program needs, all with the same structure but each with its own state. Every use of new on the class turns out another object, just as a factory turns out products from one design.

Why is a class known as a user defined data type?

Because the programmer defines it, and once defined, it can be used like any other type: variables of the class type are declared and objects are stored in them. It is a composite type, since one object holds several values and the methods that use them.

What is the difference between instance variables and class variables?

An instance variable is declared without static, so every object has its own copy. A class variable is declared static, so a single copy is shared by all objects and can be used through the class name. Changing an instance variable affects one object; changing a class variable affects them all.

What is the difference between primitive and composite data types?

Primitive types such as int, double, char and boolean are built into Java and hold a single value directly. Composite types are classes, such as String or a class you write; a variable of a composite type holds a reference to an object that may contain many values.

Is this chapter asked in Section B of the ICSE paper?

Not as a separate question, but every Section B program is a class, so the chapter is used in all of them. Its definitions and differences are asked directly in Section A, as one-mark and two-mark questions.

Where do instance and class variables come in the ICSE syllabus?

The 2026-27 syllabus for the 2027 exam lists class, instance, argument and local variables under the scope of variables in the Encapsulation chapter. Schools usually teach the instance and class distinction alongside objects and classes, as this page does.
