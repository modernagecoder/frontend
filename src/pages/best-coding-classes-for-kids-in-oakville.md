## Efficient code and input: what Grade 6 asks of an Oakville student

Oakville schools teach the Ontario curriculum, in which Grade 6 asks for code in two subjects. We pulled both from the Ontario curriculum&rsquo;s own data service on 22 October 2026. Quotes are the ministry&rsquo;s; the reading of them is ours.

- **Math C3.1**: Students solve problems by writing and executing &ldquo;efficient code&rdquo;, with conditional statements and other control structures. Our answer: Working code is no longer the finish line. A Grade 6 student is asked whether the code does its job without wasted steps.
- **Math C3.2**: Students describe how changes affect &ldquo;the outcomes and the efficiency of the code&rdquo;. Our answer: Two programs can print the same answer; one may take far longer. Children learn to compare, not just to finish.
- **Science A2**: Students &ldquo;use coding in investigations and to model concepts&rdquo; and assess the impact of coding on everyday life. Our answer: Code turns up in science class too, as a tool for experiments and models.
- **Science A2.1**: Code in investigations, &ldquo;with a focus on obtaining input in different ways&rdquo;. Our answer: This is the expectation closest to robotics: reading a sensor, a keyboard or a file is all input.

A small example of efficiency, written by us for Grade 6 students. Both lines of output are 5050, the sum of the whole numbers from 1 to 100, but the first takes a hundred additions and the second takes one multiplication and one division:

```
total = 0
for n in range(1, 101):
    total = total + n
print(total)
print(100 * 101 // 2)
```

Asking why the shortcut works, and when a loop is still the better choice, is exactly the conversation C3.2 wants.

## How many Oakville drop-in programs suit a 9-year-old? First, clean the labels

The Town of Oakville publishes its recreation and culture drop-in programs as open data, with an AGES column. Before our students aged about 10 to 12 can filter by age, they have to turn messy words into numbers. All counts here are ours, not the Town&rsquo;s.

**What the AGES column looks like: our count of the Town of Oakville Recreation and Culture Drop in Programs file, downloaded 22 October 2026 (200 rows)**

| What we found | Rows | What the cleaning step does |
|---|---|---|
| &ldquo;50+ &rdquo; with a trailing space | 52 | strip() removes the space, so it matches &ldquo;50+&rdquo; |
| &ldquo;All Ages&rdquo; and &ldquo;All ages&rdquo; | 35 and 1 | lower() makes them one label |
| &ldquo;13-17&rdquo; and &ldquo;13 to 17&rdquo; | 1 and 1 | Replacing the hyphen with &ldquo; to &rdquo; makes them one shape |
| &ldquo;8 years and under&rdquo; and similar | 9 | Read as 0 up to the first number |
| &ldquo;Grades 6 to 12&rdquo; | 11 | Skipped: grades are not ages, and guessing would be wrong |
| A row whose age label is simply &ldquo;Test&rdquo; | 1 | Skipped: a leftover test entry, not a program |

Our script, standard library only. The function age_range returns a (lowest, highest) pair or None, and the main loop counts programs a 9-year-old fits:

```
import csv

def age_range(label):
    text = label.strip().lower().replace("-", " to ")
    if text == "all ages":
        return (0, 120)
    if text.endswith("+"):
        return (int(text[:-1]), 120)
    if text.endswith("years and under"):
        return (0, int(text.split()[0]))
    if " to " in text and not text.startswith("grades"):
        low, high = text.split(" to ")
        return (int(low), int(high))
    return None

fits = {}
skipped = []
with open("drop_in_programs.csv", encoding="utf-8-sig") as f:
    for row in csv.DictReader(f):
        span = age_range(row["AGES"])
        if span is None:
            skipped.append(row["AGES"].strip())
            continue
        if span[0] <= 9 <= span[1]:
            section = row["SECTION_HEADER"]
            fits[section] = fits.get(section, 0) + 1

print(fits)
print(sorted(set(skipped)), len(skipped))
```

### What it found

Of the 200 rows, 188 turn into an age range and 12 are skipped. Of the 188, 44 fit a 9-year-old: 15 recreational swimming, 13 recreational skating, 8 drop-in sports, 4 museum programs, 2 fitness classes and 2 art studios.

## Why should an Oakville child learn to clean data when AI can do it?

Because the cleaning rules are decisions, and somebody has to make them.

An AI tool asked to count programs for a 9-year-old might quietly turn &ldquo;Grades 6 to 12&rdquo; into ages 6 to 12, or keep the row called Test. Either choice changes the answer, and neither is announced. A child who has written age_range by hand knows those rows exist and decides, on purpose, what to do with them.

Our classes for children put that judgment first: look at the data, decide the rule, write it, check it. Children learn how AI tools work and how they fail, and they use what they learn to question answers rather than accept them. At home, remember that OpenAI&rsquo;s rules require a parent&rsquo;s permission for anyone under 18 using ChatGPT.

Ontario asks Grade 6 students to judge whether code is efficient; judging whether an answer is right comes before that. The longer argument is in [is coding still worth learning in 2026](/blog/is-coding-worth-learning-2026).
