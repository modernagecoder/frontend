Q3. Which program gets built on a Wednesday?

A String handling program from the Bengaluru batch, traced word by word

String programs turn up in Section B almost every year, and they punish students who have only memorised one pattern. This one is original: it reads a sentence, rewrites every word with a capital first letter, finds the longest word and counts words that begin and end with the same letter.

The question. Write a program to accept a sentence. Print it with the first letter of each word in capitals and the rest in small letters. Also print the longest word with its length, and the number of words whose first and last letters are the same, ignoring case. Words are separated by one or more spaces.

Trace of the second run, one word at a time

The four ideas this program is really testing

  • The sentinel space. Adding " " to the end means the last word is processed inside the loop. Forget it, and the last word is silently ignored: a classic lost mark.
  • Strings do not change in place. word.substring(1).toLowerCase() returns a new String; it has to be joined into title or it is lost.
  • Comparing chars, not Strings. first == last is correct because both are char. For two Strings, == would be wrong and equals would be needed.
  • Strictly greater. > keeps the first of two equally long words. Using >= would change the answer when there is a tie, and the question should be read for which one it wants.

More programs of this kind, from palindrome words to letter frequency, each run in Java, are on ICSE Class 10 String programs.

Q4. How does a full week run?

A sample week in the String handling unit, for a Bengaluru ICSE student

In many schools String handling is taught in the second half of Class 10, not long before the preboards, so the weeks are tight. This is how one such week is spread out so that no single evening carries too much.

  1. Tuesday class, 5:30 PM IST

    The String methods the syllabus names, taught by predicting what each call returns: charAt, indexOf, substring, compareTo, equalsIgnoreCase, replace and the rest. Twelve short output questions follow, answered in writing first and then checked.

  2. Wednesday class, 8:00 PM IST

    The WordScan program above: the plan on paper, the code in BlueJ, three test runs including the awkward one, and the variable description. Marks are given against the scheme so the student sees exactly where the 15 go.

  3. Thursday, at home, 25 minutes

    A variation of the same program with one change: count vowels in each word instead of matching first and last letters. The student writes it alone and runs it.

  4. Weekend, at home, 40 minutes

    A worksheet mixing String outputs with two error-finding questions. Anything left unsolved is the first thing raised on Tuesday.

  5. School lab period, whenever it falls

    The school's own assignments carry on as the teacher sets them. If one of them uses Strings, the student now has the method and the test habit to do it independently.

Output questions on String methods, sorted by trap, are on ICSE Java output questions.

Q5. How is the lab file supported?

School lab assignments and the internal assessment: what we do and what we leave to the school

The internal assessment is the school's process from start to finish. We make the student ready for it: able to write, document, run and defend each program they submit.

CISCE weighs the internal assessment equally with the written paper, 100 marks each. It is awarded on a minimum of twenty laboratory assignments across the year, half the marks by the subject teacher and half by an external examiner. Ten of every fifty go to the variable description, and another ten to coding and documentation, so a program that runs but is not explained can still lose a fifth of its marks.

Two lines we do not cross. We never write an assignment for a student to submit, and we never change the school's question or format to suit our teaching. What we will do is take a school question the student finds hard, teach the idea behind it with a different example, and then watch the student solve the real one themselves. Bengaluru questions

What Bengaluru parents ask about ICSE Java tuition

Is there a Modern Age Coders centre in Bangalore?

No. We have no centre in Bengaluru and no home tutors there. All ICSE Computer Applications classes are live online: the teacher and up to six students meet on screen, and every program is written and run in BlueJ while the teacher watches. If you need in-person teaching, a local tutor is the better fit.

What time are the ICSE computer classes in Bangalore?

Class runs twice a week: Tuesdays from 5:30 PM IST and Wednesdays from 8:00 PM IST, and those are simply Bengaluru times. Tuesday covers concepts and Section A questions; Wednesday is for one full Section B program. If neither evening is free, one to one classes run at a time you choose.

Which is better for ICSE Class 10 Java, a home tutor or online classes?

It depends on the child. A home tutor helps a student who needs someone physically present. Online works well for Java because the subject is done on a screen: the teacher sees the code as it is typed and run. Whichever you choose, make sure programs are actually run, not only checked on paper.

Do you teach the Karnataka SSLC computer syllabus?

No. We teach only the CISCE ICSE Class 10 Computer Applications syllabus, in Java with BlueJ, for the 2027 examination. Students on the Karnataka state board or CBSE follow different syllabi and would not fit this class.

How do you help with ICSE computer lab assignments?

Your school decides the questions, the deadlines and the internal marks. Our job is to teach the ideas behind each question, have the student talk through their class design and write a proper variable description, and run each program with awkward test cases. We never write assignments for students to hand in.

How many String programs should a student practise for ICSE?

Enough to cover the main families rather than a fixed number: word extraction, counting characters, changing case, palindromes, reversing words and comparing Strings. Each new program should be written without looking at an old one, then run with tricky input such as extra spaces or capitals.

What does ICSE computer tuition cost in Bengaluru?

Both monthly fees, batch and one to one, are printed on this page in your currency. You pay month by month with no admission charge, and the first class costs nothing. When comparing with a local tutor, compare what each hour contains: code written, code run, code marked.

Is the batch only for Class 10?

The mini batch on this page is for ICSE Class 10 students preparing for the 2027 paper. The course also covers Class 9, and a Class 9 student can start with personalised one to one classes. Ask in the demo which route fits.

Can my child join after the preboards?

Yes. A student joining late gets a quick diagnostic, then a plan that goes straight to the highest-value work: Section B program families, timed papers and the Section A traps they keep falling into. A winter start is workable if the student commits to the weekly papers.

What is the free demo like?

Your child writes a short Java program live, with a teacher watching and asking questions. You then hear honestly where they stand, what to fix first, and whether the evening batch or a one to one slot would serve them better.
