# KI-Kurs für Kinder: verstehen, wie Maschinen lernen

Kinder begegnen KI im Sprachassistenten, in Videoempfehlungen und bald im Unterricht. Verstehen lernen sie sie am besten, indem sie selbst eine kleine Maschine bauen, die aus Beispielen lernt. Diese Seite zeigt, warum wir dafür keine Chatbots einsetzen, wie oft Kinder in Deutschland laut KIM-Studie 2024 schon KI nutzen, was die Kultusministerkonferenz dazu sagt, und ein Ratespiel, mit dem ein Kind in einer Stunde seine erste KI programmiert. Der Unterricht findet auf Englisch statt, mit Mentoren aus Indien.

Auf einen Blick: Unterrichtssprache: Live-Unterricht ausschließlich auf Englisch, im eigenen Tempo; die Mentoren sprechen deutlich und stellen sich auf Tempo und Akzent der Lernenden ein; Alter: 6 bis 12 Jahre; Werkzeuge: Papier, Scratch, ab etwa 10 Python; Chatbots: Keine, kein KI-Konto nötig; Gruppe: Fünfzehn bis zwanzig, oder einzeln; Sprache: Englisch, langsam und deutlich; Probestunde: Kostenlos, ohne Karte. 4,9 von 5 bei 547 Google-Bewertungen.

### Was das für ein Kind von 8 Jahren heißt

Für ein Grundschulkind ist keines dieser Angebote vorgesehen. Ein Kurs, der Kinder trotzdem in Chatbots tippen lässt, umgeht die Regeln, die die Anbieter selbst aufgestellt haben. Unser Kinderkurs kommt deshalb ohne Konto bei einem KI-Anbieter aus.

Das ist kein Verzicht. Wer selbst eine Maschine baut, die aus Beispielen Regeln ableitet, versteht später auch einen großen Chatbot besser: Er rechnet mit Daten, er kann danebenliegen, und er weiß nur, was in seinen Beispielen steckt.

### Was wir stattdessen tun

Die Kinder sortieren Karten, stellen Ja-Nein-Fragen, zeichnen Entscheidungsbäume und bauen daraus Programme in Scratch und Python. Am Ende jeder Einheit steht eine kleine Maschine, die etwas erkennt, rät oder sortiert, und die das Kind selbst erklären kann.

Jugendliche ab 13 dürfen manche Werkzeuge mit Zustimmung ihrer Eltern verwenden. Das ist ein Thema für unsere Kurse für Jugendliche, nicht für diesen.

## Wie baut ein Kind seine erste KI?

Mit einem Ratespiel. Ein Kind denkt an ein Tier, die Maschine stellt Ja-Nein-Fragen und rät. Der Trick, den die Kinder dabei entdecken, ist derselbe, mit dem viele echte Systeme ihre Entscheidungen treffen: Eine gute Frage teilt die Möglichkeiten in zwei gleich große Hälften. Das Beispiel ist unser eigenes.

**Unsere acht Tierkarten und vier Fragen (1 = ja, 0 = nein)**

| Tier | Fell? | Wohnt im Haus? | Größer als ein Mensch? | Frisst andere Tiere? |
|---|---|---|---|---|
| Katze | 1 | 1 | 0 | 1 |
| Hamster | 1 | 1 | 0 | 0 |
| Löwe | 1 | 0 | 1 | 1 |
| Pferd | 1 | 0 | 1 | 0 |
| Frosch | 0 | 0 | 0 | 1 |
| Schnecke | 0 | 0 | 0 | 0 |
| Hai | 0 | 0 | 1 | 1 |
| Nilpferd | 0 | 0 | 1 | 0 |

**Für Kinder von 6 bis 9: erst auf Papier, dann in Scratch.** So läuft die Einheit in fünf Schritten, jeder etwa zehn Minuten lang.

1. **Karten sortieren.** Das Kind legt die acht Tierkarten auf den Tisch und sucht eine Frage, auf die genau vier Tiere mit Ja antworten. "Hat es ein Fell?" funktioniert, "Wohnt es bei Menschen im Haus?" nicht, denn da sind es nur zwei.
2. **Den Baum zeichnen.** Für jeden Stapel sucht es wieder eine Frage, die ihn halbiert. Nach drei Fragen liegt auf jedem Stapel nur noch ein Tier. Diese Zeichnung ist ein Entscheidungsbaum.
3. **In Scratch übertragen.** Mit dem Block frage [Hat es ein Fell?] und warte stellt die Figur die erste Frage. Ein Block falls <(Antwort) = [ja]> dann ... sonst teilt das Programm in zwei Wege, so wie der Baum auf dem Papier.
4. **Raten lassen.** Am Ende jedes Weges steht ein Block sage [Ist es ein Hamster?]. Das Kind spielt mit Eltern oder Geschwistern und zählt, wie viele Fragen die Figur braucht.
5. **Die Maschine überlisten.** Jetzt kommt ein neues Tier dazu, ein Hund. Das Kind merkt: Für Katze und Hund gibt der Baum dieselben Antworten. Die Figur braucht eine neue Frage.

**Für Kinder ab etwa 10: die Maschine wählt ihre Fragen selbst** (Python)
```python
FRAGEN = ['Hat es ein Fell?', 'Wohnt es bei Menschen im Haus?',
          'Ist es größer als ein Mensch?', 'Frisst es andere Tiere?']

TIERE = {
    'Katze':    [1, 1, 0, 1],
    'Hamster':  [1, 1, 0, 0],
    'Löwe':     [1, 0, 1, 1],
    'Pferd':    [1, 0, 1, 0],
    'Frosch':   [0, 0, 0, 1],
    'Schnecke': [0, 0, 0, 0],
    'Hai':      [0, 0, 1, 1],
    'Nilpferd': [0, 0, 1, 0],
}

def gute_frage(namen, tiere):
    # Die gute Frage teilt die Gruppe möglichst genau in zwei Hälften.
    wahl, abstand = None, None
    for nr in range(len(FRAGEN)):
        ja = sum(tiere[n][nr] for n in namen)
        a = abs(ja - (len(namen) - ja))
        if ja > 0 and ja < len(namen) and (abstand is None or a < abstand):
            wahl, abstand = nr, a
    return wahl

def zaehle_fragen(namen, tiere, tiefe=0, ergebnis=None):
    if ergebnis is None:
        ergebnis = {}
    if len(namen) == 1:
        ergebnis[namen[0]] = tiefe
        return ergebnis
    nr = gute_frage(namen, tiere)
    if nr is None:
        print('Nicht zu unterscheiden:', ' und '.join(namen))
        for n in namen:
            ergebnis[n] = None
        return ergebnis
    ja = [n for n in namen if tiere[n][nr] == 1]
    nein = [n for n in namen if tiere[n][nr] == 0]
    zaehle_fragen(ja, tiere, tiefe + 1, ergebnis)
    zaehle_fragen(nein, tiere, tiefe + 1, ergebnis)
    return ergebnis

# Versuch 1: acht Tiere, die Maschine wählt ihre Fragen selbst
fragen = zaehle_fragen(list(TIERE), TIERE)
print('Erste Frage:', FRAGEN[gute_frage(list(TIERE), TIERE)])
print('Fragen pro Tier:', fragen)
print('Durchschnitt:', sum(fragen.values()) / len(fragen))

# Zum Vergleich: der Reihe nach raten ("Ist es eine Katze?")
raten = [min(i + 1, len(TIERE) - 1) for i in range(len(TIERE))]
print('Der Reihe nach raten, Durchschnitt:', sum(raten) / len(raten))

# Versuch 2: ein neues Tier kommt dazu
TIERE['Hund'] = [1, 1, 0, 1]
zaehle_fragen(list(TIERE), TIERE)

# Versuch 3: eine neue Frage hilft
FRAGEN.append('Kann es bellen?')
for n in TIERE:
    TIERE[n].append(1 if n == 'Hund' else 0)
fragen = zaehle_fragen(list(TIERE), TIERE)
print('Mit der neuen Frage:', fragen['Katze'], 'Fragen für die Katze,', fragen['Hund'], 'für den Hund')
print('Durchschnitt:', round(sum(fragen.values()) / len(fragen), 2))
```
Ausgabe, so wie wir das Programm mit Python 3.14 ausgeführt haben:Erste Frage: Hat es ein Fell?Fragen pro Tier: {'Katze': 3, 'Hamster': 3, 'Löwe': 3, 'Pferd': 3, 'Hai': 3, 'Nilpferd': 3, 'Frosch': 3, 'Schnecke': 3}Durchschnitt: 3.0Der Reihe nach raten, Durchschnitt: 4.375Nicht zu unterscheiden: Katze und HundMit der neuen Frage: 4 Fragen für die Katze, 4 für den HundDurchschnitt: 3.22

Was die Kinder daraus lernen: Die Maschine schaut sich für jede Gruppe an, welche Frage sie am gleichmäßigsten teilt, und wählt diese. So kommt sie bei acht Tieren immer mit drei Fragen aus. Wer dagegen der Reihe nach fragt, "Ist es eine Katze? Ist es ein Hamster?", braucht im Schnitt 4,375 Fragen. Als der Hund dazukommt, meldet das Programm: Nicht zu unterscheiden. Erst die neue Frage "Kann es bellen?" trennt die beiden, und der Durchschnitt steigt auf 3,22 Fragen für neun Tiere.

1. **Eine gute Frage halbiert die Gruppe.** Je gleichmäßiger eine Frage teilt, desto schneller ist die Maschine am Ziel.
2. **Die Maschine weiß nur, was in ihren Daten steht.** Gibt es keine Frage, die Katze und Hund trennt, kann sie die beiden nicht unterscheiden, egal wie schnell sie rechnet.
3. **Neue Beispiele brauchen manchmal neue Merkmale.** Das gilt für ein Ratespiel genauso wie für große Systeme, die Bilder erkennen oder Texte sortieren.

## Woran Eltern sehen, dass ihr Kind KI versteht

Fünf Stufen, die wir selbst verwenden, um den Lernstand zu beschreiben und Eltern zu berichten.

**Fünf Stufen im KI-Kurs für Kinder (unsere)**

| Stufe | Typisches Alter | Ihr Kind kann |
|---|---|---|
| 1. Sortieren | 6 bis 7 | Dinge nach einem Merkmal in zwei Gruppen teilen und sagen, nach welchem |
| 2. Gut fragen | 7 bis 9 | eine Frage finden, die eine Gruppe ungefähr halbiert |
| 3. Baum bauen | 8 bis 10 | einen Entscheidungsbaum zeichnen und in Scratch umsetzen |
| 4. Lernen lassen | 10 bis 12 | ein Programm aus einer Tabelle von Beispielen seine Fragen selbst wählen lassen |
| 5. Grenzen erklären | 11 bis 12 | zeigen, wann eine Maschine scheitert, und begründen, warum |

### Für Eltern

Fragen Sie Ihr Kind nach einer Stunde nicht nur, was es gebaut hat, sondern warum die Maschine einmal falsch geraten hat. Diese Antwort zeigt am besten, was es verstanden hat.
Nach den Stunden bekommen Sie eine kurze Rückmeldung: was geübt wurde, was gut lief und was als Nächstes kommt.

### Für Kinder

Raten Sie selbst mit, bevor das Programm rät. Wer schneller richtig liegt, gewinnt die Runde.
Wenn die Maschine sich irrt, ist das kein Fehler von Ihnen, sondern ein Hinweis: Ihr fehlt eine Frage.

## KI-Kurs für Kinder: häufige Fragen

### Findet der Unterricht auf Deutsch statt?

Nein, jede Stunde läuft live und nur auf Englisch, mit Mentoren aus Indien, die langsam und deutlich sprechen und sich auf Tempo und Aussprache Ihres Kindes einstellen. Für viele Familien ist das ein Vorteil: Ihr Kind lernt, wie KI funktioniert, und übt dabei ganz nebenbei Englisch, die Sprache, in der Programmiersprachen geschrieben sind.

### Ab welchem Alter kann mein Kind am KI-Kurs teilnehmen?

Ab 6 Jahren. Die Jüngsten arbeiten mit Karten, Bildern und einfachen Blöcken, ab etwa 8 Jahren mit Scratch und ab etwa 10 Jahren mit ersten Python-Programmen. Lesen und Schreiben müssen noch nicht sicher sein, der Mentor zeigt viel und liest Aufgaben vor.

### Benutzt mein Kind im Kurs ChatGPT oder einen anderen Chatbot?

Nein. Viele Chatbots sind laut ihren eigenen Bedingungen nicht für Kinder gedacht: Claude erst ab 18 Jahren, ChatGPT ab 13 Jahren, bis zur Volljährigkeit nur mit Zustimmung der Eltern. Ein eigenes Google-Konto darf man in Deutschland erst ab 16 Jahren selbst verwalten. Unsere Kinder bauen ihre KI selbst, dafür braucht es kein Konto bei einem KI-Anbieter.

### Lernt mein Kind wirklich etwas über KI, wenn es keinen Chatbot nutzt?

Ja, sogar mehr. Wer selbst eine Maschine baut, die aus einer Tabelle von Beispielen ihre Fragen wählt, erlebt, wie Lernen aus Daten funktioniert und wo es an Grenzen stößt. Genau dieses Verständnis der Funktionsweise nennt die Kultusministerkonferenz in ihrer Handlungsempfehlung von 2024 unabdingbar.

### Wie viele Kinder in Deutschland nutzen schon KI?

Laut KIM-Studie 2024 des Medienpädagogischen Forschungsverbunds Südwest nutzen 9 Prozent der Kinder, die online sind, mindestens einmal pro Woche KI-Anwendungen. 81 Prozent der Schulkinder setzen KI zu Hause nie für die Schule ein. Befragt wurden 1.225 Kinder zwischen sechs und 13 Jahren im Herbst 2024.

### Wird in der Grundschule schon KI unterrichtet?

Das hängt vom Land und von der Schule ab. Die Kultusministerkonferenz hat ihren Kompetenzrahmen im Oktober 2026 um KI ergänzt. Ob Sprachmodelle schon in der Grundschule eingesetzt werden sollen, ist offen: Die Wissenschaftliche Kommission empfiehlt weitgehenden Verzicht, die Länder halten das für erörterungsbedürftig. Unser Kurs vergibt keine Noten und ersetzt keinen Schulunterricht.

### Braucht mein Kind Vorkenntnisse im Programmieren?

Nein. Wir beginnen mit Spielen auf Papier und bauen erst danach Programme. Kinder, die schon Scratch kennen, steigen später ein und kommen schneller zu Python.

### Zu welchen Uhrzeiten kann mein Kind teilnehmen?

Unter der Woche oder am Wochenende, flexibel: Wählen Sie eine Gruppe, oder für einen ganz persönlichen Plan den Einzelunterricht zu einer Zeit, die Ihrer Familie passt, am Wochenendvormittag oder an Nachmittagen unter der Woche. Zur Orientierung: Beginnt die Stunde im Winter um 14:50 Uhr deutscher Zeit, ist es beim Mentor in Indien 19:20 Uhr.

### Was kostet der Kurs, und in welcher Währung zahle ich?

Oben auf dieser Seite steht die Monatsgebühr in Euro; als Grundlage dient der Referenzkurs der EZB. Belastet wird Ihr Konto in US-Dollar, den Wechsel in Euro erledigt Ihre Bank. Für die erste Stunde zahlen Sie nichts und brauchen keine Kreditkarte.

### Wie geht es nach dem KI-Kurs weiter?

Viele Kinder machen mit Python und eigenen Projekten weiter. Wer forschen möchte, kann bei Jugend forscht junior ab der 4. Klasse und bis 14 Jahre antreten, die Anmeldung läuft beim Veranstalter. Ab 13 Jahren führen unsere Kurse für Jugendliche zu maschinellem Lernen mit echten Daten.
