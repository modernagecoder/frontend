> To prepare for the ICSE Class 10 Computer Applications written paper, give Section A the attention its forty compulsory marks deserve: short answers across all eight units that test exact vocabulary and careful tracing, drilled separately from program writing. Divide the two hours as roughly forty minutes for Section A, seventy for the four Section B programs chosen by family in the first minutes, and ten for checking outputs and variable descriptions. Finish the lab file and project before the school's internal assessment, then run three full papers under time with every lost mark re-attempted. ## What Section A asks

Forty compulsory marks in seven shapes: predict the output of a fragment; evaluate an expression with mixed operators, increments or casts; name the term, type, error or method; give the difference between two things; write one statement of Java; correct the error in a line; count how many times a loop runs. Every technique that earns these marks is a piece of paper: a trace table, precedence written out one operation per line, a step table for the loop, two parallel points and an example for a difference. Students lose Section A by answering from the shape of the code instead of its behaviour.

## A two-mark difference, answered two ways

Differentiate between a constructor and a method. The one-mark answer: a constructor creates objects and a method performs actions. True and not enough. The two-mark answer: a constructor has the same name as the class, no return type, and is called automatically when an object is created with new; a method has any valid name, must declare a return type or void, and is called explicitly using the object; example, Student(String n) is a constructor and void display() is a method. Parallel points, the syllabus's own words, one example: the same format earns pure and impure, linear and binary search, private and public, autoboxing and unboxing.

## The time plan for the paper

Five minutes to read the whole paper and choose the four Section B programs by family. Forty minutes for Section A. Sixty-five minutes for the four programs, strongest family first, variable description with each. Ten minutes checking that outputs match the question's format and descriptions are complete. Section A is a mark a minute and Section B slightly less; a fifth half-attempted program earns nothing and steals the checking phase from the four that count.

## The mocks

Three full papers under two-hour conditions in the final two months, each reviewed the following Tuesday in two halves, Section A answer by answer and Section B program by program, every lost mark re-attempted on the spot. Before the school's internal assessment window, a dress rehearsal: lab file reviewed, project questioned by an unfamiliar teacher, one unseen program written and tested in BlueJ under time.

## The eight-week countdown

Weeks 8 and 7: lab file and project closed, practical rehearsed. Week 6: a diagnostic paper before any revision, then a Section A audit, which almost always finds Section A leaking more than Section B. Weeks 5 and 4: Section A by shape on Tuesdays, the six program families kept warm with one program a day at home. Week 3: the second paper, reviewed in two halves. Weeks 2 and 1: the third paper, then maintenance only, no new material. CBSE's two-phase 2026 examination is a CBSE arrangement; for ICSE plan on the single written paper in the February to March window CISCE schedules.

## Six errors that cost a grade

Answering Section A from the look of the code; a difference with one point; precedence and casting guessed; five programs attempted badly; the variable description skipped under time; the practical left until the paper's revision weeks.

## Frequently asked questions

**How should the two hours be divided?** About forty minutes for Section A, seventy for the four programs, ten for checking; practised until it is habit.

**Which order?** Section A first, then the four programs starting with the strongest family, chosen once and not revisited.

**When is the practical?** The internal assessment is completed at school in the weeks before the written paper, on the school's schedule within CISCE's framework, so the file and project close before theory revision begins.

**Good programs, weak Section A?** Section A tests reading and program practice trains writing; the cure is a separate drill of traces, predicted outputs and differences in the paper's vocabulary.

**A second attempt for ICSE?** Plan on one written paper; confirm any improvement or compartment provision with the school rather than assuming CBSE's two-phase system applies.

**Too late to join?** The mini batch works until the lab file deadline nears; after that, one to one compresses the countdown into the weeks that remain.
