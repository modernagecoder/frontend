Ans. The short version

Difference between questions in ICSE Computer Applications ask for two points that separate a pair of Java ideas, such as = and ==, while and do-while, call by value and call by reference, pure and impure methods, linear and binary search, or equals() and ==. They are usually two-mark parts of Section A. The answer that earns both marks names a basis for each point and states both sides of it, in a table or two matched sentences. This page answers forty pairs from the 2027 syllabus that way. Modern Age Coders drills them live in a Tuesday and Wednesday mini batch in India, or one to one.

Q1. How is a difference answer marked?

How do you answer difference between questions in ICSE Computer?

Give two points, and make each point a matched pair: one basis, both sides. A point that describes only one side of the pair leaves the examiner to guess the contrast, and often loses the mark.

AnswerWhat was writtenLikely result
One-sided"while checks the condition first."Weak: says nothing about do-while
One matched point"while tests before the body; do-while tests after it."One of two marks
Two matched points"Test: while tests before the body; do-while after it. Runs: while may run zero times; do-while runs at least once."Both marks

Name the basis

Start each point with what is being compared: purpose, return type, when it runs, what it needs. The basis keeps both halves about the same thing.

Table or two sentences

A three-column table (basis, first, second) is fastest to write and to mark. Two sentences joined by "whereas" work just as well.

Add an example if it is quick

A one-line example, such as 17 / 5 is 3 and 17 % 5 is 2, can rescue a point whose wording comes out vague.

Questions about difference questions

What students ask about ICSE Computer difference questions

How many points should I write in an ICSE difference between question?

Two, for a two-mark question, and each point should cover both sides of the pair on the same basis. Writing three or four points does not earn extra marks, and it uses time Section A cannot spare. If the question asks for one difference, give one matched point.

Should I write differences in a table in the ICSE exam?

A table with three columns, the basis and the two items, is the clearest way and is quick to mark. Two sentences joined by "whereas" are equally acceptable. What matters is that each point compares the same feature of both items, not a different feature of each.

What is the difference between linear search and binary search?

Linear search checks each element in turn and works on an array in any order. Binary search needs a sorted array; it checks the middle element and discards half of the remaining array at each step. On a large sorted array binary search needs far fewer comparisons.

What is the difference between call by value and call by reference in Java?

In call by value a copy of a primitive is passed, so changes inside the method do not affect the caller's variable. In call by reference, as the ICSE syllabus describes it for arrays and objects, the method receives a reference to the same object, so changes it makes to that object are seen by the caller.

What is the difference between pure and impure methods?

A pure method returns a value and changes nothing outside itself, so the same inputs always give the same result. An impure method changes the state of something outside itself, such as a data member of the object or an array it was passed.

What is the difference between = and == in Java?

The single = is the assignment operator: it stores a value in a variable. The double == is a relational operator: it compares two values and gives true or false. Writing = inside an if condition with an int is a compile error in Java.

What is the difference between while and do while loop?

while is entry controlled: it tests the condition before the body, so the body may run zero times. do-while is exit controlled: it tests after the body, so the body always runs at least once. do-while also ends with a semicolon after its condition.

What is the difference between equals() and == for Strings?

equals() compares the characters of two Strings and returns true when the text matches. == compares whether two names point to the same object in memory, so two Strings with the same text can still give false. Always use equals() to compare text.

Are difference questions asked every year in ICSE Computer Applications?

Two-mark difference questions appear regularly in Section A, though the exact pairs change from paper to paper. That is why this page covers every likely pair from the 2027 syllabus rather than a short list. Learn the two points for each and any pair the paper picks is covered.
