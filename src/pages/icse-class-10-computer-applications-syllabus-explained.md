> The ICSE Class 10 Computer Applications syllabus for the 2027 examination has eight Java units: Revision of Class IX syllabus, Class as the basis of all computation, User-defined methods, Constructors, Library classes, Encapsulation, Arrays and String handling. It is assessed by a two-hour theory paper of 100 marks, Section A being 40 compulsory short-answer marks across the whole syllabus and Section B being 60 marks of programs with any four attempted at 15 marks each, written in Java with variable descriptions and no flowcharts required, plus a 100-mark internal assessment from at least 20 lab assignments and a project, marked 50 by the internal teacher and 50 by an external examiner. ## The scheme as CISCE sets it out

Theory paper: one written paper of two hours, 100 marks. Section A: 40 marks of compulsory short-answer questions covering the entire syllabus. Section B: 60 marks of programming questions with a choice, any four of those offered at 15 marks each, in Java, written using variable descriptions or mnemonic codes so the logic is clearly depicted; flowcharts and algorithms not required. Internal assessment: 100 marks from practical lab work of at least 20 assignments in the year plus a project, 50 assessed by the internal teacher and 50 by an external examiner.

## The eight units, and how the paper asks about each

1. Revision of Class IX syllabus: object-oriented ideas, objects and classes, values and data types, operators and precedence, input, mathematical library methods, conditional and iterative constructs, nested loops. The most examined unit in the book: Section A's output-prediction and loop-count questions come from it and every Section B program assumes it.
2. Class as the basis of all computation: objects and classes, the class as a user-defined type, primitive and composite data types, objects as instances with state and behaviour.
3. User-defined methods: syntax, invocation, pure and impure methods, actual and formal parameters, return, multiple methods, method overloading. Section B's class-skeleton format lives here.
4. Constructors: definition, characteristics, default and parameterised types, uses, and the difference from a method. A reliable two-mark Section A difference.
5. Library classes: wrapper classes and their methods, string-to-number conversions, character methods, autoboxing and unboxing. Section A output questions.
6. Encapsulation: access specifiers private, public, protected and default, visibility rules, scope of variables. Why a program will or will not compile.
7. Arrays: single and double dimensional, declaration, initialisation, input, linear and binary search and the sort techniques. A Section B program in almost every paper.
8. String handling: the String class and its methods, extracting and modifying characters, implementing string methods by hand. The other guaranteed Section B program.

## A Section A trace, two ways

For s = "Computer", the guessed answer to s.substring(3).toUpperCase() + s.indexOf('t') is "Puter6", from one-based counting and an ignored method. The traced answer writes the index table (C0 o1 m2 p3 u4 t5 e6 r7), reads substring(3) as "puter", uppercases to "PUTER", finds indexOf('t') = 5, and joins string and int as text: "PUTER5". The index table answers half of Section A.

## The internal assessment

At least 20 lab assignments completed during the year, each a working program with output; a documented project the student can present; 50 marks from the internal teacher and 50 from an external examiner who reviews the practical work and questions the student. A strong lab file spans every unit: input-and-compute programs, a class with constructor and methods, a menu-driven program, several array programs including a search and a sort, several string programs, and combined programs, each with a variable description and its real output.

## A school-year sequence

April to May: the revision unit rebuilt through programs, the lab file begun. June to July: classes, methods and constructors as one arc. August: library classes and encapsulation, taught with Section A in mind. September to November: arrays and strings, the Section B core, with the file passing twenty and the project drafted. December to February: mocks, the practical rehearsal, then the paper. For the 2027 examination CISCE's published syllabus keeps Computer Applications consistent with recent years, with a general move toward questions that test application over recall.

## Frequently asked questions

**Exam pattern?** A two-hour 100-mark paper (Section A 40 compulsory, Section B 60 with any four programs at 15 each) plus a 100-mark internal assessment.

**Changed for 2027?** CISCE's published syllabus keeps Computer Applications consistent with recent years; confirm against the school's copy.

**Which units produce Section B programs?** Arrays, strings, methods and constructors, usually combined, on top of the Class 9 constructs.

**Is Class 9 examined?** Yes, directly in Section A and implicitly in every program.

**Flowcharts or algorithms needed?** No; programs in Java with variable descriptions are what is expected.

**Study order?** Revision, then classes, methods and constructors, then library classes and encapsulation, then arrays and strings with the most practice time.
