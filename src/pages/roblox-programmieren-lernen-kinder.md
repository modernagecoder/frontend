Viele Kinder kennen Roblox als Spieleplattform. Weniger bekannt ist, dass jedes Spiel darauf mit einem kostenlosen Werkzeug gebaut wird, Roblox Studio, und mit einer echten Programmiersprache, Luau. ## Wie bewegt man in Roblox etwas gleichmäßig, auf jedem Rechner?

Mit der Zeit seit dem letzten Bild. Roblox ruft das Ereignis Heartbeat einmal pro Bild auf und übergibt dabei deltaTime, die Zeit in Sekunden seit dem vorigen Bild. Wer das nutzt, baut Spiele, die auf einem alten Laptop genauso schnell laufen wie auf einem neuen. Das Beispiel ist unser eigenes.

**Eine fahrende Plattform in Roblox Studio** (Luau)
```luau
local RunService = game:GetService("RunService")
local plattform = workspace.Plattform   -- ein verankertes Bauteil

-- Version A: pro Bild ein halbes Stud weiter
-- RunService.Heartbeat:Connect(function()
--     plattform.Position += Vector3.new(0.5, 0, 0)
-- end)

-- Version B: 30 Studs pro Sekunde, egal wie viele Bilder
local TEMPO = 30
RunService.Heartbeat:Connect(function(deltaTime)
    plattform.Position += Vector3.new(TEMPO * deltaTime, 0, 0)
end)
```
Dieses Skript gehört in ein Script unter ServerScriptService; die Plattform ist ein verankertes Bauteil namens Plattform. Wir zeigen es für Roblox Studio, haben es hier aber nicht ausgeführt, weil uns außerhalb von Studio keine Luau-Laufzeit zur Verfügung steht. Die Rechnung dahinter prüft der Python-Zwilling darunter.

**Der Python-Zwilling: dieselbe Rechnung, die wir ausgeführt haben** (Python)
```python
# Python-Zwilling des Luau-Skripts: eine Plattform fährt zwei Sekunden lang
SCHRITT = 0.5   # Version A: Studs pro Bild
TEMPO = 30      # Version B: Studs pro Sekunde

def fahren(bildzeiten):
    a = b = 0.0
    for dt in bildzeiten:          # dt = deltaTime, Sekunden seit dem letzten Bild
        a += SCHRITT               # A: zählt Bilder
        b += TEMPO * dt            # B: zählt Zeit
    return round(a, 2), round(b, 2)

for fps in [30, 60, 144]:
    bilder = [1 / fps] * (2 * fps)    # genau zwei Sekunden
    a, b = fahren(bilder)
    print(f'{fps:>3} Bilder pro Sekunde: A = {a} Studs, B = {b} Studs')

# Ein Ruckler: 60 Bilder pro Sekunde, aber ein Bild dauert eine halbe Sekunde
ruckler = [1 / 60] * 90 + [0.5]
print('Mit Ruckler:', round(sum(ruckler), 2), 'Sekunden, A, B =', fahren(ruckler))
```
Ausgabe mit Python 3.14: 30 Bilder pro Sekunde: A = 30.0 Studs, B = 60.0 Studs 60 Bilder pro Sekunde: A = 60.0 Studs, B = 60.0 Studs144 Bilder pro Sekunde: A = 144.0 Studs, B = 60.0 StudsMit Ruckler: 2.0 Sekunden, A, B = (45.5, 60.0)

**Wie weit die Plattform in zwei Sekunden fährt (unser Python-Zwilling)**

| Bilder pro Sekunde | Version A: pro Bild | Version B: pro Sekunde |
|---|---|---|
| 30 | 30 Studs | 60 Studs |
| 60 | 60 Studs | 60 Studs |
| 144 | 144 Studs | 60 Studs |
| 60 mit einem Ruckler | 45,5 Studs | 60 Studs |

Version A sieht auf dem Rechner, auf dem das Kind sie baut, oft perfekt aus. Auf einem Rechner mit doppelt so vielen Bildern pro Sekunde fährt dieselbe Plattform aber doppelt so weit, auf einem langsamen nur halb so weit, und bei einem Ruckler bleibt sie zurück. Version B rechnet Tempo mal Zeit und kommt immer nach 60 Studs an. So entstehen Hindernisparcours, die für alle Spieler gleich schwer sind.

1. **Erst raten.** Bevor das Kind Version A auf einem zweiten Rechner testet, schätzt es: Wie weit fährt die Plattform dort? Danach wird gemessen.
2. **Die Einheit aufschreiben.** 0,5 ist "Studs pro Bild", 30 ist "Studs pro Sekunde". Wer die Einheit dazuschreibt, merkt, warum nur die zweite Zahl mit deltaTime multipliziert werden darf.
3. **Nicht nach Gefühl warten.** Auch task.wait(1) wartet nicht genau eine Sekunde. Laut Roblox gibt die Funktion die tatsächlich vergangene Zeit zurück; gute Skripte rechnen mit diesem Wert weiter.
4. **Auf dem schwächsten Gerät testen.** Im Unterricht spielen wir jedes Spiel einmal auf dem langsamsten Rechner der Familie durch.

## Was lernt ein Kind im Roblox-Kurs, Schritt für Schritt?

Unsere eigene Reihenfolge. Jede Stufe endet mit etwas Spielbarem, das das Kind Familie und Freunden zeigen kann.

**Lernweg im Roblox-Kurs (unsere Planung)**

| Phase | Was das Kind baut | Was es dabei lernt |
|---|---|---|
| 1. Bauen | Eine eigene Insel mit Hindernissen | Studio bedienen, Bauteile, Koordinaten in Studs |
| 2. Bewegen | Fahrende Plattformen und Türen | Variablen, Funktionen, Heartbeat und deltaTime |
| 3. Reagieren | Fallen, Schalter und Checkpoints | Ereignisse wie Touched, Bedingungen mit if |
| 4. Zählen | Münzen und eine Punktetabelle | Zahlen speichern, Schleifen, Tabellen in Luau |
| 5. Mehrere Spieler | Ein Rennen für zwei bis vier Freunde | Server und Client, warum der Server prüft |
| 6. Veröffentlichen | Ein fertiges kleines Spiel | Testen, Fehler suchen, anderen erklären |

### Was über Roblox hinaus bleibt

Variablen, Bedingungen, Schleifen und Funktionen funktionieren in Luau wie in Python oder Java. Wer in Roblox gelernt hat, eine Bewegung mit der vergangenen Zeit zu rechnen, kann das in jeder anderen Spiel-Engine genauso.

Dazu kommt Mathematik, die Kinder sonst eher trocken erleben: Koordinaten, Geschwindigkeit als Strecke pro Zeit, Prozente bei Punkten und Wahrscheinlichkeiten bei Zufallsereignissen.

### Wann der Wechsel zu anderen Sprachen sinnvoll ist

Viele Kinder wechseln mit 12 oder 13 Jahren zu Python, um die Schulinformatik zu begleiten, oder zu C# und Unity, um größere Spiele zu bauen. Luau ist dafür ein guter Anfang, weil es klein und übersichtlich ist.

Bei gekauften Videospielen hilft Eltern in Deutschland die Alterskennzeichnung der USK; laut KIM-Studie 2024 ist sie für alle Videospiele gesetzlich verpflichtend. Wir empfehlen Kindern nur Werkzeuge und Spiele, die zu ihrem Alter passen.

## Roblox programmieren lernen: häufige Fragen

### Findet der Unterricht auf Deutsch statt?

Nein, ausschließlich auf Englisch und immer live. Die Mentoren aus Indien sprechen langsam und deutlich und richten sich nach Tempo und Aussprache Ihres Kindes. Das hilft beim Programmieren: Luau-Befehle wie local, function und end sind englische Wörter, die Ihr Kind dann jede Stunde auch hört und ausspricht.

### Ab welchem Alter kann mein Kind Roblox programmieren lernen?

Unser Roblox-Kurs ist für 8 bis 14 Jahre gedacht. Jüngere Kinder beginnen besser mit Scratch. Roblox selbst ordnet Kinder von 5 bis 8 Jahren in den meisten Regionen dem Konto Roblox Kids zu und Kinder von 9 bis 15 dem Konto Roblox Select.

### Ist Roblox für Kinder sicher?

Roblox beschreibt auf seinen eigenen Seiten Konten mit Einschränkungen nach Alter: Bei Roblox Kids ist der Chat aus, Kinder von 9 bis 12 können den Chat-Tab nur mit vertrauenswürdigen Freunden nutzen, und Eltern können für Kinder unter 13 Chat, Bildschirmzeit und Ausgaben steuern. Für unseren Kurs braucht Ihr Kind weder Chat noch Robux.

### Kostet Roblox Studio etwas?

Nein. Laut Roblox ist Studio eine kostenlose Anwendung für Windows und Mac. Zum Anmelden braucht Ihr Kind ein Roblox-Konto, das Sie als Eltern einrichten und über die Kindersicherung begleiten.

### Reicht ein Tablet oder ein Chromebook?

Zum Bauen nicht. Roblox nennt als Mindestvoraussetzung für Studio Windows 10 oder macOS 10.14 und 3 GB Arbeitsspeicher, empfohlen sind 8 GB. Spielen geht auf vielen Geräten, programmiert wird am Windows-PC oder Mac.

### Welche Programmiersprache lernt mein Kind?

Luau, die Skriptsprache von Roblox, die laut Roblox von Lua 5.1 abgeleitet ist. Die Grundideen, also Variablen, Bedingungen, Schleifen und Funktionen, gelten genauso in Python, JavaScript oder C#, und viele Kinder wechseln später ohne Mühe.

### Lernt mein Kind dabei mehr als ein Spiel?

Ja. Schon die erste Lektion auf dieser Seite verbindet Code mit Mathematik: Geschwindigkeit ist Strecke pro Zeit. Später kommen Koordinaten, Zufall, Prozente und die Frage dazu, warum in einem Spiel für mehrere Spieler der Server prüfen muss, was die Spieler melden.

### Zu welchen Zeiten finden die Stunden statt?

Unter der Woche oder am Wochenende, flexibel: Wählen Sie eine Gruppe, oder für einen ganz persönlichen Plan den Einzelunterricht zu einer Zeit, die Ihrer Familie passt, am Wochenendvormittag oder an Nachmittagen unter der Woche. Ja, wenn Sie als Eltern einverstanden sind. Im letzten Abschnitt testen wir das Spiel gründlich und besprechen, welche Einstellungen das Kind vorher wählen sollte. Ein privates Spiel, das nur Familie und Freunde sehen, ist ebenfalls ein schöner Abschluss.
