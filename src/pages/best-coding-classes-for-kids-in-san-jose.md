## Three kinds of kids coding class, side by side

Most San Jose families end up choosing between these. Each suits some children; the table is our honest summary of the trade-offs.

**Kids coding class formats compared (our own assessment, not a ranking of providers)**

| What matters | In-person club or camp | Recorded video course | Live online class |
|---|---|---|---|
| Teacher sees the child work | Yes, if the group is small | No | Yes, through a shared screen |
| Help when stuck | Depends on the ratio | Forums or none | In the moment, from the teacher |
| Travel | Drive and wait | None | None |
| Placement by level | Often by age | Self-chosen | A placement lesson |
| Year-round rhythm | Often seasonal | Easy to drift off | Weekly, with the same teacher |

### When in person wins

A great club ten minutes away, with a teacher who knows your child, is hard to beat. If you have one, keep it. Many families add an online class for depth, not instead.

### When video works

Recorded courses suit a self-driven twelve-year-old who reads error messages calmly. Most younger children need someone to ask, and stall without one.

### When live online fits

For busy families across a spread-out city, a live class removes the drive while keeping the teacher. That is the format we teach in, so weigh our view accordingly.

Search results for the best kids coding class in San Jose mix all three formats, and no independent ranking covers them fairly. A useful test for any option is a trial: watch one class from the doorway and count how often your child is helped to think rather than told what to type.

## How far is each San Jose library from a park? A nearest-neighbor project

The City of San Jose publishes its libraries and its parks as open map data. Students find, for each of the 25 libraries, the closest open neighborhood park, using nothing but latitude, longitude and a loop.

**Straight-line distance from San Jose libraries to the nearest open neighborhood park (our calculation from City of San Jose Open Data, downloaded 18 October 2026)**

| Result | Our number |
|---|---|
| Libraries in the Library dataset | 25, all listed as open |
| Open neighborhood parks used | 211 |
| Median distance to the nearest one | 0.27 miles |
| Libraries within half a mile of one | 23 of 25 |
| Closest pair | Rose Garden Library, 0.02 miles |
| Farthest library from its nearest park | Bascom Library, 0.64 miles |

### Find a center

Libraries and parks arrive as outlines, not points. Students average each outline&rsquo;s corner coordinates to get an approximate center, then check a few on a map to see that the method behaves.

### Measure the curve

Degrees of longitude shrink away from the equator, so subtracting coordinates is not enough. The haversine formula, with the Earth&rsquo;s radius as 3,958.8 miles, gives distance across the curved surface.

### Search every pair

For each library, a loop measures all 211 parks and keeps the smallest. That is 25 times 211, or 5,275 distances, which Python finishes before a child can blink.

Some pairs read like a riddle with an easy answer. Alviso Library sits 0.06 miles from Alviso Park, Calabazas Library 0.10 miles from Calabazas Park, and Hillview Library 0.35 miles from Hillview Park. Children enjoy predicting the match from the names, then discovering that the nearest park is not always the one with the matching name.

The bigger lesson is about filters. The park file has 611 records, and only 526 are currently open; others are closed, planned as future parks or under construction. It also covers land beyond the city, from Santa Clara County to parts of San Mateo County, and includes school grounds and trails. Before measuring anything, a student must decide which records count as a park a family could walk to, and write that rule down.

### About these distances

All distances here are ours: straight lines between approximate centers, not walking routes, from one download on 18 October 2026. The City publishes the library data weekly on Mondays under a Creative Commons Attribution licence, so this project credits City of San Jose Open Data and expects later numbers to shift.

## Should a San Jose child learn to code when AI can?

Yes, for the same reason children still learn arithmetic in a world of calculators.

A child who has written the nearest-park loop knows why the farthest library is 0.64 miles away and why that number is a straight line, not a walk. A chatbot asked the same question might give a tidy answer with no way to check it. Understanding comes from building, and young children build best with a teacher beside them.

For children under thirteen we keep AI tools out of the lesson and teach the logic underneath. AI literacy comes later as a subject: how a model guesses, where it goes wrong, and why its answers need checking.

Children growing up next to the companies building AI deserve to understand it from the inside, starting with simple code they wrote. The longer argument is in [why coding is still worth learning](/blog/is-coding-worth-learning-2026).
