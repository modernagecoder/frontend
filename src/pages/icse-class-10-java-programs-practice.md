> Section B of the ICSE Class 10 Computer Applications paper is 60 marks of Java programs: any four of the questions offered, at 15 marks each, written with variable descriptions and no flowcharts required. The programs come from six families: number and pattern programs, menu-driven programs using switch, single-dimensional arrays with searching and sorting, string handling character by character, classes with constructors and methods, and two-dimensional arrays. A student fluent in four families can score the whole section. Modern Age Coders practises all six in a live Wednesday 8 PM lab, one program and one variation a week from a blank class in BlueJ, in a mini batch of four or five, reaching about sixty written programs before the board exam.

## The six families and what each tests

Number and pattern programs test nested loops, counters and exact output format. Menu-driven programs test Scanner input, switch with break and default, and formatted output. Single-dimensional arrays test indexing from zero, linear and binary search, bubble and selection sort. String handling tests charAt and length, building a new string, and String methods used correctly. Classes with constructors and methods test constructors, parameters, methods that return values, and calling them from main. Double-dimensional arrays test nested loops over rows and columns with two indices kept apart. The choice of any four is the strategic fact of the section.

## Eight worked programs

1. Floyd's triangle: a counter n printed across rows i of length i, three variables with three roles.
2. An area menu: Scanner, a switch on the choice with a break in every case and a default for invalid input.
3. Linear search with a sentinel: pos starts at minus one and only changes when the key is found, which is the idea being tested.
4. Bubble sort: the inner loop's upper limit shrinks by the pass number because the largest value has already bubbled to the end.
5. Palindrome and vowel count in one loop: rev = c + rev builds the reversal by prepending; indexOf on "aeiou" replaces five comparisons.
6. Reverse each word of a sentence: the last word has no trailing space and must be appended after the loop, the family's most common bug.
7. A Student class with a constructor, a grade method that returns a char, a display method, and a main that creates an object and calls it: the class-skeleton question.
8. Row sums of a matrix: sum declared inside the outer loop so it resets per row; the column-sum variation swaps which index the outer loop owns.

Every program carries a variable description table listing each variable, its type and its purpose, because the board asks for it and because writing it catches misused variables.

## Where the fifteen marks come from

The logic, secured by tracing the program on paper with an ordinary and an awkward input. The construct the question targets: an array question wants an array, a class question wants a constructor and methods. The class and method structure, secured by writing the class shell first. The variable description, written while writing the program. The output in the question's exact format. Legibility and completeness: four complete programs beat five half-attempted ones.

## The twenty-one-week ladder

Weeks 1 to 3: patterns and number properties. Weeks 4 to 6: menus with switch and input done properly. Weeks 7 to 10: arrays, the biggest family, from accepting values to search and sort. Weeks 11 to 14: strings character by character. Weeks 15 to 17: classes with constructors and methods, and matrices. Weeks 18 to 21: the second pass with harder variations, then full Section B papers under time, five questions, choose four, seventy minutes, reviewed program by program.

## Six errors that turn a fifteen into a nine

Counting from one; the missing break; no variable description; output that ignores the question's format; attempting five programs badly; reproducing last year's version of the question.

## Frequently asked questions

**How many programs in the paper?** Any four of those offered in Section B, 15 marks each, 60 marks in total.

**Most common families?** Arrays and strings in almost every paper, a class with constructor and methods nearly as often, then menus, patterns and matrices.

**What are the 15 marks for?** Logic, the targeted construct, class and method structure, the variable description, and the output format; CISCE publishes expectations rather than a line-by-line rubric.

**Is the variable description compulsory?** Treat it as such: the syllabus asks for variable descriptions or mnemonic codes and papers instruct students to include them.

**Scanner or BufferedReader?** Either; Scanner by default, with the import line written every time.

**How many programs before the exam?** Around sixty, roughly ten per family, one program and one variation a week.
