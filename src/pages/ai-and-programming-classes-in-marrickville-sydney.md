### What the eight runs say

Dulwich Hill stays first and Petersham second whichever measure is removed, so the match does not hang on any one number. Removing people per household brings Dulwich Hill closest, from 0.83 to 0.69, so that is where the two differ most; removing professionals changes almost nothing, because the two suburbs are 39.5% and 39.7%.

Why rescale at all? Without it, the gap in flats (47.2% against 57.0%) would supply about 85% of the raw distance to Dulwich Hill, simply because percentages run to bigger numbers than household sizes. The measures and their values are ABS figures; the distances, the rescaling and the conclusions are ours, and "alike" here means alike on these eight measures only.

## Answer, then explain, then try to break it

The model is a few lines of Python. The explanation step is a loop around it, and that loop is where students learn the most.

**The three parts of the project**

| Part | What the code does | Question it answers |
|---|---|---|
| Match | Finds the suburb with the smallest distance to Marrickville | Which suburb is most alike? |
| Explain | Repeats the match eight times, each time without one measure | Which measures does the answer depend on? |
| Stress test | Checks whether the first and second places ever change | Is the answer fragile or solid? |

The same remove-and-rerun idea explains far bigger models, from a recommendation engine to an exam-mark predictor. If removing one input flips the answer, that input deserves a close look before anyone relies on the result.

## If an AI can give the answer, why should a Marrickville student learn to explain it?

Because an answer nobody can explain is an answer nobody can check.

An AI assistant asked which suburb is most like Marrickville might say Dulwich Hill, Petersham or Newtown, with a confident paragraph each time. Without a way to test the reasoning, there is no telling which paragraph rests on evidence and which simply sounds right.

A learner who has removed one measure at a time and watched the answer hold knows how to probe any model, including the AI ones. That habit is what employers mean when they ask for people who can work with AI responsibly.

The Marrickville student who asks a model to show its working is the one who can tell a solid answer from a lucky one. The longer argument is in [why teenagers should still learn to code in 2026](/blog/is-coding-worth-learning-2026).
