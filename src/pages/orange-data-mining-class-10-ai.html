Q2. How do I build the Palmer penguins model?

Palmer penguins class 10 AI: the Orange workflow, step by step

The penguins model predicts a penguin's species, Adelie, Chinstrap or Gentoo, from its island and four body measurements. CBSE's own workflow file uses eleven widgets, and each one maps to a stage of the AI project cycle.

The data. CBSE's training file has 344 penguins: 152 Adelie, 124 Gentoo and 68 Chinstrap. Columns are species, island, culmen length and culmen depth (the culmen is the upper ridge of the bill), flipper length and body mass. Two penguins have all four measurements missing, which is why the workflow needs Impute.

StepWidgetConnectWhat to set or readProject cycle stage

2ImputeTrainData to ImputeFill the missing measurements, for example with the averageData exploration

4Select ColumnsImpute to Select ColumnsMove species to Target; keep island and the four measurements as featuresModelling (set up)
5Data SamplerSelect Columns to Data SamplerFixed proportion 80 percent, stratified; about 275 penguins train, 69 are held backModelling (split)
6Data Info, twiceData Sample to one, Remaining Data to the otherConfirm the two row counts add up to 344Checking the split
7Tree and Random ForestData Sample to each learnerDefaults are fine to startModelling

What the exploration should show

  • Island gives a lot away. Gentoo appear only on Biscoe and Chinstrap only on Dream; Adelie live on all three islands.
  • Flippers separate Gentoo. Their average flipper is about 217 mm against about 190 mm for Adelie.
  • Culmen length separates Adelie from Chinstrap. About 38.8 mm against about 48.8 mm on average.

Drop a Scatter Plot on the Impute output with culmen length against flipper length, coloured by species, and the three groups are visible before any model is trained.

One honest caution about the CBSE test file

CBSE's penguins_test.csv holds the same 344 penguins as the training file, with the species column renamed "actual species". So the Predictions table will look almost perfect: the models have already seen those birds. The fair score is the one Test and Score reports on the 69 held-back penguins. If an examiner asks why Predictions looks better than Test and Score, that is the answer, and it is the same idea as never testing on training data in Unit 3. The full evaluation reasoning is on CBSE Class 10 AI evaluating models questions.

Q3. How does Orange classify coral photos?

Coral bleaching project class 10: the image classification chain in Orange

Orange cannot learn from raw pixels directly. The Image Embedding widget turns every photo into a long row of numbers that describe its features, and from then on an ordinary classifier treats the photos like rows in a table.

The data. Two folders, Train and Test. Inside each, one sub-folder per class: Bleached and Unbleached. Import Images reads the sub-folder name as the label, so the folder layout is the labelling.

StepWidgetConnectWhat to set or read
1Import Images (renamed Train Data)Starts the chainChoose the training folder; it should report two categories
2Image ViewerTrain Data to Image ViewerScroll the photos; check for blurred, duplicate or wrongly filed images
3Image EmbeddingTrain Data to Image EmbeddingSqueezeNet runs offline and is the default; Inception v3 and the others need internet
4Data TableImage Embedding to Data TableSee each image now as a row of numeric columns plus its category
5Logistic Regression, Random Forest, SVMEach learner to Test and ScoreThree models, so their scores can be compared
6Test and ScoreImage Embedding to DataCross-validation is a sound choice here; compare CA, F1, Precision and Recall
7Confusion MatrixTest and Score to Confusion MatrixSwitch between learners on its left to see which one misses bleached coral
8Import Images (Test Data), Image Viewer, Image EmbeddingA second chain for the test folderPoint it at the test folder, not the training one
9Logistic Regression (second copy)Train embeddings to its DataTrains the chosen model on all training photos
10PredictionsTest embeddings to Data; the model to PredictorsEach test photo with its predicted class and probability

Which model won

In the CBSE walkthrough, Logistic Regression gave the best accuracy of the three, which is why the final chain uses it. On your own photos another learner may win; the method of choosing is what earns marks.

Which error matters

A bleached reef predicted as unbleached is a false negative, and it is the costly one, because the reef gets no attention. So read recall for the Bleached class, not only overall accuracy.

A slip in the steps PDF

CBSE's step sheet tells you, at the prediction stage, to select the training folder. Choose the test folder: predicting photos the model trained on proves nothing.

Pixels, RGB channels and convolution, the theory behind what Image Embedding does, are on CBSE Class 10 AI computer vision questions. Coral as a full project with its 4Ws is on CBSE Class 10 AI project ideas.

Q4. How is sentiment analysis done in Orange?

Sentiment analysis in Orange for the NLP unit

Sentiment analysis decides whether a piece of text is positive, negative or neutral. In Orange, the Text add-on loads the texts as a corpus, cleans them, and the Sentiment Analysis widget adds a score to every document.

The curriculum names a sentiment walkthrough for Unit 6, but the shared CBSE folder for it does not hold a workflow file we could open, so the chain below is the standard route the Text add-on documents. Schools may use their own review or tweet dataset.

StepWidgetWhat it doesWhat to set or read
1Corpus (or Import Documents)Loads the texts as documentsPick the column that holds the text as the text feature
2Preprocess TextText normalisationLowercase, tokenise, remove punctuation and stopwords: the Unit 6 theory, as tick boxes
3Sentiment AnalysisScores each documentChoose Vader: it adds positive, negative, neutral and compound columns; compound runs from -1 to +1
4Data TableShows the scoresSort by compound to see the most negative and most positive texts
5Word CloudShows frequent wordsCompare clouds for the positive and the negative texts
6Box Plot or DistributionsSummarises the scoresHow many texts fall on each side of zero

What the five scores teach

  • Neutral is real. A plain fact scores 0, neither positive nor negative.
  • Negation is handled. "Not bad" comes out mildly positive, because VADER reads "not" before "bad".
  • Sarcasm is not. "Great" pulls the power-cut complaint positive. A lexicon counts words; it does not understand intent.

That last point answers a favourite viva question on the limits of NLP. Bag of Words and TFIDF, the counting ideas underneath, are worked by hand on Bag of Words and TFIDF for Class 10 AI.

Q5. What is no-code AI, and what will I be asked?

No code AI class 10: price prediction, code versus no-code, and viva questions

No-code AI means building, training and testing a model by dragging and connecting ready-made blocks instead of writing a program. Low-code tools mix blocks with a little code.

The handbook's regression example

In Unit 4 the handbook tells of Kayla, who budgets animal food at a zoo and needs to predict rising food prices without knowing how to code. The chain is short:

  1. File

    Load the food price index data and set the price index as the target.

  2. Data Table

    Look at the rows before modelling.

  3. Linear Regression

    File to Linear Regression; the output is a number, so this is regression.

  4. Test and Score

    File to Data, Linear Regression to Learner; read RMSE, MAE and R2 instead of accuracy.

  5. Predictions

    Data to Data, and the Linear Regression model to Predictors.

The handbook's last step joins Test and Score to Predictions and mentions a logistic model. In Orange, Predictions takes data plus a trained model, as in the last step above, and a price is predicted with linear, not logistic, regression.

Code versus no-code for statistical data

The handbook also warns that no-code platforms give less control over security, so they suit data that is not sensitive.

Questions examiners ask at the Orange screen

  1. Why did you use Select Columns?
    Answer To mark species as the target, the label the model must predict. Without a target, Test and Score has nothing to check against.
  2. What does Data Sampler do, and why stratified?
    Answer It splits the data into a training part and a held-back test part. Stratified keeps the same share of each species in both parts.
  3. What does Image Embedding output?
    Answer A row of numbers per image that describes its features, so a normal classifier can learn from photos.
  4. Which stage of the AI project cycle is Test and Score?
    Answer Evaluation. Impute and the plots belong to data exploration; the learners to modelling.
  5. Is your sentiment tool always right?
    Answer No. It scores word lists, so sarcasm and mixed reviews fool it. Checking a sample by hand shows how often it agrees with a person.

Questions about Orange in Class 10 AI

What students ask about Orange Data Mining in class 10 AI

What is Orange Data Mining in class 10 AI?

Orange is a free, open-source tool for data analysis and machine learning in which you build a model by dragging widgets onto a canvas and connecting them, without writing code. CBSE 417 uses it in 2026-27 for three practical walkthroughs: Palmer penguins (Statistical Data), coral bleaching (Computer Vision) and sentiment analysis (NLP).

Is Orange Data Mining in the class 10 AI theory exam?

The walkthroughs belong to Units 4, 5 and 6 practical work, which is assessed through the practical file, practical exam and viva. Units 4 and 7 are practical only. Objective items about no-code tools can still appear, so know what Orange is and what its main widgets do.

What is the Palmer penguins case study in class 10 AI?

It is the Unit 4 use case in which an Orange model predicts a penguin's species, Adelie, Chinstrap or Gentoo, from its island, culmen length and depth, flipper length and body mass. CBSE's training file has 344 penguins. The workflow runs File, Impute, Select Columns, Data Sampler, Tree and Random Forest, Test and Score, then Predictions.

Which widgets are used for the coral bleaching project?

Import Images to load photos from Bleached and Unbleached sub-folders, Image Viewer to check them, Image Embedding to turn each photo into numbers, then Logistic Regression, Random Forest and SVM compared in Test and Score with a Confusion Matrix. A second Import Images chain feeds the test photos into Predictions.

Why does Image Embedding need the internet?

Only some embedders do. SqueezeNet, the default in current versions, runs on your own computer. Inception v3, VGG-16, VGG-19 and the others send images to a server to be embedded, so they need a connection. If the lab has no internet, choose SqueezeNet.

How do I do sentiment analysis in Orange?

Install the Text add-on, load your texts with Corpus, clean them with Preprocess Text, then connect Sentiment Analysis and choose a method such as Vader. It adds positive, negative, neutral and compound scores. View them in a Data Table sorted by compound, and use Word Cloud to compare frequent words.

What is no code AI in class 10?

No-code AI means building and testing a model through a visual interface, dragging and connecting blocks, instead of programming. Examples in the curriculum are Orange, Teachable Machine and Lobe. Low-code tools combine blocks with some code. The trade-off is speed and ease against flexibility and control.

Is Teachable Machine in the class 10 AI syllabus?

Yes. The 2026-27 CBSE 417 curriculum lists Teachable Machine with supervised learning in Unit 2 and, with Lobe, for a smart sorter activity in the Unit 5 practical, where a model learns to tell bottles, cans and paper apart from photos.

Why are my Predictions almost 100 percent correct?

Usually because you are predicting rows the model was trained on. CBSE's penguins test file repeats the training penguins, so it will look near perfect. The honest measure is Test and Score on the data held back by Data Sampler.
