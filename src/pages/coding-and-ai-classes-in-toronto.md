# Coding and AI classes in Toronto

**Where can a Toronto student learn coding and AI with a real teacher?** Modern Age Coders teaches coding and AI live online to Toronto students from age 6 to adult, in a batch of fifteen to twenty or one to one. Most begin with Python for Teens or Python and AI for Kids, then AI and machine learning or our ICS3U and ICS4U companion. Classes run on Toronto time, and the first is free.

A Toronto child meets code long before high school. Since the 2020 Ontario math curriculum, writing and reading code has been part of the Algebra strand from Grade 1, and the de-streamed Grade 9 course, MTH1W, asks students to use it again. What school rarely has room for is depth: time to build something large, break it, find the bug and explain the fix. This page sets out what the curriculum actually asks of a Toronto student at each stage, quoting the ministry where it matters. It also lays out a data project we built on a City of Toronto file, the CEMC contests a Toronto student can enter in 2026 to 2027, and how our live classes sit beside school without pretending to replace it.

## What the Ontario curriculum asks of a Toronto student, grade by grade

Every Toronto public school follows the Ontario curriculum. We read the expectations from the ministry&rsquo;s own curriculum service on 22 October 2026; quoted words are the ministry&rsquo;s, the rest is our summary.

**Coding expectation C3.1 in Ontario elementary math (2020), by grade. Quotes from the Ontario Ministry of Education curriculum; plain summaries are ours**

| Grade | What C3.1 adds that year |
|---|---|
| Grade 1 | Solving problems &ldquo;by writing and executing code, including code that involves sequential events&rdquo;: instructions that run one after another |
| Grades 2 to 4 | Our summary: concurrent events in Grade 2, repeating events in Grade 3 and nested events in Grade 4, so loops inside loops by about age nine |
| Grade 5 | Code &ldquo;that involves conditional statements and other control structures&rdquo;: the first if and else |
| Grade 6 | The same structures, with the new word &ldquo;efficient&rdquo;: students now judge how well code runs, not only whether it runs |
| Grade 7 | Our summary: code driven by a defined count or a subprogram, which is a function by another name |
| Grade 8 | Code &ldquo;that involves the analysis of data in order to inform and communicate decisions&rdquo; |

The ladder is steeper than many parents expect. A Toronto student who reaches Grade 8 is expected, on paper, to have written code with loops, conditions, subprograms and data. In a busy classroom where coding is one strand among many, the time each child spends actually typing and debugging is small, which is where a live class with a teacher watching the screen earns its place.

### Grade 9: MTH1W

The de-streamed Grade 9 math course (2021) keeps coding in. Expectation C2.1 asks students to &ldquo;use coding to demonstrate an understanding of algebraic concepts including variables, parameters, equations, and inequalities&rdquo;, and C2.3 has them read code to predict its outcome.

### Grades 11 and 12: ICS3U and ICS4U

ICS3U, Introduction to Computer Science, has no prerequisite; the ministry says students &ldquo;will design software independently and as part of a team&rdquo;. ICS4U follows it and asks for complex, fully documented programs built with modular design. Each is worth one credit.

### Grade 10: ICD2O

The ministry&rsquo;s current list adds ICD2O (2023), an open Grade 10 course on coding, artificial intelligence and cybersecurity. The 2008 document still describes the older ICS2O, which the current list no longer shows.

**EQAO provincial assessment windows for 2026 to 2027, as published by EQAO (read 22 October 2026)**

| Assessment | Who writes it | Window |
|---|---|---|
| Grade 3 Reading, Writing and Mathematics | Grade 3 students | 4 May to 8 June 2027 |
| Grade 6 Reading, Writing and Mathematics | Grade 6 students | 4 May to 8 June 2027 |
| Grade 9 Assessment of Mathematics | Students in Grade 9 math | 12 January to 5 February 2027 |
| OSSLT (literacy test) | From Grade 10 | 3 to 30 November 2026 |

EQAO says Grade 9 math results are to be included as part of a student&rsquo;s final course mark, so the January to February 2027 window matters to a Toronto Grade 9 student in a way the elementary assessments do not. Our classes do not prepare students for EQAO by drilling the format; they build the algebra and coding that MTH1W expects, and the assessment follows from that.

## How many Toronto parks list a playground? A project on the city&rsquo;s own file

The City of Toronto publishes its Parks and Recreation Facilities list as open data. Our students download it, count it in Python and then work out what the count does not say. The figures below are ours, not the city&rsquo;s.

**Our count of the City of Toronto file, downloaded 22 October 2026 (Parks and Recreation Facilities, 1,802 rows). Counts are rows, and a row can list several amenities**

| Label in the file (column) | Rows |
|---|---|
| Park (TYPE) | 1,519 |
| Community Centre (TYPE) | 277 |
| Civic Centre (TYPE) | 6 |
| Playground (AMENITIES) | 844 |
| Ball Diamond (AMENITIES) | 231 |
| Washroom (AMENITIES) | 219 |
| Sports Field (AMENITIES) | 174 |
| Tennis Court (AMENITIES) | 169 |
| Wi-Fi (AMENITIES) | 136 |
| Basketball Court (AMENITIES) | 121 |
| Pickleball Court (AMENITIES) | 105 |

This is the beginner Python that prints every number in the table. It uses only the standard library, so it runs on any computer with Python 3, in the same folder as the downloaded file:

```
import csv

type_counts = {}
amenity_counts = {}

with open("parks-and-recreation-facilities-4326.csv", encoding="utf-8") as f:
    for row in csv.DictReader(f):
        kind = row["TYPE"]
        type_counts[kind] = type_counts.get(kind, 0) + 1
        if row["AMENITIES"] != "None":
            for amenity in row["AMENITIES"].split(","):
                amenity = amenity.strip()
                amenity_counts[amenity] = amenity_counts.get(amenity, 0) + 1

print(type_counts)
top = sorted(amenity_counts.items(), key=lambda pair: pair[1], reverse=True)
for name, count in top[:8]:
    print(name, count)
```

### 1. Fetch the file

Students open the dataset page on the City of Toronto Open Data portal and download the CSV named parks-and-recreation-facilities-4326.csv. On our download it had ten columns, among them TYPE, AMENITIES and ADDRESS.

### 2. Count by category

The TYPE column holds one label per row, so a dictionary count is enough. AMENITIES holds a comma-separated list, so each row is split, each piece is stripped of spaces, and every label is counted where it appears.

### 3. Audit the rows

Then they check their own data. Of the 1,802 rows, 1,800 have distinct LOCATIONID values: LOCATIONID 3891 appears twice with every column identical except _id, and LOCATIONID 883 is listed once as a Park and once as a Community Centre.

### What the counts cannot tell you

The file says whether a park lists a playground, not how many play structures it has, how large they are, or what condition they are in. And 667 rows list no amenity at all, which means none is recorded in this file, not that the park is empty. A student who writes that sentence correctly has learned more than one who only prints 844.

A good second step is the Grade 8 expectation in action: compare the 841 Park rows that list a playground with the 3 Community Centre rows that do, and decide what a fair chart would show. ## Why learn to code in Toronto when AI writes code?

Because someone still has to know whether the code, and the number it prints, is right.

Ask an AI assistant to count playgrounds in the Toronto file and it will hand back a script in seconds. It may not notice the duplicated row, the park that is also a community centre, or that a blank amenity list means unrecorded rather than absent. Those are judgments, and they come from having written the loop yourself.

That is the habit we teach: think through the problem, write the code, then question the output before believing it. Students use AI tools as they grow older, under age rules we follow, but they use them the way an editor uses a spell checker, not the way a student copies an answer key.

Ontario put coding in the math curriculum so that students learn to reason in steps; that reasoning is exactly what an AI tool cannot do on the student&rsquo;s behalf. The longer argument is in [is coding still worth learning in 2026](/blog/is-coding-worth-learning-2026).
