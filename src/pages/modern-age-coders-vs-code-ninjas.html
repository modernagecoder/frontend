Modern Age Coders vs Code Ninjas in Canada

Parents who search for Code Ninjas in Canada are usually choosing between two shapes of coding education rather than two brands. Code Ninjas is a franchise of physical centres, which it calls dojos, where children drop in after school and work through belt levels at their own speed with staff nearby. Modern Age Coders is a live online school: a teacher runs a scheduled class over video, the same teacher week after week, and the class moves through a planned course together. This page sets the two side by side using what Code Ninjas publishes about itself, read on 22 October 2026, and what we publish about ourselves. It also says, case by case, when a centre is the more sensible choice.

What the table cannot show

A table makes two options look like rivals on every line. They are not. A child can learn a great deal in a dojo, and a child can learn a great deal in a live online class. The real differences sit in three places: whether the child travels to a building, whether the child sets the pace or the class does, and how much of each session a teacher spends talking with that one student.

None of those is good or bad in itself. A self-paced child who loves being in a room with other kids may thrive on belts. A child who needs someone to stop them, ask what they expect the code to do, and wait for an answer may do better in a led class.

We do not repeat figures from third-party sites, because a franchise fee can differ between two centres in the same city.

The belt path in CREATE

Code Ninjas says that in the White to Green belts children build projects with "block based coding in Microsoft MakeCode", and that in the second half "your child will begin writing in code with JavaScript". The advanced Black Belt degrees move into a professional game engine, Unity with C# or Godot with GDScript.

IMPACT, the platform behind CREATE, gives each child "a tailored learning track through the Belts in IMPACT" and "Live feedback on their progress", according to Code Ninjas. The belt colours give children a visible goal, which many find motivating.

The centre itself

The FAQ explains that centres open after school on weekdays, that some may open at weekends, and that "kids can attend multiple times a week" in CREATE. Parents can wait on site, and only enrolled students and trained Senseis go into the dojo.

Code Ninjas also stresses the social side: it says it encourages "collaboration with like-minded peers through in person sessions". For a child who wants friends who also code, a room full of them is a real draw that an online class does not copy.

A live online class

What a Modern Age Coders class looks like from the student's chair

Our model starts from the opposite end. Instead of a room the child walks into whenever the centre is open, there is a booked class with a start time, a teacher who has planned the hour, and a group that meets that teacher again a few days later.

  1. Before class: the student has one short task from last time, such as changing how many lives a game starts with and noting what happens.
  2. The first ten minutes: the teacher asks two or three students to show their screen and explain their change in their own words. Wrong guesses are welcome; they are what the lesson is built on.
  3. The new idea: the teacher introduces one concept, for example a loop that stops early, and writes a small program live while the class predicts each line.
  4. Building: students extend the program in their own copy. The teacher moves between screens, asking questions rather than typing fixes.
  5. The last ten minutes: one student's bug becomes the whole class's puzzle, and the session ends with a new short task for next time.

Why the same teacher matters

A regular teacher remembers that a student mixed up the score and lives variables last week, and checks for it again this week. That memory is what turns a set of sessions into a course.

It also means a parent has one person to ask. After any class, a parent can message us and hear from the teacher who actually watched their child code.

Typed code, sooner or later

Young beginners start with blocks, as they would at a centre. We move a student to typed Python or JavaScript when they can explain what their block programs do, not at a fixed age.

Older students can continue the same path into teen courses, Ontario computer science companion classes, and contest preparation for the Canadian Computing Competition, because our courses run all the way up to adult learners.

A worked example

Our teaching approach in one short program: predict, run, explain, change

This is a teaching example we wrote for our own classes. It is not taken from Code Ninjas or from any other curriculum. It shows the habit we build in every lesson: before running code, the student says what it will print and why.

  1. Predict. The teacher covers the output and asks: what will the score be? Most students add the coins (3 + 5 + 2 + 4 = 14), multiply by ten and say 140. Some forget the two empty levels cost lives and say there are 3 lives left.
  2. Run. The program prints Score: 140 and Lives left: 1. The students who said 3 lives now have a reason to read the if block again.
  3. Explain. A student traces the loop aloud, level by level: 30, then a life lost, then 80, 100, a second life lost, then 140. Saying it out loud is where the understanding lands.
  4. Change one thing. The teacher asks what happens if the game starts with 2 lives. Now the fifth level ends the game, break leaves the loop, the last level is never played, and the program prints Score: 100 and Lives left: 0.
  5. Explain the change. The class decides why 4 coins on the last level never count. The answer, that break stops the loop before the sixth level, is the lesson.

Why we teach it this way

A student who only runs code and watches what happens learns what the program did. A student who predicted first learns whether their picture of the program was right, which is the skill that later lets them write code without trial and error.

The same five steps work in Scratch with an eight-year-old and in Java with a Grade 11 student. Only the code changes.

What it looks like in blocks

For a younger student, the same idea is a Scratch sprite that collects coins, with a lives variable and a stop block. The teacher still asks for a prediction before the green flag is clicked.

The point is not the game. It is the moment a child sees that their guess of 3 lives ignored the empty levels, and repairs their own picture of the loop.

Which suits whom

When a Code Ninjas centre fits, and when a live online class fits

We would rather a family chose the option that suits their child than chose us by default. Here is our honest reading of both, based on what each side publishes.

A Code Ninjas centre is likely the better fit when

Your child is 5, 6 or 7 and not yet reading with confidence. Code Ninjas JR is designed for ages 5 to 7 with no reading needed, and our youngest classes begin at age 6.

Your child learns best in a room with other children, likes to drop in more than once a week, and enjoys earning belts at their own speed.

There is a centre on your route home, and an in-person after-school slot also solves a supervision question for your family. Camps during school breaks and robotics with physical kits are other reasons families choose a centre.

A live online class is likely the better fit when

There is no centre within easy reach of home or school, or the drive would take longer than the class.

Your child does better when a teacher leads, asks questions and expects an answer, rather than working through levels alone.

Your child is 14 or older, or already past block coding, and wants a path that continues into teen and adult courses, school computer science, or contest preparation. You also want to see the monthly fee before you call anyone.

Ages 5 to 7

An in-person, no-reading program such as JR suits many children this young. From 6 we also teach Scratch online, in a batch or one to one.

Ages 8 to 13

Both work. Choose on pace: self-paced belts at a centre, or a teacher-led course online.

Ages 14 and up

Code Ninjas publishes programs up to 14. Our teen and adult courses carry on from there.

Deciding

Five steps to decide between a centre and a live class

A simple order that saves time, whichever way you go.

  1. Check the map. Use the Code Ninjas Canadian directory to see whether a centre is near your home or school, and how long the trip would take on a weekday afternoon.
  2. Ask the centre four questions. What does a month cost for the number of visits we want? How many children are usually in the dojo at the time we would come? Who will my child work with each visit? How do you show us progress between belts?
  3. Book both free starts. Code Ninjas offers a free tour or session at a centre. We offer a free first class online. Seeing both is the quickest way to know.
  4. Watch your child, not the screen. Afterwards, ask your child to explain one thing they made and how it works. The setting where they can explain more is usually the right one.
  5. Decide for one term. Neither choice is permanent. Our classes are billed monthly, and a child who outgrows one setting can move to the other.

For more on the online side of this choice, our page on live versus recorded coding classes explains why we keep every class live, and how we teach shows a full lesson plan.

Where a student starts

Four starting points we use in a first class

Our own placement stages, used whether a child has been to a dojo or not.

Placement stages for young coders (ours)
StageWhat we look for
1. ExplorerDrags blocks to make something move, but cannot yet say why it moves
2. BuilderBuilds a small game in blocks and can explain each event
3. TranslatorReads a short typed program and predicts what it prints
4. AuthorWrites a typed program from a blank file and debugs it without help

For parents

A child coming from Code Ninjas belts often places at stage 2 or 3, depending on how far into JavaScript they went. We place by what the child can explain, not by a belt colour.

The step from stage 2 to stage 3 is where many children stall, because typed code punishes small slips. A teacher who asks for predictions shortens that stall.

For students

Before you press run, say out loud what will happen. Then check.

When something breaks, change one thing at a time. Two changes at once hide which one mattered.

Questions from Canadian parents

Code Ninjas and Modern Age Coders: common questions

Is Modern Age Coders part of Code Ninjas?

No. Modern Age Coders is an independent live online school and is not affiliated with, endorsed by or connected to Code Ninjas. Everything on this page about Code Ninjas comes from its own website, read in October 2026.

Does Code Ninjas have centres in Canada?

Yes. On 22 October 2026 the Code Ninjas Canadian directory linked to centre listings in Alberta, British Columbia, Manitoba, Newfoundland and Labrador, Nova Scotia, Ontario and Saskatchewan. Check the directory for a centre near you, because centres open and close.

What ages does Code Ninjas teach?

Code Ninjas says it has programs for kids ages 5 to 14, and that programs vary by centre. JR is for ages 5 to 7 and needs no reading; CREATE is its main belt program for school-age children. Modern Age Coders teaches ages 6 to 67.

How much does Code Ninjas cost in Canada?

Code Ninjas does not publish a fee on its national or Canadian pages. Its FAQ says rates are set by its locally owned and operated centres and asks families to contact a nearby centre for pricing. Our own monthly fee is shown on our pricing page.

Is Code Ninjas self-paced?

Yes, by its own description: kids progress at their own pace through belt-based levels on its IMPACT platform, with Code Senseis in the dojo. Our classes are different: a teacher leads a planned course and the class moves through it together.

Is there an online alternative to Code Ninjas in Canada?

Modern Age Coders teaches coding live online to students across Canada, in a batch of 15 to 20 or alone with a teacher. Every class is taught over live video, so there is no centre to visit.

What times are live online classes for Canadian families?

Weekdays or weekends, flexible: choose your batch, or for a very personalised plan choose 1-on-1 at your convenience, weekend mornings or weekdays. We agree the time in your own province's time zone.

My child already has a Code Ninjas belt. Where would they start with you?

We place every new student in a free first class by what they can explain, not by belt colour. A child who reached the JavaScript belts often starts with typed Python or JavaScript; a child still in MakeCode may continue with blocks for a while.

Code Ninjas or online classes for a 6-year-old?

It depends on the child. Code Ninjas JR is built for ages 5 to 7 with no reading needed, and many young children enjoy being in a room. We teach Scratch online from age 6, in a batch of 15 to 20 or one to one, which suits a child who can sit with a screen and a teacher for an hour.

Can my child do both?

Some families do: a centre for the social side and camps, and a live class for a structured course in a typed language. If your child is at a centre now, a free first class with us is an easy way to see whether a led class adds something.
