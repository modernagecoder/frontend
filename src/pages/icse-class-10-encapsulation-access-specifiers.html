Ans. The short version

Encapsulation in ICSE Class 10 means wrapping a class's data and the methods that use it into one unit, and controlling access to that data. Java does it with access specifiers: private (same class only), default with no keyword (same package), protected (same package and subclasses) and public (everywhere). Making data private and reaching it only through public methods is called data hiding. The same 2027 syllabus unit covers the scope of variables: class, instance, argument and local. Q1. What are access specifiers in Java?

Access specifiers Java ICSE: private, public, protected and default in one table

An access specifier is a keyword placed before a member that decides which other classes may use it. The ICSE syllabus names three, private, protected and public; a member written with no keyword gets a fourth level, called default or package access.

SpecifierSame classAnother class, same packageSubclass, other packageAny other class, other package
privateYesNoNoNo
none (default)YesYesNoNo
protectedYesYesYesNo
publicYesYesYesYes

Read the table as a ladder: each row opens one more door than the row above it. We did not copy it from a book. We wrote a class Locker in a package school with one member at each level, then tried to read all four from three places. Here is what javac 21 reported.

Encapsulation, in one line

Binding data and the methods that work on it into a single unit, the class, so that the data is used only in the ways the class allows.

Data hiding, in one line

Keeping data members private so that no code outside the class can read or change them directly.

Access specifier, in one line

A keyword that sets the visibility of a class member: private, protected, public, or none for default access.

Inheritance is not part of the ICSE Class 10 syllabus, so for the 2027 paper it is enough to know that protected opens a member to subclasses as well as to its own package. Where a class sits among objects and classes generally is covered on class as the basis of all computation.

Q2. How does a class hide its data?

Data hiding ICSE: private members with getter and setter methods

A class hides its data by declaring the members private and offering public methods to read them (accessors, or getters) and to change them (mutators, or setters). The mutator can check a value before accepting it, which is the whole point.

Encapsulation, data hiding and abstraction: the difference

TermWhat it meansIn the Thermostat class
EncapsulationData and methods bundled in one classtemp, getTemp and setTemp live together in Thermostat
Data hidingData kept out of reach of other classestemp is private, so Room cannot touch it
AbstractionShowing what an object does, not howRoom calls setTemp without knowing the 16 to 30 rule inside it
  1. Data members are usually private; methods that other classes need are public.
  2. A getter returns the member's type and takes no parameter: double getTemp().
  3. A setter is usually void and takes one parameter of the member's type.
  4. A private method is allowed: it is a helper used only inside its own class.
  5. A private member is still fully usable inside its own class, including in main if main belongs to that class.

The last rule surprises students in output questions: a main written inside the same class can read a private member directly. Constructors that fill private members are on ICSE Class 10 constructors questions.

Q3. What is the scope of a variable?

Scope of variables ICSE: class, instance, argument and local variables

Q5. What does Section A ask on this chapter?

Encapsulation ICSE Class 10 questions with answers

In Section A, the 40 compulsory marks, this chapter turns up as one-mark MCQs and two-mark definitions or differences. Try each one before opening the answer.

One-mark questions

  1. Which access specifier makes a member visible only inside its own class? (a) public (b) protected (c) private (d) default
    Answer (c) private.
  2. A member declared with no access specifier can be used by:
    Answer Any class in the same package, but no class outside it.
  3. Which keyword lets a method reach a data member hidden by a parameter of the same name?
    Answer this, as in this.marks = marks;
  4. Name the kind of variable declared inside a method body.
    Answer A local variable.
  5. Which kind of variable has exactly one copy however many objects exist?
    Answer A class variable, declared with static.
  6. Which of these is the most open: protected or default?
    Answer protected. It allows everything default allows, plus subclasses in other packages.

Two-mark questions

  1. Define encapsulation. How does a class implement it?
    Answer Encapsulation is wrapping data and the methods that operate on it into a single unit. A class implements it by declaring the data members and methods together, and by keeping the data private and reachable only through its public methods.
  2. Differentiate between private and public members.
    Answer A private member can be used only inside its own class; a public member can be used by any class in any package. Data members are usually private and the methods others need are public.
  3. State the difference between an instance variable and a local variable.
    Answer An instance variable is declared in the class outside every method, belongs to an object and gets a default value. A local variable is declared inside a method or block, exists only until that block ends and must be assigned before use.
  4. Why is data hiding useful? Give one example.
    Answer It stops other classes from putting an object into an impossible state. A private balance can be changed only through a method that refuses a negative amount, so the balance is always valid.
  5. What is the scope of an argument variable?
    Answer The body of the method or constructor in whose header it is declared. It is created when the method is called, holds the passed value, and ends when the method returns.

Questions about encapsulation

What students ask about encapsulation and access specifiers

What is encapsulation in Java ICSE Class 10?

Encapsulation is the wrapping of data and the methods that act on that data into a single unit called a class. In practice it means keeping the data members private and letting other classes use them only through the class's public methods, so the class decides what changes are allowed. It is Unit 6 of the 2026-27 ICSE Computer Applications syllabus.

What are the access specifiers in Java for ICSE?

The syllabus names private, protected and public. private allows access from the same class only; protected from the same package and from subclasses; public from everywhere. A member with no specifier has default, or package, access: any class in the same package can use it, but nothing outside the package can.

What is the difference between private, public and protected?

They differ in how far a member can be seen. private stops at the class itself. protected reaches the whole package and any subclass, even one in another package. public reaches every class in every package. Data members are usually private and methods that other classes call are public.

What is data hiding in ICSE Computer Applications?

Data hiding means keeping a class's data members private so that code outside the class cannot read or change them directly. Other classes must go through public methods, which can check every value first. For example, a private balance changed only by a method that refuses negative amounts can never become negative.

What is the difference between encapsulation and data hiding?

Encapsulation is the bundling of data and methods into one class. Data hiding is one result of it: restricting direct access to that data with the private specifier. A class could bundle data and methods yet leave everything public; that is encapsulated but not hidden, and it is weak design.

What is the scope of variables in Java ICSE?

Scope is the region of a program where a variable can be used. Class variables (static) and instance variables can be used throughout the class. An argument variable can be used only inside its own method. A local variable can be used only from its declaration to the end of the block in which it is declared.

What are the four types of variables in ICSE Class 10?

Class variables, declared static with one shared copy; instance variables, declared in the class without static, one copy per object; argument variables, declared in a method header to receive values; and local variables, declared inside a method or block. The syllabus groups all four under the scope of variables in the Encapsulation unit.

Can a private variable be accessed outside the class?

Not directly. The compiler rejects the line with a message such as "temp has private access in Thermostat". The only way in is through a non-private method of the same class, such as a getter that returns the value or a setter that checks and stores a new one.

Is protected access asked in ICSE Class 10 even though inheritance is not in the syllabus?

The syllabus lists protected among the access specifiers, so a one-mark question on its visibility is fair. You need the rule, not inheritance programs: protected allows access within the same package and from subclasses in other packages. Writing subclasses is an ISC topic.
