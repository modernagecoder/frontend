## One capital region, two school systems, one clock

Statistics Canada treats Ottawa and Gatineau as one census metropolitan area, which it names Ottawa - Gatineau and publishes in an Ontario part and a Quebec part. For a family choosing a class, three practical differences follow.

### The capital itself

Section 16 of the Constitution Act, 1867 settles where Parliament sits: the Seat of Government of Canada shall be Ottawa. The city that holds that role still runs its schools under a provincial curriculum, like every other Canadian city.

### Across the bridge

Quebec's secondary program runs from Secondary I to Secondary V, and students then usually go to CEGEP, where a pre-university program takes two years of full-time study. A Gatineau teenager of sixteen is placed by what they can do, not by the Ontario grade they would be in.

### The same hour

Ontario and Quebec keep the same Eastern clock, so a class booked from Gatineau and one booked from Barrhaven start at the same moment. Both provinces move to UTC-5 on 1 November 2026 and back to UTC-4 on 14 March 2027.

Gatineau families with a student in Secondary IV or V can read our pages on [Quebec Secondary 4 math options](/quebec-secondary-4-math-cst-ts-science) and [Secondary 5 math](/quebec-secondary-5-math-tutor), and students heading to college on [preparing for CEGEP computer science](/cegep-computer-science-preparation). One honest line for every family on either bank: our teaching, our materials and our written feedback are in English.

## Two languages, one parks file: an Ottawa data audit

The City of Ottawa publishes its Parks and Greenspace inventory as open data, with an English and a French version of most columns. Our students decode it, count it, and then check whether the two languages tell the same story. Every figure below is ours, from the file as downloaded on 22 October 2026.

**Our count of the dogs-in-parks designation in the City of Ottawa Parks and Greenspace file (1,378 rows, one per park; downloaded 22 October 2026). The file stores a number; the labels come from the city's map service**

| Code in the file | What the code means | Parks |
|---|---|---|
| 4 | Not Designated (Dogs on Leash) | 631 |
| 1 | Dogs on Leash | 356 |
| 0 | Dogs Allowed (off-leash) | 175 |
| 3 | No Dogs | 119 |
| 2 | Mixed | 69 |
| (blank) | No code recorded | 28 |

The first surprise is that the CSV holds only digits in that column. The meaning of 0 to 4 lives in the city's map service, as a list the service calls a coded-value domain, and a student has to fetch that list before a single count makes sense. The script below carries the list as a Python dictionary, counts the parks, and then runs the audit. It needs nothing beyond Python 3 and the downloaded file in the same folder:

```
import csv

LABELS = {
    "0": "Dogs Allowed (off-leash)",
    "1": "Dogs on Leash",
    "2": "Mixed",
    "3": "No Dogs",
    "4": "Not Designated (Dogs on Leash)",
}
SWAPPED = {("Active Recreation", "Loisirs passifs"),
           ("Passive Recreation", "Loisirs dynamiques")}
counts = {}
type_clash = 0
dog_clash = 0

with open("parks-and-greenspace.csv", encoding="utf-8-sig") as parks:
    for row in csv.DictReader(parks):
        label = LABELS.get(row["DOG_DESIGNATION"], "(blank code)")
        counts[label] = counts.get(label, 0) + 1
        if (row["PARK_TYPE"], row["PARK_TYPE_FR"]) in SWAPPED:
            type_clash += 1
        if row["DOG_DESIGNATION"] != row["DOG_DESIGNATION_FR"]:
            dog_clash += 1

for label in sorted(counts, key=counts.get, reverse=True):
    print(label, counts[label])
print("English and French park type disagree:", type_clash)
print("English and French dog code disagree:", dog_clash)
```

### 1. Decode before counting

A dictionary turns "4" into Not Designated (Dogs on Leash). Rows with no code at all fall through to the label we chose, (blank code), so 28 parks are reported as missing rather than silently dropped.

### 2. Compare the two languages

PARK_TYPE says Active Recreation or Passive Recreation; PARK_TYPE_FR should say Loisirs dynamiques or Loisirs passifs to match. On 36 rows the pair is crossed, 18 in each direction, so the English and French park type disagree.

### 3. Find the one that matters

The dog code is stored twice, once per language, and on exactly one park the English column says 1 (on leash) while the French says 3 (no dogs). A dog owner reading the French map and one reading the English map would get different instructions.

**Our audit checks on the same file. Counts are rows of the City of Ottawa file; none of these totals is published by the city**

| Check | Result |
|---|---|
| Distinct PARK_ID values | 1,378, one per row |
| Wards named in WARD_NAME | 24 |
| Wards with at least one off-leash park | 21; River ward has the most, 23 |
| Park type crossed between English and French | 36 rows |
| Dog code different between English and French | 1 row |
| ACCESSIBLE written as yes/oui, no/non, blank | 269, 1,062 and 47 |

### What the file does not tell you

A park coded on-leash can still keep dogs away from its play area: the city's detail text mentions play areas on 981 of the 987 parks coded 1 or 4, which the code alone cannot show. Nor does the file say which of two disagreeing columns is right. The honest finding is a list of 37 rows to report to the city, not a correction we invent.

## If an AI tool writes the script, what is left for an Ottawa student to learn?

The part where someone notices that the French column and the English column disagree.

Give an AI assistant the Ottawa parks file and ask for a count of off-leash parks, and you will get working code and a number. You will probably not be told that one park says on-leash in English and no dogs in French, or that 36 rows swap their park type between languages. The tool answered the question asked. Knowing which question to ask next is the skill.

That is why we teach students to reason first and type second: plan the steps, write the loop, then interrogate the output. As they get older they use AI tools within age rules we follow, and they use them to check and extend their own thinking, never to hand in someone else's.

Ontario put coding into science and math so that students learn to break a problem into steps; an AI tool can follow those steps, but only a student who understands them can tell when it has followed the wrong ones. The longer argument is in [our essay on why writing code still pays off for a capital-region student](/blog/is-coding-worth-learning-2026).
