Q3. What does a class teach, concretely?

A worked Computer Vision question, from paper to program

Unit 5, Computer Vision, is worth 4 theory marks, but its ideas run straight into the practical, so a good class takes one question from the written answer to working code. This question is ours.

Question

A traffic camera records frames of 1280 x 720 pixels in colour. (a) How many pixels does one frame have? (b) How many values are stored for one frame in RGB? (c) If each value uses 8 bits, what range can a pixel value take? (d) A pixel reads (200, 120, 40). What is its grayscale value by the averaging method?

Written answer

  1. Pixels = width x height = 1280 x 720 = 921,600.
  2. RGB stores three values per pixel: 921,600 x 3 = 2,764,800.
  3. 8 bits give 28 = 256 levels, so values run from 0 to 255.
  4. (200 + 120 + 40) / 3 = 360 / 3 = 120.

A follow-up we set in class: a 640 x 360 thumbnail has 230,400 pixels and 691,200 RGB values, a quarter of the full frame because both sides are halved.

Where students lose the marks

  • Multiplying by 3 in part (a), which asks for pixels, not values.
  • Writing the range as 1 to 256 instead of 0 to 255.
  • Leaving out the working: a bare 120 shows no method.

The same idea as a practical program: a tiny RGB image turned grayscale

Q5. How do online classes prepare a practical that happens at school?

Python or Orange in the school practical: prepare for both

Your school sets the practical task, the date and the examiner, and the 417 curriculum leaves room for both code and no-code tools. So students prepare the same task both ways and arrive able to do whichever the school asks.

The 50 practical marks, as the school awards them

  • Practical file, 15: at least 15 programs, written and run during the year.
  • Practical exam, 15: a task on the day, drawn from the practical units: Statistical Data, Computer Vision, NLP and Advance Python.
  • Viva, 5: questions on the file and the practical units.
  • Project, 10, and project viva, 5: one AI project taken through the project cycle and explained aloud.

Questions from Bengaluru parents

Class 10 AI tuition in Bangalore: questions parents ask

Do you offer class 10 AI tuition in Bangalore?

Yes, as live online classes; there is no Modern Age Coders centre in Bengaluru. Students taking Artificial Intelligence (417) at a CBSE school log in to the twice-weekly group at 9:00 PM IST (Mondays and Wednesdays) or book private classes on days that suit them. Both the written paper and the lab half are taught.

My child is on the Karnataka state board. Is AI 417 for them?

No. Subject 417 is a CBSE skill subject, so it is examined only for students at CBSE-affiliated schools. State board students write the SSLC, which has its own syllabus. This page and its classes are for CBSE students. If your child moves from a state board school to a CBSE school for Class 9, 417 becomes an option then.

We are on ICSE. Is there a Java equivalent?

Yes. ICSE students take Computer Applications in Java with BlueJ, a different paper with its own internal assessment. We teach it in a separate small batch; see the ICSE computer tuition in Bangalore page linked on this page. It is a mini batch for families in India, with one to one as the other choice.

How do I find a 417 tutor in Bangalore?

Check four things: the tutor teaches the 2026-27 unit names, knows that Statistical Data and Advance Python are tested only in the practical, uses Python and Orange, and prepares the file, project and viva. A free live class shows you those things better than a phone call.

Which CBSE regional office covers Bengaluru schools?

The Bengaluru regional office, on Hesaraghatta Main Road in Chikkabanavara, covers Karnataka, according to the regional offices page on cbse.gov.in. Your school deals with it for registration and admit cards; families normally do not need to. Schools in Tamil Nadu, Andhra Pradesh and Telangana are under Chennai instead.

Are AI classes for Bengaluru CBSE students only theory?

No. Half of the 100 marks are practical, awarded by the school for the program file, a task on lab day, the project and two oral rounds. Wednesday classes teach Python and Orange for those tasks, build the file and project, and rehearse the viva.

Is 9 PM too late for a Class 10 student?

For many it is the first hour without school, travel or activities. If it is too late for your child, one to one can be set earlier in the evening or on a weekend, and moved when the school calendar changes.

Can my child take both AI 417 and Computer Applications 165?

No. CBSE does not allow 417 to be taken with Computer Applications (165), so a student has one or the other. If your child is on 165, these classes are not the right match. Check the subject list on the school timetable or the registration slip if you are unsure which code your child has.
