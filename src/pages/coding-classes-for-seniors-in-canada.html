Coding classes for seniors in Canada

Plenty of people start programming after a working life in something else entirely. Some want to understand the technology their grandchildren talk about, some want a small tool that does a job at home, and some simply enjoy a puzzle that answers back. This page is for them. It explains how we pace classes for older beginners, how to make the screen easy to read before the first line of code, and walks through two complete projects from our classes: a birthday reminder written in Python, and a checker that tells you whether text on a web page is easy enough to read.

How we pace it

A patient way to learn programming later in life

Older beginners learn programming perfectly well. What usually goes wrong is the pace: courses written for students racing to a deadline pile up new words faster than anyone can absorb them. These are the principles we teach by, written by us.

How we teach older beginners (our principles)
PrincipleWhat it means in a class
One idea per classA class introduces one new idea, such as a loop, and spends the rest of the hour using it in different ways.
Plain words firstEvery technical word is explained in everyday language before it is used, and kept on a running word list.
Typing it yourselfYou type every line. Watching someone else code feels like learning but rarely sticks.
Mistakes on purposeThe teacher breaks a working program and you fix it, so error messages become familiar instead of frightening.
A recap you writeThe last minutes of each class go on writing down, in your own words, what was covered, plus one small exercise to try.
Repeat without apologyAny idea can be taught again, in another way, as often as needed. Nobody is behind.
Finish something usefulEvery few weeks ends with a small program you will actually use, not an exercise thrown away.

Why one to one often suits

Many older learners prefer a teacher to themselves at first, because the pace is entirely theirs and questions never feel like an interruption.

Others enjoy learning alongside other adults in a batch of fifteen to twenty. Both work; the first class is a good time to decide.

What you need at home

A laptop or desktop computer, a reliable internet connection, and a quiet place for an hour. A mouse often feels easier than a touchpad.

Nothing needs to be bought. Python and the editor we use are free, and we install them together, step by step, during the first class.

Before the first line of code

Making the screen comfortable to read

Small grey text on a bright screen makes any lesson harder. We spend part of the first class making text larger and clearer, using settings that already exist. The web standards behind this are public, and so are Python's own settings.

Settings that make coding easier on the eyes, with the standard or documentation behind each (read 22 October 2026)
What to changeWhat the source saysHow we do it in class
Text size on web pagesWCAG 2.2 asks that text "can be resized without assistive technology up to 200 percent without loss of content or functionality."Browser zoom: hold Ctrl (Command on a Mac) and press the plus key until reading is comfortable.
Contrast between text and backgroundWCAG 2.2 sets a contrast ratio "of at least 4.5:1" for normal text, and at least 3:1 for large-scale text.Dark text on a pale background in the editor; our second project below measures it.
Buttons and links you can hitWCAG 2.2 added a new criterion, Target Size (Minimum): a pointer target "is at least 24 by 24 CSS pixels", with some exceptions.When you build web pages, we make buttons generous from the start.
The Python editor's fontIDLE, "Python's Integrated Development and Learning Environment", lets you change "fonts, indentation, keybindings, text color themes, startup windows and size".Options, then Configure IDLE, then the Font tab, where the documentation says to "see the text sample for the effect of font face and size".

A checklist for the first class

Zoom the browser so this page reads easily. Set the editor font to a size you can read from a relaxed sitting position. Choose a light or dark colour theme, whichever feels calmer.

Turn up the volume on the video call, and if it helps, turn on the call's own captions. Keep a notebook and pen beside the keyboard.

Why accessibility is part of the course

The settings that help you read your own code are the same ideas good web developers build into every page. Learners who build websites with us learn to meet these standards for other people too.

Canada's federal Accessible Canada Act sets the aim of "a Canada without barriers, on or before January 1, 2040". Readable, usable websites are one small part of that.

Sources: W3C, Web Content Accessibility Guidelines (WCAG) 2.2, Recommendation of 12 December 2024; Python documentation, IDLE; Accessible Canada Act. All read 22 October 2026.

Project one

Project one: a birthday reminder in Python

This is a project we wrote for our older beginners, usually around week six. It reads a short list of family birthdays from a file and prints the ones coming up in the next thirty days, soonest first.

The list lives in a CSV file, the plain format spreadsheets can save. The Python documentation describes it as "the most common import and export format for spreadsheets and databases", so a learner can keep the list in a spreadsheet and save it as CSV.

  1. Read it aloud first. Before running anything, the teacher and learner read the program line by line in plain English: open the file, look at each row, work out the next birthday, keep it if it is close.
  2. Run it and compare. Three names appear. Daniel (19 December) and Priya (8 January) are further than thirty days away, so they are left out.
  3. Change one thing. Set window to 60 and run it again. Daniel now appears, Priya still does not. This is how a learner discovers what a variable does.
  4. Break it on purpose. Add a line Sam,13,5 to the CSV. Python stops with an error, because there is no thirteenth month. Reading that message calmly is a skill in itself.
  5. Ask the awkward question. What happens to someone born on 29 February in a year that has no 29 February? Finding that out, and deciding what the program should do, is real programming.

What this project teaches

Reading a file, looping over its rows, making a decision for each one, and sorting the results. Those four ideas sit underneath a surprising amount of everyday software.

It also teaches the habit we care about most: change one thing, run it, see what happened.

Where it can go next

Add anniversaries in a second column. Print how old each person will be. Later, turn the list into a small web page that shows the month ahead.

Each step adds one small idea to a program that already works. We call that our rule for older beginners: one small, useful program at a time.

Project two

Project two: a colour contrast checker built on WCAG 2.2

Older learners who build websites often care about readability more than anyone. This project, also ours, turns the contrast formula published in WCAG 2.2 into a short Python program that tells you whether text will be easy to read on its background.

WCAG 2.2 defines relative luminance as "L = 0.2126 * R + 0.7152 * G + 0.0722 * B", after each colour channel is adjusted with the rule "if RsRGB <= 0.04045 then R = RsRGB/12.92 else R = ((RsRGB+0.055)/1.055) ^ 2.4". The contrast ratio is then "(L1 + 0.05) / (L2 + 0.05)", lighter colour on top. The program follows those three formulas exactly.

Reading the result

Near-black on cream scores about 16.65 to 1, far above the 4.5 to 1 that WCAG 2.2 asks for normal text. Mid-grey on white scores 3.54 to 1 and fails, which is why so much small grey web text is tiring to read.

The third pair is the colour used for headings on this page, and it passes with 8.08 to 1.

Why a formula is a good first project

It shows that a published standard can be turned into code line by line, and that the code can be checked against the standard. Nothing is magic.

Learners then use the checker on the colours of their own first website, before anyone else sees it.

The first eight weeks

An eight-week start for a complete beginner

Our plan for an older learner starting Python one to one, with two classes a week. A group moves at the pace of the group, and any week can be repeated.

  1. Week 1: set up the screen and the editor together; type a first line and see it run; learn what an error message looks like and that it is not your fault.
  2. Week 2: storing information in variables; asking a question with input and answering it with print; a greeting program that uses your name.
  3. Week 3: making decisions with if and else; a program that answers differently depending on the reply.
  4. Week 4: repeating with loops; a times-table printer; a number-guessing game to play with family.
  5. Week 5: lists of things; adding, removing and sorting a shopping list or a list of club members.
  6. Week 6: reading a file; the birthday reminder above, built step by step over both classes.
  7. Week 7: writing your own small functions, so a program reads like a set of named steps.
  8. Week 8: a project of your choice from the table above, finished and kept, with a talk about what comes next.

Across Canada

Class times for learners in every province

Our teachers teach from India, which lets them cover hours across all of Canada's time zones. Times are agreed in your own local clock.

Two clock changes affect learners this season. Eastern and Atlantic Canada, and Newfoundland, set their clocks back on Sunday 1 November 2026 and forward on Sunday 14 March 2027. British Columbia stays on UTC-7 all year, Alberta and Saskatchewan on UTC-6, and Manitoba moves to UTC-5 all year from 1 November 2026. If your grandchildren live in another province, a class time can look different on their clock than on yours, so we always state the time in your own zone and check it again after each change. Many retired learners like weekend mornings; others prefer a weekday slot. Both are available, and a one-to-one plan can move from week to week.

Questions from older learners

Coding for seniors: common questions

Is it too late to learn to code in retirement?

No. Programming rewards patience, care and curiosity, which many retired learners have in abundance. Our learners include adults in their sixties, and steady practice matters far more than age.

Do you have a special course for seniors?

Not a separate course. We teach our beginner courses, such as Python from zero or HTML and CSS for Beginners, at a slower pace for older learners, with a recap at the end of each class and as much repetition as each person wants.

I am not confident with computers. Can I still join?

Yes. The first classes include any computer basics you need, such as saving and finding files, and we set up everything together on the call.

Can you make the text bigger on screen?

Yes, and we do it in the first class. We use the browser's own zoom and the font settings in the Python editor, so text is large and clear before any coding starts.

What can I actually make?

Small programs that help at home: a birthday reminder, a planting log, a sorted list for a club, a game for grandchildren, or a simple family website. Each one is finished and kept.

Is one-to-one better than a group?

Many older learners start one to one so the pace is entirely their own, then some move to a batch of fifteen to twenty for company. Both work well.

What equipment do I need?

A laptop or desktop computer and a reliable internet connection. A mouse is often easier than a touchpad. The software we use is free.

When can classes be held?

Weekdays or weekends, flexible: choose your batch, or for a very personalised plan choose 1-on-1 at your convenience, weekend mornings or weekdays. We give every time in your own province's clock.

Will there be tests or homework?

There are no exams. Each class ends with a short recap and one small optional exercise, usually twenty to thirty minutes of practice.

Can my grandchild and I learn together?

Our courses for children and our courses for adults are separate, but many grandparents and grandchildren take parallel courses and compare projects. We are happy to suggest matching courses.
