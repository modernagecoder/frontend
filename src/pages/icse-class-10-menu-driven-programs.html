Ans. The short version

A menu driven program in Java for ICSE Class 10 prints a list of options, reads the user's choice with Scanner, and uses a switch statement to run only the code for that choice. A full-mark Section B answer has five parts: the printed menu, the choice read in, one case per option, a break ending every case, and a default case printing a message such as "Invalid choice" for any other input. Stacked labels let 'A' and 'a' share code. Modern Age Coders teaches this live in a Tuesday and Wednesday mini batch in India, or one to one at the family's time.

Q1. What should a menu driven answer look like in Section B?

Menu driven program Section B template: five parts, in order

Write the same five parts every time, whatever the options do. The examiner looks for each part, and a missing default case or a missing break is the commonest way to drop marks on an otherwise working menu.

PartWhat to writeWhy it matters
1. The menuOne System.out.println per option, numbered or lettered exactly as the question words themThe user, and the examiner, must see what each choice does
2. The choiceint ch = sc.nextInt(); or char ch = sc.next().charAt(0);The type of ch decides how the case labels are written
3. One case per optioncase 1: followed by the full logic for that option, including its own inputEach option is a small program; read only the data that option needs
4. A break per casebreak; as the last line of every caseWithout it, control falls into the next case and runs that code too
5. The default casedefault: System.out.println("Invalid choice");The question almost always says "for an incorrect choice, display an appropriate message"; this is that message

Q2. How do you write a menu with letters instead of numbers?

Switch case programs ICSE Class 10: a char menu with stacked case labels

Read the choice as a char with sc.next().charAt(0) and put each letter in single quotes. To accept both capital and small letters, stack two labels on one block: case 'G': case 'g':. This is deliberate fall-through, the one place it helps.

Q3. How do you make a menu repeat until the user exits?

A repeating menu driven program: do-while, methods and an exit option

Wrap the menu and the switch in a do-while loop that runs until the exit choice is entered. do-while fits because the menu must appear at least once. Moving each option's work into a method keeps the switch short and shows user-defined methods at the same time.

Q4. What do switch case questions in Section A ask?

Switch case questions ICSE: fall-through, stacked labels, conversions and errors

Short switch questions test four things: what a fragment prints when a break is missing, how to convert an if-else ladder into a switch, which selector types are allowed, and which case labels will not compile. Try each before opening the answer.

  1. Rewrite with switch: marks m (0 to 100) give grade A for 90 and above, B for 70 to 89, C for 60 to 69 and D below 60.

  2. Predict the output.

  3. Predict the output. The default label does not have to come last.

  4. Can a switch work on a String? Yes. Since Java 7 the selector can be a String, compared with equals behind the scenes.

Questions about menu programs

What students ask about menu driven programs and switch case

What is a menu driven program in Java?

It is a program that shows the user a list of options, reads which option they want, and then runs only the code for that option. In ICSE Class 10 the choice is read with Scanner and the branching is done with a switch statement, with a default case for a choice that is not on the list.

How do you write a menu driven program using switch case in Java?

Print the menu with one println per option, read the choice into an int or char, then write switch (choice) with one case per option. Put the full logic for each option inside its case and end it with break. Finish with a default case that prints a message such as "Invalid choice".

Why is the default case important in a menu driven program?

ICSE questions usually ask for an appropriate message when the user enters a wrong choice, and the default case is where that message goes. Leaving it out means a wrong choice silently does nothing, and the answer misses part of what the question asked.

What happens if break is missing in a switch case?

Control falls through into the next case and runs its statements too, until it meets a break or the end of the switch. The case is chosen only once, at the top, so changing the variable inside a case does not redirect control. Stacking labels such as case 'A': case 'a': uses fall-through on purpose.

Can we use a char in a switch statement in Java?

Yes. Read the choice with sc.next().charAt(0) and write each label in single quotes, such as case 'G':. To accept both capital and small letters, stack two labels on the same block of code.

Can switch case be used with double or boolean in Java?

No. In the switch with constant case labels that ICSE uses, the selector may be byte, short, char, int, their wrapper classes, a String or an enum. A double, float, long or boolean selector does not compile, so use an if-else ladder for those.

What is the difference between switch case and if-else in Java?

switch compares one expression with fixed constant values and needs break to stop fall-through. if-else can test any condition, including ranges and several variables, and runs only the first true branch. Menus suit switch; slabs and ranges suit if-else.

How do you repeat a menu until the user chooses exit?

Put the menu and the switch inside a do-while loop and declare the choice variable before the loop. Add an exit option, for example case 4, and end the loop with while (choice != 4). do-while suits a menu because it must be shown at least once.

Are menu driven programs asked in the ICSE Class 10 board exam?

Menu and switch case questions are a regular Section B shape, often pairing a pattern with a series or two calculations. Switch also appears in Section A as output and conversion questions. Practising the five-part template prepares a student for both.
