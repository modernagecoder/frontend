> BlueJ is the free, open-source Java environment that ICSE schools use for Computer Applications, that CISCE's papers name, and in which the internal assessment and practical examination take place. Coaching for it means four things: a working installation on the student's own Windows or Mac machine, fluency with the class diagram, object bench and terminal as tools for understanding classes and objects, the ability to read the eight compiler and runtime errors a Class 10 student regularly meets and fix them without help, and lab assignments organised as clean BlueJ projects ready for an external examiner. Modern Age Coders teaches all of it inside the Tuesday 5:30 PM and Wednesday 8 PM mini batch of three or four, with screens shared every Wednesday.

## Set-up in one evening, and the four parts of the window

Download the current BlueJ 5 installer; the Windows and Mac installers bundle a Java runtime. Create one subject folder with one BlueJ project per assignment or topic, the folder that travels between home and the school lab. Write, compile and run one class in the first fifteen minutes. The window has four parts worth knowing: the class diagram, where each class is a box; the editor, with the Compile button; the object bench, where objects appear when created from a class and can have their methods called and fields inspected; and the terminal window, where output appears and input is typed. Two objects of one Student class on the bench turn the class-versus-object definition into two boxes with different names in them.

## The eight errors decoded

cannot find symbol: a name used that was never declared or is spelt differently; check spelling, capitals and scope. ';' expected: a statement did not end, usually a missing semicolon on the previous line. incompatible types: a value of one type put where another is required; cast it or change the type. missing return statement: some path through a method reaches the end without returning; check the if and else branches. unreachable statement: a line after a return or break. ArrayIndexOutOfBoundsException: an index the array does not have, usually length itself; the loop condition must be i less than a.length. NullPointerException: a method called on a variable holding nothing; check the object was created with new. InputMismatchException: Scanner asked for one type and the user typed another. The first five stop compilation; the last three appear at run time, which is why awkward-input testing matters.

## Reading an error, two ways

A grade method with an if and an else-if but no final else will not compile: missing return statement. Student one retypes it three times and closes BlueJ. Student two reads the message as a sentence, asks which path reaches the end without returning, marks below 60, adds the else, compiles, and tests with 45. Read the message, find the line, ask what the message says about that line, change one thing, compile again.

## The lab file as BlueJ projects

One folder tree, one project per assignment or topic, named so a stranger could find the array search program; each with its source, its variable description, its real terminal output and a line saying what it demonstrates. Twenty is the minimum, the batch produces closer to twenty-five spanning every unit, and the two-sentence walk-through of every program is practised weekly for the external examiner.

## What wins on the practical day

Read the whole question before touching the keyboard. Write the class shell first, then the variable description. Compile early and often. Test with one ordinary input and one awkward one. Be ready to explain any line out loud. The school sets the day's format within CISCE's framework; the dress rehearsal runs it once with an unfamiliar teacher.

## Six BlueJ mistakes the syllabus never mentions

The class name and file name disagree after a rename outside BlueJ; running a striped, uncompiled class; typing input into the editor instead of the terminal; projects scattered across the desktop; output not captured before the terminal is closed; the object bench never used.

## Frequently asked questions

**Is BlueJ free, and on a Mac?** Free and open source, on Windows, Mac and Linux, with a Java runtime bundled in the installers.

**Which version?** A current BlueJ 5 release, 5.4 or later, on Java 11 or later; older school versions behave the same for Class 10 work.

**Can another editor be used?** CISCE refers to BlueJ or any environment with Java as the base; schools use BlueJ, and its object bench is a genuine teaching tool.

**What is the object bench?** Where created objects live so their methods can be called and fields inspected; not examined directly, but the best way to learn what is examined.

**The practical day?** A problem solved in Java in the school lab within a set time, with questions from the examiner; format set by the school within CISCE's framework.

**Slow typing?** Programs are thirty to sixty lines; what slows students is retyping without a plan.
