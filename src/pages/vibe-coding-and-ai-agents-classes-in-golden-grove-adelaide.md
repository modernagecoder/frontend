## One question, six true answers

Vague request: "How busy is Golden Grove's public transport?" Every answer below was computed from the same timetable file (feed version 1708). Each is correct for some reading of the question.

| Reading of "busy" and "Golden Grove" | Answer |
| --- | --- |
| Stop records inside the ABS suburb boundary | 75 |
| Stop records whose name contains "Golden Grove" | 46 (only 15 inside the suburb) |
| Scheduled visits on Wednesday 21 October 2026 | 2,843 |
| Scheduled visits on Saturday 24 October 2026 | 1,188 |
| Scheduled visits on Sunday 25 October 2026 | 1,116 |
| Routes serving the suburb that Wednesday | 28 |

### Place is ambiguous

Golden Grove Road runs well beyond the suburb, so searching stop names finds 46 records, 31 of them outside the boundary.

### Measure is ambiguous

Stops, visits and routes all describe "busy" differently, and visits change more than twofold between a weekday and a Sunday.

### Day is ambiguous

A timetable covers six months of service patterns. Without a date, any count mixes days that never run together.

### The specific version

"Count scheduled visits at stop records inside the ABS boundary of Golden Grove, all modes, on Wednesday 21 October 2026." That request has one answer, 2,843, and anyone can check it against the file. Given that wording, our scripted agent has nothing left to guess.

All six answers come from one Adelaide Metro open data file; deciding which stops sit inside Golden Grove, and every tally, was our own work. The agent answering these questions is a script we wrote to show the effect of wording, not a transcript from a commercial AI model.

## Turning a vague request into a specific one

Four quick edits remove most ambiguity before an agent writes a line of code.

| Pin down | Vague | Specific |
| --- | --- | --- |
| The place | Golden Grove | Inside the ABS suburb boundary |
| The measure | How busy | Scheduled stop visits, all modes |
| The time | Unstated | Wednesday 21 October 2026 |
| The source | Unstated | Adelaide Metro timetable, version 1708 |

### Primary learners

Give a friend directions to draw a house, first vaguely, then precisely, and compare the drawings.

### Secondary learners

Ask an AI tool a vague and a specific question about local buses and explain why the answers differ.

### Adults

Before delegating analysis to an agent, write down the place, measure, period and source you mean.

Specific wording also makes the result reusable: next month, the same request run on a newer timetable gives a number that can be compared like for like, which six loosely related answers never allow.

## If the agent does the work, what is left for the learner?

Deciding exactly what is being asked. That part cannot be delegated.

Vibe coding turns descriptions into software, so the quality of the description sets the ceiling on the result. An agent given "how busy is Golden Grove" will pick a reading, perhaps 46 name matches, and present it with full confidence.

Learners who have seen six true answers to one question learn to specify place, measure, day and source. That skill makes every AI tool they use more accurate, now and as the tools change.

In Golden Grove, the learner who asks precisely gets the one answer that matters. The longer argument is in [why teenagers should still learn to code in 2026](/blog/is-coding-worth-learning-2026).

## Golden Grove vibe coding and agent questions

Questions Golden Grove families and adults ask about AI and coding.

### How many people live in Golden Grove?

The 2021 Census QuickStats count 10,299 residents in the suburb of Golden Grove, with 2,974 families and 4,119 private dwellings.

### Why do vague prompts give unreliable answers?

A vague prompt allows several reasonable interpretations, and an AI picks one without saying so. Different runs or tools may pick differently, so the answer seems to change.

### What makes a prompt specific?

It names the exact place, the measure, the time period and the data source, so only one answer fits and anyone can check it.

### How busy is public transport in Golden Grove?

It depends what you mean. By our count of the Adelaide Metro timetable, stop records inside Golden Grove had 2,843 scheduled visits on Wednesday 21 October 2026 and 1,116 on Sunday 25 October.

### What is an AI agent?

An AI system that plans and carries out several steps, such as querying data and writing code, to complete a task rather than answer one message.
