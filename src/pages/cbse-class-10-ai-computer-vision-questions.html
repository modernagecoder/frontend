Q2. Count the pixels

Pixel and resolution class 10: definitions and the sums

A pixel, short for picture element, is the smallest unit of a digital image. Resolution is the number of pixels in an image, written as width x height, so a 1920 x 1080 image has 1920 pixels across and 1080 down.

Grayscale and RGB

Grayscale: each pixel holds one number for brightness. In a byte image that number runs from 0 (black) to 255 (white), because one byte has 8 bits and 2 to the power 8 is 256 possible values.

RGB: each pixel holds three numbers, one each for red, green and blue, each from 0 to 255. Mixing them gives the colour. That is why an RGB image stores three times as many values as a grayscale image of the same size.

One simple way to turn a colour pixel grey is to average its three values: (90, 180, 30) becomes 100. Image libraries such as OpenCV weight green most, which gives 136 for the same pixel, so say which method you used.

Q3. Name the task

Computer vision tasks and applications, with the one-mark distinctions

Computer vision is the field of AI that lets a machine take in images or video and extract information from them to make a decision. Image processing, by contrast, only changes an image, such as brightening or resizing it; it is a subset of computer vision.

Q4. Apply the kernel

Convolution operator class 10 and the kernel, worked by hand, then CNN

Convolution is the operation of sliding a small matrix, the kernel, over an image, multiplying the overlapping values cell by cell and adding them up to give one output value per position. A kernel is that small matrix; its numbers decide the effect, such as blurring, sharpening or finding edges.

The first position, step by step

Place the kernel on the top-left 3 x 3 patch (columns 1 to 3). Each row gives -10 + 0 + 80 = 70, and three rows give 210.

Move one column right (columns 2 to 4). Each row now gives -80 + 0 + 10 = -70, so the sum is -210. One more step right gives -210 again.

A 5 x 5 image and a 3 x 3 kernel, with no padding, give a 3 x 3 output, because 5 - 3 + 1 = 3. Each output row is 210, -210, -210: a large positive value where dark turns light, a large negative one where light turns dark. That is an edge, found by arithmetic.

The four layers of a CNN class 10 students should name

LayerWhat it doesWorked numbers
1. Convolution layerApplies kernels to pull out features such as edges, giving a feature mapThe 3 x 3 map above
2. ReLU (Rectified Linear Unit)Replaces every negative value with 0 and keeps positives as they are-210 becomes 0; 210 stays 210
3. Pooling layerShrinks the feature map while keeping the important values; max pooling keeps the largest in each block, average pooling the mean[[3,1,0,2],[5,4,1,1],[0,2,6,8],[1,3,7,2]] with 2 x 2 blocks: max gives [[5,2],[3,8]], average gives [[3.25,1],[1.5,5.75]]
4. Fully connected layerTakes the final features and decides the label"healthy coral" or "bleached coral"

Q5. Practise for paper and viva

Computer vision class 10 questions and answers to practise

The first set is the shape of the theory paper. The second is what an examiner may ask in the practical viva, where kernels and CNN layers come up.

For the theory paper

  1. How many pixels does an 800 x 600 image have, and how many values does it store in RGB?
    Answer 800 x 600 = 480,000 pixels; x 3 = 1,440,000 values.
  2. A grayscale pixel reads 255. What does it show?
    Answer White, the brightest possible value. 0 would be black.
  3. Which colour is (255, 255, 0)?
    Answer Yellow: full red and full green, no blue.
  4. A model outlines the exact shape of each of three dogs in a photo. Name the task.
    Answer Instance segmentation. Boxes alone would be object detection.
  5. Is brightening a dark photo computer vision or image processing?
    Answer Image processing: it changes the image but extracts no information.
  6. Differentiate between grayscale and RGB images. (2 marks)
    Answer A grayscale image stores one value per pixel, from 0 for black to 255 for white, showing only brightness. An RGB image stores three values per pixel, for red, green and blue, each from 0 to 255, and mixes them to show colour, so it holds three times as much data.

For the practical and viva

  1. A 6 x 6 image is convolved with a 3 x 3 kernel without padding. What size is the output?
    Answer 4 x 4, since 6 - 3 + 1 = 4.
  2. Kernel [[0,1,0],[1,-4,1],[0,1,0]] is placed on the patch [[2,4,6],[1,3,5],[0,2,4]]. What is the result?
    Answer 0. The four neighbours add to 4 + 1 + 5 + 2 = 12 and the centre gives 3 x -4 = -12. A smooth region gives no edge response.
  3. The same kernel on a patch of 1s with a 9 in the centre gives -32. What does ReLU turn it into?
    Answer 0, because ReLU replaces every negative value with 0.
  4. Why is pooling used in a CNN?
    Answer It makes the feature map smaller, so later layers have less to process, and it keeps the result steady when the object shifts slightly in the image.
  5. What is the first layer of a CNN, and what does it produce?
    Answer The convolution layer. It produces feature maps that show where features such as edges occur.

Questions about Computer Vision in Class 10 AI

Computer vision class 10: questions students ask

How many marks is computer vision in class 10 AI 2026-27?

Unit 5, Computer Vision, carries 4 of the 50 theory marks in CBSE 417 for 2026-27, the smallest theory unit. The curriculum gives it 10 theory hours but 20 practical hours, so much of its weight is felt in the practical exam, the practical file and the viva rather than in the written paper.

What questions come from computer vision in the class 10 AI paper?

In the 2025-26 sample paper there were four one-mark objective items and one two-mark question from this unit, and no four-mark question. Expect pixel or value counts, grayscale against RGB, naming a CV task from a description and examples of applications. The 2026-27 sample paper for 417 is not out yet.

What is CNN in class 10 AI?

A Convolutional Neural Network is a deep learning model built for images. It passes an image through a convolution layer that finds features, a ReLU layer that removes negative values, a pooling layer that shrinks the result, and a fully connected layer that gives the final label. In 2026-27 it is listed in the practical part of Unit 5.

What is the convolution operator in class 10?

Convolution slides a small matrix called a kernel across an image. At each position the overlapping numbers are multiplied cell by cell and added, giving one value of the output. With a 5 x 5 image and a 3 x 3 kernel and no padding, the output is 3 x 3. It is used to find features such as edges.

What is a kernel in class 10 AI?

A kernel is a small matrix of numbers, often 3 x 3, that is slid over an image during convolution. Its values decide the effect: one kernel blurs, another sharpens, another finds vertical edges. In a CNN, the kernel values are learned during training instead of being typed in.

What is a pixel and resolution in class 10?

A pixel is the smallest unit of a digital image, one dot holding a value. Resolution is the number of pixels, written as width x height, so a 1920 x 1080 image has 2,073,600 pixels. Higher resolution means more pixels and finer detail, and a larger file.

What is the difference between grayscale and RGB?

A grayscale image stores one number per pixel, from 0 for black to 255 for white. An RGB image stores three numbers per pixel, for red, green and blue, each from 0 to 255. So an RGB image of the same size stores three times as many values: 800 x 600 gives 480,000 grayscale values but 1,440,000 RGB values.

Why do pixel values go from 0 to 255?

A byte image gives each value 8 bits. Eight bits can form 2 to the power 8, or 256, different patterns, so the values run from 0 to 255. That is also why each of R, G and B has 256 levels in a standard colour image.

Which computer vision programs are in the class 10 AI practical file?

CBSE's suggested list for 2026-27 includes two image programs: read an image and display it using Python, and read an image and identify its shape. The shape is the array's height, width and number of colour channels. Your school may add more; at least 15 programs are needed in the file.

Is it worth studying computer vision if it is only 4 marks?

Yes, for two reasons. The theory marks are among the easiest to secure, since most are short definitions or counts. And the practical exam, file and viva together are worth far more than 4 marks, and Computer Vision is part of them, so skipping the unit costs marks there.
