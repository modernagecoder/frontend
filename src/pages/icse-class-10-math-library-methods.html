Ans. The short version

The Math library methods in ICSE Computer Applications are the static methods of Java's Math class in java.lang: pow, sqrt, cbrt, ceil, floor, round, abs, max, min and random. Most marks depend on return types. pow, sqrt, cbrt, ceil, floor and random always return double, so whole answers print with .0; round of a double returns a long with no decimal; abs, max and min return the type of their arguments after promotion. They are part of the Class 9 syllabus that the 2027 Class 10 paper revises. Modern Age Coders drills them live in a Tuesday and Wednesday mini batch in India, or one to one.

Six always give double

pow, sqrt, cbrt, ceil, floor and random return double whatever you pass in. Even Math.sqrt of a perfect square prints a decimal point.

round is the odd one out

Math.round of a double returns long, of a float returns int. Either way, the answer has no .0. Halves round upwards, towards positive infinity.

Three follow their arguments

abs, max and min return int for ints and double for doubles. If one argument is int and the other double, the int is promoted first, so the result is double.

Your textbook may mention other Math methods such as sin, log or exp. The 2026-27 syllabus list we checked names only the ten above, so this page stays with those. How these methods sit beside the wrapper classes and Character methods is covered on wrapper and library classes for ICSE.

Q4. How do you get a random whole number in a range?

Math.random in ICSE Java: whole numbers in a range, and two programs

Math.random() gives a double from 0.0 up to but not including 1.0. To get a whole number from low to high, use low + (int) (Math.random() * (high - low + 1)): multiply to stretch the range, cast to cut off the fraction, then shift it.

GoalExpressionSmallest and largest seen
A dice roll, 1 to 6(int) (Math.random() * 6) + 11 and 6 (a million runs)
A four-digit code, 1000 to 99991000 + (int) (Math.random() * 9000)1000 and 9999 (two million runs)
The bracket slip(int) Math.random() * 6 + 11 and 1 (a million runs)

The last row is the trap. The cast applies to Math.random() alone, which is always below 1.0, so it becomes 0 every time and the "dice" always shows 1. Brackets around the multiplication are what make the expression work.

Q5. What does Section A ask about Math methods?

Math library methods ICSE questions with answers

These questions come in Question 1 as one-mark MCQs and in Question 2 as two-mark parts: give the output, name the return type, or write the expression. Answer each before opening it.

One-mark questions

  1. Which package contains the Math class?
    Answer java.lang, which is imported into every program automatically.
  2. What is the return type of Math.ceil(5)?
    Answer double. It returns 5.0.
  3. Give the output of Math.round(8.49) + Math.round(8.5).
    Answer 17. 8 + 9, added as long values.
  4. Which Math method returns a value from 0.0 up to but not including 1.0?
    Answer Math.random().
  5. Give the output of Math.abs(Math.floor(-3.2)).
    Answer 4.0. floor of -3.2 is -4.0, and abs of a double is a double.
  6. Which method finds the cube root: Math.sqrt, Math.cbrt or Math.pow?
    Answer Math.cbrt, which also works for negative numbers.

Two-mark questions

  1. Write the Java expression for √(3x + y²).
    Answer Math.sqrt(3 * x + Math.pow(y, 2)), or Math.sqrt(3 * x + y * y).
  2. Differentiate between Math.ceil() and Math.floor().
    Answer ceil returns the smallest whole number greater than or equal to its argument; floor returns the largest whole number less than or equal to it. Both return double: Math.ceil(4.2) is 5.0 and Math.floor(4.2) is 4.0.
  3. Give the output: double d = Math.pow(2, 10) / Math.sqrt(64); System.out.println(d);
    Answer 128.0. 1024.0 divided by 8.0.
  4. Why does int k = Math.round(9.6); not compile? Correct it.
    Answer Math.round of a double returns long, which cannot be stored in an int without a cast. Write long k = Math.round(9.6); or int k = (int) Math.round(9.6);.
  5. Write an expression for a random whole number from 10 to 20, both included.
    Answer 10 + (int) (Math.random() * 11). There are eleven values, so the multiplier is 11.

Questions about Math methods

What students ask about Math library methods in ICSE

Which Math methods are in the ICSE Computer Applications syllabus?

The 2026-27 syllabus lists ten methods of the Math class: pow(x, y), sqrt(x), cbrt(x), ceil(x), floor(x), round(x), abs(a), max(a, b), min(a, b) and random(). They are taught in Class 9 and revised in Class 10, and the 2027 paper can ask about any of them in Section A or use them inside a Section B program.

What is the return type of Math.pow and Math.sqrt?

Both return double, whatever type of argument you pass. So Math.pow(5, 2) prints 25.0 and Math.sqrt(81) prints 9.0. To store the result in an int you must cast it, as in (int) Math.pow(5, 2), and the cast removes any fractional part.

What is the difference between Math.round, Math.ceil and Math.floor?

Math.ceil moves up to the next whole number and Math.floor moves down; both return double, so 6.1 gives 7.0 and 6.0. Math.round goes to the nearest whole number, with halves moving up, and returns a long for a double argument, so 6.5 gives 7 with no decimal point.

What does Math.round(-2.5) return in Java?

It returns -2. Java rounds a half towards positive infinity, and the next whole number up from -2.5 is -2. A value just past the half, such as -2.51, rounds to -3. This is one of the most common Math traps in ICSE output questions.

Why does Math.sqrt of a negative number print NaN?

A negative number has no real square root, so Java returns the special double value NaN, meaning "not a number", instead of stopping with an error. Use Math.cbrt for cube roots of negative numbers, which works, or take Math.abs first if the question allows it.

What is the return type of Math.abs, Math.max and Math.min?

They return the same type as their arguments: int for int arguments and double for double arguments. If one argument is int and the other is double, the int is promoted first, so Math.max(8, 11.0) returns the double 11.0.

How do you generate a random number between 1 and 100 in Java?

Use 1 + (int) (Math.random() * 100). Math.random() gives a double from 0.0 up to but not including 1.0; multiplying by 100 stretches it, the cast removes the fraction to give 0 to 99, and adding 1 shifts it to 1 to 100. Keep the brackets around the multiplication.

Do I need to import anything to use Math methods in Java?

No. The Math class is in the java.lang package, which Java imports into every program automatically. You call its methods through the class name, as in Math.sqrt(x), because they are static; you never create a Math object.

Are trigonometric methods like Math.sin in the ICSE 2027 syllabus?

The 2026-27 syllabus list we checked names only pow, sqrt, cbrt, ceil, floor, round, abs, max, min and random. Some textbooks mention sin, cos, log or exp, but questions should be set from the syllabus list, so learn those ten thoroughly first.
