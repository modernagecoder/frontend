Formulas 1 to 8. Evaluating Models

Accuracy, precision, recall and F1 formula for class 10 AI

Accuracy is correct predictions over all predictions; precision is how many of the predicted positives were right; recall is how many of the real positives were caught; F1 combines precision and recall into one score. All four start from the confusion matrix, so build that first.

Error for a number prediction (formula 7)

When a model predicts a number, not a yes or no, there is no matrix. Error is the gap, ignoring the sign. A bus app predicts a 230-second wait; the bus takes 250. Error = 20 seconds, error rate = 20 / 250 = 0.08, and accuracy for that prediction = 1 - 0.08 = 0.92.

Train-test split (formula 8)

Multiply the rows by each share. 1,200 rows split 75:25 gives 900 to train on and 300 to test on. The test rows must be ones the model never saw in training.

Formulas 13 to 16. Natural Language Processing

TFIDF formula for class 10, with tokens and Bag of Words

TFIDF = TF x log10(N / DF), where TF is how often the word appears in this document, N is the number of documents and DF is how many of them contain the word. It is high for a word common in one document and rare in the rest.

The four NLP rules in order

  1. Tokens. Split into words and keep each punctuation mark as its own token. "Rain fell, and the match stopped." has six words, a comma and a full stop: 8 tokens.
  2. Bag of Words. After normalising, list each unique word once as the dictionary, then count. Dictionary [ball, bat, run, out]; "bat ball bat run" becomes [1, 2, 1, 0]. Order follows the dictionary, not the sentence.
  3. TF and IDF. TF is the raw count from the vector. The CBSE handbook writes IDF as the ratio N / DF, and takes its logarithm in the next step.
  4. TFIDF. Multiply TF by log10 of that ratio. Base 10, not the natural log: a calculator's ln key gives different numbers that will not match the marking scheme.

Questions about Class 10 AI formulas

What students ask about class 10 AI formulas

What are the formulas in class 10 AI?

Most are in Evaluating Models: accuracy, error rate, precision, recall and F1 score from a confusion matrix, plus error for number predictions and the train-test split. The others are the perceptron weighted sum, pixel and colour-value counts in Computer Vision, and token counts, Bag of Words and TFIDF in NLP. Mean, median, mode and convolution belong to the practical.

What is the formula of accuracy, precision and recall?

Accuracy = (TP + TN) / (TP + TN + FP + FN). Precision = TP / (TP + FP), the share of predicted positives that were right. Recall = TP / (TP + FN), the share of real positives the model caught. For TP 56, FP 14, FN 8, TN 122 they are 0.89, 0.80 and 0.875.

What is the F1 score formula in class 10 AI?

F1 = 2 x precision x recall / (precision + recall). It balances the two and is pulled toward the lower one. With precision 0.80 and recall 0.875, F1 = 1.4 / 1.675 = 0.84, slightly below their plain average of 0.8375. Never take the simple average.

What is the TFIDF formula for class 10?

TFIDF(W) = TF(W) x log10(N / DF(W)). TF is how many times the word appears in the document, N is the total number of documents, and DF is how many documents contain the word. For a word appearing twice in a document and in 3 of 6 documents, TFIDF = 2 x log10 2 = 0.602.

Is log base 10 or natural log used for TFIDF in class 10 AI?

Base 10. The CBSE handbook for Class 10 AI takes log to base 10 of N divided by DF. Natural log, or the smoothed version software libraries use, gives different numbers that will not match the marking scheme, so use the log button for base 10 when you check your work.

How do you calculate error in class 10 AI?

For a model that predicts a number, error = |actual - predicted|, error rate = error / actual, and accuracy = 1 minus the error rate. A wait predicted as 230 seconds that was really 250 gives error 20, rate 0.08 and accuracy 0.92. For a classifier, error rate = (FP + FN) / total, which is 1 minus accuracy.

How do you calculate the number of pixels in an image?

Multiply width by height in pixels. A 1024 x 768 image has 786,432 pixels. A grayscale image stores one value per pixel, so 786,432 values; an RGB image stores three, one each for red, green and blue, so 2,359,296. With 8 bits per value each one runs from 0 to 255.

How is the perceptron output calculated?

Multiply each input by its weight, add the products, add the bias, then compare with the threshold. Inputs 1, 0, 1, 1 with weights 0.2, 0.9, -0.4, 0.6 and bias -0.3 give 0.1, above a threshold of 0, so the output is 1. In the latest sample paper this appears only as an objective item.

Is there an AI class 10 cheat sheet I can print?

Yes, the numbered table at the top of this page is the cheat sheet: twenty formulas and rules with a worked line each. Use your browser's Print option and save it as a PDF if you want a file. It is for revision at home; nothing can be taken into the board exam hall.

Are mean, median and mode asked in the class 10 AI theory paper?

No. They belong to Statistical Data, which is assessed only in the practical, together with Advance Python. Expect them in the lab exam and viva, often as a NumPy program whose output you must predict, such as the median of an even-length list.
