Q1. What actually happens in a session?

What happens in a one to one ICSE Computer Applications session?

A one to one session moves through six steps: last week's work is checked, one gap is taught, the student writes a program while the tutor watches the screen, the program is traced, and new set work is agreed. The student does most of the typing; the tutor does most of the listening.

  1. The set work, opened first

    The student shares the BlueJ window with last week's set program. The tutor asks for it to be compiled and run in front of them, never pasted, so the work shown is the work done.

  2. One line from the error list

    Every student has a running list of the mistakes they make. The session picks the top one, for example "forgets that substring stops before the end index", and fixes it with three tiny examples.

  3. One idea taught on the student's own code

    New material is introduced as a change to a program the student already wrote, so a wrapper class or a 2D array arrives as a small step, not a fresh chapter.

  4. A program written from a blank class

    The student writes a Section B style program while the tutor watches the shared screen and stays quiet until the student is stuck for long enough to need a question, not an answer.

  5. Traced by hand, then run

    Before running, the student predicts the output with a trace table. If the run disagrees, the trace shows the line where the program left the plan.

  6. Set work and the next gap, agreed aloud

    The session ends with the student saying what the set program must do and what will be checked next time. Saying it is how the tutor knows it was understood.

How BlueJ work is checked on a shared screen

  • The student types, the tutor reads. A tutor who types for the child has written the program, not taught it.
  • Compile errors are read aloud. The student reads BlueJ's message and points at the line it names before anyone suggests a fix.
  • Wrong output means a trace, not a guess. Changing lines at random until the answer looks right is the habit the session exists to break.
  • Every program gets its variable description. Written at the end, every time, because the paper asks for it and a tired student leaves it out.

Questions about private tutoring

What parents ask before hiring an ICSE Computer Applications tutor

How do I find a good private tutor for ICSE Computer Applications?

Ask to see a session, not a profile. A good tutor has your child type Java in BlueJ while they read the screen, checks set work by watching it compile and run, knows that recursion is not in the 2027 syllabus, and will mark a full mock paper. A free first session is the easiest way to judge all four.

Is one to one better than group tuition for ICSE Java?

It depends on the student. One to one is better for a student with gaps from missed school, a timetable that clashes with fixed classes, or one who stays silent in groups. A small batch is often better for a student who is on track and works harder beside peers. Many students mix the two.

Can an online tutor check my child's BlueJ programs?

Yes. The student shares the BlueJ window, compiles and runs the program while the tutor watches, and reads any error message aloud. The tutor sees every keystroke, which is more than a home tutor sees if the session happens on paper.

Is a home tutor or an online tutor better for ICSE Computer Applications?

What matters is whether the tutor watches your child write and run Java. A home tutor who teaches from the textbook on paper cannot check Section B programs properly. An online tutor on a shared BlueJ screen can, and there is no travel time for anyone.

How often should my child have one to one classes?

In India our personalised plan is one private class a week at your time, with set work in between; abroad it is two private classes a week. Students in the mini batch get two group classes a week instead. The demo is a good place to ask which rhythm suits your child.

What happens in the first one to one session?

A short diagnosis: a few Section A questions, one small program written from a blank class, and a look at the school notebook. From that the tutor writes a plan of the first weeks and the checks that will show progress, and talks it through with the family.

Can a private tutor help with the ICSE lab file?

Yes, by teaching the programs, not by writing them. Each session's program is written by the student, run, and then written up as a lab assignment with its variable description, so the file grows from work the student can explain to the external examiner.

Do you offer a 1 on 1 Java tutor for ICSE students outside India?

Yes. Outside India the ICSE Computer Applications course is taught one to one only, as two private classes a week, at an after-school time in your own time zone. The tutors and the 2027 syllabus are the same as in India.

Will the same tutor teach my child every session?

The plan, the error list and the set work stay with the student from session to session, so whoever teaches knows exactly where the last session ended. If the family has a strong preference about continuity, say so after the demo.
