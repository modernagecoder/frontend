## How 200 marks split

Theory paper, 100 marks, two hours: Section A, 40 compulsory short-answer marks across the whole syllabus; Section B, 60 marks of programs, any four of the questions offered at 15 marks each, written in Java with variable descriptions so the logic is clear, with flowcharts and algorithms not required. Internal assessment, 100 marks: at least 20 lab assignments in the year plus a project, assessed 50 by the internal teacher and 50 by an external examiner. So 160 of the 200 marks are earned by producing working Java, Section A needs its own short-answer practice, and half the internal marks come from an examiner who will ask the student to explain their own work.

## Tuesday is for Section A, Wednesday is for Section B and the lab file

Tuesday takes one unit at a time as an idea with a program attached, then the paper's own shapes for it: predict this output, correct this error, how many times does this loop run, differentiate these two. The last ten minutes revisit Class 9. Wednesday is the programs lab: every student writes one Section B-style program from a blank class while the teacher watches each screen, so the missing semicolon and the off-by-one loop are caught while the student is still thinking about them. Each week's program is the week's lab assignment, and the variable description table is written every time.

## What the examiner tests in each of the eight units

Revision of Class IX: objects, data types, operators and precedence, conditional and iterative constructs; Section A outputs and loop counts. Class as the basis of all computation: objects as instances, primitive against composite types. User-defined methods: syntax, invoking, pure against impure, actual against formal parameters. Constructors: types, uses, the difference from a method. Library classes: wrapper classes, autoboxing and unboxing, character and string methods. Encapsulation: access specifiers, visibility, scope. Arrays: single and double dimensional, linear and binary search, a guaranteed Section B program. String handling: the String class and its methods, extracting and modifying characters, the other guaranteed Section B program.

## Writing beats memorising in Section B

A memorised number-triangle program answers last year's question and cannot be inverted when the examiner asks for 1234 down to 1. The understood program changes one loop header, because the student knows i is the row and j is the value, and adds the variable description table that earns the presentation marks. The question that separates the two students is not what does this print, but what does each variable do.

## Banking the 100 internal marks

The lab file grows one assignment a week from the first month, closer to twenty-five against a minimum of twenty. The project is scoped early and drafted in the second term. Every program is explained aloud, every week, because half the internal marks come from an examiner who was not there. A timed practical mock in the second term, and a dress rehearsal before the school's practical day.

## Why a mini batch

A teacher can explain a concept to thirty students but can read only a few screens at once, and Java is learned in the seconds between typing a line and seeing what it does. Three or four is the largest group in which every one of those seconds has a teacher watching. It suits a student who wants Section B programs to come from their own head; it does not suit a family wanting recordings or a two-week pre-board blast.
