> Learning to code with AI works when the model is used as a tutor and fails when it is used as a ghostwriter, and the difference is entirely in the prompts. Ask for the fix and you get working code plus nothing; ask for an explanation, a hint ladder, or three questions that lead you to the fix, and the same model becomes a patient teacher. The reliable method pairs assisted building with one unassisted exercise a week, so dependence never takes root. ## The fork in every session

A beginner's Python function crashes on an empty list. Ghostwriter mode: "fix this", paste, receive twelve clean lines, say thanks, learn that pasting works, crash identically next time. Tutor mode: "Do not fix this or show code. Explain what this error means, then ask me one question that points me at the cause." The model explains the error, asks what the function assumes on line 3, and the learner finds the empty-list case themselves. Five extra minutes, permanent upgrade. Both transcripts are the model doing exactly what it was asked: there is no learning-mode toggle in the settings, because the toggle is your first sentence.

## The six tutor patterns

1. Explain first: "Tell me what this error means. Do not show me any code." Errors are a language; this is how you learn to read it rather than forward it.
2. The hint ladder: "Give me a hint. If I ask again, a stronger one. Never the answer." Three rungs: region, line, assumption. You stay the finder.
3. Socratic reverse: "Ask me three questions that would lead me to the bug." Trains checking beliefs against reality instead of stacking guesses.
4. Make it worse: "Write me a version of this with two subtle bugs. I will find them." Endless custom reading practice at exactly your level.
5. The teacher's red pen: "Review my working code like a strict teacher. What is fragile?" For the dangerous moment after something works.
6. Why did that work: "Explain why your fix worked and mine did not, line by line." Converts an accepted fix back into a lesson.

## Where AI helps learning and where it quietly hurts

Concept explanations on demand help; nodding along is not knowing, so test yourself after. Hint ladders help debugging; pasting whole errors outsources the exact skill being built. Endless custom practice problems help; one-click solutions make abandoning attempts free. Speed on parts you already understand helps project building; speed on parts you do not looks identical that day. A tireless second reader helps review; accepting rewrites wholesale, unread, is not applying feedback. In every case the damage comes from the model doing a thing while you believe you are doing it, which is why the fix is structural: one unassisted exercise a week, and the assisted-versus-unassisted gap watched honestly.

## The eight-week Python shape

Weeks 1 and 2: variables, lists and loops, explain-first as the only permitted pattern. Weeks 3 and 4: functions and files, hint ladder unlocked. Weeks 5 and 6: a small real project, all six patterns free, one no-AI session. Weeks 7 and 8: a second project where the student picks the pattern per situation, because pattern choice is judgement and judgement is the graduation.

## Frequently asked questions

**Can AI replace a coding teacher?** It replaces the patience brilliantly and the judgement not at all: a teacher withholds the answer you almost have, and models are built to satisfy.

**Will I become dependent?** Only if you never practise unassisted. One unassisted exercise a week measures the gap, and the gap does not lie.

**Which AI is best for learning?** How you use it matters more than which one; the real constraint is age, since under 13 no mainstream tool permits an account and 13 to 17 requires parental consent.

**Is it faster than the traditional way?** Faster to first output by miles, equal to real competence, because the practice hours have no shortcut. What changes is the failure rate: fewer beginners die at setup or the first cryptic error.

**Do employers care?** They care what is underneath: reading code you did not write, debugging when the assistant loops, explaining your project cold.
