## How long are the road sections in Ayacucho's road inventory?

The answer is in the file, but not in a column. The distances are written inside sentences such as "PACCHANCCA (KM 46+191)", and a program has to dig them out. That makes the inventory a good, honest exercise in regular expressions.

### The dataset

The Gobierno Regional de Ayacucho publishes "Infraestructura y estado de la red vial departamental de Ayacucho" on datosabiertos.gob.pe with an ODC-By licence (Open Data Commons Attribution), so anyone may reuse it as long as the source is credited. It was created on 4 September 2026 and last changed on 15 September 2026.

We use only its road inventory file, saved as inventario-vial.csv. It has two header lines and 17 route rows, each with a route code such as AY-100, the provinces it crosses, a surface type, a condition, start and end coordinates, and a long text describing the sections programmed for work.

### How a chainage is written

Peruvian road engineers mark a point on a road by its chainage: whole kilometres, a plus sign, then metres. "KM 46+191" means 46 kilometres and 191 metres from the start of the route, or 46,191 metres.

The data dictionary describes the text column as the "detalle o alcance específico de las secciones o sub-tramos de vía programados o intervenidos". So the chainages in it mark where each section begins and ends, often several sections per route.

**Version 1: first mark to last mark** (Python)
```python
import csv
import re

CHAINAGE = re.compile(r"(\d+)\s*\+\s*(\d+)")

with open("inventario-vial.csv", encoding="utf-8-sig", newline="") as f:
    rows = list(csv.reader(f, delimiter=";"))[2:]

for row in rows:
    if not row[1]:
        continue
    marks = [int(km) * 1000 + int(m) for km, m in CHAINAGE.findall(row[4])]
    if marks:
        span = (marks[-1] - marks[0]) / 1000
        print(row[1], "first to last:", span, "km")
```
It prints fourteen lines, one per route row that has any marks. Among them: AY-100 first to last: 62.143 km, AY-101 first to last: 148.648 km and AY-117 first to last: 0.0 km.

The pattern (\d+)\s*\+\s*(\d+) reads as "some digits, maybe spaces, a plus sign, maybe spaces, some digits", and the brackets capture the kilometres and metres separately. Multiplying the kilometres by 1,000 and adding the metres turns every mark into one whole number, so int("09") and int("00") are handled without fuss. Version 1 then takes the last mark minus the first. It looks reasonable, and two lines of its output already show that it is not: AY-117 comes out at zero kilometres, and AY-100 counts the stretch between two of its sections as if it were part of the work.

**Version 2: pair the marks, measure the gaps, and refuse to guess** (Python)
```python
import csv
import re

CHAINAGE = re.compile(r"(\d+)\s*\+\s*(\d+)")

with open("inventario-vial.csv", encoding="utf-8-sig", newline="") as f:
    rows = list(csv.reader(f, delimiter=";"))[2:]

worked = gaps = 0
odd = []
for row in rows:
    marks = [int(km) * 1000 + int(m) for km, m in CHAINAGE.findall(row[4])]
    if not row[1] or not marks:
        continue
    if len(marks) % 2:
        odd.append(row[1])
        continue
    starts, ends = marks[0::2], marks[1::2]
    worked += sum(e - s for s, e in zip(starts, ends))
    gaps += sum(s - e for e, s in zip(ends, starts[1:]))

print("Sections with an odd count:", odd)
print("Inside the sections:", worked / 1000, "km")
print("Between the sections:", gaps / 1000, "km")
```
It prints: Sections with an odd count: ['AY-104', 'AY-107', 'AY-108', 'AY-116', 'AY-117'], Inside the sections: 622.28 km and Between the sections: 34.176 km.

Version 2 treats the marks as start, end, start, end. The slices marks[0::2] and marks[1::2] separate the starts from the ends, zip lines them up, and a second zip measures the gap from each end to the next start. A route with an odd number of marks cannot be split into pairs, so the program puts it on a list instead of inventing the missing number. Five routes land there. AY-117 has a single mark. AY-107 begins at a junction written as "Emp. PE-30 D" with no chainage, so its first start is missing from the text, even though a person reading it would assume kilometre zero.

| Measure | Value |
|---|---|
| Route rows in the file | 17 |
| Rows with no chainage at all | 3 |
| Rows set aside with an odd count of marks | 5 |
| Length inside the paired sections | 622.28 km |
| Length between consecutive sections | 34.176 km |

Data: Gobierno Regional de Ayacucho, Infraestructura y estado de la red vial departamental de Ayacucho, inventory file, ODC-By. Every count and length here is ours, computed from the text column and nothing else; it is not an official network length. The surface column says AFIRMADO on 12 rows, ASFALTADO on 4 and "AFIRMADA " with a trailing space on 1; the condition column says REGULAR on all 17.

1. **For the youngest (around 6 to 8).** Lay a skipping rope on the floor and stick paper marks on it: 2, 5, 9 and 12. Colour the rope between 2 and 5 and between 9 and 12. How much is coloured, and how much is left between?
2. **Blocks (around 8 to 11).** Make a list of four numbers in Scratch, then use a loop that takes them two at a time and adds up each difference. What should happen if the list has five numbers?
3. **First Python (around 11 to 13).** Change Version 1 so it also prints how many marks each route has. Which routes would you not trust?
4. **Teenagers.** Write a pattern that also captures the word before each mark, such as PACCHANCCA, so the program can print the place names in order.
5. **University and adults.** Clean the surface column with strip() and a small mapping so "AFIRMADA " and "AFIRMADO" count as one type, then total the paired lengths by surface.

The habit we are building is simple to say and hard to keep: when the data does not give you a number, say so and set the row aside, instead of filling the hole with a guess that looks tidy. It is the same habit we ask for when students use AI tools, and our page on [learning to think rather than copy](/learn-to-think-not-copy-coding-peru) explains why we teach it from the first week.

## Is programming taught in Ayacucho's schools?

Not as its own subject. Ayacucho's schools teach the national CNEB, where digital skills are spread across all subjects, and the regional government's recent work has been about devices and distance rather than a coding course.

### The national picture

Peru's General Education Law gives primaria six years and secundaria five. Grade placement uses the child's age on the last day of March, which puts six year olds in first grade and most sixteen year olds in the final year of secundaria.

Competency 28 of the CNEB, about working in virtual environments created by ICT, is transversal, so every subject shares it and no subject owns it. Across the 35 weekly hours of regular secundaria, Matemática gets four and nothing is called programming.

### What the regional government reports

On 15 September 2026 the Gobierno Regional de Ayacucho said it had received 16,955 tablets from PRONATEL for pupils and teachers, in the seventh year of its regional broadband project, and that laptop deliveries for rural areas were being arranged.

On 29 August 2026 it announced Decreto Regional 004-2026-GRA/GR creating the UGEL VRAEM, seated in Santa Rosa, for 207 educational institutions with 14,861 pupils and 826 teachers in Anchihuay, Samugari, Ayna, Santa Rosa and Río Magdalena.

Both notes point the same way: in Ayacucho, the hard part is reaching learners, not deciding what to teach them. Fábrica de Programadores, the MINEDU pilot that teaches Python to secundaria pupils, opened in July 2025 for a first group of 1,000 in Lima Norte; we found nothing showing it in Ayacucho yet. Competitions reach the region all the same. The ONEM maths olympiad held its school round on 8 July 2026, with over 1.7 million secundaria pupils taking part across Peru, and the OPI computing olympiads run by UTEC cost nothing to enter. We have no tie to the regional government, MINEDU, UTEC or either competition, and every problem we set is written by us.

### What a learner actually needs

To watch and talk, a phone or tablet is enough. To program, a learner types, runs, reads an error and fixes it, again and again, and that needs a keyboard and a bigger screen.

A shared family laptop works well if the class time is protected. University students can often use a faculty lab. Young children can start block coding on a tablet, which may be one of the 16,955 the region is distributing.

Tell the mentor in the free class what you have. If there is no computer the learner can use regularly, we will say that waiting is better than paying for a course that cannot be practised between sessions.

Whenever suits you. Ayacucho keeps Peru time, the mentor works from India, and the hour is set around the learner rather than the other way round.

Ayacucho uses Peru time, five hours behind UTC, with no daylight saving since 1994 (tz database zone America/Lima). India runs five and a half hours ahead of UTC, so the difference never changes from 10 hours 30 minutes.
