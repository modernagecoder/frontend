Ans. The short version

Constructors ICSE Class 10 questions test four things. A constructor is a member method with the same name as its class and no return type, not even void, that runs automatically when an object is created with new, to give the data members their starting values. A default constructor takes no parameters; a parameterized constructor takes values; overloading means several constructors that differ in their parameter lists. And a constructor differs from a method in name, return type and how it is called. Q1. What is a constructor in Java, in the words ICSE expects?

What is a constructor? Definitions for ICSE Class 10 in one sentence each

A constructor is a member method with the same name as the class and no return type, which is called automatically when an object is created and is used to initialise the object's data members. Each term below is worth one mark when written this cleanly.

TermOne-sentence definitionSmallest example
ConstructorA member method with the same name as its class and no return type, invoked automatically by new to initialise a new object.Pen() { ink = 100; }
Default constructorA constructor with no parameters, which gives every data member a fixed starting value.Pen() { colour = "blue"; ink = 100; }
Parameterized constructorA constructor that receives values as parameters and copies them into the data members of the new object.Pen(String c, int i) { colour = c; ink = i; }
Compiler-supplied constructorIf a class defines no constructor at all, Java adds an empty no-argument one, which leaves members at their default values (0, 0.0, false, null).new Box() works with no constructor written
Constructor overloadingDefining more than one constructor in the same class, each with a different number, type or order of parameters.TimeSpan(), TimeSpan(int), TimeSpan(int, int)
The this keywordA reference to the current object, used inside a constructor when a parameter has the same name as a data member.this.x = x;

Characteristics of a constructor (the list examiners mark)

  1. Its name is exactly the class name, with the same capital letters.
  2. It has no return type, not even void. Add one and it stops being a constructor.
  3. It is called automatically, once, when new creates the object; you never call it with a dot.
  4. It is usually declared public so objects can be created from outside the class.
  5. It can be overloaded, but a class cannot have two constructors with the same parameter list.
  6. Once you write any constructor yourself, Java no longer supplies the empty one.

Constructors only make sense once a class is seen as a template for objects, which is the chapter before this one: class as the basis of all computation.

Q2. How is a constructor different from a method?

Four rules that settle every constructor trap

  1. A constructor runs only when new runs, once per object.
  2. Members not set by the constructor keep their defaults: 0, 0.0, false, null, and the character with code 0.
  3. If any constructor is written, the free no-argument one disappears.
  4. A parameter with the same name as a member hides it, unless this. is used.

Q5. What do Section A constructor questions look like?

Constructors ICSE Class 10 questions with answers for Section A

These are original questions in the shapes Question 1 (one-mark MCQs) and Question 2 (two-mark answers) use. Write your answer before opening each one.

One-mark questions

  1. Which of these can be a constructor of class Kite? (a) void Kite() (b) Kite() (c) kite() (d) int Kite()
    Answer (b). No return type, and the name matches the class exactly, including the capital K.
  2. The constructor Java supplies when none is written takes how many parameters?
    Answer None. It is a no-argument constructor that leaves the members at their default values.
  3. Which keyword refers to the object whose constructor is running?
    Answer this.
  4. Two constructors Car(int a) and Car(int b) in one class: will it compile?
    Answer No. Parameter names do not count; both have the parameter list (int), so the class has the same constructor twice.
  5. What is the default value of a String data member that no constructor sets?
    Answer The value null, meaning the member does not refer to any String yet.

Two-mark questions

  1. State two differences between a constructor and a method.
    Answer A constructor has the same name as the class and no return type; a method has any name and must declare a return type. A constructor runs automatically when an object is created; a method runs only when it is called.
  2. What is a parameterized constructor? Give an example.
    Answer A constructor that receives values through parameters and stores them in the data members. Example: Book(String t, int p) { title = t; pages = p; }, used as new Book("Kim", 320).
  3. Write a default constructor for class Tank with members double litres and boolean full.
    Answer Tank() { litres = 0.0; full = false; }
  4. What is constructor overloading? Why is it useful?
    Answer Defining several constructors in one class that differ in their parameter lists. It lets objects be created in different ways, for example with default values or with values supplied by the user.
  5. A class has only Shop(String n). Why does new Shop() fail, and give one fix.
    Answer Once a constructor is written, Java does not supply the no-argument one, so no constructor matches an empty argument list. Fix: add Shop() { name = ""; }, or pass a name.

Questions about constructors

What students ask about constructors in ICSE Class 10

What is a constructor in Java ICSE Class 10?

A constructor is a member method with the same name as its class and no return type, not even void. It runs automatically, once per object, when new creates the object, and gives the data members their starting values.

What is the difference between a constructor and a method?

A constructor has the class's name, has no return type and runs automatically when an object is made. A method can have any name, must declare a return type such as void or int, and runs only when it is called with the object and a dot. Constructors initialise; methods do the work.

What is a parameterized constructor in ICSE?

A parameterized constructor receives values through its parameters and copies them into the new object's data members, so each object can start with different values. For example, Book(String t, int p) stores a title and a page count, and is used as new Book("Kim", 320).

What is a default constructor in Java for ICSE?

A default constructor takes no parameters and gives every data member a fixed starting value, such as 0 or an empty String. If a class has no constructor at all, Java adds an empty no-argument constructor, which leaves members at their default values: 0, 0.0, false or null.

What is constructor overloading with an example?

Constructor overloading means writing more than one constructor in the same class, each with a different parameter list. A TimeSpan class can have TimeSpan(), TimeSpan(int total) and TimeSpan(int h, int m); Java chooses the one whose parameters match the arguments given with new.

Can a constructor have a return type?

No. Write any return type, even void, and Java treats it as an ordinary method that happens to share the class name. It compiles, but it does not run when the object is created: a favourite output-question trap.

Why does new ClassName() give an error when I have written a constructor?

Because Java supplies the empty no-argument constructor only when a class has no constructors at all. Once you write a parameterized one, new ClassName() has nothing to match. Write a default constructor as well, or always pass the values the constructor expects.

What is the use of the this keyword in a constructor?

this refers to the object being created. When a parameter has the same name as a data member, as in Point(int x, int y), the plain name means the parameter, so this.x = x is needed to store the value in the member. Without this, the member stays at 0.

Are copy constructors in the ICSE 2027 syllabus?

The 2027 syllabus wording for the chapter names the definition, characteristics, types and use of constructors, the default and parameterized constructor, constructor overloading and the difference from a method. Copy constructors are not named, so this page does not teach them for the exam.
