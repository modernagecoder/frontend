Ans. The short version

ICSE Computer Applications output questions give a short Java fragment and ask exactly what it prints. They sit in Section A, the 40 compulsory marks, as one-mark MCQs and two-mark answers. Almost all of them test the same traps: integer division and type promotion, pre and post increment, char arithmetic, String methods and immutability, Math return types, loop counts, switch fall-through, the ternary operator, short-circuit && and ||, array default values and wrapper methods. Q5. How should an output answer be written in the exam?

Exam technique: writing the trace and showing working in Section A

Section A is 40 compulsory marks: Question 1 is twenty one-mark MCQs and Question 2 is ten parts of two marks each. Output questions appear in both, and each shape needs a slightly different habit.

In an MCQ, trace before you read the options

The wrong options are usually the answers a trap produces. For snippet 9 the choices might be b, c, 98 and 99. A student who skims the options first is drawn to b. Work the answer on the margin, then find it in the list.

In a two-mark part, show a compact trace

Write a small table of the variables that change, then the output on its own line. The output itself must be right; the trace is how you get it right and check it in seconds.

Copy the layout, not just the values

print and println decide where lines break, and a missing space between two printed numbers changes the answer. Write each println as a new line and show spaces where the code prints " ".

Mark the type of every number

Before writing a number, ask: is this int, long or double? That one question catches 3.0 against 3, 8.0 against 8 and 1.0 against 1, which are the commonest slips on this page.

Tick each line as it runs

For switch, short-circuit and ternary questions, put a small tick beside every statement that executes. Lines without a tick produce nothing, however close to the answer they sit.

Budget the time

The paper is two hours for 100 marks, so Section A deserves roughly a minute per mark. A loop of more than five passes earns its trace table; a one-line String call does not.

When a fragment would not compile at all, the question is about error finding rather than output, and that shape has its own page: ICSE Class 10 Java error finding questions. One-mark questions of every other kind are on ICSE Computer Applications MCQ questions.

Q6. How does the mini batch drill output questions?

From paper trace to BlueJ run, every week

The skill comes from committing to an answer under time pressure, being wrong, and finding the exact step where the trace went off course.

  1. A timed set on Tuesday

    At the 5:30 PM IST class, students get a fresh set of fragments from two or three trap families and write their outputs on paper against the clock. Nobody sees the answers until everyone has committed.

  2. Run in BlueJ on a shared screen

    The teacher pastes each fragment into BlueJ and runs it while the group watches. The real output appears beside each student's guess, so there is no arguing about who was right.

  3. Wrong outputs traced again, aloud

    A student with a wrong answer re-traces it in front of the group, one variable at a time, until the step that broke is found. Usually it is one of the eleven traps above, and that trap goes on the student's own list.

  4. Traces inside Wednesday's program

    At the 8:00 PM IST class, the program of the week is dry run before it is executed, so tracing becomes a way to check one's own Section B code as well.

  5. Full mock tests from December

    Output questions then appear inside complete two-hour papers, marked like the board, so the habit holds when the paper is long and the clock is running.

With at most six students in the batch, every wrong output in every set gets looked at. The full mock ladder is described on the ICSE specimen paper and mock tests page.

Questions about output questions

What students ask about ICSE Java output questions

How do you solve predict the output questions in Java for ICSE?

Trace, do not guess. Write the variables across the top of a small table, add one row each time a statement changes a value, and only then write the output. Before writing any number, decide whether it is an int or a double, and before writing any line, check whether the code used print or println.

Where do output questions come in the ICSE Computer Applications paper?

In Section A, the 40 compulsory marks. Question 1 has twenty one-mark MCQs, some showing a fragment with four possible outputs. Question 2 has ten two-mark parts, several of which typically ask for an output or a loop count.

What are the most common traps in ICSE Java output questions?

Integer division, increments, char arithmetic, unstored String results, Math return types, loop counts, switch fall-through, ternary promotion, short-circuit && and ||, array defaults and wrapper methods. Each has original snippets on this page.

Why does 5 / 2 give 2 in Java and not 2.5?

When both operands are int, Java does integer division and drops the fraction. Make one operand a double, as in 5.0 / 2 or (double) 5 / 2, to get 2.5. Casting after the division, as in (double) (5 / 2), is too late and gives 2.0.

What is the difference between x++ and ++x in an output question?

Both add 1 to x. x++ gives the old value to the expression and then increases x; ++x increases x first and gives the new value. In a line such as b = a++ + ++a, trace each term separately, left to right, writing down x after every step.

Why does Math.sqrt(16) print 4.0 and not 4?

Because sqrt, cbrt, pow, ceil and floor all return double, so Java prints a decimal point even when the value is whole. Math.round of a double returns a long, so it prints without .0. Writing 4 instead of 4.0 is marked wrong.

How do I count how many times a loop runs?

List every value the control variable takes, including the one that makes the test fail, then count the values that passed. For i starting at 10, falling by 3 while it stays above 0, the values are 10, 7, 4 and 1, so the loop runs four times. A do-while loop always runs at least once.

What is a dry run in ICSE Class 10?

A dry run means executing a program by hand, line by line, while keeping a table of each variable's value. It is how output questions are solved, and the fastest way to find a logic error in your own Section B program.

Is recursion asked in ICSE 2027 output questions?

No. Recursion is not in the ICSE Computer Applications syllabus for 2027, so no output question should need it. Concentrate on operators, loops, nested loops, Strings, Math, wrapper classes and single and double dimensional arrays.

Do you teach output questions in live classes?

Yes. In the mini batch every Tuesday there is a timed set of output questions, each answer is then run in BlueJ on a shared screen, and every wrong answer is traced again aloud. Students who need more focus can take personalised one to one classes at a time the family chooses.
