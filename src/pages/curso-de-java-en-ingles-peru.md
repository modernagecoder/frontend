Java pide más disciplina que otros lenguajes al principio: hay que declarar tipos, compilar y respetar una estructura. ## ¿Se puede aprender Java desde cero sin saber programar?

Sí. Java no exige experiencia previa, solo paciencia con sus reglas. La diferencia con un lenguaje como Python es que Java revisa su programa antes de ejecutarlo y no deja pasar errores de tipo, lo que al principio frustra y después ahorra horas.

### Tipos declarados

En Java cada variable dice qué guarda: int para enteros, double para decimales, String para texto. El compilador vigila que no se mezclen. Es una disciplina que luego se agradece en cualquier lenguaje.

### Compilar y ejecutar

Primero javac traduce el programa y avisa de los errores; recién después java lo ejecuta. Leer esos avisos, que siempre están en inglés, es la primera habilidad que enseñamos.

### Objetos desde temprano

Java está construido alrededor de clases y objetos. Aprenderlo bien es aprender a dividir un problema en piezas que tienen datos y comportamiento, algo que pide cualquier equipo de software.

1. **Mes 1: el primer programa y los tipos.** Variables, operadores, entrada y salida por consola, y los primeros mensajes de error del compilador, leídos en voz alta y en inglés.
2. **Meses 2 y 3: decisiones y repeticiones.** if, switch, for y while, arreglos y métodos propios. Programas pequeños pero completos, como un registro de notas.
3. **Meses 4 a 6: clases y objetos.** Encapsulamiento, herencia, interfaces y excepciones. Es el corazón de Java y el tema que más se pregunta en entrevistas.
4. **Meses 7 a 9: colecciones y datos.** ArrayList, HashMap, ordenamiento y búsqueda, lectura de archivos, primeras pruebas automáticas.
5. **Desde el mes 9: aplicaciones.** Para adolescentes, juegos y aplicaciones con ventanas; para mayores de 18, APIs con Spring Boot y bases de datos.

Este recorrido es nuestro y orientativo; el mentor lo ajusta. Según la ficha de cada curso, Java para adolescentes dura de 10 a 12 meses (40 a 48 semanas) y Java de cero a Spring Boot, de 10 a 12 meses (44 a 52 semanas), con dos sesiones semanales en directo y ejercicios para la casa. Quien practica de forma constante escribe programas útiles hacia el tercer mes; quien deja pasar semanas sin abrir el editor tarda bastante más, sea cual sea el lenguaje.

## ¿Qué versión de Java conviene aprender en 2026?

Una versión LTS reciente: Java 21 o Java 25. Las versiones LTS (de soporte a largo plazo) son las que usan las empresas, y Oracle publica una nueva cada dos años.

**Versiones LTS de Java según la hoja de ruta de soporte de Oracle**

| Versión | Publicación | Soporte Premier de Oracle hasta |
|---|---|---|
| Java 8 | Marzo de 2014 | Marzo de 2022 |
| Java 11 | Septiembre de 2018 | Septiembre de 2023 |
| Java 17 | Septiembre de 2021 | Septiembre de 2026 |
| Java 21 | Septiembre de 2023 | Septiembre de 2028 |
| Java 25 | Septiembre de 2025 | Septiembre de 2030 |
| Java 29 (planificada) | Septiembre de 2027 | Septiembre de 2032 |

Fuente: Oracle, "Oracle Java SE Support Roadmap", leída el 9 de noviembre de 2026. La misma página dice: "Java SE 8, 11, 17, 21, and 25 are LTS releases" y anuncia la siguiente LTS, Java 29, para septiembre de 2027. Las fechas futuras son planes de Oracle y pueden cambiar. Las páginas del proyecto OpenJDK fechan la disponibilidad general de JDK 21 el 19 de septiembre de 2023 y la de JDK 25 el 16 de septiembre de 2025.

Para alguien que empieza hoy, Java 25 trae una novedad pensada justo para principiantes. La propuesta JEP 512, entregada en esa versión, permite escribir el primer programa sin la famosa línea public static void main(String[] args): basta con void main() { IO.println("Hello, World!"); }. Y desde Java 11, gracias a la JEP 330, un programa de un solo archivo se puede ejecutar directamente con java HelloWorld.java, sin compilar aparte. Ninguna de las dos cosas reemplaza aprender la estructura completa, pero hacen que la primera semana sea menos abrumadora.

En clase empezamos con la estructura clásica de una clase con main, porque es la que encontrará en casi todo el código real, en los libros y en las entrevistas, y mostramos las formas nuevas como lo que son: atajos. La lección de esta página se compiló con OpenJDK 21, una LTS que sigue con soporte Premier de Oracle hasta septiembre de 2028.

## ¿Cuándo se aprende Spring Boot en un curso de Java?

Después de dominar Java básico y la programación orientada a objetos, no antes. Spring Boot es un marco de trabajo para construir aplicaciones y servicios web, y da por hecho que usted ya entiende clases, interfaces, colecciones y excepciones.

### Lo que pide Spring Boot

Según su página de requisitos del sistema, "Spring Boot 4.1.2 requires at least Java 17 and is compatible with versions up to and including Java 27". Es decir, quien aprende con Java 21 o 25 está dentro de lo que la versión actual de Spring Boot exige.

Además del lenguaje, hay que conocer una herramienta de construcción como Maven o Gradle, algo de HTTP y lo básico de bases de datos con SQL. Por eso Spring Boot llega en la parte final de nuestro curso para mayores de 18.

### Por qué no empezar directamente por ahí

Muchos anuncian "Java con Spring Boot" desde la primera clase. El resultado suele ser una persona que copia anotaciones como @RestController sin saber qué hace el código que hay detrás, y que se bloquea en el primer error que no está en el tutorial.

Nuestra forma de enseñar va al revés: primero el lenguaje, después el marco. Cuando llega Spring Boot, usted entiende por qué existe cada pieza, y eso se nota en una entrevista técnica.

En el curso para adolescentes también hay una introducción a Spring Boot al final, como primer contacto con el desarrollo de servidores. En el curso para mayores de 18 el tramo es completo: APIs, seguridad, pruebas y conexión con bases de datos. En ninguno de los dos casos prometemos un empleo ni un sueldo; lo que prometemos es que usted entienda el código que escribe.

## ¿Cómo es una clase de Java en inglés por dentro?

Este ejercicio es nuestro, de las primeras semanas: sacar el promedio de cuatro notas. Parece trivial, y por eso mismo sorprende. Lo compilamos y ejecutamos con OpenJDK 21 antes de publicarlo.

**Promedio.java** (Java)
```java
public class Promedio {
    public static void main(String[] args) {
        int[] notas = {14, 17, 15, 12};
        int suma = 0;
        for (int nota : notas) {
            suma = suma + nota;
        }
        int promedioEntero = suma / notas.length;
        double promedioReal = (double) suma / notas.length;
        System.out.println("Sum: " + suma);
        System.out.println("int average: " + promedioEntero);
        System.out.println("double average: " + promedioReal);
        System.out.println("7 / 2 = " + (7 / 2) + ", 7 / 2.0 = " + (7 / 2.0));
    }
}
```
Antes de ejecutar, el mentor pregunta en inglés: "What will the int average be? And the double one?"

**Lo que imprime** (Salida)
```salida
Sum: 58
int average: 14
double average: 14.5
7 / 2 = 3, 7 / 2.0 = 3.5
```
Salida copiada tal cual tras javac Promedio.java y java Promedio con OpenJDK 21.0.12.1.

Las cuatro notas suman 58, y 58 entre 4 es 14,5. Pero la segunda línea dice 14. En Java, cuando se dividen dos enteros, el resultado es otro entero y los decimales se pierden sin ningún aviso: 7 / 2 da 3, no 3,5. Al convertir la suma a double antes de dividir, con (double) suma, la división ya es decimal y sale 14.5. Un registro de notas que redondea mal en silencio es un error real, de los que llegan a producción.

**TipoIncorrecto.java** (Java)
```java
public class TipoIncorrecto {
    public static void main(String[] args) {
        int nota = "15";
        System.out.println(nota);
    }
}
```
Ahora el error contrario: guardar un texto en una variable entera.

**Lo que responde el compilador** (Salida)
```salida
TipoIncorrecto.java:3: error: incompatible types: String cannot be converted to int
        int nota = "15";
                   ^
1 error
```
Respuesta exacta de javac TipoIncorrecto.java con OpenJDK 21. El programa ni siquiera llega a ejecutarse.

1. **Predecir en voz alta.** El estudiante dice qué espera ver en cada línea antes de ejecutar. Casi todos dicen 14.5 en la segunda; el error de predicción es la puerta de la lección.
2. **Leer el mensaje del compilador.** "incompatible types: String cannot be converted to int" se lee en clase palabra por palabra. La flecha ^ señala exactamente dónde está el problema: la línea 3.
3. **Comparar los dos errores.** El primero no da ningún aviso y produce un resultado incorrecto; el segundo lo detiene todo antes de empezar. Java atrapa el segundo tipo de error por usted; el primero solo lo atrapa quien entiende los tipos.
4. **Arreglar sin borrar.** Para el segundo programa hay dos soluciones: quitar las comillas, o convertir el texto con Integer.parseInt("15"). El estudiante explica en inglés cuándo usaría cada una.
5. **Reto para la casa.** ¿Qué imprime (double) (suma / notas.length), con los paréntesis en otro lugar? Escriba su predicción y compruébela.

Una herramienta de IA le corregiría el programa en un segundo. Lo que no hace es enseñarle a sospechar de un 14 cuando esperaba 14,5. Ese reflejo, mirar un resultado y preguntarse si tiene sentido, es lo que enseñamos en cada clase, en Java y en cualquier lenguaje.

## ¿Por qué aprender Java en inglés si vivo en Perú?

Porque todo lo que rodea a Java está en inglés: las palabras clave, los mensajes del compilador, la documentación de Oracle y de Spring, y las preguntas que se responden en internet. El que entiende esos textos sin traducir avanza más rápido.

En el EF EPI 2025, quienes declaran trabajar en el área de TI en Perú obtienen 522 puntos, apenas por encima del promedio nacional de 519 y lejos de los 555 de Lima, que EF ubica en el nivel alto. Es decir, muchos profesionales de sistemas del país leen inglés técnico con esfuerzo. Aprender Java directamente en inglés convierte cada clase en práctica de ese idioma, sin sumar otra actividad a la semana.

No hace falta llegar con un inglés avanzado. El mentor escribe en pantalla las palabras nuevas, habla con frases cortas y le pide que explique su código en voz alta, aunque sea con frases sencillas. Al cabo de unas semanas, términos como constructor, override o null pointer dejan de sonar extraños. Si su familia es de habla inglesa o su hijo estudia en un colegio bilingüe limeño, también puede leer nuestra página de [programación en inglés en Lima](/english-medium-coding-classes-lima).

Un requisito práctico: Java se programa en una computadora, no en un celular. El boletín de tecnologías de la información del INEI del segundo trimestre de 2026 indica que el 36,4% de los hogares del país tiene al menos una computadora. Si en su casa hay una, aunque sea compartida, basta para todo el curso; el JDK y el editor se instalan gratis en la primera clase.

## ¿Cómo sé que avanzo en Java?

Cinco etapas propias que el mentor usa para ubicarlo y contarle su progreso. No son niveles oficiales ni de ninguna certificación.

**Cinco etapas de Java (nuestras)**

| Etapa | Momento habitual | Usted puede |
|---|---|---|
| 1. Compilar sin miedo | Primer mes | escribir un programa, leer el error de javac y corregirlo solo |
| 2. Controlar el flujo | Meses 2 y 3 | resolver problemas con condicionales, bucles, arreglos y métodos propios |
| 3. Pensar en objetos | Meses 4 a 6 | diseñar dos o tres clases que colaboran y explicar por qué las separó así |
| 4. Manejar colecciones | Meses 7 a 9 | elegir entre ArrayList y HashMap y justificar la elección |
| 5. Construir una aplicación | Desde el mes 9 | terminar un proyecto propio, con pruebas, y presentarlo en inglés |

### Mientras aprende

Escriba cada programa usted mismo, aunque tenga el ejemplo delante. Copiar y pegar se olvida al día siguiente.
Cuando javac le marque un error, léalo completo antes de tocar el código. La mitad de las veces el mensaje ya dice la solución.

### Cuando se sienta trabado

Vuelva a un programa más pequeño que sí funcione y añada una sola cosa a la vez.
Explique en voz alta, en inglés, qué debería hacer cada línea. El error suele aparecer en la frase que no puede terminar.
