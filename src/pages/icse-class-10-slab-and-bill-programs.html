Ans. The short version

Slab programs in ICSE Java calculate a charge from a rate card divided into bands, such as an electricity bill by units, a discount by purchase amount, a tax by income or a courier charge by weight. There are two kinds: a bracket slab applies one rate to the whole amount, and a band slab charges each band at its own rate and adds them. They are written with if-else-if ladders inside a class with accept, compute and display methods and a variable description table. Modern Age Coders teaches them live in a Tuesday and Wednesday mini batch in India, or one to one at the family's time.

Q1. What is a slab program, and how many kinds are there?

Slab programs ICSE Java: the two ways a rate card can be read

A slab program works out a charge when the rate changes from one band of values to the next. Before writing any code, decide which of two kinds the question describes, because the same table of rates gives very different answers.

PointBracket slab (whole amount)Band slab (band by band)
How the rate is usedFind the one band the value falls in; that rate applies to the entire valueEach band is charged at its own rate; the parts are added
Typical wording"Purchase amount 3001 to 6000: discount 15%""First 100 units at 2.00, next 200 units at 3.50"
Usual examplesDiscount, commission, grade, fine categoryElectricity and water bills, tax, parcel weight steps
Code shapeif (amt <= 1000) rate = 5; else if ... then one multiplicationEach branch adds the full charge of the lower bands to the part above
At a boundaryThe total can jump down: a bigger amount can cost lessThe total rises smoothly; there is never a jump

The words that decide it

"First", "next", "for every unit above" and "remaining" mean band slab. "If the amount is between" or "on the total purchase" means bracket slab.

The cost of guessing

With the electricity rates below, 450 units billed as a bracket (all units at 5.00, plus the meter charge) gives 2300.0. Read correctly, band by band, it is 1700.0.

What the paper asks for

A class with named data members, a method to accept input, one to calculate and one to display, and a main that creates an object and calls them. A variable description table earns its own credit.

Q3. How are discount and tax programs different?

Discount program ICSE and a tax slab: if else programs in board format

A discount is usually a bracket slab: find the one rate and apply it to the whole purchase. A tax is a band slab like the electricity bill, but here it is written a second way, by peeling off one band at a time, which is shorter when there are many bands.

Q4. What about "for every 500 g or part thereof"?

Courier charge program: switch for the zone, Math.ceil for the weight steps

"Or part thereof" means any extra weight, however small, is charged as a full step. Math.ceil of the extra weight divided by the step size, written with a double, gives exactly that number of steps.

Q5. How do you make sure a slab program earns all 15 marks?

Conditional statements ICSE Class 10: a checklist for slab questions

A Section B question is worth 15 marks, and the mark scheme rewards a correct class structure, correct input, correct logic and correct output. Most marks lost on slab programs are lost at a boundary or in a missing piece of structure.

  1. Copy the names exactly

    Use the class, data member and method names from the question, with the same types and capital letters. A renamed method can cost marks even when it works.

  2. Decide bracket or band, in writing

    Write "whole amount" or "band by band" above the rate table on your rough work, then the band totals if it is a band slab.

  3. Check every boundary sign

    "Up to 100" is <= 100; "above 600" is > 600; "1001 to 3000" in an else-if after <= 1000 needs only <= 3000.

  4. Keep the fraction

    Use double for money, and write percentages as * rate / 100 on a double, or divide by 100.0. An int division can silently turn a 5% discount into zero.

  5. Do the extras in the stated order

    A fixed charge, then a surcharge on the total, is not the same as a surcharge first. Follow the wording of the question line by line.

  6. Test the edges, not the middle

    Dry run one value at the top of each band and one just above it. If those agree with the rate table, the middle values will too.

  7. Finish the paperwork

    A main that creates the object and calls every method, comments on the data members, and a variable description table.

Quick check questions

  1. Write the condition for "units from 201 to 400, both included", as one boolean expression.
    Answer units >= 201 && units <= 400. Inside an else-if ladder that has already handled units <= 200, units <= 400 is enough.
  2. With the ElectricBill tariff, what is the bill for 250 units?
    Answer 200 + 150 × 3.50 = 725, plus 50 is 775.0.
  3. Why does disc = amount * (rate / 100); give 0 when rate is an int below 100?
    Answer rate / 100 is int division, so 15 / 100 is 0 before it is multiplied. Write amount * rate / 100 with amount a double, or rate / 100.0.
  4. How many 500 g steps does Math.ceil give for 1501 g after the first 500 g?
    Answer 3. The extra weight is 1001 g, and 1001 / 500.0 is 2.002, which rounds up to 3.0.

Questions about slab programs

What students ask about slab and bill programs in ICSE

What is a slab program in Java ICSE?

A slab program calculates a charge when the rate changes from one range of values to the next, such as an electricity bill where the first 100 units cost less per unit than the next 200. It is written with an if-else-if ladder, or sometimes switch, usually inside a class with methods to accept, compute and display.

How do you write an electricity bill program in Java for ICSE?

Create a class with name, units and bill as data members, and methods to accept input, calculate and print. In the calculate method, use an if-else-if ladder: each branch adds the full charge of all lower bands, worked out beforehand, to the units above the last boundary multiplied by the new rate. Then add any fixed charge or surcharge the question states.

What is the difference between a slab rate on the whole amount and band by band?

With a whole-amount slab, you find the one range the value falls in and apply that rate to all of it, as in most discount questions. With a band-by-band slab, each part of the value is charged at the rate of its own band and the parts are added, as in electricity bills and tax.

How do you write a discount program in ICSE Java?

Read the purchase amount and any customer type, use an if-else-if ladder on the amount to choose the discount percentage, then compute discount = amount * rate / 100 and net = amount - discount. If the rate also depends on a type, a ternary or a nested if inside each branch keeps the ladder short.

Are slab programs asked in the ICSE Computer Applications board exam?

Class-based programs with a slab or rate table have appeared in Section B in several recent papers, usually as the question on class and object. The 2027 specimen paper is not yet confirmed, so treat slab programs as a very likely shape rather than a promise, and practise the other families too.

How do you calculate a charge "for every 500 g or part thereof" in Java?

Work out the extra weight beyond the first slab, divide it by the step size as a double and apply Math.ceil, then cast to int: steps = (int) Math.ceil((weight - 500) / 500.0). Dividing by 500 as an int would cut off the part step before ceil could round it up.

Should I use if-else or switch for slab programs?

Use if-else-if for ranges, because switch can only compare one value against fixed constants. switch suits a choice such as a zone letter or a category number. Many good answers use both: switch to pick the rates for a category, then if-else or a formula for the amount.

What are conditional statements in ICSE Class 10?

They are statements that choose what to run based on a condition: if, if-else, the if-else-if ladder, nested if, the ternary operator and switch-case. The ICSE syllabus covers them in Class 9 and the Class 10 paper re-tests them, most visibly in slab, menu-driven and number-checking programs.

Do I need a variable description table in an ICSE slab program?

It is expected in the laboratory assignments for internal assessment and is good practice in the board paper. List every variable, its data type and its purpose. Students often include it in Section B answers as well, and it helps the examiner follow your logic.
