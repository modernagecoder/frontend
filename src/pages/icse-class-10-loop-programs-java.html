Ans. The short version

Loop programs in ICSE Class 10 use Java's three iterative constructs. for suits a known number of passes; while is entry controlled and may run zero times; do-while is exit controlled and always runs at least once. Any loop converts into the others by moving the initialisation before the loop and the update to the end of the body, but a do-while differs when its condition starts false. Section A asks for conversions and counts; Section B programs are built on loops. Loops are taught live in our ICSE evening mini batch in India, and one to one everywhere.

Q1. What is the difference between for, while and do-while?

for, while and do-while in ICSE Java, compared

for and while test the condition before each pass, so they are entry controlled and can run zero times. do-while tests after each pass, so it is exit controlled and always runs at least once. Choose for when the count is known, while when it is not, do-while when the body must run first.

Infinite loop

A loop whose condition never becomes false: for ( ; ; ), while (true), or a test the variable can jump past. i != 10 with i += 2 from 1 skips 10 for ever; our run stopped it after 1,000 passes with i at 2001.

Empty loop

A loop with no statement in its body, such as for (int i = 0; i < 1000; i++);. It only uses up time, so older textbooks call it a delay loop.

Finite loop

A loop with a condition that is certain to fail after a fixed number of passes. Every loop in a Section B answer should be finite, and your trace should prove it.

Q2. How do you convert a for loop to a while loop in ICSE?

Convert for loop to while in ICSE, and on to do-while

Move the initialisation above the loop, keep the condition in the while brackets, and put the update as the last statement of the body. For do-while, keep the same three pieces but move the test to the end, after a semicolon-terminated while.

Q4. How do nested loops, break and continue work?

Nested loops ICSE: counting inner passes, with break and continue

Questions about loops

What students ask about loop programs in ICSE Class 10

What are iterative constructs in Java?

Iterative constructs are statements that repeat a block of code while a condition holds. Java has three: the for loop, the while loop and the do-while loop. ICSE calls them iterative constructs, and they also cover nested loops and the jump statements break and continue that change how a loop runs.

What is the difference between while and do-while?

while checks its condition before each pass, so it is entry controlled and may not run at all. do-while checks after each pass, so it is exit controlled and always runs at least once. A do-while also needs a semicolon after its closing while (condition).

How do you convert a for loop into a while loop?

Take the three parts of the for header apart. Write the initialisation as a statement before the loop, put the condition inside while ( ), and make the update the last statement inside the loop body, adding braces if the body now has more than one statement. The output stays the same.

How do you find how many times a loop will execute?

Write down every value the loop variable takes, starting from the first, and stop at the first value that makes the condition false. Count the values before it. For a loop that adds a fixed step, (last value reached minus first value) divided by the step, plus 1, gives the same answer quickly.

What is an entry controlled and an exit controlled loop?

An entry controlled loop tests its condition before running the body, so it can run zero times; for and while are entry controlled. An exit controlled loop runs the body first and tests afterwards, so it runs at least once; do-while is the only exit controlled loop in Java.

What is the difference between break and continue?

break ends the loop immediately and control moves to the first statement after it. continue ends only the current pass: the rest of the body is skipped and the loop goes on to its next pass, running the update first in a for loop. In nested loops both affect only the innermost loop they sit in.

What is a nested loop in Java with an example?

A nested loop is a loop placed inside the body of another loop. The inner loop completes all its passes for each single pass of the outer loop. If the outer loop runs 5 times and the inner loop 4 times, the inner body runs 20 times. Nested loops are used for patterns, tables and 2D arrays.

What is an infinite loop? Give an example.

An infinite loop is one whose condition never becomes false, so it never ends on its own. A for loop with all three header parts left empty, and while (true), are deliberate examples. A common accidental one starts i at 1, adds 2 each pass and tests i != 10; i is always odd, so it never equals 10.

Which loop is best for ICSE Section B programs?

Use for when the number of passes is known, such as running through the digits of a fixed range or the elements of an array. Use while when the count depends on the data, such as reducing a number digit by digit. Use do-while for menus and input that must be read before it can be checked.
