AP CSP Create performance task guide

The Create performance task is the part of AP Computer Science Principles you build yourself, over several weeks of class time, before the exam. It is also the part where students lose points for reasons that have nothing to do with how good their program is: a video with narration, a comment left in a screen capture, a file that was uploaded but never submitted as final. This guide pulls together what College Board’s own handouts, tip sheet, Digital Portfolio guide and FAQs say, in the order a student meets it, with the exact limits and the exact deadline. It does not give you a project to submit. College Board forbids that, and we teach the ideas so the program is yours.

In short

The AP CSP Create performance task asks you to build a program of your choice in at least 9 hours of class time and submit three components as final in the AP Digital Portfolio: your program code as a PDF, a video of up to 1 minute with no narration, and a Personalized Project Reference of screen captures with no comments. The deadline for the 2027 exam is April 30, 2027, at 11:59 PM ET.

What you submit

The three components, and who may help with each

College Board’s Student Handouts set out three components. The rule on collaboration is different for each one, and that difference trips students up.

Create performance task components, from the AP CSP Student Handouts and Digital Portfolio guide (read 17 October 2026)
ComponentWhat it isWho may work on it
A: Program codeOne PDF with all of your program code, including comments, with acknowledgment of any code someone else wroteYou alone, or with your partner(s)
B: VideoOne video of your program running, showing input, at least one aspect of functionality, and outputYou alone, no collaboration
C: Personalized Project ReferenceScreen captures of your own code segments: a procedure and a call to it, a list being stored and a list being usedYou alone, no collaboration

Time in class

The handouts say you "will be provided with a minimum of 9 hours of class time" to complete and submit the three components. The FAQ adds that students may work outside the classroom as long as they have been given that class time.

Nine hours sounds generous until you count it: planning, building, testing, recording, capturing and checking. Students who arrive already comfortable with procedures and lists use those hours to build, not to learn.

Partners, and what they may do

College Board’s FAQ gives examples of acceptable collaboration on the program: two students writing it together, perhaps with pair programming; splitting a larger program into parts; giving feedback; or helping each other debug.

Code you were not actively involved in writing should be cited, and the FAQ says it should not be used in your Personalized Project Reference. To keep the work anonymous, you say a part was written by your collaborative peer rather than naming them.

Sources, read 17 October 2026: AP CSP Student Handouts, AP Digital Portfolio Student User Guide and AP CSP: Questions About the Exam. We are not connected with College Board.

Component A

What the program has to contain

You choose the program: College Board says it can be an app, a game, art or anything else, in the language of your choice. What it must contain is fixed.

Program requirements, from the AP CSP Student Handouts (read 17 October 2026)
RequirementWhat counts
InputFrom "the user (including user actions that trigger events)", "a device", "an online data stream" or "a file"
A list or other collectionUsed to store data and manage complexity, so the program is easier to develop or maintain than it would be without it
A student-developed procedureWith a name, a return type if needed, and one or more parameters, that helps fulfil the program’s purpose
An algorithm inside itUsing sequencing, selection and iteration, in the body of that procedure
Calls to the procedureYour own program calling your own procedure
OutputTactile, audible, visual or textual, based on input and functionality

What does not count as yours

The handouts say that built-in or existing procedures and language structures, "such as event handlers or main methods", are not considered student-developed. A click handler is not your procedure, even if you wrote the code inside it.

Any existing program code you use "needs to be extended in some new way by adding new functionality", and must be cited, with credit given to the author.

Choosing a language

There is no required language. When you submit the code, the Digital Portfolio asks which language you used, and College Board says that choice "will NOT impact your final AP score".

One limit from the FAQ: HTML "is a markup language and not a programming language" for this task. A web page alone will not meet the requirements; it needs a real program behind it, for example in JavaScript.

Component B

The video: short, silent and anonymous

The video is the easiest component to get right and the easiest to get wrong on a technicality. These limits are from the Student Handouts.

Video rules, from the AP CSP Student Handouts (read 17 October 2026)
RuleLimit
Must showInput to your program, at least one aspect of its functionality, and its output
LengthNo more than 1 minute
File sizeNo more than 30MB
Format.webm, .mp4, .wmv, .avi or .mov
Must not containAny distinguishing information about yourself, or voice narration
AllowedText captions, which the handouts encourage

Make input visible

If your program takes input from a click, show the pointer and the result. If it reads a file, show the file being chosen. The 2026 Scoring Guidelines allow the reader to look at the code if the source of input is unclear, but a clear video saves them the trouble.

The guidelines are also explicit that screenshots or storyboards are not acceptable: the video must show the program actually running.

Our checklist before recording

Close anything that shows your name: browser profiles, file paths, chat windows, a sign-in badge in the corner of an editor.

Turn the microphone off rather than relying on staying quiet, and check the finished file is under a minute and under 30MB before you upload it.

Component C

The Personalized Project Reference, the component that matters on exam day

The Personalized Project Reference, or PPR, is what you will have in front of you when you answer the written-response questions. It has strict rules, and breaking one can cost the whole task.

PPR rules, from the Student Handouts, the PPR Tip Sheet and the exam FAQ (read 17 October 2026)
SectionCapture 1Capture 2
ProcedureYour procedure: its name and return type if needed, one or more parameters that affect what it does, and an algorithm with sequencing, selection and iterationWhere your procedure is called in the program
ListHow data is stored in the listThe same list being used, for example creating new data from it or accessing several of its elements
  1. No comments, anywhere. The handouts say your code segments "should not include any comments", and that course content or comments in the PPR lead to a score of 0 on the Create performance task, including the written responses.
  2. Readable text. At least 10-point font. The tip sheet adds: "The use of 12-point font is even better."
  3. Capture at 100 percent. The FAQ says to take captures while the application displays at 100%, and the tip sheet warns against zooming out and enlarging later, which makes text blurry.
  4. Split long code. "Each image box allows up to three screen captures." For a long segment, capture it in sections and upload them in order.
  5. Handle wide code. Shorten long lines with variables if you can. If not, the tip sheet says to rotate the captures 90 degrees and "always rotate them in the same direction".
  6. Print it once. Saving the PPR in the Digital Portfolio creates a PDF; print it and read it before submitting as final, because that printout is close to what you will have on exam day.

Sources: AP CSP Personalized Project Reference Tip Sheet and the AP CSP Student Handouts, read 17 October 2026. The exam-day prompts change every year.

On exam day

The four written-response prompts your PPR has to support

On the end-of-course exam you answer two questions, split into four prompts, about the code in your PPR. AP Central lists the learning objectives each prompt can assess.

Written-response categories and some of their learning objectives, from the AP CSP exam page (read 17 October 2026)
PromptCategoryExamples of objectives it can assess
Written Response 1Program Design, Function, and PurposeCRD-2.B explain how a code segment functions; CRD-2.C and CRD-2.D identify inputs and outputs; CRD-2.G documentation
Written Response 2(a)Algorithm DevelopmentAAP-2.J express an algorithm that uses iteration without a programming language; AAP-2.L compare algorithms
Written Response 2(b)Errors and TestingCRD-2.I.a identify the error; CRD-2.I.b correct it; CRD-2.J choose inputs and expected outputs to test
Written Response 2(c)Data and Procedural AbstractionAAP-1.D.b how a list manages complexity; AAP-3.B how a procedure manages complexity

Why the PPR choices matter

Every prompt points at the PPR. If your procedure has a parameter that does nothing, or your list holds one item, the prompt about it has nothing real to grip, and the answer is hard to write well.

So choose PPR segments with the exam in mind: a procedure whose parameter clearly changes the result, a loop whose stopping point you can name, and a list whose removal would make the code longer.

Practice before you submit

College Board’s FAQ advises completing some practice written-response prompts before submitting the components as final, so students discover whether the PPR contains all the code segments they need.

That is the single most useful piece of advice in the whole FAQ. Once submitted as final, nothing can be changed unless a teacher returns the component.

Help, AI and plagiarism

What help is allowed, and what costs the whole task

College Board’s rules on generative AI and plagiarism are clear once laid side by side. The consequences are not small.

Help and integrity rules, from the Student Handouts and the AP CSP plagiarism and AI FAQ (read 17 October 2026)
QuestionWhat College Board says
Can I use generative AI?Yes, "as supplementary resources for understanding coding principles, assisting in code development, and debugging"
What must I do if I use it?Review and understand any code co-written with AI, be ready to explain it in detail on the exam, and acknowledge it through citation, attribution or reference
What counts as plagiarism?Using code, media, data, information or evidence created by someone else or with generative AI tools without appropriate acknowledgment
What is the penalty?A score of 0 on the Create performance task, including the written responses on the end-of-course exam
Can I reuse a class practice task?No: "You cannot submit any work from AP Central samples, curriculum provider samples, or practice performance tasks"
Can I post my project online?No. The Digital Portfolio guide says: "Do not publicly post or share any portions of your performance task."
How would I be told?By email to your College Board account, usually in the summer, with 6 weeks to respond

What a teacher may and may not do

The handouts say that once your teacher assigns the task for AP scoring, you complete it without help from anyone except your partner, and then only on the program code. The FAQ adds that teachers may not give feedback on the three components until after they are submitted as final.

Teachers may check that the right, uncorrupted files were uploaded, and check the PPR for comments and course content. That is all.

How we teach around those rules

We teach the concepts, and we set practice projects that are deliberately different from anything a student would submit. During the scored task we do not look at, suggest or fix the student’s Create code, video or PPR.

If a student uses AI while learning, we ask them to explain every line back in their own words, which is exactly what the written responses demand. Our post on studying with ChatGPT without cheating covers the habit.

Submitting as final

Getting all three components scored before the deadline

Uploading is not submitting. Only components marked Submitted in the AP Digital Portfolio are sent for scoring.

  1. Join the class section. Use the join code from your teacher in My AP; homeschooled and virtual school students get theirs from the AP coordinator at the school where they test.
  2. Upload, then check. If you upload more than one version, the Digital Portfolio guide says "only the latest file version that you upload will be submitted as final".
  3. Submit each component as final. Open each one, view the file you are submitting, confirm personal information has been removed, and confirm you cannot change it afterwards.
  4. Attest. Agree that the work is original and accept the terms. A confirmation window shows College Board received it.
  5. Leave time. The FAQ advises allowing at least 30 minutes to submit all three, and warns that uploads slow down near the deadline of April 30, 2027, at 11:59 PM ET.
  6. Then sit the exam. The end-of-course exam is on Friday, May 14, 2027. A student who submits the task but skips the exam has the score cancelled.

No second chances

College Board’s FAQ is plain: "resubmission of performance tasks across any of the AP Exams isn’t allowed", apart from rare extreme circumstances. Extensions to the deadline are not guaranteed.

So treat the April date as the end of the work, not the start of the upload.

Planning backwards from April 30

Our own rule for students: everything submitted as final by mid-April, a printed PPR read once, and two practice written responses answered from it before then.

A practice exercise

Practise the ideas on code that is not your project

This tiny program is ours and is for practice only. It must never be submitted: College Board forbids submitting sample or practice work. It shows, in eight lines, what a procedure with a meaningful parameter and a list in use look like.

Practice prompts on the example, in the style of the four categories (ours; model answers are ours)
Practice promptOne acceptable answer
What does min_length do?It sets the shortest word that counts. With 6 the call returns 2 (nebula and galaxy); with 0 it returns 5, every word.
What stops the iteration?The for loop ends after the last element of words, so it stops when every item in the list has been checked.
Give a call that behaves incorrectlycount_long_words("comet", 3) returns 0, because a string is passed instead of a list, so the loop visits single letters, each of length 1.
How does the list manage complexity?One variable holds every word, so the same loop works for five words or five hundred. Without it you would need a variable and an if statement per word.

Write your own answers before reading ours, in two or three sentences each. Then do the same exercise, out loud, on a practice project your teacher sets. For a broader look at the two AP computer science courses, see AP CSP or AP CSA first.

Questions from students

The AP CSP Create task: common questions

What is the AP CSP Create performance task?

It is the through-course part of the AP Computer Science Principles exam. You build a program of your choice in at least 9 hours of class time and submit your program code, a video and a Personalized Project Reference as final in the AP Digital Portfolio.

When is the AP CSP Create task due in 2027?

AP Central lists Friday, April 30, 2027, at 11:59 PM ET as the deadline to submit all components as final.

How long can the Create task video be?

No more than 1 minute and no more than 30MB, in .webm, .mp4, .wmv, .avi or .mov format, with no voice narration and nothing that identifies you. Text captions are encouraged.

Can my Personalized Project Reference have comments?

No. College Board says comments or course content in the PPR result in a score of 0 on the Create performance task, including the written responses.

Can I use ChatGPT or other AI for the Create task?

College Board allows generative AI as a supplementary resource for understanding coding principles, helping with code development and debugging. You must understand and be able to explain any AI-assisted code and acknowledge it.

Can I work with a partner on the Create task?

Only on the program code. The video and the Personalized Project Reference must be made individually, and the written responses are answered alone on exam day.

Can I use HTML for the Create task?

College Board says HTML is a markup language, not a programming language that can be used for the task. You need a real programming language such as Python or JavaScript.

Can I change my Create task after submitting it as final?

No, unless your teacher returns a component to you. College Board also says resubmitting performance tasks is not allowed except in rare extreme circumstances.

Will you help with my Create task code?

No. We teach the concepts and set separate practice projects. During the scored task we do not look at, suggest or fix a student's Create work, which College Board does not allow.

What times are AP CSP lessons for US students?

Weekdays or weekends, flexible. Choose your batch, or for a very personalised plan choose 1-on-1 at your convenience, weekend mornings or weekdays.

How much do AP CSP lessons cost?

The first lesson is free. After that, lessons are paid month by month, with the monthly amount shown in US dollars in the fees section.
