## What is a Girls Who Code Club, and what does it cover?

A Girls Who Code Club is a free, regular meeting where students explore coding together with a facilitator. GWC says clubs are open to students in grades 3 to 12 of any skill level and can meet in person or online.

### In GWC's own words

The Clubs page describes clubs as "free programs for all 3rd-12th graders of any skill level", and says they "can be integrated into STEM-focused classes or take place after school, on weekends, or during the summer. Held in-person or entirely online."

The Programs page adds the practical detail families ask about: clubs are grouped into two bands, grades 3 to 5 and grades 6 to 12, run from beginner to advanced, and take 1 to 2 hours per week, after school or on weekends during the school year.

### Who leads a club

A club is led by a facilitator rather than a professional coding teacher. GWC lists facilitators as "teachers, librarians, parents, and volunteers", and says plainly that "Many Facilitators have no technical experience and learn to code alongside their Club members."

That is a strength for confidence and community. It also explains why many club members reach a point where they want a teacher who can answer "why does my code do that?" straight away.

If there is no club nearby, GWC lets adults start one. Its Start a Club page lists the requirements: a nonprofit host organization such as a school or library, "2-4 hours to plan and host sessions each week", internet access, a background check, and "I am age 18 or older."

## How does a club member move from block code to Python?

By translating one block at a time. A block program and a Python program say the same thing; Python simply writes it down in words and indentation. The worked example below is ours, written for a student who has used a drag-and-drop editor.

### The block program (ours)

Picture a stack of four blocks: a "repeat 4" block, and inside it "move 50 steps" and "turn 90 degrees". Run it and the sprite draws a square, because four equal sides with four quarter turns bring it home.

Ask the student first: why 90? Because a full turn is 360 degrees, and 360 / 4 = 90. Understanding that one line of arithmetic is what lets her change the shape later.

### The same idea in Python

The repeat block becomes a for loop. The blocks inside it become the indented lines under the loop. Moving becomes forward and turning becomes right.

The single biggest change from blocks is that indentation now carries meaning. In blocks, a piece sits visibly inside the repeat; in Python, four spaces of indent put a line inside the loop.

**square.py (ours)** (Python)
```python
# square.py (ours): the block program "repeat 4: move 50, turn 90", in Python
import turtle

pen = turtle.Turtle()
for side in range(4):      # the repeat block becomes a for loop
    pen.forward(50)        # "move 50 steps"
    pen.right(90)          # "turn 90 degrees"

turtle.done()
```
Run on our machine with Python 3 and its built-in turtle module: the pen draws a 50-step square and stops where it started.

**A translation table from common blocks to Python (ours)**

| Block idea | Python | What to watch |
|---|---|---|
| repeat 4 | for i in range(4): | The colon and the indented lines below it |
| forever | while True: | Needs a way to stop, or the program never ends |
| if touching edge | if x > 200: | A test that is either True or False |
| set score to 0 | score = 0 | One equals sign stores a value |
| change score by 1 | score = score + 1 | Read it right to left: add 1, store it back |
| say "Hello" | print("Hello") | Text needs quotation marks |

1. Change one number (ours). Make the square bigger by changing 50 to 100. Nothing else changes, which shows which line controls size.
2. Change the shape. For a triangle, repeat 3 times and turn 360 / 3 = 120 degrees. For a hexagon, repeat 6 times and turn 60.
3. Name the number. Write sides = 6 at the top, then range(sides) and 360 / sides. Now one line changes the whole shape.
4. Break it on purpose. Remove the indent from the turn line and run it. The pen draws one line and turns once, because the turn has left the loop. Seeing a mistake happen is how the rule sticks.

## What is a good first real project after a club?

Something small, useful to the club itself and finished in a week. Counting a vote is ideal: the club decides what to build next, and the program tells them the winner. The program below is ours.

**club_poll.py (ours)** (Python)
```python
# club_poll.py (ours): count a club vote on which project to build next
votes = ["Game design", "Web", "Game design", "AI", "Web", "Game design"]

tally = {}
for choice in votes:
    tally[choice] = tally.get(choice, 0) + 1

for choice, count in sorted(tally.items(), key=lambda pair: -pair[1]):
    print(choice, count)

winner = max(tally, key=tally.get)
print("Next project:", winner)
```
Run by us with Python 3: it prints Game design 3, Web 2, AI 1, then Next project: Game design.

### What each part teaches

The list holds every vote in order, exactly as the club called them out. The dictionary named tally keeps one count per choice, and tally.get(choice, 0) + 1 means "the count so far, or zero if this is new, plus one".

The sorted line prints the biggest count first. The last two lines pick the winner with max, using the counts to compare.

### Make it hers (ours)

Swap in the club's real choices: cybersecurity, data science, a website for the school library. Add a tie check: if two choices share the top count, print both and call a re-vote.

Then make it ask for votes with input() until someone types "done". That one change turns a fixed script into a tool the club can actually use at its next meeting.

**Five short translation exercises with answers (ours; each checked in Python 3)**

| Exercise | A good answer | Why |
|---|---|---|
| Draw a triangle with sides of 80 | for i in range(3): forward(80); right(120) | 360 / 3 = 120 |
| Say "Go!" five times | for i in range(5): print("Go!") | range(5) runs 5 times |
| Start a score at 10 and add 5 twice | score = 10, then score = score + 5 twice | The score ends at 20 |
| Print "Big" only if n is over 100 | if n > 100: print("Big") | The test decides |
| Count the letter a in "banana" | "banana".count("a") | The answer is 3 |

## How can a girl keep coding between club meetings?

With a short, regular routine and one project at a time. A club gives community; a weekly lesson and twenty minutes of home practice give steady progress. This twelve-week outline is ours.

1. Weeks 1 to 2 (ours). Rebuild a favorite club project in blocks, then translate it into Python line by line using the table above.
2. Weeks 3 to 4. Variables and loops in Python: shapes with turtle, a times-table printer, a countdown.
3. Weeks 5 to 6. Decisions with if and else: a quiz that keeps score and a guessing game with hints.
4. Weeks 7 to 8. Lists and dictionaries: the club poll above, then a reading log or a playlist sorter.
5. Weeks 9 to 10. A project of her own choice, planned on paper first: what goes in, what comes out, what the user sees.
6. Weeks 11 to 12. Finish, test with two friends, fix what they found, and show it at the next club meeting.

### Grades 3 to 5

Stay with blocks a little longer if she enjoys them, then try the square in Python. Short sessions, lots of drawing.

### Grades 6 to 8

Move fully to Python. Small games and quizzes keep it fun, and the club's video tutorials become easier to follow.

### Grades 9 to 12

Look at GWC Pathways tracks, and build a portfolio project in web development, data or AI with Python.

## Four stages from club coder to independent programmer

Our own description of how a young coder grows, so you can tell what kind of help fits.

**Stages of growing as a coder (ours)**

| Stage | What it looks like |
|---|---|
| 1. Follows along | Completes club activities step by step with the tutorial open |
| 2. Changes things | Edits numbers and text in a working program to see what happens |
| 3. Builds from a plan | Writes a small program from her own idea, with help on errors |
| 4. Debugs alone | Reads an error message, finds the line and fixes it herself |

### For parents

Most girls leave a beginner club somewhere between stages 1 and 2, which is exactly right. The jump to stage 3 is where a regular teacher helps most.
Ask to see what she made rather than how long she spent. A finished small project is worth more than a long unfinished one.

### For students

When code breaks, read the last line of the error first. It usually names the problem and the line number.
Keep a notebook of mistakes you fixed. By week twelve it will be the most useful page you own.

## Girls Who Code next step: questions answered

### What do you do after Girls Who Code?

Within Girls Who Code, high school students can apply to the free online Pathways program, and older students can join College Loops or career programs. Outside GWC, the most useful next step is regular practice that moves from block code into Python and finished projects.

### Is Girls Who Code free?

Yes. Girls Who Code describes its Clubs, Pathways and College and Career programs as free on its Programs page. Clubs usually meet for 1 to 2 hours a week.

### What grades can join a Girls Who Code Club?

GWC says clubs are for students in grades 3 to 12 of any skill level, grouped into a grades 3 to 5 band and a grades 6 to 12 band.

### What is Girls Who Code Pathways?

Pathways is GWC's free, year-round, fully virtual program for high school students. It offers self-paced tracks in game design, data science, AI, cybersecurity and web development, with about 6 to 7 weeks per course project.

### What language should she learn after club block coding?

Python is the usual first text language because its short, readable lines map neatly onto blocks. A repeat block becomes a for loop and the blocks inside it become indented lines.

### Can a parent start a Girls Who Code Club?

Yes, if you meet GWC's requirements: a nonprofit host organization such as a school or library, 2 to 4 hours a week, internet access and devices, a background check, and being 18 or older. No coding experience is needed.

### Do you have a coding course just for girls?

Yes. Princess Coders is our coding course designed for girls and women, and families can choose a girls-only batch or a mixed batch as described on our coding classes for girls page.

### How is a class with you different from a club?

A club is a free, friendly community led by a facilitator who may be learning alongside the members. Our classes are taught by a coding teacher on a planned course, with homework and feedback each week. Many girls enjoy doing both.

### When are your classes?

Weekdays or weekends, flexible: choose your batch, or for a very personalised plan choose 1-on-1 at your convenience, weekend mornings or weekdays.

### Are you part of Girls Who Code?

No. Modern Age Coders is an independent online school and has no connection with Girls Who Code. We describe GWC only from its own public pages.
