Ans. The short version

ICSE Class 10 string programs ask you to read a word or sentence with Scanner and process it one character at a time with charAt, length, indexOf, substring and the Character methods. The families the board returns to are palindrome words, Pig Latin, letter frequency, word extraction (counting, capitalising, finding the longest word), coding by shifting letters and spotting double letters. Each answer earns its marks through a working loop, correct method use, comments and a variable description table. Q1. What kinds of string programs does ICSE set?

String handling ICSE: the six program families

Nearly every Section B string question belongs to one of six families, and all six rest on one loop: walk the string with charAt from index 0 to length() minus 1. Learn the family, and an unseen question becomes a small change to a program you already know.

The word-extraction template

Four of the six programs need the words of a sentence one at a time. The ICSE way, without split, is to add one space to the end of the sentence so the last word is closed like the others, then build each word letter by letter:

  1. Read the sentence with nextLine(), then trim() it and add " " at the end.
  2. Loop over every index. If the character is not a space, add it to w.
  3. When a space arrives and w is not empty, the word is complete: process it.
  4. Set w = "" and carry on. The extra space guarantees the last word is processed too.

Q4. How do you find the frequency of characters in Java?

Frequency of characters in Java ICSE, and word-by-word programs

Use an int array of 26 counters. Convert the string to capitals, and for every letter add one to f[ch - 'A']: 'A' lands in f[0], 'B' in f[1] and 'Z' in f[25]. One pass counts the whole alphabet, which is faster and shorter than 26 separate loops.

Questions about string programs

What students ask about ICSE Class 10 string programs

What are the important string programs for ICSE Class 10?

The families that keep returning are palindrome words, Pig Latin, frequency of letters or vowels, word handling such as capitalising each word or finding the longest word, coding by shifting letters, and double or consecutive letters. All of them use one loop over the string with charAt, so practise the loop until it is automatic.

Which String functions are in the ICSE Class 10 syllabus?

Programs and output questions regularly use length, charAt, indexOf, lastIndexOf, substring, toLowerCase, toUpperCase, trim, replace, concat, equals, equalsIgnoreCase, compareTo, compareToIgnoreCase, startsWith, endsWith and String.valueOf. For each one, learn the return type as well as an example value, because output questions test both.

How do you check if a word is a palindrome in Java ICSE?

Build the reverse with a loop from length() minus 1 down to 0, adding each charAt to an empty String, then compare the original and the reverse with equals or equalsIgnoreCase. Do not use == for Strings. To find palindrome words in a sentence, run the same check on each word as it is extracted.

How do you write a Pig Latin program in ICSE?

Find the index of the first vowel, then return substring(i) + substring(0, i) + "AY". Convert the word to capitals first so one vowel test works, and decide what to do with a word that has no vowel; the usual rule is to add AY to the whole word. Program 2 on this page does this for every word of a sentence.

How do you count the frequency of each character in Java?

Make an int array of 26 counters, convert the string to one case, and for every letter increase f[ch - 'A'] by one. After the loop, print each letter whose counter is above zero. For vowels only, five counters or a single test with indexOf on "AEIOU" is enough.

Can I use split() in ICSE string programs?

split runs in BlueJ, but it works with regular expressions, which are outside the Class 10 course, and you must be able to explain every line you write. It is safer to use the word-extraction template on this page: add one space to the end of the sentence and build each word character by character with charAt.

What is the difference between == and equals for Strings?

equals compares the characters inside two Strings; == checks whether two variables point to the very same object. Two Strings with identical letters can be different objects, so == may give false. In every ICSE string program, compare text with equals or equalsIgnoreCase.

Do I need a variable description table for string programs?

Yes, whenever the question asks for one, and it is a good habit for every Section B answer. List each variable, its data type and its purpose in one line. It takes two minutes and shows the examiner you understand your own program.

Why does my string program skip the last word?

Because a word is processed only when a space arrives, and there is no space after the last word. Add one space to the end of the sentence before the loop, as in s = s.trim() + " ", and the last word is closed like all the others.
