Online coding and Python classes in Vaughan

Are there live online coding and Python classes for Vaughan students?

Yes. Modern Age Coders teaches coding and Python live online to Vaughan students from age 6 to adult: a teacher on screen, code typed and checked while the class is running, in a group of fifteen to twenty students or with a private teacher. Children start with Python and AI for Kids, teens with Python for Teens. The first class is free.

"Online" covers a lot of things that are not teaching: a video playlist, a worksheet emailed on Mondays, a chatbot that answers questions at midnight. A live class is narrower and harder to fake. There is a teacher, there is a time, and there is a student whose code is on the shared screen being read line by line. This page explains, step by step, what that looks like for a Vaughan student, then lays out a Python route from the first line of code to a project on real data. The data comes from York Region, which publishes the cycling routes that Vaughan supplied, and we use it to show how a beginner's loop turns into a measured answer that still needs checking.

Inside one class

What actually happens in a live online Python class

Below is the order of one of our teens' Python lessons, written as an example plan. Lengths vary by course and level, but the order holds: the student types more than the teacher talks.

One live lesson for a Grade 9 Python student in Vaughan, in order (an example plan written by us)
StepWhat the teacher doesWhat the student does
1. Warm-upPuts last week's program on the shared screen with one line brokenFinds the broken line and says why it fails before touching the keyboard
2. New ideaShows one new construct, for example a dictionary that countsPredicts the output of a four-line example, then runs it
3. BuildWatches the student's own editor and stays quiet unless the student is stuck for longWrites a small program that uses the new idea on a fresh problem
4. Break itChanges one input so the program gives a wrong answerTraces the values by hand and fixes the logic, not just the symptom
5. ExplainAsks the student to talk through the finished codeExplains each block in plain words, as if to a classmate
6. Next stepSets one short task and notes what to revisitWrites the task down and asks anything left unclear

Steps 4 and 5 are where a live class earns its time. A recorded video cannot change the input on a student's program, and a chatbot will happily fix the code for them. Our teachers do neither the typing nor the thinking for the student; they ask the next question.

Code on a shared screen

The student writes in their own editor and shares it, so the teacher reads the real code, typos included. Nothing is pasted in from a finished answer.

A batch of fifteen to twenty

Everyone in the batch is at the same stage. The teacher calls on students by name, and code from two or three of them is read aloud each class.

One to one

One teacher, one student, a pace set by that student. Families pick it for faster progress, for ICS4U project work or for CCC practice.

From a first print() to a real project, step by step

Vaughan students already meet code in Ontario math class. Each step below is ours; the right-hand column quotes the Ontario expectation it builds on, read from the ministry curriculum service on 22 October 2026.

Our Python path for Vaughan students, matched to Ontario expectations (expectation wording quoted from Ontario's curriculum service; the steps are ours)
Our stepWhat the student can do after itOntario expectation it extends
1. Run and changeRun a short program, change one value, explain the new outputGrade 1 C3.2: “read and alter existing code” and describe how changes affect the outcomes
2. Loops and choicesWrite for loops and if statements without copying an exampleGrade 6 C3.2: changes to “the outcomes and the efficiency of the code”
3. FunctionsSplit a problem into named functions with inputs and a return valueGrade 7 C3.1: events influenced by “a defined count and/or subprogram”

The numbering is a sequence, not a calendar. A Grade 5 child may spend months on steps 1 and 2 with games and turtle drawings; an adult with spreadsheet experience may reach step 5 within weeks. What we never do is skip step 1. A student who cannot predict what a changed line will print is not ready for a project, whatever their age.

Vaughan data project

How many kilometres of cycling routes did Vaughan supply to the regional file?

York Region publishes a Bike Path layer for the whole region. Each line records who supplied it, so a student can pull out the lines whose SOURCE is Vaughan and measure them. Every number below is our own count of that download.

Our sum of line lengths in the York Region Bike Path layer, rows with SOURCE = Vaughan (238 rows, downloaded 22 October 2026). Lengths come from each line's geometry in metres, converted to km

The script below printed every figure in the table. It needs nothing beyond Python's built-in modules and reads the JSON file saved from the York Region map service:import json from collections import defaultdict with open("bike-path-source-vaughan.json", encoding="utf-8") as f: rows = [feat["attributes"] for feat in json.load(f)["features"]] km_by_class = defaultdict(float) owners = defaultdict(int) for row in rows: km_by_class[row["BIKE_FACILITY_CLASS"]] += row["SHAPE.STLength()"] / 1000 owner = (row["OWNER"] or "no owner listed").strip().upper() owners[owner] += 1 print(len(rows), "rows") for name, km in sorted(km_by_class.items(), key=lambda p: p[1], reverse=True): print(f"{name}: {km:.1f} km") print(dict(owners))

Why a defaultdict

A defaultdict(float) starts every new facility class at 0.0, so the loop can add a length without first checking whether the class exists. It is the same counting idea as a tally chart, with decimals.

Two length columns

The file has ACTUAL_LENGTH and a geometry length. ACTUAL_LENGTH is blank in 6 of the 238 rows and differs from the geometry by more than half a metre in 20, so our script sums the geometry, which every row has.

Labels that almost match

The OWNER column holds “CITY OF VAUGHAN” on 88 rows and “Vaughan” on 4. Calling upper() merges York Region with YORK REGION, but the two Vaughan labels stay apart, and 112 rows list no owner at all.

What the 114.2 km does and does not say

Adding the rows gives 114.2 km of line that Vaughan supplied to the regional file. That is our sum, not a figure York Region or the City publishes, and it is not the length of every route in Vaughan: lines supplied by others are excluded, and two lines can describe the same stretch. A student who writes that sentence has understood the data.

A sensible next task is a judgment call, not more code: should “CITY OF VAUGHAN” and “Vaughan” be merged, and what should a program do with 112 blank owners? Students write the rule down before writing the line that applies it. The data is used under the York Region Open Data Licence: contains public sector information made available under The Regional Municipality of York's Open Data Licence (York Region open data). Nothing here is endorsed by York Region.

Python and AI

If AI can write Python, what is a Vaughan student learning?

How to tell whether the Python an AI tool writes is right, which is a skill only writing it yourself builds.

An AI assistant asked for the kilometres of Vaughan cycling routes would sum something and print a confident number. It would not stop to ask which length column to trust, whether two owner labels mean the same city, or whether the lines Vaughan supplied are the whole network. Those questions decided every figure on this page.

So we teach thinking before tools. Students solve the problem, write the code and question the output; later, older students use AI assistants under the age rules we follow, as a second opinion they must check, never as a way to copy an answer.

A student who can explain why 114.2 km is not the length of every route in Vaughan has learned the part of programming that does not get automated. The longer argument is in our essay on learning to code beside AI.

FAQ

Vaughan online coding and Python questions

What Vaughan parents and students ask us before the first class.

What does a live online coding class mean in practice?

A teacher on video at a fixed time, the student sharing their own editor, and code written and checked during the class. It is not a recorded course or a chatbot.

Are your Python classes for Vaughan students in person?

No. Modern Age Coders has no Vaughan centre. Every class is live online, so students in Woodbridge, Maple, Concord, Kleinburg or Thornhill join from home.

How many students are in a Vaughan class?

A batch has fifteen to twenty students at the same stage. A one to one class has one student with one teacher. The course content is the same in both.

At what age can my child start Python?

Most children are ready for typed Python at about 9 or 10. Younger children, from age 6, start with blocks. The free class checks readiness rather than going by age alone.

Does Python help with Grade 9 math in Ontario?

Yes, in a specific way. MTH1W includes coding expectations in its algebra strand, and EQAO says the Grade 9 math assessment counts in the final course mark. Writing algebra as code is part of our path.

Can a Vaughan teen write the CCC in Python?

Yes. CEMC allows Python 3 for the CCC on Wednesday 17 February 2027. Entry goes through the school; our preparation uses problems we write ourselves.

Do your classes count as an Ontario credit?

No, and we do not grant Ontario credits. Credits come only from a school; our ICS3U and ICS4U companion adds practice alongside the school course.

When are online classes held for Vaughan?

Weekdays or weekends, flexible: choose your batch, or for a very personalised plan choose 1-on-1 at your convenience, weekend mornings or weekdays. Times are confirmed in Eastern time.

Do adults in Vaughan take these classes?

Yes. Adults follow the same Python path at their own pace, often towards data work or automation, in a batch or one to one.

Will a 905 or 289 phone number work in the form?

Yes. Vaughan numbers in the 289, 365, 742 or 905 area codes work. Enter all ten digits; the country code +1 is set for you.
