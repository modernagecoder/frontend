## ¿Cómo junta una clase de Python las palabras en inglés y el código?

Con anagramas: palabras que usan exactamente las mismas letras en otro orden. El ejercicio es nuestro. El programa ordena las letras de cada palabra y compara el resultado; si coincide, son anagramas.

**Buscar anagramas en inglés** (Python)
```python
def same_letters(a, b):
    return sorted(a.lower()) == sorted(b.lower())

pairs = [('listen', 'silent'), ('Night', 'thing'), ('apple', 'paper'), ('read', 'dare')]
for a, b in pairs:
    print(a, '+', b, '->', same_letters(a, b))
print('Signature of read:', sorted('read'))
```
Antes de ejecutarlo, el mentor lee cada par en voz alta y pregunta: "Same letters or not?" El niño responde par por par y anota sus apuestas.

**Lo que imprime el programa** (Salida)
```salida
listen + silent -> True
Night + thing -> True
apple + paper -> False
read + dare -> True
Signature of read: ['a', 'd', 'e', 'r']
```
Copiado sin cambios de lo que mostró Python 3 al correr el archivo en nuestra computadora.

1. **La firma de una palabra.** sorted('read') devuelve las letras en orden alfabético: a, d, e, r. Dos palabras con la misma firma tienen las mismas letras, en cualquier orden.
2. **Las mayúsculas engañan.** Para Python, N y n son letras distintas. Por eso la función usa lower() antes de ordenar; sin eso, Night y thing no coincidirían.
3. **Parecidas no es lo mismo.** apple y paper comparten casi todas las letras, pero una tiene dos p y una l, y la otra una r. El programa dice False. Mirar a ojo no basta; hay que contar.
4. **Vocabulario de regalo.** En diez minutos el niño aprendió listen, silent, night, thing, read y dare, y las dijo en voz alta. El mentor pide una frase con dos de ellas: "I read in silence at night."
5. **Su propia lista.** El reto de la semana: encontrar dos anagramas nuevos en inglés, agregarlos a pairs y predecir el resultado antes de correrlo.

Detrás del juego hay una idea que sirve mucho más allá de las palabras: para comparar dos cosas, primero se ponen en una forma común y recién después se comparan. Un niño que entiende esto revisa con otros ojos lo que le dice una página web o una herramienta de IA: no se queda con lo que "parece" igual.

## ¿Cómo se sigue una clase en inglés sin hablarlo en casa?

Paso a paso. El mentor no espera que el niño llegue hablando: usa frases cortas, escribe cada palabra clave, repite con otras palabras y deja que el niño conteste como pueda.

Las primeras semanas, el niño entiende más de lo que dice, y es normal. Las palabras del código ayudan, porque cada una tiene un efecto que se ve: print muestra algo, sorted ordena, lower pasa a minúsculas. Cuando una palabra tiene un efecto visible, se recuerda sola.

El índice EF EPI 2025 coloca a Lima con 555 puntos, lo suficiente para entrar en la categoría alta de EF, por encima del promedio nacional, que es moderado. Esa muestra se arma con personas adultas que hacen el examen en línea de EF, no con escolares, así que vale como referencia de ciudad: un inglés oral útil para estudiar y trabajar.

## ¿Qué hora será para el mentor cuando su hijo se conecte desde Carabayllo?
