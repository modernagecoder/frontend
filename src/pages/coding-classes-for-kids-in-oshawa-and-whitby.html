Coding classes for kids in Oshawa and Whitby

Can a child in Oshawa or Whitby, aged 6 to 12, join a live coding class?

Yes. Modern Age Coders runs live online coding for children aged 6 to 12 in Oshawa and Whitby, privately or in a group of fifteen to twenty. Coding for Kids and Roblox Game Coding suit younger starters; Python and AI for Kids or C++ for Kids suit children from about 9. A teacher leads each lesson, and the first is free.

Ontario adds one word to the Grade 6 coding expectation: efficient. A Grade 6 child in Oshawa or Whitby is no longer asked only to make a program work, but to make it work without wasted steps. That is a grown-up idea, the same one professional programmers argue about, and it is easier to understand with a real file than with a worksheet. This page sets out the Grade 6 expectations in the ministry’s words, a park-size project on the Town of Whitby’s open data that is efficient by design, the Gauss contest that Grade 7 brings, and how live online classes fit a Durham family’s evenings and weekends.

Grade 6 coding in Oshawa and Whitby

Efficient code: the Ontario Grade 6 coding a child in Oshawa or Whitby meets

Schools in Oshawa and Whitby teach the Ontario curriculum. The Grade 6 math and science wording below was downloaded from the ministry’s curriculum service on 22 October 2026. The ministry’s words are quoted on the left, and our classroom version sits on the right.

Grade 6, C3.1Children solve problems “by writing and executing efficient code”, with conditions and other control structures.
We ask two questions of every program: does it work, and could it do the same job with less? Children enjoy finding the line nobody needed.
Grade 6, C3.2Children “describe how changes to the code affect the outcomes and the efficiency of the code”.
We time programs. A version that reads a file once and a version that reads it eight times give the same answer, but one is clearly slower on a big file.
Grade 6, notes“Efficient code may involve using the instructions to solve a problem, using the smallest amount of space to store program data, and/or executing as fast as possible.”
Space and speed are both on the list. Our Whitby project uses a set to remember IDs it has seen, a classic speed trick children can explain in one sentence.
Grade 6, notes“A flow chart can be used to plan and organize thinking.”
Before typing, children draw boxes for steps and diamonds for decisions. A flow chart that fits on a page usually means a program that fits in their head.

The notes make a point we repeat often: “Efficient code can be altered more easily than inefficient code to adapt to new mathematical situations.” Their example is a probability simulation, where the number of trials goes up “by changing the number of repeats rather than writing additional lines of code for each of the new trials”. In our class that becomes a coin-flip program: one loop flips 10 coins, and changing one number makes it flip 10,000. Grade 6 science adds its own coding expectation, to write and run code “with a focus on obtaining input in different ways for a variety of purposes”, so our Grade 6 students also read input from the keyboard and from a file. Whitby data project

How big is a typical Whitby park? An efficient program on the Town’s parks file

The Town of Whitby publishes a points file of its parks, with a class for each (LOCAL, PARKETTE, DISTRICT and so on) and an area in hectares. Oshawa publishes open data too, but its licence document would not load when we tried on 22 October 2026, so this project uses Whitby data only. Every figure below is our own calculation from the Whitby download of that day.

The download has 128 rows but 127 parks: one ID appears twice with identical details, and another starts with a stray space, so the program strips spaces before comparing. 48 parks are under one hectare. The efficient part is the shape of the loop. A beginner might loop through the whole file once for each of the eight classes, eight passes. This program makes one pass, dropping each park into a list for its class as it goes, which is the Grade 6 idea of fewer wasted steps. A 12-year-old in our class writes:import csv, statistics sizes = {} seen = set() with open("whitby-parks.csv", encoding="utf-8-sig") as f: for park in csv.DictReader(f): pid = park["FACILITYID"].strip() if pid in seen: continue seen.add(pid) sizes.setdefault(park["CLASS"], []).append(float(park["AREA1_HECT"])) for kind, ha in sizes.items(): print(kind, len(ha), round(statistics.mean(ha), 2), round(statistics.median(ha), 2))

A set for repeats

Checking whether an ID is in a set takes about the same time however many IDs it holds. Checking a long list means walking along it. For 128 rows either works; for a million, only one does.

One mean that misleads

TOWN PARK has three parks: about 0.06, 2.14 and 30.66 hectares. Their mean is 10.95, larger than two of the three. The median, 2.14, describes the middle park far better.

Typical is a choice

For PARKETTE the mean and median are both 0.39, because the sizes are even. Children learn to check both, and to say which one they used and why.

The file and its description disagree

The Town’s description lists five classes as included and says FACILITY is not included. The file holds a FACILITY row anyway, plus OFFLEASH and LEASED TOWN LANDS rows, and spells waterfront as WATERFRONT (TOWN). The dataset page says it was updated in December 2025, while the attached metadata says it was last updated in October 2024. Neither is wrong on purpose; they were written at different times. We teach children to report what the file actually contains and to note the mismatch.

There is a friendlier question in the AMENITIES column. Splitting it on commas, our count found Playspace listed at 90 of the 127 parks and Splashpad at 18, while 25 parks list no amenity at all. Park names are in the file, but several honour people, so in class we work with IDs and classes only. Younger writers allowed

Because CEMC welcomes motivated students below Grade 7, a keen Grade 6 child can sometimes write Gauss in May 2027 if the school agrees. Ask early in the spring.

Why coders do well

Gauss questions reward careful counting, patterns and checking cases, the same habits efficient code needs. Neither requires memorised tricks.

Practice without copying

CEMC keeps ten years of past contests free online. We send families there and teach with our own problems, labelled as ours, rather than reproducing CEMC papers.

One of our problems, for a Grade 6 child: a park is 1.65 hectares and a parkette is 0.39 hectares; how many parkettes, side by side, would cover about the same land as the park? Children estimate first, then check with a two-line program, then ask whether rounding up or down makes more sense. The Gauss contest preparation page goes further, and the free CEMC resources guide lists the practice material. We are independent of CEMC and the University of Waterloo.

Class times

Durham evenings, Sunday mornings, and the clock in India

Oshawa and Whitby keep Eastern time, back an hour on 1 November 2026 and forward on 14 March 2027. India does not change its clock. Our conversions use the offsets in the IANA time zone database, release 2026e.

A 7:00 pm weekday class in Whitby is 4:30 am the next morning in India while Eastern time is UTC-4, which it is until 1 November 2026 and again from 14 March 2027. In the winter months between, at UTC-5, the same class is 5:30 am in India. A 9:00 am Sunday class is 6:30 pm in India in summer time and 7:30 pm in winter. Our teachers plan around those hours, which is why early-evening and weekend-morning slots are the easiest to offer.

Coding and AI

If AI can code, why should an Oshawa or Whitby child learn?

Because efficient, correct code still needs someone who understands it.

An AI tool asked for the average size of a Whitby town park will happily report 10.95 hectares. A child who has seen the three numbers behind it knows that figure describes almost no real park, and knows to ask for the median. Spotting a misleading answer is a human job, and it starts with having done the work yourself.

Our students under 13 are not given adult chatbots. They learn how AI systems are trained and why they make mistakes through activities their teacher leads, and they spend most of each class reasoning: planning with a flow chart, writing a step, testing it, and fixing what breaks.

Ontario asks Grade 6 children to judge the efficiency of their own code, and judging work, not just producing it, is what keeps people useful next to AI. The longer argument is in is learning to code still worth it.

FAQ

Oshawa and Whitby parents ask

Common questions from families in Oshawa and Whitby.

Are there coding classes for kids in Oshawa and Whitby?

Yes, live online. We have no local premises, so children join from home with a teacher, either one to one or in a group of fifteen to twenty.

What is efficient code in Grade 6?

Ontario Grade 6 math asks children to write efficient code and to describe how changes affect a program's efficiency. In practice that means no wasted steps, sensible loops and good use of decisions.

Is coding part of Grade 6 science as well?

Yes. The 2022 Ontario science curriculum asks Grade 6 students to write and run code in investigations, with a focus on getting input in different ways.

At what age can my child start?

Six is a good age, roughly Grade 1. Our kids classes run to 12, and older children continue in our teen courses.

Is Roblox coding real coding?

Yes. Roblox games are scripted in Luau, a real programming language. Children write code that controls how a game behaves, and the skills carry over to other languages.

When are classes for Durham families?

Weekdays or weekends, flexible: choose your batch, or for a very personalised plan choose 1-on-1 at your convenience, weekend mornings or weekdays. Every time is given in Eastern time.

Can a Grade 6 child write the Gauss contest?

Gauss is for Grades 7 and 8, but CEMC says motivated students in lower grades are welcome. Entry is through a school, and CEMC lists 10 to 21 May 2027 for the contest.

Will my child use AI chatbots?

No. We do not give adult chatbots to children under 13, and OpenAI requires a parent's permission for anyone under 18 to use ChatGPT. Children learn about AI through teacher-led activities.

Why does the data project use only Whitby?

The Town of Whitby publishes its parks file under an open government licence. We could not load Oshawa's licence document when we checked, so we did not use Oshawa data.

Where are the fees?

Just above the parent reviews. You will see that the opening lesson costs nothing, followed by two monthly plans, group and private, priced in the currency of your country.
