### Our advice for a new learner

Install the newest Python 3 release from python.org, unless a school or employer says otherwise. On 22 October 2026 that is the 3.15 line, whose first maintenance release came out the day before. Anything we teach in a first year works the same on 3.14.

Avoid Python 2. It is still listed as a CCC language, but it is not what any new course teaches, and code written for it trips over small differences in Python 3.

### The exception: contest practice

A student preparing for the Canadian Computing Competition should write code that also runs on Python 3.8, because that is what the CCC grader runs. Newer features, such as the match statement, fail there.

We teach contest students to keep to the plain core of the language for that reason. It loses nothing: loops, lists, dictionaries and functions are the same in every recent version.

## Summarising Winnipeg's 305,969 trees in twenty lines of Python

The City of Winnipeg publishes its tree inventory under an open licence that allows commercial reuse: one row per city tree, with the species, the neighbourhood and the trunk diameter. At 42.9 MB it is far too big to scroll through, which makes it the right file for learning to summarise. The program, the rule inside it and every number below are ours, from the file downloaded on 22 October 2026.

The question: which species are most common on Winnipeg's city-owned land, and how thick is a typical trunk of each? The columns used are Common Name and Diameter at Breast Height, in centimetres.

**Our program · tree_sizes.py** (python)
```python
# Our Winnipeg tree summary (Modern Age Coders, written for this page)
import csv
from statistics import median

sizes = {}            # species name -> list of trunk diameters in cm
skipped = 0

with open("winnipeg-tree-inventory.csv", encoding="utf-8") as f:
    for row in csv.DictReader(f):            # one row at a time, never the whole file
        name = row["Common Name"].strip().lower()
        cm = float(row["Diameter at Breast Height"])
        if cm <= 0 or cm > 500:              # our sanity rule: no zero trunks, none wider than 5 m
            skipped += 1
            continue
        sizes.setdefault(name, []).append(cm)

top = sorted(sizes.items(), key=lambda pair: len(pair[1]), reverse=True)[:5]
for name, cms in top:
    print(f"{name:26}{len(cms):7}   mean {sum(cms) / len(cms):5.1f}   median {median(cms):5.1f}")
print("species:", len(sizes), " skipped rows:", skipped)
```

**Output on the city's file (about two seconds on a laptop)** (text)
```text
green ash                   81885   mean  31.4   median  31.0
american elm                39651   mean  43.7   median  47.0
linden species              28540   mean  28.1   median  28.0
siberian elm                17940   mean  40.5   median  38.0
bur oak                     16226   mean  33.5   median  32.0
species: 197  skipped rows: 137
```
Green ash is the most common species by a wide margin. American elm has the thickest typical trunk of the five, and its median is larger than its mean.

**Four decisions inside the program, and what each one protects against (our checks on the same file)**

| Decision | What we found | Why it matters |
|---|---|---|
| Use csv.DictReader, not line.split(",") | A plain split gives the wrong number of columns on 20,051 rows | Names such as "Manitoba maple, boxelder" contain a comma inside quotes, and only a real CSV reader respects them |
| Read one row at a time | 305,969 rows pass through without loading the file into a list first | The same code works on a file ten times larger |
| A written sanity rule | 118 trunks are listed at 0 cm; 19 are above 500 cm, the widest at 3552 cm | A trunk 35 metres across is a typing error, and it would wreck a maximum |
| Report the median beside the mean | American elm: mean 43.7 cm, median 47.0 cm | When the two differ, the data is lopsided, and one number alone misleads |

### The rule is a judgement, so say it

Our rule keeps diameters above 0 and up to 500 cm. It removes 137 rows. It also keeps a 489 cm American elm in Kildonan Park, which is almost certainly another error, and 75 values above 200 cm in all. A stricter rule is defensible; so is a looser one.

What is not defensible is having no rule. We ask every learner to write the rule as a comment, report how many rows it removed, and show the result both with and without it.

### What changes across ages

A twelve year old runs this program with the teacher, changes the species list and explains the output. A teenager writes it from a blank file and adds a neighbourhood filter. An adult rebuilds it with pandas and compares the two approaches line by line.

All three meet the same three ideas: never trust a split on commas, look at the extremes before the averages, and write down every rule that removes data.

Data: [City of Winnipeg Open Data](https://data.winnipeg.ca/), Tree Inventory. Contains information licensed under the Open Government Licence, Winnipeg. The licence allows use "including for commercial purposes". Program, rule and results are ours; the City of Winnipeg does not endorse this page.

## Six ways to extend the Winnipeg program

Our exercises, each with the answer we got on the same file, so a learner can check their work. Change one thing at a time and rerun.

1. Count by location. Count trees by the Location Class column. Answer: Boulevard leads with 210,581, then Park with 89,468.
2. The busiest neighbourhood. Which Neighbourhood value has the most trees? Answer: PULBERRY, with 6,077.
3. Elms only. Filter to American Elm and find the neighbourhood with the most. Answer: NORTH RIVER HEIGHTS, with 1,515.
4. The text that looks empty. Count trees in a named park. Careful: the Park column says "Not In Park" on 211,919 rows rather than being blank. Answer: 94,050 trees are in a named park.
5. Before and after the rule. Print the single widest trunk with no rule, then with ours. Answer: 3552 cm (a Manitoba maple, boxelder) without; 489 cm (an American elm) with.
6. Your own rule. Choose a stricter upper limit, say it in a sentence, and report how many rows it removes. For comparison, 75 values are above 200 cm.

Exercise 4 is the one most learners miss. A program that counts non-empty cells in the Park column returns all 305,969 rows, because "Not In Park" is text. Looking at the actual values before writing a condition is a habit worth more than any library.

## Python taught as thinking, not as copying

Our promise is the same in Canada as everywhere we teach: a learner leaves able to think a problem through and solve it, not to paste an answer from a forum or an AI tool. In a Python class that shows up in three habits.

### Read the error first

A Python traceback names the file, the line and the kind of mistake. Learners read it aloud before touching the code, and most bugs are found right there.

### Predict the output

Before running, the learner writes down what they expect. The gap between prediction and result is where the real lesson is.

### Rebuild from blank

After an example works, the learner closes it and writes it again from an empty file. What they cannot rebuild, they have not learned yet.

### AI assistants and Python learners

Adults in our classes may use an AI assistant to explain an error, then must explain the fix themselves. For younger learners the companies set the limits: OpenAI's terms require a parent's or guardian's permission for anyone under 18, and Anthropic's terms set 18 as the minimum age for Claude.

Children and teens in our Python courses write their own code. An assistant can make a program appear; it cannot make the learner able to write the next one.

### What progress looks like

Not the number of lessons finished, but the size of problem a learner can start alone. In the first month that is a few lines; by the end of a course it is a program like the Winnipeg summary, written from a blank file with its rule stated.

We report that progress in plain words after classes, so a parent or the learner can see it.

## Learning Python in Canada: common questions

### Which version of Python should I install in 2026?

The newest Python 3 from python.org. Python 3.15.0 came out on 9 October 2026 and 3.15.1, an expedited security release, on 21 October 2026. Everything taught in a first year works the same on 3.14. Students practising for the CCC should keep their code compatible with Python 3.8.

### What age can someone start learning Python?

Our Python and AI for Kids course starts at 9, Python for Teens covers 13 to 18, and the Python Masterclass is for adults of any age. Younger children usually start with blocks first.

### Is Python taught in Canadian schools?

No provincial document we read requires Python by name. Ontario math asks for coding from Grade 1, with data analysis in Grade 8 and algebra through code in Grade 9, and BC's Computer Science 11 is built around decomposition. Many schools choose Python for those courses, and others choose Java.

### Can I use Python in the Canadian Computing Competition?

Yes. CEMC allows C, C++, Python 2, Python 3 and Java. It also warns that a perfect score is not always possible in Python or Java, and its grader runs Python 3.8, so contest code should avoid the newest features.

### Are there free Python lessons from a Canadian source?

Yes. CEMC at the University of Waterloo runs Computer Science Circles, free Python tutorials that teach Python 3, and says its resources need no registration or fee. A live class adds a teacher who watches how you think.

### How long does it take to learn Python?

Our courses run eight to twelve months with two live classes a week, depending on age. Most learners write useful small programs within the first two months; writing a program like our Winnipeg tree summary from a blank file takes longer.

### Can adults in Canada learn Python for work?

Yes. Our Python Masterclass is for complete beginners aged 18 and up, and the automation and data analysis courses build on it. We make no job or salary promises; we teach the skill.

### Do learners use ChatGPT or Claude to write Python?

Not to write it for them. Adults may ask an assistant to explain an error and then fix it themselves. OpenAI requires a parent's or guardian's permission under 18, and Anthropic requires Claude users to be 18 or over, so children and teens write their own code.

### What times are Python classes in Canada?

Weekdays or weekends, flexible: choose your batch, or for a very personalised plan choose 1-on-1 at your convenience, weekend mornings or weekdays. Classes are booked in your own province's time zone.

### What projects will I build?

It depends on the course: turtle art and games for children, apps and a capstone for teens, automation and data work for adults. Everyone works with real files, such as the City of Winnipeg tree inventory on this page.
