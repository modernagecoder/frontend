## A French-English coding glossary for Laval children

Our own glossary, for children who learn coding words at school in French and meet them in English in our classes. The Python column shows the keyword a child actually types, which is the same in every country.

**Coding words in French, in English and in Python (our glossary for young learners)**

| In French | In English | In Python | Example a child might say |
|---|---|---|---|
| une boucle | a loop | for or while | &ldquo;The loop runs ten times.&rdquo; |
| si ... sinon | if ... else | if ... else | &ldquo;If the score is 10, the game ends.&rdquo; |
| une variable | a variable | a name such as score | &ldquo;The variable score starts at zero.&rdquo; |
| une fonction | a function | def | &ldquo;I wrote a function to draw a square.&rdquo; |
| une liste | a list | [ ] | &ldquo;My list has five colours.&rdquo; |

### Names in any language

Python lets a child name things in French: pointage = 0 works as well as score = 0. We let younger children choose, so the logic stays theirs.

### Accents in names

Python 3 even accepts accented letters in names. We still suggest plain letters, because some tools and keyboards handle accents badly, which the project below shows.

### Reading aloud

We ask children to read their code aloud. A Laval child may do it half in French, half in English, and that is fine. What matters is that they can explain each line.

## Splash pads, play structures and accents: a Ville de Laval open data project

The Ville de Laval publishes its recreation sites, Sites de loisirs, as open data on Données Québec. The file is in French, column names included. Before any counting, children in our upper classes learn to open it without breaking the accents. All numbers here are ours.

Step 1: the accent trap. The file is saved as UTF-8, where é takes two bytes. Read those bytes with the wrong encoding and every é turns into two strange characters. This four-line demonstration, ours, shows the damage and the repair:

```
word = "Régional"
broken = word.encode("utf-8").decode("latin-1")
print(word, broken)
print(broken.encode("latin-1").decode("utf-8"))
```

It prints Régional RÃ©gional and then Régional again. On some Windows computers Python may default to a different encoding, so we teach children to write encoding="utf-8" every time they open a file.

**Selected facility types for children, by sector: our count from the Ville de Laval Sites de loisirs file, downloaded 22 October 2026 (1,264 rows)**

| Sector (nom_secteur) | Modules de jeux (play structures) | Jeu d&rsquo;eau (splash pad) | Pataugeoire (wading pool) | Butte de glisse (sledding hill) |
|---|---|---|---|---|
| Secteur 1 | 0 | 1 | 2 | 0 |
| Secteur 2 | 16 | 3 | 4 | 0 |
| Secteur 3 | 12 | 1 | 2 | 0 |
| Secteur 4 | 0 | 0 | 3 | 0 |
| Secteur 5 | 0 | 2 | 3 | 0 |
| Secteur 6 | 0 | 2 | 4 | 1 |

This is our counting script. A set holds the four facility types we want, and a dictionary inside a dictionary keeps the count for each sector:

```
import csv

wanted = {"Modules de jeux", "Jeu d'eau", "Pataugeoire", "Butte de glisse"}
by_sector = {}
with open("sites-de-loisirs.csv", encoding="utf-8") as f:
    for row in csv.DictReader(f):
        kind = row["descr_type_plateau"]
        if kind in wanted:
            sector = row["nom_secteur"]
            by_sector.setdefault(sector, {})
            by_sector[sector][kind] = by_sector[sector].get(kind, 0) + 1

for sector in sorted(by_sector):
    print(sector, by_sector[sector])
```

### A label used in two sectors only

All 28 Modules de jeux rows sit in Secteur 2 and Secteur 3. It is very unlikely that four sectors have no play structures at all; more likely they are recorded under another type, or not at all. Students learn to say the file is uneven rather than that the sectors are.

### Reading the column names

nom_secteur is the sector name, descr_type_plateau the facility type and ind_sans_reserv a yes or no flag, O or N, which we read as whether booking is needed. That reading is ours; the file does not define it.

### Blank rows

Twenty-four rows are blank in every column. The script skips them naturally, because a blank type is not in the wanted set, but a careful student counts them and says so.

### What the file cannot tell you

The CSV on Données Québec was last modified in January 2021, so it is a snapshot from several years ago. A splash pad built since then will not appear, and one listed may have changed. Students write the file date beside every result.

## Can an AI tool replace learning to code for a Laval child?

No. It can write code, but it cannot tell your child whether the accents survived.

Ask an AI assistant to count Laval splash pads and it may open the file with the wrong encoding, so that Jeu d&rsquo;eau never matches anything and the answer is zero. It will present that zero calmly. A child who has seen RÃ©gional on their own screen knows to check the text first, and knows why the count was wrong.

So our classes for children teach thinking first: look at the data, understand it, write the code, test it, explain it, in whichever of their languages helps. Children learn how AI works and where it goes wrong, but they do their own reasoning. If ChatGPT is used at home, OpenAI&rsquo;s terms say a parent must agree for any child under 18.

A bilingual child already knows that one idea can wear two sets of words; checking that an answer means what it seems to mean is the same skill. The longer argument is in [whether learning to code still pays off in 2026](/blog/is-coding-worth-learning-2026).
