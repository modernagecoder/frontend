Ans. The short version

Function overloading in ICSE Class 10 Computer Applications means defining two or more methods with the same name in one class, each with a different parameter list: a different number of parameters, different types, or a different order of types. Java decides which one to run from the arguments in the call. The return type alone cannot tell overloaded methods apart. Overloading is how the Class 10 syllabus shows polymorphism, and a Section B question often asks for three versions of one method plus a main method that calls them. Modern Age Coders teaches it live in a Tuesday and Wednesday mini batch in India, or one to one.

Q1. What are the parts of a user-defined method?

User defined methods ICSE: prototype, signature and parameters

A user-defined method is a named block of code written by the programmer, which can take values in through parameters and send one value back with return. Its first line is the prototype; its name with the parameter types is the signature.

Q3. Which overloaded version does Java call?

How Java chooses an overloaded method, and what is not overloading

Java first looks for a version whose parameter types match the arguments exactly. If there is none, it allows a widening conversion, such as char to int or int to double. If two versions fit equally well, the program does not compile.

show(7.0)double 7.0Exact match for double
show('A')int 65No char version, so char widens to int, the nearest type
show(9L)double 9.0A long cannot shrink to int, but it can widen to double
show(5.0f)double 5.0float widens to double

Q4. What are pure and impure methods, and how are values passed?

Pure and impure methods, call by value and call by reference in ICSE

A pure method returns a result that depends only on its parameters and changes nothing outside itself. An impure method changes something outside itself, such as a data member of the object or an array it was given. The syllabus asks for pass by value with programs, and pass by reference as a definition with an example.

PointCall (pass) by valueCall (pass) by reference
What the method receivesA copy of the valueA reference to the same object or array
Types passed this wayPrimitive types: int, double, char, boolean and the restReference types: arrays and objects
Change inside the methodNot seen by the callerChanges to the object's contents are seen by the caller
Example aboveswap(a, b)doubleAll(m)

Strictly, Java copies the reference itself, which is why assigning a new String or a new array to a parameter does not affect the caller. Q5. How is an overloading question marked?

A marking checklist for a 15-mark overloading question

An overloading answer is easy to get mostly right and annoyingly easy to lose marks on. Tick these seven points before moving to the next question. They are the points our teachers mark against in class.

  • Class name exactly as given. If the question says class Compute, it is Compute, not Overload or Main.
  • Method name identical in every version. work, work and work. A version called work2 is not overloading at all.
  • Parameter types and order as stated. If the question says (double x, int n), writing (int n, double x) is a different signature.
  • Return type as stated. void versions print; returning versions return and let main print. Swapping the two changes what the question asked for.
  • Each body correct on its own. Test each version with one small value you can check by hand, as the outputs above were checked.
  • main creates an object and calls every version. Non-static methods need ob.work(...); a version that is never called shows nothing.
  • Variable descriptions. Meaningful names or a short description of each variable, as the Section B instructions ask.
Common slipResult
Two versions differ only in return typeDoes not compile: "already defined"
Method declared inside mainDoes not compile (illegal start of expression): a method cannot be defined inside another method
Non-static method called from main without an objectDoes not compile: non-static method cannot be referenced from a static context
Missing return in a non-void versionDoes not compile: missing return statement
Digit loop changes n, then n is printed in the messagePrints 0 instead of the number the user gave

Questions about methods and overloading

What students ask about function overloading and user-defined methods

What is function overloading in Java ICSE Class 10?

Function overloading means writing two or more methods with the same name in one class, where each has a different parameter list: a different number of parameters, different types, or the same types in a different order. Java picks the version to run by matching the arguments in the call. It is how the Class 10 syllabus shows polymorphism.

Can methods be overloaded by changing only the return type?

No. Java tells methods apart by their signature, which is the name and the parameter types. Two methods with the same name and parameters but different return types have the same signature, so javac reports that the method is already defined. The parameter list must differ.

What is the difference between a method prototype and a method signature?

The prototype is the whole first line of the method: access specifier, return type, name and parameter list, for example public double area(double l, double b). The signature is only the name and the parameter types in order, area(double, double). Overloaded methods must have different signatures.

What is the difference between pure and impure methods?

A pure method returns a value that depends only on its parameters and does not change anything outside itself, so calling it twice with the same arguments gives the same result. An impure method changes something outside itself, such as a data member of the object or the contents of an array passed to it.

What is call by value and call by reference in ICSE?

In call by value the method receives a copy of a primitive value, so changes inside the method do not affect the caller. In call by reference the method receives a reference to an object or array, so changes made to its contents are seen by the caller. The syllabus asks for call by value with programs and call by reference as a definition with an example.

What are actual and formal parameters?

Formal parameters are the variables named in the method header that receive values, such as l and b in area(double l, double b). Actual parameters are the values or variables written in the call, such as 7.5 and 4 in ob.area(7.5, 4). Their number, types and order must match a version of the method.

Which method is called if there is no exact match for the argument?

Java widens the argument to the nearest type that has a version. A char argument goes to an int version before a double one, and a long or float argument goes to a double version. If two versions fit equally well after widening, the call is ambiguous and the program does not compile.

What is the difference between static and non-static methods?

A static method belongs to the class and can be called without creating an object, like Math.sqrt. A non-static method belongs to each object and is called through an object, like ob.work(5). Calling a non-static method directly from the static main method, without an object, does not compile.

How many marks is a function overloading question in ICSE?

An overloading program is usually set as a full Section B question, and each Section B question carries 15 marks; students answer any four of the six. Overloading also appears in Section A as short theory or output questions about which version is called.
