## A quadratic in context: a launched ball

This problem is ours. It touches four Pre-calculus 11 skills in one story: completing the square, reading a vertex, solving a quadratic inequality by sign analysis, and restricting a domain to what makes sense.

The problem. A ball is launched upward from a platform. After t seconds it is h(t) = &minus;5t2 + 20t + 1 metres above the ground. (a) Find the greatest height and when it happens. (b) For how long is the ball at least 16 m up? (c) When does it land, and what domain makes sense for h?

1. Complete the square. Factor &minus;5 from the t terms: &minus;5(t2 &minus; 4t) + 1. Half of &minus;4 is &minus;2, and (&minus;2)2 = 4, so add and subtract 4 inside: &minus;5[(t &minus; 2)2 &minus; 4] + 1 = &minus;5(t &minus; 2)2 + 21.
2. Read the vertex. The vertex is (2, 21). The parabola opens down, so the greatest height is 21 m, at t = 2 s.
3. Set up the inequality. h(t) &ge; 16 means &minus;5t2 + 20t &minus; 15 &ge; 0. Divide by &minus;5 and flip the sign: t2 &minus; 4t + 3 &le; 0, that is (t &minus; 1)(t &minus; 3) &le; 0.
4. Use sign analysis. The zeros 1 and 3 split the line into three intervals. Testing t = 0, 2 and 4 gives positive, negative, positive for (t &minus; 1)(t &minus; 3). The product is at most 0 on the closed interval [1, 3].
5. Answer in context. The ball is at least 16 m up from t = 1 s to t = 3 s, so for 2 seconds.
6. Find the landing time. Solve h(t) = 0 with the quadratic formula: t = 2 &plusmn; &radic;(21/5), so t &asymp; 4.049 or t &asymp; &minus;0.049. Reject the negative root: time starts at launch. The sensible domain is 0 &le; t &le; about 4.049, and the range is 0 &le; h &le; 21.

**Sign analysis for (t &minus; 1)(t &minus; 3) (ours)**

| Interval | Test value | t &minus; 1 | t &minus; 3 | Product |
|---|---|---|---|---|
| t < 1 | 0 | negative | negative | positive |
| 1 < t < 3 | 2 | positive | negative | negative |
| t > 3 | 4 | positive | positive | positive |

### The sign flip

Step 3 divides an inequality by a negative number, and the inequality sign reverses. Forgetting that turns the right answer, [1, 3], into its opposite: t &le; 1 or t &ge; 3, which says the ball is high up before launch and after landing. Reading the answer in context catches it immediately.

That is the inquiry question &ldquo;How do we tell if a mathematical solution is reasonable?&rdquo; in action: the algebra produced an answer, and the story decides whether to trust it.

### Why the domain matters

The formula h(t) is defined for every real t, but the situation is not. The curriculum lists &ldquo;domain and range restrictions from problems in situational contexts&rdquo; for exactly this reason. A negative time or a negative height has no meaning here.

Students who write the restricted domain before solving tend to reject the negative landing time without a second thought, and the marks for interpretation follow.

## A radical equation with an extraneous root, solved twice

The curriculum asks students to solve one-radical equations &ldquo;algebraically and graphically&rdquo; and to identify extraneous roots. This problem of ours does both, and uses a few lines of Python as the graph.

The problem. Solve &radic;(2x + 9) = x + 3. State the domain restriction, find every candidate, and decide which candidates are real solutions.

1. Restrict the domain first. The expression under the root cannot be negative: 2x + 9 &ge; 0, so x &ge; &minus;4.5. A square root is never negative either, so the right side must satisfy x + 3 &ge; 0, that is x &ge; &minus;3.
2. Square both sides. 2x + 9 = (x + 3)2 = x2 + 6x + 9.
3. Solve the quadratic. 0 = x2 + 4x = x(x + 4), so the candidates are x = 0 and x = &minus;4.
4. Check each candidate in the original equation. At x = 0: &radic;9 = 3 and 0 + 3 = 3. Keep it. At x = &minus;4: &radic;1 = 1 but &minus;4 + 3 = &minus;1. Reject it.
5. Explain the rejection. Squaring turned &minus;1 into 1, so the squared equation accepted a value the original never could. The restriction x &ge; &minus;3 from step 1 already ruled out &minus;4.
6. Confirm graphically. The program below compares the two sides at each candidate, then scans the domain for every place the graphs meet.

**Python · check and scan (ours)** (python)
```python
# sqrt(2x + 9) = x + 3: test both candidates, then scan the graph (ours)
import math

def left(x):
    return math.sqrt(2*x + 9)

def right(x):
    return x + 3

for x in [0, -4]:                      # the two candidates from squaring
    print(f"x = {x:>2}: left = {left(x):.1f}, right = {right(x):.1f}",
          "keep" if math.isclose(left(x), right(x)) else "reject")

# Scan the domain x >= -4.5 in steps of 0.5 for places where left - right changes sign
xs = [-4.5 + 0.5*i for i in range(20)]
for x1, x2 in zip(xs, xs[1:]):
    d1, d2 = left(x1) - right(x1), left(x2) - right(x2)
    if d1 == 0:
        print(f"graphs meet exactly at x = {x1}")
    elif d1 * d2 < 0:
        print(f"graphs cross between x = {x1} and x = {x2}")
```

**Output, Python 3.13** (text)
```text
x =  0: left = 3.0, right = 3.0 keep
x = -4: left = 1.0, right = -1.0 reject
graphs meet exactly at x = 0.0
```
One meeting point, at x = 0. The graphs never meet near x = &minus;4, which is what extraneous means.

### Domain and extraneous roots, connected

This is the curriculum&rsquo;s inquiry question about domain and extraneous roots, answered with one example. Squaring is not reversible: it erases signs. Any value that makes the right side negative can sneak through the squared equation, and the domain restriction on the right side names exactly those values.

Students who write both restrictions in step 1 can often reject an extraneous root before they compute it, and they still check, because checking is quicker than losing marks.

### Why the graph helps

Algebra produced two candidates and the graph showed one crossing. When the two disagree, the graph is telling you something real about the original equation. Graphing technology is named in the curriculum&rsquo;s competencies for exploring relationships, and a short program does the same job.

Our scan uses steps of 0.5, which would miss two crossings very close together. For a test, the algebraic check is the proof; the scan is the sanity check.

Twelve questions of our own, not lifted from any classroom, district test or exam. They move through the year in order, powers first and triangles last. Try every one on paper before looking below.

7. Rational equation. Solve x/(x &minus; 3) = 3/(x &minus; 3) + 2.

11. Cosine law. Two sides of a triangle are 8 cm and 11 cm with a 40&deg; angle between them. Find the third side to two decimal places.

## Answers and the reasoning behind them

We confirmed every result by computer algebra (SymPy 1.14) or by running Python. Read the reasoning even when your number matches; it is what the marker looks for.

1. 1/9 and 4x4. The cube root of 27 is 3, squared is 9, and the negative exponent gives the reciprocal. For the second, the cube root of 8 is 2 and squared is 4; x6 to the power 2/3 is x4.
2. 8&radic;2. &radic;50 = 5&radic;2, 3&radic;8 = 6&radic;2 and &radic;18 = 3&radic;2, so 5 + 6 &minus; 3 = 8 of them.
3. 3.3, &radic;11, 2&radic;3, 3&radic;2. Square everything: 10.89, 11, 12 and 18. Squaring keeps the order for positive numbers.
4. (2x + 3)(3x &minus; 5). Find two numbers that multiply to 6 &times; (&minus;15) = &minus;90 and add to &minus;1: &minus;10 and 9. Split and group: 6x2 &minus; 10x + 9x &minus; 15.
5. (5x &minus; 6y)(5x + 6y). Both terms are perfect squares and they are subtracted.
6. 1, with x &ne; &minus;3, &minus;2, 3. Factor: (x &minus; 3)(x + 3)/[(x + 2)(x + 3)] &times; (x + 2)/(x &minus; 3). Everything cancels. The excluded values come from every denominator, including the divisor&rsquo;s numerator x &minus; 3, which becomes a denominator when you flip it.
7. No solution. Multiply by x &minus; 3: x = 3 + 2(x &minus; 3), so x = 3. But 3 is non-permissible, so the only candidate is extraneous.
8. y = 2(x &minus; 3)2 &minus; 5. Vertex (3, &minus;5), axis x = 3, range y &ge; &minus;5, x-intercepts 3 &plusmn; &radic;10/2, about 1.42 and 4.58.
9. (&minus;&infin;, &minus;3) &cup; (5, &infin;). Factor as (x &minus; 5)(x + 3) > 0. Testing an interval each side and between the zeros shows positive outside, negative between. Round brackets, because the inequality is strict.
10. Two triangles. sin B = 11 sin 35&deg; / 7 &asymp; 0.9013, so B &asymp; 64.3&deg; or 115.7&deg;. Both leave room for C: 80.7&deg; with c &asymp; 12.04, or 29.3&deg; with c &asymp; 5.98. The code below does the same check.
11. About 7.08 cm. c2 = 82 + 112 &minus; 2(8)(11) cos 40&deg; = 185 &minus; 176 cos 40&deg; &asymp; 50.18. With a 90&deg; angle the cosine term vanishes and the law becomes Pythagoras, which answers that inquiry question.
12. Reference angle 30&deg;; sin 150&deg; = 1/2, cos 150&deg; = &minus;&radic;3/2. 150&deg; is in the second quadrant, where sine is positive and cosine negative. The values come from the 30-60-90 triangle.

**Answer 10 · Python (ours)** (python)
```python
# The ambiguous case of the sine law: A = 35 degrees, a = 7, b = 11 (ours)
import math

A, a, b = 35, 7, 11
sin_B = b * math.sin(math.radians(A)) / a
print(f"sin B = {sin_B:.4f}")
if sin_B > 1:
    print("No triangle: side a is too short to reach")
else:
    B1 = math.degrees(math.asin(sin_B))      # the acute answer
    for B in (B1, 180 - B1):                 # and its supplement
        C = 180 - A - B
        if C <= 0:
            print(f"B = {B:.1f}: rejected, angles already exceed 180")
            continue
        c = a * math.sin(math.radians(C)) / math.sin(math.radians(A))
        print(f"B = {B:.1f}, C = {C:.1f}, c = {c:.2f}")
```

**Output, Python 3.13** (text)
```text
sin B = 0.9013
B = 64.3, C = 80.7, c = 12.04
B = 115.7, C = 29.3, c = 5.98
```
If sin B came out above 1, there would be no triangle at all; if the supplement left no room for C, there would be only one. The program tests both conditions, as you should by hand.

## How to get through Pre-calculus 11 without falling behind

Because each topic depends on the last, Pre-calculus 11 rewards steady work more than end-of-year cramming. This plan is ours; fit it to the order of your teen&rsquo;s course outline.

1. Run the Grade 10 check in the first two weeks. Factoring, exponent laws, lines. Fix gaps before radicals arrive.
2. Learn the exponent and radical forms as one idea. Practise rewriting each radical as a power and back until it is automatic.
3. Write restrictions before solving. For every radical or rational equation, write the domain restriction or non-permissible values first.
4. Check every candidate root. Substitute into the original equation and write the check down, even when you are sure.
5. Solve each quadratic two ways. One method you choose, one you would not, then compare. The curriculum lists five methods for a reason.
6. Draw a sign chart for every inequality. Zeros, intervals, test values, then interval notation.
7. Sketch every triangle. Label the given parts before deciding between the sine and cosine laws. For the sine law with two sides and a non-included angle, test the supplement every time.
8. Keep a mistakes page. Log each error, then mark it as carelessness or as an idea that needs teaching again.
9. Review one old unit each week. Ten minutes on a past topic stops it fading before the final.
10. Before each unit test, do a mixed set. Our twelve questions above make a reasonable start.

### What is the hardest part of Pre-calculus 11?

In our lessons, students most often struggle with rational expressions, because they need fluent factoring and careful non-permissible values, and with the ambiguous case of the sine law. Both improve quickly once factoring is secure and every triangle is sketched before solving.

### What is an extraneous root?

It is a value that solves a transformed equation but not the original one. In Pre-calculus 11 it appears when squaring both sides of a radical equation or multiplying through a rational equation. Checking every candidate in the original equation finds it.

### Does Pre-calculus 11 use radians?

The BC Pre-calculus 11 curriculum lists angles in standard position in degrees. Radians appear in Pre-calculus 12, whose curriculum lists angles in standard position in both radians and degrees.

### How should my teen keep up through the year?

Fix Grade 10 gaps early, write domain restrictions before solving, check every root, solve each quadratic two ways, draw a sign chart for every inequality, sketch every triangle, keep a mistakes page, and review one old unit every week.
