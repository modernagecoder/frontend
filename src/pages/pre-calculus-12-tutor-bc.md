### Identities by name

The trigonometry content names the identity families a student is expected to use: &ldquo;using identities to reduce complexity in expressions and solve equations (e.g., Pythagorean, quotient, double angle, reciprocal, sum and difference)&rdquo;. That list is a good checklist. A student who can write each family from memory, and say when it helps, is ready for the identity questions on any test.

Notice the verb: identities are used to reduce complexity. They are tools for simplifying and solving, not only statements to prove. Our second worked problem uses a double-angle identity in exactly that way.

### Exponents and logarithms are one topic

Another inquiry question asks: &ldquo;How are the laws of exponents connected to the laws of logarithms?&rdquo; Many students learn the two sets of laws as separate lists to memorise. They are the same facts read in opposite directions. Multiplying powers adds exponents, so the logarithm of a product is the sum of logarithms.

A competency elaboration makes a related connection, naming &ldquo;exponential functions to geometric sequences&rdquo; as an example of linked ideas. A geometric sequence is an exponential function sampled at whole numbers. Students who see that stop treating sequences as a separate unit.

### Defend the answer, not just the method

The estimation competency asks students to &ldquo;be able to defend the reasonableness of an estimated value or a solution to a problem or equation (e.g., the zeros of a graphed polynomial function)&rdquo;. In practice: sketch first, estimate where the zeros or asymptotes should be, then solve, then compare.

The reasoning competency mentions conclusions drawn &ldquo;(e.g., with puzzles, games, and coding)&rdquo;. That is why our first worked problem ends with a short Python check: a program that plugs values into a function and its inverse is a quick, honest test of an algebraic answer.

## A rational function seen as a moved reciprocal, and its inverse

This problem is ours. It takes the curriculum&rsquo;s own inquiry question about y = (ax + b) / (cx + d) and answers it with one function, from rewriting to graph features to the inverse, then checks the inverse with a few lines of Python.

The problem. Let f(x) = (2x + 7) / (x + 3). (a) Write f as a transformation of y = 1/x. (b) State its asymptotes, domain, range and intercepts. (c) Find the inverse function and check it.

1. Divide to expose the parent. 2x + 7 = 2(x + 3) + 1, so f(x) = 2 + 1/(x + 3). That is y = 1/x moved 3 units left and 2 units up. No stretch and no reflection: the coefficient of the fraction is 1.
2. Read the asymptotes from the moves. The parent has asymptotes x = 0 and y = 0, so f has x = &minus;3 and y = 2. Domain: every real number except &minus;3. Range: every real number except 2.
3. Find the intercepts. Setting x = 0 gives f(0) = 7/3. Setting f(x) = 0 means 2x + 7 = 0, so x = &minus;3.5.
4. Swap and solve for the inverse. Write x = 2 + 1/(y + 3). Then x &minus; 2 = 1/(y + 3), so y + 3 = 1/(x &minus; 2), and f&minus;1(x) = 1/(x &minus; 2) &minus; 3.
5. Check with the graph&rsquo;s logic. An inverse reflects the graph in y = x, so its asymptotes swap: x = 2 and y = &minus;3. They do. Its domain is the original range, all reals except 2.
6. Check with numbers. Feed values through f and then through the inverse; each should come back unchanged.

**Python · round-trip check (ours)** (python)
```python
# Check that two functions undo each other, on a table of values (ours)
def f(x):
    return (2*x + 7) / (x + 3)

def f_inv(x):
    return 1 / (x - 2) - 3

for x in [-5, -2, 1, 1.5, 10]:
    y = f(x)
    print(f"x = {x:>5}   f(x) = {y:8.4f}   f_inv(f(x)) = {f_inv(y):8.4f}")
```

**Output, Python 3.13** (text)
```text
x =    -5   f(x) =   1.5000   f_inv(f(x)) =  -5.0000
x =    -2   f(x) =   3.0000   f_inv(f(x)) =  -2.0000
x =     1   f(x) =   2.2500   f_inv(f(x)) =   1.0000
x =   1.5   f(x) =   2.2222   f_inv(f(x)) =   1.5000
x =    10   f(x) =   2.0769   f_inv(f(x)) =  10.0000
```
Every value returns to itself, so the inverse is right for these inputs. The value x = &minus;3 is left out on purpose: f is undefined there.

### Why rewrite first

Students who skip step 1 usually find the vertical asymptote correctly (the denominator is zero at &minus;3) and then guess at the horizontal one. Rewriting as 2 + 1/(x + 3) removes the guessing: as x grows in either direction the fraction shrinks towards 0, so f approaches 2.

The same move works for any (ax + b) / (cx + d) with c not zero: the horizontal asymptote is a/c. Here that is 2/1 = 2, which agrees.

### A hole is not an asymptote

The curriculum lists point discontinuities beside asymptotes, and the difference is a classic test question. If the top and bottom share a factor, the graph has a hole where that factor is zero, not an asymptote. Question 9 in our practice set has one.

This function has no common factor, because 2x + 7 is not a multiple of x + 3, so there is no hole. Checking for a common factor before anything else is a habit worth building.

## A trig equation where dividing loses half the answers

Our second problem is a second-degree trigonometric equation solved with a double-angle identity, on a restricted domain and then over all real numbers, as the curriculum asks. It also shows the single most common mistake in this unit.

The problem. Solve sin 2x = sin x for 0 &le; x < 2&pi;. Then write the general solution over all real numbers.

1. Use the identity to get one angle. sin 2x = 2 sin x cos x, so the equation becomes 2 sin x cos x = sin x.
2. Move everything to one side. 2 sin x cos x &minus; sin x = 0.
3. Factor, do not divide. sin x (2 cos x &minus; 1) = 0. Dividing both sides by sin x instead would throw away every solution where sin x = 0.
4. Solve each factor on the interval. sin x = 0 gives x = 0 and x = &pi;. 2 cos x &minus; 1 = 0 gives cos x = 1/2, so x = &pi;/3 or x = 5&pi;/3.
5. Collect and check. Four solutions: 0, &pi;/3, &pi; and 5&pi;/3. At x = &pi;/3, sin(2&pi;/3) = &radic;3/2 = sin(&pi;/3). A computer algebra check (SymPy solveset) returns the same four values.
6. Extend to all real numbers. x = k&pi;, x = &pi;/3 + 2k&pi; and x = 5&pi;/3 + 2k&pi;, for any integer k.

**Two ways to solve sin 2x = sin x on 0 &le; x < 2&pi; (ours)**

| Approach | Steps after the identity | Solutions found | Verdict |
|---|---|---|---|
| Divide by sin x | 2 cos x = 1 | &pi;/3, 5&pi;/3 | Loses 0 and &pi; |
| Factor out sin x | sin x (2 cos x &minus; 1) = 0 | 0, &pi;/3, &pi;, 5&pi;/3 | Complete |

### Why the general solution has three parts

The sine factor is zero at every multiple of &pi;, so one family covers both 0 and &pi;. The cosine factor repeats every 2&pi;, so &pi;/3 and 5&pi;/3 each start their own family. Writing x = k&pi; for the first, rather than two separate families, is tidier and equally correct.

Testing one value from each family in the original equation, say x = 2&pi; and x = 7&pi;/3, is a fast way to catch a wrong period.

### Radians by default

The curriculum asks students to work with angles &ldquo;in both radians and degrees&rdquo;. In Pre-calculus 12 the answer to a solve-on-an-interval question is usually expected in radians, and Calculus 12 works almost entirely in radians, so it is worth making radians the habit now.

A quick conversion check: &pi;/3 is 60&deg; and 5&pi;/3 is 300&deg;, the two angles on the unit circle whose cosine is one half.

## Twelve Pre-calculus 12 practice questions

All twelve were written by us for this page; none is copied from a BC school, district or exam. They go through the units in the order the curriculum lists them. Try each without notes before you read the answers.

1. Transformations. The point (4, 5) is on the graph of y = f(x). Where does it land on y = &minus;3f(2(x &minus; 1)) + 4?
2. Inverse. Find the inverse of f(x) = (x &minus; 2) / (x + 5).
3. Same base. Solve 4x + 1 = 82x &minus; 1.
4. Different bases. Solve 3x = 5x &minus; 2, exactly and to three decimal places.
5. Logarithm laws. Solve log3 (x + 6) + log3 x = 3, and test each candidate in the original equation.
6. Infinite series. A geometric series has first term 12 and common ratio 3/4. Write its general term and find the sum to infinity.
7. Sigma notation. Evaluate the sum of 5 · 2k &minus; 1 for k = 1 to 6.
8. Factor and remainder theorems. Factor P(x) = x3 &minus; 4x2 + x + 6 fully, then find the remainder when P(x) is divided by x &minus; 4.
9. Rational function. For y = (x2 &minus; 4) / (x2 &minus; x &minus; 2), find every asymptote and every point discontinuity.
10. Trig graph. Describe y = &minus;2 cos(3(x + &pi;/4)) &minus; 1: its amplitude, its period, its horizontal shift and its range.
11. Trig equation. Solve 2 cos2 x &minus; cos x &minus; 1 = 0 for 0 &le; x < 2&pi;.
12. Identity. Show that (1 &minus; cos 2x) / sin 2x = tan x, and state any values of x where the statement is not defined.

## Answers, with the step that matters

We checked every answer with SymPy 1.14, and by direct substitution where a solver can miss roots. The working is what a teacher marks, so each answer shows it.

1. (3, &minus;11). Horizontal changes undo in reverse: solve 2(x &minus; 1) = 4, so x = 3. Vertical changes act directly: &minus;3(5) + 4 = &minus;11.
2. f&minus;1(x) = (5x + 2) / (1 &minus; x). Swap: x = (y &minus; 2)/(y + 5). Then xy + 5x = y &minus; 2, so y(x &minus; 1) = &minus;5x &minus; 2 and y = (5x + 2)/(1 &minus; x).
3. x = 5/4. Write both sides in base 2: 22x + 2 = 26x &minus; 3. Equal bases mean equal exponents: 2x + 2 = 6x &minus; 3.
4. x = 2 ln 5 / (ln 5 &minus; ln 3), about 6.301. Take natural logarithms: x ln 3 = (x &minus; 2) ln 5. Collect the x terms: x(ln 5 &minus; ln 3) = 2 ln 5.
5. x = 3. The product law gives log3 [x(x + 6)] = 3, so x2 + 6x = 27, that is (x + 9)(x &minus; 3) = 0. The candidate &minus;9 fails: neither logarithm accepts a negative input. One genuine root and one extraneous one, the situation the inquiry question asks about.
6. tn = 12(3/4)n &minus; 1; the sum is 48. The ratio is between &minus;1 and 1, so the series converges, and the sum is 12 / (1 &minus; 3/4) = 48.
7. 315. It is a geometric series with first term 5, ratio 2 and six terms: 5(26 &minus; 1)/(2 &minus; 1) = 315.
8. (x + 1)(x &minus; 2)(x &minus; 3); remainder 10. P(&minus;1) = &minus;1 &minus; 4 &minus; 1 + 6 = 0, so x + 1 is a factor; dividing leaves x2 &minus; 5x + 6. The remainder theorem says dividing by x &minus; 4 leaves P(4), which is 64 &minus; 64 + 4 + 6 = 10.
9. A hole at (2, 4/3), a vertical asymptote x = &minus;1, a horizontal asymptote y = 1. Factor: (x &minus; 2)(x + 2) / [(x &minus; 2)(x + 1)]. The shared factor gives a hole at x = 2, where the simplified form (x + 2)/(x + 1) equals 4/3.
10. Amplitude 2, period 2&pi;/3, shifted &pi;/4 to the left, range from &minus;3 to 1. The negative sign reflects the curve but leaves the amplitude at 2. Dividing 2&pi; by 3 gives the period, and the midline &minus;1 plus or minus 2 gives the range.
11. x = 0, 2&pi;/3, 4&pi;/3. Factor as (2 cos x + 1)(cos x &minus; 1) = 0. Then cos x = 1 gives 0, and cos x = &minus;1/2 gives 2&pi;/3 and 4&pi;/3. We confirmed all three by substitution, because one solver run returned only 0: always check a tool&rsquo;s output against the factored form.
12. Use two double-angle identities. 1 &minus; cos 2x = 2 sin2 x and sin 2x = 2 sin x cos x, so the left side is 2 sin2 x / (2 sin x cos x) = sin x / cos x = tan x. It is undefined wherever sin 2x = 0, that is at every multiple of &pi;/2.

Answer 11 has a lesson beyond the math: a computer algebra system is a strong checker but not an infallible one. For more functions practice at a gentler pace, our [precalculus tutoring page](/precalculus-tutoring-online) covers the same families for any curriculum.

## Revising for Pre-calculus 12 unit tests and the final

Pre-calculus 12 assessments are set by the school, so the first job is learning what they look like. The plan below is ours; it assumes unit tests and a final, and you can trim it to your teen&rsquo;s course.

1. Ask for the assessment plan. Unit tests, quizzes, a final exam, calculator rules, and how each piece is weighted.
2. Make a parent-function sheet. One small graph each for absolute value, radical, reciprocal, exponential, logarithmic, sine and cosine, with key points and asymptotes marked.
3. Practise transformations on points, not whole graphs. Take three key points, apply the change, plot them. It is faster and catches order-of-operations errors.
4. Pair every exponential with a logarithm. For each exponential equation solved, solve its logarithmic twin. The two units then reinforce each other.
5. Check every candidate root. After any logarithm, radical or squaring step, substitute each answer into the original equation. Write the check down.
6. Build an identity list from memory weekly. Pythagorean, quotient, reciprocal, double angle, sum and difference: write them out without notes, then use two in a fresh problem.
7. Solve trig equations twice. Once on the interval asked, once over all real numbers, so the general solution is never a surprise.
8. Keep a mistakes page by unit. Note whether each error was a slip or a misunderstanding; misunderstandings get re-taught first.
9. Do a mixed set every week from week three. A final mixes units; practice should too, like our twelve questions above.
10. Seven days out, do one full paper against the clock. After that, revise only from the mistakes page; no new topics.

**A five-week run-up to a Pre-calculus 12 final (ours)**

| Weeks to go | Focus | Ready when |
|---|---|---|
| 5 | Assessment plan; parent-function sheet; transformations and inverses | Any key point moved correctly under four combined changes |
| 4 | Exponentials, logarithms, sequences and series | Same-base and different-base equations solved and checked |
| 3 | Polynomials and rational functions | Holes and asymptotes told apart on three new functions |
| 2 | Trigonometry: radians, unit circle, graphs, equations | Interval and general solutions for three equations |
| 1 | Identities and one paper against the clock | Every error from that paper copied to the mistakes page |

## Pre-calculus 12: common questions

### What is covered in Pre-calculus 12 in BC?

The BC curriculum lists transformations and inverses of functions, exponential functions and equations, geometric sequences and series with sigma notation, logarithms, polynomial and rational functions, and trigonometry in radians and degrees, including the unit circle, graphs, equations and identities.

### Do you grant Pre-calculus 12 credit?

No. Pre-calculus 12 credit is awarded by the school that teaches and evaluates the course. We tutor alongside it and we do not grant provincial credits, so a family that needs the credit takes the course through a secondary school, a district summer session or an online learning school.

### Is Pre-calculus 12 hard?

It is one of the heavier Grade 12 courses because it covers five areas and expects fluent algebra throughout. Most difficulty comes from gaps in factoring, exponent laws or trigonometry from Grade 11. Those gaps can be closed, though nobody can honestly promise a mark in advance.

### Do I need Pre-calculus 12 for UBC?

For many programs, yes. When we read UBC's tool for BC applicants on 22 October 2026, Science, Engineering and Commerce each named Pre-Calculus 12 as a requirement, and Arts required it of students planning an Economics major. Recheck in your application year.

### What comes after Pre-calculus 12?

Calculus 12 is the BC course that builds directly on it, starting from the same parent functions. Some students take Statistics 12 or Foundations of Mathematics 12 as well, depending on their plans.

### Should I take Pre-calculus 12 and Calculus 12 at the same time?

That depends on your school's timetable and prerequisites, which each school sets. If the two do overlap, plan for Pre-calculus topics such as logarithms and trigonometry to be needed in Calculus 12 early, and keep both teachers' outlines side by side.

### What is the hardest unit in Pre-calculus 12?

In our experience it is usually trigonometry: radians, the unit circle, general solutions and identities arrive together. Logarithms come a close second, mostly because of extraneous roots. Both improve quickly with regular mixed practice and a habit of checking every answer.

### How should my teen study for the Pre-calculus 12 final?

Find out the format, build a parent-function sheet, practise transformations on key points, pair exponential and logarithmic equations, check every root, write the identities from memory each week, do a mixed set weekly and sit one timed practice before the final.
