Q2. What happens in a Wednesday lab?

Small batch Java classes ICSE: one Wednesday lab, stage by stage

In a lab, every student writes the same program on their own screen, and the teacher moves from screen to screen reading the code. Here is a 2D array lab followed through its stages, with the program the batch ends up with and the faults that typically appear on different screens along the way.

  1. The task, read aloud by a student

    "Store a 3 by 4 matrix. Print it, with the sum of each row at the end of the row and the sum of each column underneath."

  2. Plan on paper first

    Each student writes, in plain words, how many loops are needed and which variable holds which sum, before opening BlueJ.

  3. Six screens, one program each

    Students share screens; the teacher reads them in turn and asks a question wherever a line is wrong, without typing the fix.

  4. The faults compared

    The teacher puts two different wrong versions side by side so the whole batch sees why each fails. One student's fault is everyone's lesson.

  5. Run, then written up

    Each corrected program is run, and its variable description is written. It becomes the week's lab file assignment.

Fault seen on a screenWhat it printsThe question the teacher asks

Q3. What is a Tuesday sprint like?

ICSE computer batch online: a sample Tuesday Section A sprint, with answers

A sprint is a short timed set in the shapes of Section A, where all 40 marks are compulsory. Everyone writes answers before any are revealed, then the snippets are run in BlueJ on the shared screen. These six are from the same week as the matrix lab; every answer was run in Java 21.

  1. int a[][] = new int[3][5]; What does System.out.println(a.length * a[0].length); print?
    Answer 15. a.length is the number of rows (3) and a[0].length the number of columns in row 0 (5).
  2. With int b[][] = {{2, 4}, {6, 8}, {1, 3}};, what is b[2][0] + b[0][1] * b[1].length?
    Answer 9. Multiplication first: 4 * 2 is 8, then 1 + 8.
  3. Same b. int t = 0; for (int i = 0; i < 3; i++) t += b[i][i % 2]; What is t?
    Answer 11. The columns used are 0, 1, 0, so t is 2 + 8 + 1.
  4. What does System.out.println(Integer.parseInt("12") + Integer.parseInt("3") + "4"); print?
    Answer 154. 12 + 3 is added as int first, then "4" is joined to 15.
  5. What does System.out.println(Character.isUpperCase('b') + " " + Character.toUpperCase('b')); print?
    Answer false B. The test returns a boolean; the conversion returns the char B.
  6. String s = "MATRIX"; What does System.out.println(s.charAt(s.length() / 2) + s.substring(4)); print?
    Answer RIX. 6 / 2 is 3, the character at index 3 is R, and a char joined to a String gives a String.

In the batch, whoever got an item wrong traces it aloud to the group, which is often where the quietest students learn the most. Longer sets of this kind, sorted by trap, are on ICSE Java output questions, and the parse and Character methods on wrapper and library classes.

Q4. Why six students?

Mini batch, one to one or a large group: how ICSE Computer Applications class formats compare

Six is small enough for a teacher to read every screen in a lab and large enough for students to learn from each other's mistakes. One to one gives more attention but no peers; a large group gives peers but almost no attention to any one program.

Why not twenty?

In a lab of twenty, a teacher cannot read twenty programs. The class turns into a demonstration, and the student who is silently stuck stays stuck until the paper.

Why not one?

One to one is excellent for gaps and awkward timetables, and we teach it. But a student alone never sees five other wrong versions of the same program, which is how faults become memorable.

Why online?

Java is written on a screen, so a shared screen shows the teacher exactly what a classroom whiteboard would hide. Nobody loses an evening to travel.

Q5. Is the mini batch right for my child?

ICSE computer mini batch: who it suits, who it does not, and joining mid-year

The mini batch suits an ICSE Class 10 student in India who can make both evenings and is roughly keeping up at school. It does not suit a student abroad, one whose evenings clash, or one with whole chapters missing.

It suits a student who

  • Lives in India and can make Tuesday 5:30 PM and Wednesday 8:00 PM IST most weeks.
  • Follows the school lessons but cannot yet write a program from a blank screen without help.
  • Works better with others around, and pushes harder when a sprint is timed.
  • Needs a steady rhythm more than extra attention: two classes, set work, repeat.

Choose one to one instead if the student

  • Lives outside India. The batch is for families in India; abroad the course is one to one.
  • Cannot make the two evenings because of school, sport or another class.
  • Has missed whole chapters, such as strings or class design, and needs them taught first.
  • Needs a very different pace, much faster or much slower than the syllabus rhythm.

Questions about the mini batch

What families ask about ICSE Computer Applications group classes

How many students are in the ICSE Computer Applications batch?

At most six. The mini batch is kept to six ICSE Class 10 students so that in every Wednesday lab the teacher can read each student's BlueJ screen and ask about the lines that are wrong. A larger group would turn the lab into a demonstration.

What are the ICSE Computer Applications batch timings?

Tuesday at 5:30 PM IST and Wednesday at 8:00 PM IST, every week, live online. Tuesday is a timed Section A sprint; Wednesday is a programs lab in BlueJ. The two classes are on different evenings, so a clash on one night does not cost both.

Are small batch Java classes for ICSE better than one to one?

Neither is better for everyone. A small batch suits a student who is roughly on track and learns from seeing other students' mistakes. One to one suits a student with missing chapters, an awkward timetable or a need for a very different pace. Both use the same teachers and syllabus.

Can students outside India join the ICSE mini batch?

No. The mini batch is taught for families in India. ICSE students in other countries take the same course as personalised one to one, two private classes a week at an after-school hour in their own time zone, with the same sprints, labs and mocks.

Is the ICSE computer batch online or offline?

Fully online and live. Students join from home with a computer that has BlueJ installed and share their screens during labs. There is no centre to travel to, and families from any Indian city join the same batch. The teacher sees each student's code through screen sharing, which is closer than a classroom allows.

What does my child need for the online batch?

A laptop or desktop with BlueJ and Java installed, a steady internet connection, and a quiet room for two evenings a week. A notebook for traces and plans matters too, since students plan programs on paper before typing them, exactly as they must in the exam hall.

Can my child join the batch in the middle of the year?

Yes. After the free demo the teacher notes which chapters the batch has already covered. The student catches up on those through set work or a few one to one sessions while joining the batch for the current chapter. Close to the paper, a late joiner steps straight into the mock and revision term.

Are mock tests part of the group classes?

Yes. From December the batch sits full two-hour mock papers, marked by the teacher and returned with the marks lost and why. Before that, every Tuesday sprint and Wednesday lab is timed practice in the shapes of the paper, so the full mocks feel familiar when they arrive.

Will my child get individual attention in a group class?

Yes, because the group is small. In each lab the teacher reads every student's screen in turn and asks about the exact line that is wrong, and in each sprint every wrong answer is traced aloud. A student who needs more than that can add a few one to one sessions.

How much do ICSE Computer Applications group classes cost?

The monthly fee for the mini batch is shown on this page, next to the personalised one to one fee. Billing is monthly, there is no admission fee, and the first class is a free demo, so you can see the batch at work before paying anything.
