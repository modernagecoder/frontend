Ans. The short version

AI 417 vs IT 402: both are CBSE Class 10 skill subjects worth 100 marks, 50 theory in a two-hour paper and 50 practical, and in the 2025-26 sample papers the theory papers had the same shape. The difference is the content. AI 417 covers the AI project cycle, ethics, modeling, model evaluation with calculations, computer vision and NLP, with Python and Orange in the practical. IT 402 covers LibreOffice Writer, Calc and Base plus workplace health and safety. Pick AI for concepts and coding, IT for software procedures. Q1. What is the difference between AI 417 and IT 402?

AI 417 vs IT 402 side by side, from the 2026-27 CBSE curricula

AI 417 teaches how AI systems are planned, built and judged, with Python as the practical tool; IT 402 teaches advanced use of a word processor, a spreadsheet and a database, framed around the job of a data entry operator. Both start from the same five employability units.

Q2. Is the board paper different?

The theory paper: same shape for AI and IT, different questions

The shape is the same. The 2025-26 sample papers for 417 and 402 both run for two hours, carry 50 marks and offer the same choice in every block, so neither subject has an easier format. What fills the blocks is what differs.

Block in the 2025-26 sample paperPrinted, answeredMarksTypical AI 417 itemTypical IT 402 item

Objective marks match

24 of the 50 theory marks are one-mark items in both papers, 4 from Part A and 20 from Part B, so a student who is careful with objective questions benefits equally in either subject.

AI asks you to calculate

Evaluating Models alone carries 10 marks, and its questions often hand you a confusion matrix and ask for a metric. That is arithmetic, done under time, with a formula you must remember.

IT asks you to recall steps

Many 402 questions name a task and ask which menu, tool or sequence of clicks does it. The work is precise memory of the software, which sticks only when each task is actually done on a computer.

In the 2026 board exams, AI 417, IT 402 and Computer Applications 165 were all set on Friday 27 February, 10:30 AM to 12:30 PM, so a student sits one of them. Q3. Which has the heavier practical?

Practical load in AI 417 and IT 402: where the other 50 marks come from

Both practicals are worth 50 marks, but they are built differently. AI puts more weight on a written file of programs; IT puts more on a hands-on test in the three LibreOffice tools and a longer viva.

What the AI practical feels like

  • Code that must run. Programs such as adding two lists, mean, median and mode with NumPy, a line chart and a scatter chart, reading a CSV file.
  • Two theory-free units. Statistical Data and Advance Python are never in the written paper, only here.
  • A no-code tool too. Orange Data Mining appears for data, and Teachable Machine for image models.
  • Ten viva marks in all, split between the practical and the project.

What the IT practical feels like

  • Base carries the most. Tables, primary keys, queries, forms and reports earn 10 exam marks and run through the project as well.
  • Precision over invention. Styles, a table of contents, track changes, Scenarios, Goal Seek, linked sheets: each has a right sequence.
  • Fifteen problems minimum across the three tools for the portfolio.
  • A ten-mark viva on its own, twice the AI practical viva.

A 15-program file for AI, with what each program prints, is on the 417 project and practical file page, and the code behind it is walked through on Python for CBSE Class 10 AI. CBSE itself lists eight suggested programs; any 15-program list is a teacher's choice, ours included.

Q4. Is AI tougher than IT?

Is AI tougher than IT, and which is the easier skill subject in Class 10?

Neither is easier for everyone, because the two papers test different habits. AI 417 is harder for a student who dislikes formulas and new code; IT 402 is harder for a student who finds long sequences of menu steps dull and hard to keep straight. CBSE does not publish subject-wise averages for skill subjects, so any claim that one "scores more" is opinion.

Q5. Which is better for my child?

Which is better, AI or IT, in Class 10: a decision checklist

The better subject is the one your child will study steadily for two years, because Classes 9 and 10 form one composite course and CBSE asks students to take in Class 9 only the subjects they will continue in Class 10. Tick the statements that are true, then count.

Lean towards AI 417 if

  • They enjoy a short calculation and want to know why an answer is right.
  • They are curious about how apps recognise faces, voices or spam.
  • They would like to start Python now rather than in Class 11.
  • They are thinking of Computer Science, Informatics Practices or AI in Class 11.
  • They can write a clear paragraph on an ethical question.
  • The school runs a working Python lab, or you can arrange practice at home.

Lean towards IT 402 if

  • They like neat documents, tidy spreadsheets and getting a task exactly right.
  • They prefer learning by doing in software over reading about ideas.
  • Formulas and code make them anxious this year.
  • They want office and database skills they can use straight away.
  • The school's lab has LibreOffice set up and an IT teacher with spare lab time.
  • They would rather revise four units than five.

  1. Ask the school what it actually offers

    Not every school runs both. Ask which skill subjects have a teacher and a lab this session, and how the timetable fits.

  2. Look at one chapter of each together

    Open a unit of each curriculum with your child for ten minutes. Their reaction is better evidence than any ranking.

  3. Decide in Class 9 and stay

    Switching in Class 10 means catching up a year of a new subject, practicals included, so make the call early.

  4. Plan the practical from day one

    Half the marks in either subject are practical. Start the file or portfolio in the first term, not in January.

About 2028: press reports in October 2026 describe a changed Class 10 scheme for students who are in Class 9 in 2026-27 and sit the board in 2028, with skill subjects such as AI and IT kept as options. That is reported, not yet notified subject by subject, so we promise nothing about it; the school's circular is the document to go by.

Q6. What do they lead to, and how is AI taught here?

Where AI 417 and IT 402 lead after Class 10, and how we teach 417

Each subject has a direct Class 11 and 12 continuation in CBSE: Artificial Intelligence (843) after 417, Information Technology (802) after 402. Neither is a formal entry rule for Computer Science or Informatics Practices; schools set their own criteria for those.

After AI 417

Python habits, a feel for data and models, and words like precision, recall and bias that turn up again in Class 11 AI, Computer Science and Informatics Practices.

After IT 402

Confident use of documents, spreadsheets and databases, the base for Class 11 IT and for any course where data is kept in tables and reports.

For both

The Part A employability units, the habit of a practical file, and a viva. A Class 10 skill subject does not lock any stream in Class 11.

Questions about AI 417 and IT 402

What parents and students ask about AI 417 vs IT 402

Which is better, AI or IT, in Class 10?

Neither is better in general. AI 417 suits a student who likes concepts, short calculations and learning Python; IT 402 suits one who prefers precise, hands-on work in a word processor, spreadsheet and database. Both carry 100 marks, split 50 theory and 50 practical, and both continue into Class 11 and 12 skill subjects. Choose by your child's habits and by what the school actually teaches well.

Is AI tougher than IT in CBSE Class 10?

AI is tougher for students who dislike formulas or code, because its theory paper includes evaluation numericals and its practical needs Python programs that run. IT is tougher for students who struggle to remember exact software steps, because many of its questions ask which menu or tool does a task. The papers themselves have the same shape and the same marks.

Which is the easier skill subject in Class 10?

There is no official answer, and CBSE does not publish subject-wise averages for skill subjects. A student comfortable with computers but not with maths often finds IT easier; a student who enjoys logic and wants to code often finds AI easier. The practical is 50 marks in both, so steady practical work matters more than which subject you pick.

What is the syllabus difference between 417 and 402?

Both share Part A employability skills for 10 marks. In Part B, AI 417 covers the AI project cycle and ethics, modeling, evaluating models, computer vision and NLP in theory, with statistical data and Python in the practical. IT 402 covers LibreOffice Writer, Calc and Base, plus a unit on keeping a workplace healthy, safe and secure.

Does AI 417 need coding?

Yes, at a basic level. The 2026-27 curriculum includes an Advance Python unit, assessed only in the practical, and the practical file needs at least 15 programs, such as finding the mean, median and mode with NumPy, drawing charts with Matplotlib and reading a CSV file. No coding is asked in the written theory paper beyond reading simple output.

Can I take both AI 417 and IT 402?

In practice, a student takes one. In the 2026 board exams, AI 417, IT 402 and Computer Applications 165 were set in the same slot on the same day, so they could not all be sat. The 2026-27 scheme also says only one of 165 and 402 can be offered. Ask the school which skill subjects it runs before deciding.

Can I change from IT to AI in Class 10?

CBSE treats Classes 9 and 10 as one composite course and asks students to take in Class 9 only the subjects they will continue in Class 10. Some schools allow a change at the start of Class 10, but the student then has a year of new theory and a full practical to make up. Ask the school first, and plan catch-up classes if it agrees.

Which is better for a future in computer science?

AI 417 gives a head start in Python and in ideas that reappear in Class 11 Computer Science, Informatics Practices and AI. IT 402 gives strong database and spreadsheet skills. Neither is a formal requirement for Class 11 Computer Science; schools set their own admission criteria, often based on overall and maths marks.

Which software is used in IT 402 and in AI 417?

IT 402 uses LibreOffice Writer, Calc and Base throughout, including styles, Goal Seek, Scenarios, macros, queries, forms and reports. AI 417 names Python in Jupyter Notebook with NumPy and Matplotlib, CSV files, the no-code Orange Data Mining tool and Google's Teachable Machine, which runs in a browser.

Do you teach IT 402 as well?

No. Our Class 10 board batch is for AI 417 only, on Mondays and Wednesdays at 9:00 PM IST, with personalised one to one at a time the family chooses. If the checklist on this page points to IT, we would rather say so plainly than suggest a subject your child is less suited to.
