Ans. The short version

The ICSE Class 10 Computer Applications internal assessment for 2027 is worth 100 marks, the same as the written paper. CISCE's syllabus asks for a minimum of twenty laboratory assignments in Java across the year, marked 50 by the subject teacher and 50 by an external examiner, each out of 50 on four criteria: class design (10), variable description (10), coding and documentation (10) and execution or output (20). The syllabus does not prescribe a separate project; many schools simply call the lab file the computer project. Modern Age Coders builds that file one documented program a week in a live BlueJ lab and rehearses the examiner session, in a Tuesday 5:30 PM and Wednesday 8 PM IST mini batch or personalised one to one.

Q1. What does CISCE actually ask for?

Twenty lab assignments, two examiners and four criteria

CISCE's 2027 syllabus pairs the written paper with internal assessment of equal weight and spells out how that half is marked. Most families have never read it, which is why the same avoidable marks are lost every year.

What it is made of

Students complete a minimum of twenty laboratory assignments during the year: programs that need design, implementation and testing and that use the concepts taught in class. The teacher keeps a record of every assignment and evaluates them at the end of the year, and each must carry an appropriate list of variables, comment statements and its output. Fifty marks come from the subject teacher and fifty from an external examiner.

The syllabus does not prescribe a separate project. Many schools call the finished lab file the computer project, and some set one larger program of their own, so always follow your school's instructions and dates on top of what follows here.

Who the external examiner is

The external examiner is nominated by the head of the school and may be a teacher from the same school who does not teach the subject to that class. That is why understanding matters more than volume: an examiner who asks why a loop stops where it does, or why a field is private, is testing whether the work on the page is really the student's.

A file copied from a guide book can look complete and still fall apart in five minutes of questions. A file written by the student, one program a week, survives any question because every line has a reason the student remembers. The written paper's pattern and dates are on the exam date and paper pattern page.

Execution carries twice the weight of each other criterion, so a program that fails on an awkward input costs more than any amount of untidy formatting. The other thirty marks reward exactly what the written paper's Section B also asks for, which is why a well-kept lab file is the best Section B revision there is.

Twenty-plus programs that cover the syllabus, not twenty of the same kind

Every program documented

Each entry carries the question, the program with comments, a variable description listing every variable with its type and purpose, and the actual output from BlueJ. Those are three of the four marking criteria, secured by a checklist rather than by luck.

Every program written in class

In our Wednesday lab, the program is written by the student in BlueJ with the teacher watching, run, corrected and documented the same evening. Nothing enters the file that the student did not write, which is exactly what the external examiner probes.

One a week, not twenty in January

At one program a week from the start of the session, the file passes twenty before winter. Students who start in December write the file instead of revising for the paper, and usually do both badly.

Q3. What does a lab entry look like?

One lab program, entered carelessly and entered well

The difference is not cleverness. It is a checklist applied to every entry: question copied, program tested on an awkward input, comments added, variable description written, real output pasted. Q4. What if the school asks for a project?

Eight bigger programs that sit squarely on the ICSE syllabus

Some schools ask for one larger program on top of the twenty assignments, and strong students often add one anyway. A good one uses classes, constructors, methods, arrays and strings in a single program that solves a small real problem: ambitious enough to show skill, small enough to explain fully.

School library manager

A Book class with private fields and a constructor, an array of books, search by title or author, and issue and return methods that update availability. Covers classes, encapsulation, arrays and string comparison.

Report card generator

A double dimensional array of marks for several students and subjects, totals and averages by row and column, grades from a slab, and the topper found by search. Covers 2D arrays, loops and methods.

Canteen billing system

A switch-driven menu, an Item class, quantity input, a running bill with a discount slab, and a printed receipt. Covers constructors, menus, conditional logic and formatted output.

Text analyser

Input a sentence and report the word count, longest word, vowel frequency, words starting with a capital and the sentence with words reversed. Covers String methods, Character wrapper methods and loops.

Number explorer

A menu that checks a number against several special-number definitions, palindrome, Armstrong, perfect, prime, Niven, using one method per check and overloading where it fits. Covers methods, loops and modular design.

Simple bank account

An Account class with a private balance, a parameterised constructor, deposit and withdraw methods that refuse invalid amounts, and a short transaction menu. Covers encapsulation and object state.

Quiz program

Arrays of questions, options and answers, a score that updates as the user answers, and a final grade with feedback. Covers parallel arrays, input handling and conditional logic.

Sorting visualiser

Input a list, then show bubble sort and selection sort pass by pass, counting comparisons and swaps for each. Covers arrays and both sort techniques in the syllabus, and gives the examiner plenty to ask about.

Whatever your school asks for in format, the qualities that score map straight onto CISCE's four criteria: sensible class design, clear coding with each class and method documented, a complete variable description, and output that is correct on every sample input. In our classes, a larger program, where the school wants one, is chosen by the end of the first term, built in stages alongside the lab file and reviewed monthly, so it never becomes a January emergency.

Q5. How do you prepare for the external examiner?

A rehearsal with a teacher your child has not met

Since the external examiner may be a teacher who has never taught your child, the rehearsal uses one too. Answering questions about your own code is a skill, and it can be practised.

  1. File walk-through

    The student opens the file and walks the rehearsal examiner through three programs of the examiner's choosing, explaining the logic aloud without reading the code line by line.

  2. Why questions

    Why is this field private? Why a while loop here and not a for loop? What must be true of the array before binary search works? Each question targets a syllabus concept the program uses.

  3. Change one thing

    The examiner asks for a small change, count only vowels, sort in descending order, refuse negative deposits, and the student makes it live in BlueJ. Students who wrote their own programs find this easy.

  4. The design conversation

    For the biggest program in the file: what problem does it solve, which classes did you design and why, what would you add with more time? Students practise answering in two or three clear sentences, not a speech.

  5. Feedback and a second run

    Weak answers are noted, revisited in the next class, and the rehearsal is repeated briefly before the school's assessment date. Doubts are taken live throughout.

Questions about the internal assessment

What families ask about the ICSE Computer Applications lab file and internal assessment

How many marks is the ICSE Computer Applications internal assessment?

One hundred marks, the same weight as the two-hour written paper. CISCE's 2027 syllabus asks for at least twenty laboratory assignments during the year, with fifty marks from the subject teacher and fifty from an external examiner, each marking out of fifty on class design, variable description, coding and documentation, and execution or output.

How are the lab assignments marked?

On four criteria, each graded excellent, good, fair or poor: class design out of 10, variable description out of 10, coding and documentation out of 10, and execution or output out of 20, making 50. The subject teacher and the external examiner each award marks out of 50 this way, for 100 in all.

Is a project compulsory in ICSE Class 10 Computer Applications?

Not in CISCE's 2027 syllabus, which asks for a minimum of twenty laboratory assignments and does not prescribe a separate project. Many schools call the finished lab file the computer project, and some set one larger program of their own, so follow your school's instructions. Good larger programs include a library manager, a report card with a 2D array, a billing system or a text analyser.

How many programs should the lab file have?

At least twenty, and a strong file usually has a few more so it can cover every syllabus unit: input and computation, loops and special numbers, menus, classes and constructors, methods and overloading, library classes, arrays and strings. Each program should have comments, a variable description and its real output.

Who is the external examiner?

Under CISCE's rules, the external examiner is nominated by the head of the school and may be a teacher from the same school who does not teach the subject to that class. The four CISCE criteria do not include a viva, but many examiners run programs from the file and ask the student to explain choices such as access specifiers, loop types or search methods, so students should be ready to.

Can you write the lab file for my child?

No, and it would not help: the external examiner's questions are designed to find out whether the student understands the work. Your child writes every program in class with guidance, documents it and rehearses explaining it, so the work and the marks are genuinely theirs.

When should the lab file be finished?

Before your school's internal assessment dates, which the school announces. We aim for the file to pass twenty programs before winter by writing one a week from the start of the session, so January can go to the written paper.

We are late. Can the lab file still be done?

Usually, yes. With personalised one to one, a teacher can work through the missing programs in order of syllabus coverage so the file still spans every unit. The free demo is the quickest way to get an honest plan for your child's deadline.

Do ICSE students abroad have the same internal assessment?

Yes. ICSE schools outside India follow the CISCE scheme, so the internal assessment works the same way. CISCE lists ICSE schools abroad in the UAE, Singapore, Indonesia and Thailand; outside India we teach the course personalised one to one, at a time set in the local time zone of the family.

Is internal assessment help charged separately?
