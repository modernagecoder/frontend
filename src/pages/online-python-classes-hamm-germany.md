## What happens in a live online Python class?

One lesson lasts sixty minutes. The learner sits at their own computer, the mentor joins by video, and both look at the same code. Here is how the hour usually goes.

1. **Minutes 0 to 5, warm-up.** The mentor asks what the learner remembers from last time and shows one line of last week's code with a small change. What will it print now?
2. **Minutes 5 to 20, one new idea.** A loop, a dictionary, a class. The mentor explains it in plain English, then writes a tiny example while the learner watches and predicts.
3. **Minutes 20 to 45, the learner drives.** The learner shares their screen and types. The mentor does not take the keyboard; they ask questions, point to the line that is wrong, and wait.
4. **Minutes 45 to 55, break it on purpose.** The learner changes one thing to make the program fail, reads the error message aloud, and fixes it.
5. **Minutes 55 to 60, what next.** A short task for the week, small enough for twenty minutes. Parents of younger learners get a note on what was built.

## Do Hamm's running route signs match the routes? A Python class finds out

Stadt Hamm publishes its signposted running routes as open data. Our teenagers and adults use them for their first object-oriented program: a Route type that carries its own data and its own methods.

### The data

The dataset Laufstrecken Stadt Hamm contains, in the city's words, the running routes signposted by Stadt Hamm, including the marathon and half-marathon course. It is listed on GovData through Open.NRW under the Datenlizenz Deutschland Namensnennung 2.0, which allows reuse with credit. We downloaded the 20 routes from the city's map service on 3 November 2026.

Each route has a name such as "10 km Rundweg Pelkum", a type such as "8-10 km Rundweg", and a measured length in kilometres. We keep those three fields in a file called hamm_routes.csv.

### The question

Fourteen route names promise a distance: 10 km, 6 km, 5 km or 2,5 km. Is the measured route really that long? A runner training for a time cares, and so does anyone who has wondered why their watch disagrees with a sign.

Rather than juggling three separate lists, the program makes one object per route. Each object knows its name, its type and its length, and later learns to answer questions about itself.

**Step 1: a Route class and twenty objects** (Python)
```python
import csv

class Route:
    def __init__(self, name, kind, km):
        self.name = name
        self.kind = kind
        self.km = float(km)

    def __repr__(self):
        return f"{self.name} ({self.km} km)"

routes = []
with open("hamm_routes.csv", encoding="utf-8") as file:
    for line in csv.DictReader(file):
        routes.append(Route(line["name"], line["type"], line["km"]))

print("Routes:", len(routes))
print("Longest:", max(routes, key=lambda r: r.km))
print("Shortest:", min(routes, key=lambda r: r.km))
```
It prints Routes: 20, Longest: Rund um Hamm-Mitte (42.19 km) and Shortest: Winterlaufstrecke Maximilianpark (1.0 km).

The __repr__ method is why print shows a readable name and length instead of a memory address. Now we add two methods: one reads the promised distance out of the name, taking care of the German decimal comma in "2,5", and one works out the difference in percent.

**Step 2: teach every route two new methods** (Python)
```python
def signed_km(self):
    first = self.name.split()[0]           # "10", "2,5", or a word
    if self.name.split()[1:2] == ["km"]:
        return float(first.replace(",", "."))
    return None

def off_by(self):
    nominal = self.signed_km()
    if nominal is None:
        return None
    return round(100 * (self.km - nominal) / nominal, 1)

Route.signed_km = signed_km
Route.off_by = off_by

named = [r for r in routes if r.signed_km() is not None]
print("Routes with a distance in the name:", len(named))
for r in sorted(named, key=lambda r: r.off_by()):
    if abs(r.off_by()) >= 2:
        print(f"  {r.name}: measured {r.km} km, {r.off_by()} %")
```
Run after Step 1. It prints Routes with a distance in the name: 14, then five routes from 6 km Rundweg Heessen: measured 5.7 km, -5.0 % to 5 km Rundweg Herringen: measured 5.17 km, 3.4 %.

The interesting line is Route.signed_km = signed_km. The method is attached to the class, not to any single route, and all twenty objects made in Step 1 can use it at once. That is what a class is for: the data lives in each object, the behaviour lives in one place.

**Step 3: a method that plans a race** (Python)
```python
def finish(self, pace):                    # pace in minutes per km
    minutes = round(self.km * pace)
    return f"{minutes // 60}:{minutes % 60:02d}"

Route.finish = finish

for name in ["Halbmarathon", "Rund um Hamm-Mitte"]:
    r = next(r for r in routes if r.name == name)
    print(name, "at 6:00 per km:", r.finish(6), " at 5:15 per km:", r.finish(5.25))
```
Run after Steps 1 and 2. It prints Halbmarathon at 6:00 per km: 2:07 at 5:15 per km: 1:51 and Rund um Hamm-Mitte at 6:00 per km: 4:13 at 5:15 per km: 3:41.

1. **Ages 9 to 12.** Make a Route with just a name and a length, then add a method that says "short" or "long".
2. **Teenagers.** Add a method laps_for(target_km) that says how many laps of a Winterlaufstrecke make 10 km.
3. **Adults.** Turn the two attached functions into proper methods inside the class, and write a test for signed_km that includes "2,5 km".
4. **Everyone.** Explain in one sentence why the marathon route has no number in its name, and what signed_km returns for it.
