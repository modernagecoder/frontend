Q1. What happens inside one class?

What does online ICSE computer tuition from Lucknow actually look like?

A teacher, a small group and BlueJ on a shared screen. Every student writes code in every class, and nothing is accepted until it has been run.

Parents who have only seen recorded lectures are often surprised by a live class. Nobody watches a video. The teacher talks to each student by name, asks them to share their screen, and reads their code as they type. Here is how a Wednesday program class unfolds, stage by stage.

  1. Last week's loose end

    The class opens with whatever went wrong in the home practice, solved on screen. If three students hit the same error, it becomes the first lesson.

  2. The question, read like an examiner

    The Section B question is read aloud and underlined: what must be input, what must be printed, which word decides the method. Students write a five-line plan before touching the keyboard.

  3. Code, typed by the student

    Each student types their own version in BlueJ. The teacher moves from screen to screen, asking why a loop starts where it does rather than fixing it for them.

  4. Run it, then try to break it

    Programs are run with the given data and then with input chosen to expose mistakes: a tie, a missing value, an unexpected case.

  5. Marked against the scheme

    The finished answer is marked the way a board examiner would, including the variable description, so each student knows which marks they kept and which they gave away.

That is the whole difference from sitting in a large room with a whiteboard: no student can stay invisible for a term. More on the format is on ICSE Class 10 BlueJ Java coaching.

Q2. What does a Section B array program look like?

An arrays program from the Lucknow batch: sort a rank list, then search it

Sorting and searching on single dimensional arrays is one of the most dependable Section B shapes. This original program keeps names and marks in two parallel arrays, sorts them with selection sort, prints a rank list, and finds one student by name.

The question. Accept the names and marks of six students into two arrays. Using selection sort, arrange them in descending order of marks, moving each name with its mark. Print the rank list. Then accept a name and print that student's rank and marks, ignoring case, or a message if the name is not present.

Selection sort, pass by pass

Pass (i)Largest from i onwardsSwapMarks after the pass
startnonenone71, 88, 64, 92, 88, 79
0Ira 92 at index 3index 0 with 392, 88, 64, 71, 88, 79
1Zoya 88 at index 1with itself92, 88, 64, 71, 88, 79
2Ved 88 at index 4index 2 with 492, 88, 88, 71, 64, 79
3Tara 79 at index 5index 3 with 592, 88, 88, 79, 64, 71
4Aman 71 at index 5index 4 with 592, 88, 88, 79, 71, 64

Why examiners like this question, and where students slip

  • Swapping only one array. Sorting the marks but not the names leaves every name attached to the wrong mark. The output looks plausible and is entirely wrong.
  • Outer loop to n - 1. Five passes sort six items; the last one is already in place. Running to 6 does no harm but shows the student does not know why.
  • Comparing Strings with ==. The search must use equalsIgnoreCase, or "kabir" will never match "Kabir".
  • Forgetting the not-found case. The flag value -1 is what lets the program report a missing name honestly.
  • Binary search on unsorted data. Binary search needs the array sorted by the key being searched. Here the list is sorted by marks, not names, so linear search is the right choice.

Bubble sort, binary search and more variations are on ICSE Class 10 sorting and searching programs.

Q4. How is the lab file handled?

Preparing for the internal assessment: the school's assignments, the student's work, our coaching

The school chooses the assignments and holds the assessment. The student writes every program. Our part is the preparation in between, above all for the moment the external examiner asks the student to run and explain their work.

ICSE Computer Applications gives the internal assessment the same 100 marks as the written paper. It rests on at least twenty laboratory assignments done across the year. The subject teacher awards 50 marks and an external examiner awards the other 50, each using the same four headings: execution or output is the heaviest at 20, then class design, variable description, and coding and documentation at 10 each.

Execution marks are the easiest to lose by surprise. A program that worked at home can fail in front of an examiner on input nobody tried. So we teach students to write a small test plan for each of their own assignments. Here is what one looks like for the RankList program; the student makes their own for the school's questions.

Alongside the test plan, students practise explaining their class design and variable choices in a minute or two, which is what an examiner tends to ask. What we will not do is write any part of an assignment for submission, or rewrite the school's question. Lucknow questions

What Lucknow families ask about ICSE computer tuition

Is there an ICSE computer tuition centre of yours in Lucknow?

No. Modern Age Coders runs no centre in Lucknow and sends no tutors to homes there. Classes are entirely live online: a teacher with six students at most, each sharing their BlueJ screen. If a teacher in the room is essential for your child, a local tutor is the honest recommendation.

What are the class timings for Lucknow students?

The group meets on Tuesday at 5:30 PM and Wednesday at 8:00 PM, Indian Standard Time, which is Lucknow time. Tuesday covers concepts and short Section A questions; Wednesday is one long Section B program. Private classes can be booked at other hours.

How do I find a good computer applications tutor in Lucknow?

Ask four things. Does the student write a full program every week? Is every program run, not only checked on paper? Is the variable description marked? Will the tutor help with the school lab assignments without writing them? Any tutor, including us, should answer yes to all four.

Do you teach the UP Board computer syllabus?

No. These classes cover only the CISCE ICSE Class 10 Computer Applications syllabus for the 2027 examination, in Java with BlueJ. UP Board and CBSE students study different syllabi, so this class would not match their exams. A sibling on another board can ask us on WhatsApp for the course that fits.

Which sorting and searching methods are in the ICSE Class 10 syllabus?

Students are expected to know bubble sort and selection sort, and linear search and binary search, on single dimensional arrays. Binary search only works on an array already sorted by the value being searched, which is a common question in its own right.

How do you help with ICSE computer lab assignments?

We teach the concept behind each school question with a different example, help the student build a test plan for their own program, and rehearse explaining it as an external examiner might ask. The school sets and marks the assignments, and the student writes every line.

What is the fee for online ICSE computer tuition?

The monthly fees for the group and for private classes are shown on this page in your currency. Payment is monthly, there is no joining fee, and the first class is a free demo so you can see the teaching first.

Is online tuition enough for ICSE Computer Applications?

For most students, yes, because Computer Applications is practised on a computer. In a live class the teacher sees each student type and run code and corrects errors as they appear. A student who cannot focus on a screen may still do better with a tutor in person.

When should a Class 10 student start tuition?

The earlier the better for the lab file, which is built across the whole year. Starting at the beginning of Class 10 leaves room for every unit and full papers. A later start still works, with a plan that puts the highest-mark program families first.

What does the free demo involve?

A live class in which your child writes and runs a small Java program, explains it, and gets direct feedback. Afterwards you get a plain view of strengths and gaps, and a recommendation between the group and private classes. Nothing is charged for the demo and there is no obligation to continue.
