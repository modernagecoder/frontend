## How many public schools are in Campbelltown, and which Campbelltown?

The NSW public schools master dataset, extracted on 2 October 2026, questioned five ways by an AI agent and checked by hand.

**One question, five readings (our code, 10 October 2026)**

| What the agent matched | Rows | What that really counts |
|---|---|---|
| Town typed exactly as Campbelltown | 1 | A spelling, not a place |
| School name contains Campbelltown | 4 | Schools named after the town |
| Town field, spaces and capitals cleaned | 10 | Schools in the suburb, all postcode 2560 |
| Council area is Campbelltown (NSW) | 53 | Schools across the whole city |
| Campbelltown anywhere in the row | 111 | Mostly rows naming a regional office |

### 1. The words are not the key

Campbelltown is a suburb, a council area, part of four school names and a regional office location. A text search cannot tell these apart; only the column it searches can.

### 2. The other Campbelltown

South Australia has a Campbelltown council of its own, with 54,800 residents in 2021. The ABS keeps them apart with codes, LGA11500 for NSW and LGA40910 for SA, and with a state in brackets after each name.

### 3. Qualified keys

Matching on a code, or on name plus state, removes the ambiguity entirely. A learner who tells the agent to use LGA11500 gets 53 every time, whatever the spelling.

### Why the agent cannot guess

Each of the five answers is correct for some reading of the question. An agent that picks one without saying so will sound confident and may still be wrong for the person asking. The fix is not a smarter agent; it is a question that names the column, the cleaning rule and the place code. Once those are written down, the 53 schools break down into 33 primary, 12 secondary and 8 for specific purposes, and the answer stops moving.

Within the council area the oldest school on record is Minto Public School, with a first teacher in 1867, followed by Campbelltown Public School in 1876; the newest is Denham Court Public School, whose first teacher is dated 18 October 2021. The records are the department's; the matching and counts are ours.

## Making a place name into a reliable key

Practised on Campbelltown, then used on customer addresses, product names and any data where two things share a name.

**Steps that fixed the Campbelltown count**

| Step | What to tell the agent | Effect here |
|---|---|---|
| Name the column | Count by the LGA field, not the whole row | 111 becomes 53 |
| Use a code | Match ABS code LGA11500, not the word | SA Campbelltown can never leak in |
| State the cleaning | Strip spaces and ignore case before comparing | 1 becomes 10 for the suburb |
| Ask for the definition back | Have the agent restate what it counted | Mismatched readings show up before the number |

Asking an agent to restate its interpretation is the single most useful habit here. If it says it counted rows mentioning Campbelltown, the learner knows at once that 111 is not the answer they wanted.

### Secondary students

Ask an agent the school question three ways, record each answer and explain which reading it used.

### University students

Design keys for a table that mixes NSW and SA places, and write tests that fail if names collide.

### Adults at work

Before an agent merges two lists, agree the key in writing; a shared name is never enough.

## If an agent can search the data, why learn to define the question?

Because the agent will answer whichever question it thinks you asked.

A coding agent given the schools file and the word Campbelltown will produce a number quickly, and that number will match one of five readings. Without a stated column, cleaning rule and place code, nobody can tell which, including the agent.

Our Campbelltown learners write the definitions first, then let the agent do the work, then ask it to restate what it counted. The agent supplies speed; the learner supplies the meaning.
