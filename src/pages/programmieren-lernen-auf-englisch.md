## Wo braucht man beim Programmieren Englisch?

An mehr Stellen, als man denkt, und an einer Stelle unausweichlich: bei den Meldungen des Computers. Die Tabelle ist unsere Übersicht; die Belege stehen darunter.

**Wo Lernende beim Programmieren auf Englisch treffen (unsere Übersicht)**

| Stelle | Gibt es das auf Deutsch? | Was das für Lernende heißt |
|---|---|---|
| Befehle im Code (if, for, return, class) | Nein | Wer die Wörter versteht, ahnt, was eine Zeile tut |
| Fehlermeldungen von Python und Java | Nein, auch bei deutscher Spracheinstellung | Die wichtigste Lesefähigkeit beim Programmieren |
| Offizielle Python-Dokumentation | Teilweise, es gibt eine deutsche Übersetzung | Neues erscheint zuerst auf Englisch |
| Namen von Funktionen in Bibliotheken | Nein | split, append, sort lesen sich wie Anweisungen |
| Fragen und Antworten in Foren | Selten | Die meisten Lösungen stehen auf Englisch im Netz |
| Wettbewerbe wie der BWKI | Ja, beides erlaubt | Projekte dürfen auf Deutsch oder Englisch eingereicht werden |

Belege: Die englische Fehlermeldung haben wir mit Python 3.14 auch unter deutscher Spracheinstellung (LANG=de_DE.UTF-8) erzeugt. Die deutsche Übersetzung der Python-Dokumentation ist im Build-Verzeichnis der Python-Dokumentation als Sprache "Deutsch" eingetragen; der Prozess für Übersetzungen ist in PEP 545 beschrieben, angelegt am 4. März 2017. BWKI: Teilnahmebedingungen, gelesen am 2. November 2026. Alles Übrige ist unsere Einschätzung.

### Warum das ein Vorteil ist

Wer im Unterricht von Anfang an Englisch hört, muss später nichts übersetzen. Das Wort "loop" bedeutet im Unterricht dasselbe wie im Code und in der Fehlermeldung. Schülerinnen und Schüler, die auf Deutsch lernen, haben oft zwei Wörter für eine Sache: "Schleife" im Heft und for auf dem Bildschirm.

Dazu kommt das Englisch selbst. In jeder Stunde erklärt man, fragt nach und beschreibt Probleme in ganzen Sätzen. Das ist Sprechpraxis zu einem Thema, das Lernende wirklich interessiert.

### Was es nicht ist

Kein Englischkurs mit Programmierteil. Grammatik korrigieren wir nicht, außer jemand wünscht es. Ziel ist, dass Sie verstehen und verstanden werden.

Und kein Hindernis für Anfänger: Viele Lernende beginnen mit einem Englisch, das sie selbst als "nur Schulenglisch" beschreiben. Die Mentoren sprechen langsamer, wiederholen und schreiben schwierige Wörter in den Chat.

## Warum lohnt es sich, die englische Dokumentation zu lesen?

Weil dort in einem Satz steht, was eine Funktion zurückgibt, und genau das ist die häufigste Ursache für rätselhafte Fehler. Python hat die Dokumentation sogar eingebaut: Jede Funktion trägt eine kurze Beschreibung auf Englisch bei sich. Das Beispiel ist unser eigenes, mit einer Liste von Schulnoten.

**Sortieren, zweimal versucht** (Python)
```python
noten = [3, 1, 2, 2, 4]

# Versuch 1: sortieren und das Ergebnis speichern
sortiert = noten.sort()
print('Versuch 1:', sortiert)

# Was sagt die Dokumentation?
print(list.sort.__doc__.splitlines()[0])
print(sorted.__doc__.splitlines()[0])

# Versuch 2: sorted() gibt eine neue Liste zurück
noten = [3, 1, 2, 2, 4]
sortiert = sorted(noten)
print('Versuch 2:', sortiert, '| Original:', noten)
```
Ausgabe unseres Laufs mit Python 3.14, identisch unter deutscher Spracheinstellung:Versuch 1: NoneSort the list in ascending order and return None.Return a new list containing all items from the iterable in ascending order.Versuch 2: [1, 2, 2, 3, 4] | Original: [3, 1, 2, 2, 4]

**Zwei Sätze aus der eingebauten Dokumentation, Wort für Wort (unsere Übung)**

| Englisch | Was es heißt | Was daraus folgt |
|---|---|---|
| Sort the list in ascending order | Sortiert die Liste aufsteigend | Die Liste selbst wird verändert |
| and return None. | und gibt None zurück | In sortiert landet nichts: None |
| Return a new list | Gibt eine neue Liste zurück | Das Ergebnis kann man speichern |
| containing all items from the iterable | mit allen Elementen aus der Eingabe | Die ursprüngliche Liste bleibt, wie sie war |
| in ascending order. | in aufsteigender Reihenfolge | Kleinste Note zuerst |

Versuch 1 sieht vernünftig aus und liefert doch None. Python meldet keinen Fehler, das Programm läuft einfach mit einem leeren Ergebnis weiter, und der Absturz kommt oft erst viele Zeilen später. Die Erklärung steht in einem einzigen englischen Satz: list.sort sortiert die Liste an Ort und Stelle "and return None". Die Funktion sorted dagegen "Return a new list". Wer diese beiden Sätze lesen kann, findet den Fehler in Sekunden statt in einer halben Stunde.

Im Unterricht rufen wir solche Beschreibungen mit help(list.sort) oder über __doc__ direkt im Programm auf. Die Texte sind kurz, die Wörter wiederholen sich: return, list, new, order, item. Nach einigen Wochen lesen Lernende sie ohne Wörterbuch.

1. **Erst nachlesen, dann aufrufen.** Bei jeder neuen Funktion fragen wir: Was gibt sie zurück? Die Antwort steht fast immer im ersten Satz der Beschreibung.
2. **Auf "return None" achten.** Funktionen, die etwas verändern, statt etwas Neues zu liefern, sagen das oft genau so. Ihr Ergebnis zu speichern, ist ein klassischer Fehler.
3. **Das Original prüfen.** Versuch 2 gibt auch die ursprüngliche Liste aus. So sieht man, dass sorted sie unverändert lässt.
4. **Laut übersetzen.** Lernende übersetzen einen Satz der Dokumentation laut ins Deutsche. Wer ihn übersetzen kann, hat ihn verstanden.

## Für wen lohnt sich Programmieren auf Englisch besonders?

Für fast alle, aus unterschiedlichen Gründen. Drei Gruppen fragen uns besonders oft.

### Schülerinnen und Schüler

Informatik in der Schule und Englisch als Prüfungsfach üben sich gegenseitig. Wer später an einem Wettbewerb teilnimmt, profitiert doppelt: Beim BWKI dürfen Projekte auf Englisch eingereicht werden, und die Internationale Informatik-Olympiade findet vom 12. bis 19. September 2027 in Potsdam statt, mit erwartet rund 400 Teilnehmenden aus 90 bis 100 Ländern.

### Familien, die Englisch sprechen

Kinder, die zu Hause oder an einer internationalen Schule Englisch sprechen, lernen in ihrer Unterrichtssprache. Für sie ist ein Kurs auf Englisch oft der natürlichere Weg, auch wenn sie in Deutschland leben.

### Erwachsene im Beruf

In vielen Teams in Deutschland sind Code, Tickets und Besprechungen ohnehin englisch. Wer Programmieren direkt auf Englisch lernt, muss die Fachsprache nicht ein zweites Mal lernen.

Für jüngere Kinder ab 8 beginnen wir mit Scratch. Die Blöcke dürfen auf Deutsch eingestellt bleiben; der Mentor sagt zu jedem Block das englische Wort, und mit der Zeit wechseln viele Kinder von selbst auf die englische Ansicht.

Die IOI und der BWKI sind Wettbewerbe mit eigenen Veranstaltern; wir sind mit ihnen nicht verbunden, und die Anmeldung läuft dort.

## Programmieren lernen auf Englisch: häufige Fragen

### Findet der Unterricht auf Deutsch statt?

Nein, nie. Jede Stunde ist live und auf Englisch, mit Mentoren aus Indien, die deutlich sprechen und sich auf Ihr Tempo und Ihre Aussprache einstellen. Darin liegt der Gewinn: Sie lernen Programmieren in der Sprache, in der Python, Java und ihre Fehlermeldungen geschrieben sind, und üben Englisch in jeder Stunde mit.

### Wie gut muss mein Englisch sein?

Schulenglisch reicht für den Anfang. Nach den KMK-Bildungsstandards sollen Schülerinnen und Schüler bis zum Mittleren Schulabschluss im Wesentlichen das Niveau B1 erreichen; damit kann man Erklärungen folgen und Fragen stellen. Kinder ab 8 starten auch mit weniger, weil der Mentor viel zeigt.

### Gibt es Fehlermeldungen von Python auch auf Deutsch?

Nein. Python meldet Fehler auf Englisch, auch wenn der Rechner auf Deutsch eingestellt ist; das haben wir für diese Seite mit Python 3.14 geprüft. Die Dokumentation gibt es dagegen teilweise auf Deutsch. Englische Meldungen und Beschreibungen lesen zu können, gehört also ohnehin dazu, und im Kurs üben wir das jede Stunde.

### Ist ein indischer Akzent nicht schwer zu verstehen?

Selten, und die Mentoren achten darauf. Sie sprechen langsam, wiederholen und schreiben Wörter in den Chat. Die KMK-Standards für das Abitur nennen ausdrücklich Varietäten und Akzente, deren Färbung das Verstehen nicht generell behindert, als Teil dessen, was Lernende verstehen sollen.

### Lernt mein Kind dabei auch besser Englisch?

Sehr wahrscheinlich übt es mehr, weil es jede Stunde zuhört, fragt und erklärt. Eine Englischnote versprechen wir nicht, und wir korrigieren keine Grammatik, außer Sie wünschen es. Das Ziel ist Verständigung über Code.

### Ab welchem Alter geht das?

Ab 8 Jahren mit Scratch, ab etwa 10 mit Python. Für Jugendliche gibt es Python, Java und JavaScript, für Erwachsene eigene Kurse bis zur Webentwicklung.

### Hilft das bei Wettbewerben?

Ja. Beim Bundeswettbewerb Künstliche Intelligenz dürfen Projekte auf Deutsch oder Englisch eingereicht werden. Die Internationale Informatik-Olympiade 2027 findet in Potsdam statt, mit rund 400 Teilnehmenden aus 90 bis 100 Ländern. Mit beiden Wettbewerben sind wir nicht verbunden.

### Kann ich zwischendurch ein deutsches Wort sagen?

Natürlich. Der Mentor versteht häufige Fachwörter wie Schleife oder Variable und nennt Ihnen das englische Wort dazu. Niemand muss in jeder Minute perfekt Englisch sprechen.
