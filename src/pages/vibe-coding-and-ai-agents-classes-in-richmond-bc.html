How we teach it

Vibe coding in Richmond, taught the test-first way

The word for the method is old; the reason for it is new. When a model can write fifty lines in a few seconds, the slow part of programming moves to deciding whether those fifty lines are right.

1. Say what right looks like

Before a prompt is typed, the learner writes down two or three checks the answer must pass, in plain code. A check is a promise that can be tested, not a feeling that the output looks sensible.

2. Let the AI draft

Only then does the assistant write the function. Teens use a tool their age allows; adults may use an agent that edits files and runs commands. Either way the draft is treated as a suggestion from a fast, careless colleague.

3. Run, read, repair

The tests run. Any failure is read and understood before anything is changed, and the repair is written or approved line by line by the learner. A line nobody can explain does not stay in the project.

This is how we keep the owner's promise in a subject where it is easy to break: we teach students to think a problem through, not to copy an answer, and AI output is an answer like any other. A Richmond Grade 10 student and a Richmond software tester will meet the same three steps; the teen practises them in Python with permitted tools, the adult on a larger codebase with an agent.

Richmond data project

Which Richmond greenways are open end to end? Tests before the AI draft

Metro Vancouver publishes its Regional Greenway Network 2050 as open data. The file splits each route into segments and gives every segment a status. Our learners ask one question of the Richmond rows, write the tests first, and then watch an AI-style draft fail them. The code and every count below are ours, run on the file downloaded on 23 October 2026.

Richmond segments in the Regional Greenway Network 2050 file, by status (our count of the 51 rows tagged Richmond; the status meanings are Metro Vancouver's own wording, shortened)
Status in the fileWhat Metro Vancouver says it meansRichmond segments
Operational - Class 1“complete routes that are available to the public for walking and cycling”23
Operational - Class 2“interim routes” that “do not meet the 3m wide width goal and/or are not separated from traffic”13
PlannedFuture routes already in providers' plans, still needing planning, land, design, funding or construction12
Proposed NewConceptual routes proposed to fill gaps in the network3

The question: which named Richmond routes are open along their whole length? The 51 segments carry only 13 route names, and one of them, Steveston Greenways / South Dike / East Richmond Trails+, is split into 24 segments: 11 in Class 1, 6 in Class 2, 5 Planned and 2 Proposed New. That single route is where a hasty answer goes wrong.

Here is the whole exercise as one Python file. It uses only the standard library and runs beside the downloaded JSON:# Tests first, then the AI-style draft, then the fix (Modern Age Coders, written for this page) import json DATA = json.load(open("mv_regional_greenway_network_2050_all.json", encoding="utf-8")) SEGMENTS = [f["attributes"] for f in DATA["features"] if f["attributes"]["Municipality"] == "Richmond"] # Step 1: the learner writes the tests before asking for any code. A tiny route of our own invention: FIXTURE = [{"Name": "Test Route", "Status": "Operational - Class 1"}, {"Name": "Test Route", "Status": "Planned"}] def run_tests(open_routes): results = [] results.append(("half-built test route is not open", "Test Route" not in open_routes(FIXTURE))) every = open_routes(SEGMENTS) results.append(("open routes are a subset of route names", set(every) <= {s["Name"] for s in SEGMENTS})) results.append(("no open route has a Planned segment", all(s["Status"].startswith("Operational") for s in SEGMENTS if s["Name"] in every))) return results # Step 2: the draft, the kind an assistant returns first. It reads well and is wrong. def draft_open_routes(segs): return sorted({s["Name"] for s in segs if s["Status"].startswith("Operational")}) # Step 3: the version that passes, written after a test failed. def open_routes(segs): names = {s["Name"] for s in segs} return sorted(n for n in names if all(s["Status"].startswith("Operational") for s in segs if s["Name"] == n)) for label, fn in (("draft", draft_open_routes), ("fixed", open_routes)): print(label, [("PASS" if ok else "FAIL") + ": " + name for name, ok in run_tests(fn)])

Why the draft fails

It keeps a route if any one segment is operational. In Python that is the difference between any() and all(), and it is the most common shape of mistake in AI-written data code: correct syntax, wrong meaning. The draft names 10 routes; only 6 are open end to end.

What the fix returns

Six routes have every Richmond segment operational: Cambie Skytrain Bridge, Delta South-Surrey Regional Greenway, Knight St. Bridge, Oak St Bridge, Railway Ave. Greenway and West Dike Trail. The four the draft added wrongly include the 24-segment Steveston route and the Sea Island Recreational Trail.

Why test 1 uses made-up data

The two-row Test Route is ours, invented on purpose. A small case whose right answer you know by heart catches a wrong idea faster than a 51-row file whose answer you are still trying to find.

Three things the file cannot tell you

Three segments, OBJECTID 618, 812 and 1005, were Operational in the PreviousStatus column and are Planned now; the file does not say why, so we do not guess. Six rows carry the placeholder NA as their route description. And Metro Vancouver says the dataset reflects progress between 2020 and 2023, so a route opened since may still read Planned here.

The file is Metro Vancouver's, not the City of Richmond's: we could not find a City of Richmond dataset published under an open licence, so we used the regional district's, filtered to the rows tagged Richmond. Some of those rows are bridges at the city's edge, which is why we count routes and never print a total length. Coding and AI

If an AI writes the code, what is left for a Richmond learner to learn?

The part that decides whether the code is any good.

In the greenway example the draft was short, readable and confident, and it named four routes as open that are not. Nothing in the code looked wrong. The only reason anyone noticed is that a person had already decided, in a test, what a half-built route must return. That decision is not something a model can make for you, because it depends on what you mean by open.

So our classes spend less time on typing and more on judgement: choosing the question, writing the check, reading the failure, and owning the fix. Teens build that judgement with tools their age allows; adults apply it to agents that act on their behalf. In both groups, the person stays the author.

A Richmond learner who can write the test before the code will still be useful when the tools change again next year. The longer argument is in is coding still worth learning in 2026.

Vibe coding and AI agents in Richmond, BC: questions

What Richmond teens, parents and adults ask us most.

Do you teach vibe coding classes in Richmond, BC?

Yes, live online. Richmond teens aged 13 to 17 take Vibe Coding for Teens, and adults take separate courses. There is no Richmond classroom; every lesson is with a real teacher over video.

Is this page about Richmond, BC or Richmond Hill, Ontario?

Richmond, British Columbia, in Metro Vancouver. Richmond Hill is a different city in Ontario with different school courses and a different time zone.

What is vibe coding, in plain words?

Describing the program you want in ordinary language and letting an AI model write the code. Our classes treat that as the first step and teach the rest: testing, reading and fixing what the AI wrote.

Can my 15-year-old use Claude or Claude Code in your classes?

No. Anthropic sets 18 as the minimum age for its consumer services, so Claude and Claude Code appear only in our adult courses and are never suggested to anyone under 18.

Does my teen need ChatGPT for the teen course?

No. OpenAI's terms say anyone under 18 needs a parent's or guardian's permission, so we ask you first. Teens can work with GitHub Copilot instead, which GitHub offers free to verified students.

Can a Richmond adult learn to build and use AI agents?

Yes. Our Codex and Claude Code course is for adults only and works on real repositories with version control. Vibe Coding for College suits learners aged 18 and up who want full stack projects.

What does test-first mean for a beginner?

Before asking an AI for code, you write a few small checks the code must pass. Then you run them. On this page a first draft about Richmond greenways failed two of three checks, which is how the mistake was found.

Will this help with BC Computer Programming 11 or 12?

It sits beside them. The courses ask for logic, decisions, loops and functions, which are what tests check. We teach alongside the school course and do not grant British Columbia credits.

Are AI assistants allowed in the CCC?

No. Contest rules ban generative AI, editor plug-ins included. CEMC lists the 2027 CCC for Wednesday 17 February 2027, written through a school, so contest practice is done without assistants.

What time are classes for Richmond?

Weekdays or weekends, flexible: choose your batch, or for a very personalised plan choose 1-on-1 at your convenience, weekend mornings or weekdays. Times are confirmed in Pacific time, which BC keeps all year.
