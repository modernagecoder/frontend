### The hard parts, from our classes

Negative numbers trip up more Grade 6 students than anything else, because the rules that worked for whole numbers suddenly need a direction. Fractions with unlike denominators are a close second, usually because the idea of a common denominator was memorised in Grade 5 rather than understood.

Percents are the pleasant surprise. Once a child can find 10% by moving the decimal point, 5%, 15% and 25% follow quickly, and the curriculum asks for exactly that mental math.

### Why the strands connect

The Grade 6 strands are not separate units in real life. A probability simulation (Data) needs fractions and percents (Number) and a loop with a condition (Algebra, C3). A translation on the grid (Spatial Sense) needs integers.

That is why we teach Grade 6 math and Grade 6 coding in the same lesson. A child who writes the code for a dice experiment does fraction work, percent work and loop work at once, and sees why each one matters.

## The Grade 6 coding expectation: efficient code with conditions

Grade 6 C3.1 asks students to solve math problems &ldquo;by writing and executing efficient code, including code that involves conditional statements and other control structures&rdquo;. C3.2 asks them to read and alter code and describe how changes affect &ldquo;the outcomes and the efficiency of the code&rdquo;. Grade 5 asked for the conditions; Grade 6 adds the efficiency.

### Plan with a flow chart

The Grade 6 notes say: &ldquo;A flow chart can be used to plan and organize thinking. The symbols used in flow charts have specific meanings, including those that represent a process, a decision, and program input/output.&rdquo; A diamond for each if, a box for each step.

### Two different flow charts

The notes add a warning worth knowing: &ldquo;The reverse flow chart that is used to solve equations is not the same as the flow chart used in coding.&rdquo; Children meet both in Grade 6 and often mix them up.

### Why efficiency matters

In the curriculum&rsquo;s words: &ldquo;More efficient code can reduce execution time and reduce computer storage space.&rdquo; For a Grade 6 child, that means fewer steps doing the same job, and reusing an answer already worked out.

### What Grade 6 coding tasks are about

The curriculum lists possible math situations for Grade 6 coding. Among them are &ldquo;grouping numbers using the divisibility rules&rdquo;, &ldquo;simulating probability situations&rdquo; and &ldquo;identifying whether a growing pattern is linear&rdquo;. Every one is a math topic from another strand, done with code.

So a Grade 6 coding task is rarely a game for its own sake. It is a math question where the program does the repetitive part and the child does the thinking: which rule to test, in which order, and how to know the answer is right.

### Coding in Grade 6 science too

Science class carries its own coding line. Expectation A2.1 of the 2022 Science and Technology curriculum says Grade 6 students will &ldquo;write and execute code in investigations and when modelling concepts&rdquo;. In practice that might be a program that reads a sensor or asks the user for a value, then reports a result.

The same skills carry across: variables, a loop, a decision. A child who is comfortable with conditions in math will find the science tasks familiar, even when the class uses a different tool.

## From divisibility rules to an efficient program

Our own worked example, built the way we teach it. The math is Grade 6 B2.2, the divisibility rules for 2, 3, 4, 5, 6, 8, 9 and 10. The coding is Grade 6 C3.1: conditional statements, and one deliberate efficiency.

1. Write each rule in words first. 2: the last digit is even. 3: the digit sum divides by 3. 4: the last two digits divide by 4. 5: the last digit is 0 or 5. 6: it passes both 2 and 3. 8: the last three digits divide by 8. 9: the digit sum divides by 9. 10: the last digit is 0.
2. Spot the work that repeats. The digit sum is needed twice, for 3 and for 9, so it becomes its own small function.
3. Draw the flow chart. One decision diamond per rule, each with a yes branch that adds the divisor to a list.
4. Find the free answer. The test for 6 needs no new arithmetic at all: if 2 and 3 are already on the list, 6 goes on too. That reuse is the efficiency.
5. Code it and run it on three numbers chosen to behave differently: one that passes everything, one that passes some, one that passes few.
6. Check the rules against real division. We had the computer compare our rule-based list with plain division for every whole number from 1 to 10,000. There were no mismatches.

**Python · divisibility tests (ours)** (python)
```python
# Grade 6: which divisibility tests does a number pass? (ours)
def digit_sum(n):
    total = 0
    for d in str(n):
        total = total + int(d)
    return total

def passes(n):
    tests = []
    last = n % 10
    if last % 2 == 0:
        tests.append(2)
    if digit_sum(n) % 3 == 0:
        tests.append(3)
    if n % 100 % 4 == 0:              # last two digits
        tests.append(4)
    if last == 0 or last == 5:
        tests.append(5)
    if 2 in tests and 3 in tests:      # 6 needs both: no new work
        tests.append(6)
    if n % 1000 % 8 == 0:             # last three digits
        tests.append(8)
    if digit_sum(n) % 9 == 0:
        tests.append(9)
    if last == 0:
        tests.append(10)
    return tests

for n in [2520, 7416, 1155]:
    print(n, "passes", passes(n))
```
Output: 2520 passes [2, 3, 4, 5, 6, 8, 9, 10], 7416 passes [2, 3, 4, 6, 8, 9] and 1155 passes [3, 5]. The digit sum of 7416 is 18, which divides by both 3 and 9; its last three digits, 416, are 8 times 52.

### Where the efficiency is

Testing 6 by dividing would be one more division. Testing it from the list costs nothing, because the program already knows the answers for 2 and 3. The same idea, keeping an answer you have already worked out, is what makes much bigger programs fast.

There is a second, quieter lesson. The digit sum is calculated twice in this version, once for 3 and once for 9. Ask the student to alter the code so it is calculated only once and stored in a variable. That is a C3.2 task: change the code, then explain the effect on efficiency.

### Where the math is

Why does the digit-sum rule work? Because 10, 100 and 1,000 are each one more than a multiple of 9, so a number and its digit sum leave the same remainder when divided by 3 or 9. A Grade 6 student does not need the proof, but a curious one enjoys it.

And why do 4 and 8 only look at the last digits? Because 100 is a multiple of 4 and 1,000 is a multiple of 8, so everything to the left cannot change the remainder. A computer could just divide; the rules are for people working by hand on a test without a calculator.

## Twelve Grade 6 math and coding practice questions

These are our practice questions, written for this page and matched to the Grade 6 strands. They are not taken from EQAO, any school or any textbook. Questions 9 to 11 are short Python programs to read. Try each one on paper before checking the answers.

1. Number. Without dividing, decide whether 7,416 is divisible by 3, by 9 and by 8. Say which rule you used for each.
2. Number. Find 15% of 240 in your head. Explain your steps.
3. Number. At 7 a.m. the temperature in Thunder Bay was &minus;7&deg;C. By noon it was 5&deg;C. By how many degrees did it rise?
4. Number. Round 4.6382 to the nearest tenth and to the nearest hundredth.
5. Number. Add 2/3 and 1/4. Show the common denominator.
6. Number. Use a factor tree to write 360 as a product of prime factors.
7. Algebra. The pattern 4, 7, 10, 13 continues. Is it linear? Write a rule for the nth term and find the 20th term.
8. Algebra. Find the whole-number solutions of 3x + 5 < 32.

**Question 9 · read the code** (python)
```python
count = 0
for n in range(1, 51):
    if n % 6 == 0:
        count = count + 1
print(count)
```
What does this print? What question about the numbers 1 to 50 does it answer?

**Question 10 · efficiency** (python)
```python
a = 0
n = 6
while n <= 50:
    a = a + 1
    n = n + 6
print(a)
```
This prints the same number as Question 9. How many times does each loop run? Which is more efficient, and why?

**Question 11 · inequality by code** (python)
```python
x = 0
while 3 * x + 5 < 32:
    x = x + 1
print(x - 1)
```
Predict the output. How does it connect to Question 8? Why does the last line subtract 1?

Question 12 · spatial sense. The point (&minus;3, 2) is translated 5 units right and 4 units down. Where does it land, and in which quadrant?

Bonus, data. Two fair dice are rolled. What is the theoretical probability of a sum of 7? In an experiment of 200 rolls a class got a sum of 7 forty times. What is the experimental probability, and why might the two differ? The six numbers 14, 9, 22, 9, 16 and 20 are a separate data set: find the mean, median, mode and range. Bonus, measurement: a trapezoid has parallel sides of 8 cm and 12 cm and a height of 5 cm. Find its area.

## Worked answers to the Grade 6 practice set

Each answer shows the reasoning, because that is what a Grade 6 teacher marks. We checked every number with a short program.

1. Yes, yes, yes. The digit sum is 7 + 4 + 1 + 6 = 18, which divides by 3 and by 9. For 8, look at the last three digits: 416 = 8 &times; 52. (Our worked program above gives the same list.)
2. 36. 10% of 240 is 24. 5% is half of that, 12. 15% is 24 + 12 = 36.
3. 12 degrees. From &minus;7 up to 0 is 7, and from 0 up to 5 is 5 more. 7 + 5 = 12. On a vertical number line, count the steps.
4. 4.6 and 4.64. For tenths, look at the hundredths digit, 3, which is less than 5, so round down. For hundredths, look at the thousandths digit, 8, so round up.
5. 11/12. The lowest common denominator of 3 and 4 is 12. 2/3 = 8/12 and 1/4 = 3/12, so the sum is 11/12.
6. 2 &times; 2 &times; 2 &times; 3 &times; 3 &times; 5, or 23 &times; 32 &times; 5. One tree: 360 = 36 &times; 10, then 36 = 4 &times; 9 and 10 = 2 &times; 5, then 4 = 2 &times; 2 and 9 = 3 &times; 3.
7. Linear; 3n + 1; 61. The pattern grows by 3 every time, the same amount, so it is linear. Term 1 is 3 &times; 1 + 1 = 4, which checks. Term 20 is 3 &times; 20 + 1 = 61.
8. x = 0, 1, 2, 3, 4, 5, 6, 7 or 8. Subtract 5 from both sides: 3x < 27, so x < 9. Check the edge: 3 &times; 8 + 5 = 29, which is less than 32, and 3 &times; 9 + 5 = 32, which is not.
9. 8. It counts the multiples of 6 from 1 to 50: 6, 12, 18, 24, 30, 36, 42 and 48. The if asks the divisibility question once per number.
10. The first loop runs 50 times; the second runs 8 times. Both print 8. The second is more efficient because it jumps straight from one multiple of 6 to the next instead of testing every number. This is the Grade 6 C3.2 question in miniature: same outcome, less work.
11. 8. The loop keeps adding 1 to x while 3x + 5 is still less than 32. It stops when x reaches 9, the first value that fails, so the largest solution is one less: 8. That matches Question 8, worked by code instead of algebra.
12. (2, &minus;2), in Quadrant IV. Right 5 changes x from &minus;3 to 2; down 4 changes y from 2 to &minus;2. Positive x and negative y is the fourth quadrant.

Bonus answers. Six of the 36 equally likely outcomes give a sum of 7, so the theoretical probability is 6/36 = 1/6, about 0.17. The experiment gives 40/200 = 1/5 = 0.2. Experiments vary from the theory, especially with few trials; more rolls usually bring them closer. For the data set, sorted it is 9, 9, 14, 16, 20, 22: the mean is 90 &divide; 6 = 15, the median is halfway between 14 and 16, so 15, the mode is 9 and the range is 22 &minus; 9 = 13. The trapezoid&rsquo;s area is (8 + 12) &divide; 2 &times; 5 = 50 cm&sup2;.

## Signs a Grade 6 student needs help, and what helps

Most Grade 6 struggles start small. These are the signs we see most often in first classes, and the fix we use for each.

### Guessing with negatives

If a child adds &minus;7 and 5 and says 12, the number line is missing. We go back to a vertical line, like a thermometer, until direction makes sense.

### Rules without reasons

A child who knows the divisibility rules but cannot say why 6 needs both 2 and 3 will forget them by spring. Writing the rules as code forces the reason.

### Code copied, not read

If a child can type a program but not predict its output, they have met the tool and not the expectation. We ask for a prediction before every run.

### A week that works

Two live lessons, each with one math idea and one short program that uses it. Ten minutes a day at home on three practice questions, with the working shown. One saved program a week in a folder.

Parents need no coding knowledge to help. Ask what the program calculates and what it should print before your child runs it.

### Getting ready for Grade 7

Grade 7 coding adds subprograms and loops that stop when a condition is met. A Grade 6 student who already writes small functions, like digit_sum above, walks into Grade 7 a step ahead.

On the math side, integers and fractions are the two foundations Grade 7 builds on most. Time spent on them in Grade 6 is never wasted.

| Stage | What it looks like |

| 2. Rule user | Picks the right rule and explains it in a sentence |
| 3. Rule coder | Turns a rule into an if test and checks it on tricky numbers |

### For parents

Ask your child to explain one rule from this week without a worksheet in front of them. If they can, they are at stage 2 or beyond.
Stage 3 is where coding starts helping math directly, and it usually takes a few weeks of short programs to reach.

### For students

When a rule feels like magic, test it on a number that should fail. Rules you have tried to break are the ones you remember.
Before you run a program, write down what it should print.

## Ontario Grade 6 math and coding: common questions

### What coding does Grade 6 math ask for?

In Grade 6, Ontario expects code that is efficient and that uses conditional statements, such as if and else, along with loops and other control structures, all in the service of math problems. Students also read code written by someone else, change it, and say whether the change made it work better or faster.

### What does efficient code mean in Grade 6?

The Grade 6 curriculum notes say more efficient code can reduce execution time and computer storage space. For a Grade 6 student it usually means fewer steps doing the same job, such as using a loop instead of repeating a line, or reusing an answer the program already worked out.

### What math is taught in Grade 6 in Ontario?

The 2020 curriculum has five content strands in Grade 6: Number, Algebra, Data, Spatial Sense and Financial Literacy, with social-emotional learning skills and the mathematical processes running through them. Grade 6 includes integers, divisibility rules, percents, fractions, linear patterns, inequalities, probability, four-quadrant coordinates and the areas of trapezoids and other polygons.

### Which divisibility rules does Grade 6 cover?

The Grade 6 curriculum asks students to understand the divisibility rules and use them for 2, 3, 4, 5, 6, 8, 9 and 10. Our worked program on this page turns each rule into a conditional test and checks it against real division.

### Does my child need to know Python for Grade 6?

No. The curriculum does not name a coding tool, and many classes use block-based programs. We teach in Python or Scratch, depending on what the class uses, and many children start Python around Grade 6 because conditions and variables read clearly as words.

### When is the Grade 6 EQAO assessment?

EQAO lists the next administration of the Grade 6, Junior Division Assessment of Reading, Writing and Mathematics for May 4 to June 8, 2027. Ask your child's school which days it plans to use.

### Are your practice questions EQAO questions?

No. The twelve questions on this page are our own, written to match the Grade 6 curriculum strands. They are not EQAO questions or copies of any school or textbook material.

### What is the Beaver Computing Challenge?

It is a computational thinking contest run by CEMC at the University of Waterloo. Students in Grade 6 or below can write the Grade 5/6 level, which CEMC describes as 12 multiple-choice questions in 45 minutes. CEMC lists the 2026 contest for 9 to 20 November 2026, written through a school.

### Can coding help my child with math?

It can, when the code computes the math rather than decorating it. Writing a divisibility rule or a probability experiment as a program makes a child state the rule exactly and test it, which is often where understanding finally clicks. We cannot promise a mark, but we see the habit grow.
