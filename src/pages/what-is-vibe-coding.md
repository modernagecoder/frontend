> Vibe coding is building software by describing what you want in plain language while an AI model writes the code, then steering it by running the result and saying what to change. The term was coined by Andrej Karpathy in February 2025 and named Collins Dictionary word of the year within the same year. It genuinely works for prototypes and personal tools, and it genuinely collapses at the first bug the model cannot see, which is why the skill worth teaching is describe, run, read, steer rather than prompt and hope. ## The definition, and where the word comes from

In February 2025, Andrej Karpathy, a founding member of OpenAI and former director of AI at Tesla, described a new way he was building small projects: talking to a model, accepting what it wrote, and in his words fully giving in to the vibes and forgetting that the code even exists. He called it vibe coding. By November, Collins Dictionary had named it word of the year for 2025.

The mechanism without the mystique: a large language model has been trained on enormous amounts of public code, so when you describe a program it predicts the code that would plausibly follow such a description. You run that code, describe what differs from what you meant, and the model predicts a revision. Describe, run, react, revise. The person supplies intent, the test of reality, and the judgement about what "wrong" means. The model supplies syntax at extraordinary speed.

## A real session, both halves

A 15 year old student built a chemistry revision quiz app. Minutes 0 to 30: the app exists, gains a timer, saves best scores, shows correct answers. Real, useful, hers, before she had learned what a function is.

Minute 41: questions repeat after refresh. Three prompt attempts produce three rewrites; one breaks the timer, none fixes the bug. At minute 52 she stops prompting and reads the code with her teacher: the app shuffles the question list but saves the unshuffled copy. She describes the cause instead of the symptom, and the model fixes it in one pass.

That is the entire case for learning vibe coding rather than merely doing it. The loop is easy. Steering the loop when it stalls is a skill, and it is teachable.

## What it is good for, and what it is not

Genuinely good for: first versions of almost anything, personal tools, momentum for beginners, speed for people who already read code, and teaching precision, because a model does exactly what you said rather than what you meant.

Quietly not: it does not know your intent, it does not verify correctness, it has no stake in security, and it does not teach by itself. Generated code that runs is not generated code that is correct.

## The six teachable skills

1. Describe with precision: turning wishes into specifications.
2. Read what came back: where does data live, what runs on click.
3. Test on purpose: empty input, double click, refresh, wrong password.
4. Name the cause, not the symptom: the highest-leverage move in the discipline.
5. Keep versions in Git, so a bad rewrite costs a revert, not an evening.
6. Know what never goes in a prompt: passwords, keys, personal details.

## Frequently asked questions

**Is vibe coding a real skill or a fad?** The name may age, the activity will not. Describing software precisely, reading what a model produces and steering it with tests is how a growing share of professional programming already works.

**Can a ten year old vibe code?** Not with mainstream chat tools; the published floors forbid it. Under 13 the same instinct is built in Scratch and teacher-operated tools.

**Is it cheating?** Depends what the exercise was testing. If the goal was practising loops, yes. If the goal was shipping a working tool, directing a model well is how the work is done now.

**Do you still need to read code?** Yes. The session above stalled on one line that reading finds in seconds and prompting missed three times.

**How is it different from agentic coding?** Vibe coding is the conversational loop. Agentic coding gives the model autonomy to plan, run commands and edit many files; those tools are mostly 18 plus and taught separately.
