## Which program families repeat in ICSE computer board papers?

Three families were in all four papers: a class with a calculation, method overloading and a String program. Three more appeared in three of the four. Because a candidate picks four of six, a student strong in the steady families always has four questions to choose from.

- Program family | 2023 | 2024 | 2025 | 2026 | Papers

- Class and object with a slab, ladder or formula (always Question 3) | Q3 | Q3 | Q3 | Q3 | 4 of 4

- Method overloading, with a nested-loop pattern inside | Q5 | Q4 | Q7 | Q7 | 4 of 4

- String program (count, test or rebuild) | Q6 | Q8 | Q5 | Q8 | 4 of 4

- Number check built on digit extraction, as its own question | inside Q5 | Q5 | Q8 | Q6 | 3 of 4

- Double dimensional (2D) array | none | Q6 | Q4 | Q5 | 3 of 4

- Searching: linear or binary | Q7 | none | Q6 | Q4 | 3 of 4

- Sorting: bubble or selection | Q4 | Q7 | none | none | 2 of 4

### What the count tells a 2027 candidate

- Question 3 is a gift. A class with three or four methods and a calculation came first every year. Practise it until it takes fifteen minutes.

- Overloading carries a pattern. Every overloading question hid a nested-loop pattern inside it, so pattern practice pays twice.

- 2D arrays have arrived. They were absent in 2023 and present in each of the next three papers, always as a short scan of rows and columns.

- Sorting and searching rotate. One of them came every year, so learn bubble sort, selection sort, linear search and binary search, not just one.

### Practice 1: class and object with a slab calculation (the Question 3 shape)

Define a class CabRide with members name, km, ac (Y or N) and fare. The fare is 18 per km for the first 4 km, 15 per km for the next 6 km and 12 per km beyond 10 km; an AC ride adds 10 percent. Write accept(), calculate(), display() and a main that uses an object.

```
import java.util.Scanner;
class CabRide {
    String name; double km; char ac; double fare;
    void accept() {
        Scanner sc = new Scanner(System.in);
        System.out.print("Rider name: ");
        name = sc.nextLine();
        System.out.print("Distance in km: ");
        km = sc.nextDouble();
        System.out.print("AC ride (Y/N): ");
        ac = sc.next().charAt(0);
    }
    void calculate() {
        if (km <= 4)
            fare = km * 18;
        else if (km <= 10)
            fare = 4 * 18 + (km - 4) * 15;
        else
            fare = 4 * 18 + 6 * 15 + (km - 10) * 12;
        if (ac == 'Y' || ac == 'y')
            fare = fare + fare * 10 / 100;
    }
    void display() {
        System.out.println("Name: " + name);
        System.out.println("Distance: " + km + " km");
        System.out.println("Fare: " + fare);
    }
    public static void main(String[] args) {
        CabRide ob = new CabRide();
        ob.accept(); ob.calculate(); ob.display();
    }
}
```

Distance: 13.5 km
Fare: 224.4

// 3 km, no AC: Fare: 54.0
```

### Practice 2: method overloading with a pattern inside

Overload compute: void compute(int n) prints n rows, row i counting down from n to i; double compute(double r, double h) returns the volume of a cylinder; boolean compute(String s, char ch) returns true when ch occurs more than once in s.

```
class Compute {
    void compute(int n) {
        for (int i = 1; i <= n; i++) {
            for (int j = n; j >= i; j--)
                System.out.print(j + " ");
            System.out.println();
        }
    }
    double compute(double r, double h) {
        return Math.PI * r * r * h;
    }
    boolean compute(String s, char ch) {
        int c = 0;
        for (int i = 0; i < s.length(); i++)
            if (s.charAt(i) == ch)
                c++;
        return c > 1;
    }
    public static void main(String[] args) {
        Compute ob = new Compute();
        ob.compute(4);
        System.out.println(ob.compute(7.0, 10.0));
        System.out.println(ob.compute("BLUEJ", 'E') + " " + ob.compute("TEETH", 'E'));
    }
}
```

4 3 2
4 3
4
1539.3804002589986
false true
```

### Practice 3: a digit-based number check

A Twin-end number (our own definition) has the same first and last digit, and a digit sum divisible by 3. 2742 qualifies: it starts and ends with 2 and its digits add to 15. Accept a number and say whether it is one.

```
import java.util.Scanner;
class TwinEnd {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter a number: ");
        int n = sc.nextInt();
        int last = n % 10, first = 0, sum = 0, t = n;
        while (t > 0) {
            int d = t % 10;
            sum = sum + d;
            first = d;
            t = t / 10;
        }
        if (first == last && sum % 3 == 0)
            System.out.println(n + " is a Twin-end number");
        else
            System.out.println(n + " is not a Twin-end number");
    }
}
```

```
2742 is a Twin-end number
4504 is not a Twin-end number
3713 is not a Twin-end number
5 is not a Twin-end number
```

### Practice 4: a String program that rebuilds words

Accept a sentence. Print it with the first and last letters of every word swapped, and count the words that begin with a vowel.

```
import java.util.Scanner;
class SwapEnds {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter a sentence: ");
        String s = sc.nextLine().trim() + " ";
        String word = "", result = "";
        int vowelStart = 0;
        for (int i = 0; i < s.length(); i++) {
            char ch = s.charAt(i);
            if (ch != ' ') {
                word = word + ch;
            } else if (word.length() > 0) {
                char f = Character.toUpperCase(word.charAt(0));
                if ("AEIOU".indexOf(f) >= 0)
                    vowelStart++;
                int L = word.length();
                if (L > 1)
                    word = word.charAt(L - 1) + word.substring(1, L - 1) + word.charAt(0);
                result = result + word + " ";
                word = "";
            }
        }
        System.out.println(result.trim());
        System.out.println("Words starting with a vowel: " + vowelStart);
    }
}
```

eht mxae si rean
Words starting with a vowel: 2

### Practice 5: a double dimensional array check

Accept a 3 by 3 integer matrix. Say whether it is symmetric (each a[i][j] equals a[j][i]) and print the sum of its boundary elements.

```
import java.util.Scanner;
class Symmetric {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int[][] a = new int[3][3];
        System.out.println("Enter 9 elements:");
        for (int i = 0; i < 3; i++)
            for (int j = 0; j < 3; j++)
                a[i][j] = sc.nextInt();
        boolean sym = true;
        int boundary = 0;
        for (int i = 0; i < 3; i++)
            for (int j = 0; j < 3; j++) {
                if (a[i][j] != a[j][i])
                    sym = false;
                if (i == 0 || i == 2 || j == 0 || j == 2)
                    boundary += a[i][j];
            }
        System.out.println(sym ? "Symmetric matrix" : "Not a symmetric matrix");
        System.out.println("Sum of boundary elements = " + boundary);
    }
}
```

```
// input 1 4 7 / 4 2 5 / 7 5 3
Symmetric matrix
Sum of boundary elements = 36
```

### Practice 6: sort a String array, then binary search it

Store six city names, arrange them alphabetically by bubble sort, print them, then search for a city typed by the user with binary search, ignoring case.

```
import java.util.Scanner;
class CitySearch {
    public static void main(String[] args) {
        String[] c = {"Pune", "Agra", "Surat", "Kochi", "Delhi", "Bhopal"};
        int n = c.length;
        for (int i = 0; i < n - 1; i++)
            for (int j = 0; j < n - 1 - i; j++)
                if (c[j].compareToIgnoreCase(c[j + 1]) > 0) {
                    String t = c[j]; c[j] = c[j + 1]; c[j + 1] = t;
                }
        for (int i = 0; i < n; i++)
            System.out.print(c[i] + " ");
        System.out.println();
        Scanner sc = new Scanner(System.in);
        System.out.print("City to search: ");
        String key = sc.next();
        int low = 0, high = n - 1, pos = -1;
        while (low <= high) {
            int mid = (low + high) / 2;
            int r = key.compareToIgnoreCase(c[mid]);
            if (r == 0) { pos = mid; break; }
            else if (r < 0) high = mid - 1;
            else low = mid + 1;
        }
        if (pos >= 0)
            System.out.println(key + " found at index " + pos);
        else
            System.out.println(key + " not found");
    }
}
```

```
Agra Bhopal Delhi Kochi Pune Surat
surat found at index 5

Agra Bhopal Delhi Kochi Pune Surat
Goa not found
```

## How to solve ICSE Computer Applications previous year papers so they raise your marks

Solve each past paper twice: once by family, early, to learn the shapes, and once whole, timed, near the exam. Reading a solution is not solving a paper.

-
**Group the questions by family first** Take all four Question 3s together, then all four overloading questions, and so on. Seeing the same shape four times in a row shows what is fixed and what changes from year to year.

-
**Write, then run, every Section B answer** Write the program on paper as the exam demands, then type it into BlueJ exactly as written. The compiler finds the missing semicolon and the wrong method name that your eye skipped.

-
**Test with more than the example** The example in a question is the easy case. Try a one-digit number, an empty space, the first and last elements of an array, and a value that is not there. The 2025 binary search only proves itself when a missing character is searched.

-
**Mark against points, not a feeling** For each program, check the parts an examiner looks for: the class and method headers asked for, input taken the way the question says, correct logic, the output in the format shown, and the meaningful variable names or short variable description the Section B instructions ask for so the logic is clear. Flowcharts and algorithms are not required.

-
**Then sit whole papers, timed** From January, sit one complete past paper at a time in two hours, choosing your four Section B questions in the first minutes and sticking to the choice.

The latest paper, discussed question by question with an answer key, is on [ICSE Computer Applications paper analysis](/icse-computer-applications-paper-analysis).

## Frequently asked questions

**Where can I find ICSE Computer Applications previous year question papers with solutions?** Past board papers are printed in the solved-paper books most ICSE schools recommend, and CISCE publishes specimen papers on cisce.org. This page does not reprint any paper. It describes what Section B asked in 2023, 2024, 2025 and 2026, tags each question by program family and gives original practice programs in the same shapes, with full solutions that were compiled and run.

**What was asked in the ICSE Computer Applications 2025 paper Section B?** In our own words: a cloud storage class billed in three slabs, the square root of the sum of squares of a 4 by 4 matrix, a String with equal capital and small letters, a binary search of a sorted character array, an overloaded method with a symbol pattern, a half-step series and a character comparison, and the parity of the sum of a number's largest and smallest digits.

**How many questions are there in Section B of ICSE Computer Applications?** Six, numbered Questions 3 to 8. A candidate answers any four, each worth 15 marks, for 60 marks. Section A, Questions 1 and 2, is 40 compulsory marks: twenty one-mark MCQs and ten two-mark parts. The whole paper is 100 marks in two hours, with reading time before writing starts.

**Which programs come every year in the ICSE Computer Applications board exam?** In the 2023 to 2026 papers, three families came every year: a class with a calculation as Question 3, a method overloading question containing a nested-loop pattern, and a String program. A digit-based number check, a 2D array task and a searching task each came in three of the four years. Sorting came twice.

**Are 2D array questions asked in ICSE Computer Applications?** Yes. Double dimensional arrays are in the 2027 syllabus and a 2D array program appeared in Section B in 2024, 2025 and 2026: comparing diagonal sums, finding the square root of the sum of squares, and counting zeros to test a sparse matrix. Each was a short scan of rows and columns with nested loops.

**How many previous year papers should I solve for ICSE Computer Applications?** At least the last four board papers and the current specimen paper, each solved twice: first question by question grouped by family, then as a whole timed paper. Older papers are useful for extra Section B practice, but their Section A layout differs, so use them for programs rather than for timing.

**Do ICSE Computer Applications questions repeat from previous years?** The exact questions rarely repeat, but the shapes do. Every recent paper opened Section B with a class that calculates a bill or a result, and every one had an overloading question with a pattern. Practising new questions in each repeating shape prepares you better than memorising old answers.

**Are assertion and reason questions in the ICSE Computer Applications paper?** Yes, inside Question 1. Solved copies of the papers show one assertion and reason MCQ in 2024 and two in each of 2025 and 2026. They test the same Java facts as the other MCQs, so the key is to judge the assertion and the reason separately before deciding whether one explains the other.
